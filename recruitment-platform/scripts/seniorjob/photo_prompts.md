# シニアジョブ 画像生成プロンプト（職種別）

画像が必要な16職種に、それぞれ個別プロンプトを用意。各職種で写真を変えられます。

## 全プロンプト共通の制約（末尾に必ず付与）
```
制約: 画像内に文字・ロゴ・看板・車のナンバーを一切入れない。人物の顔は写さない（後ろ姿または手元のみ）。会社名・住所・個人名を写さない。実写風・自然光・清潔感のある構図。日本の職場。中高年（50〜60代）が無理なく働けるイメージ。
```

---

## A系: 点検・メンテナンス

### 設置点検・相談訪問
```
オフィスの一角で作業着姿の人物が複合機やネットワーク機器の設置状態を点検し、手元でチェックしている様子。機器と手元が主役。
```

### 定期メンテ・提案訪問
```
店舗のバックヤードで、空調や業務用設備を工具で定期メンテナンスしている様子。設備と作業する手元が主役。
```

### アフターサービス巡回
```
納品済みの機器の前で、タブレットや点検票を手に動作確認・巡回している様子。機器まわりと手元が主役。
```

### 訪問機器取替
```
古い機器を新しい機器に取り替える搬入・据付作業の様子。台車に載せた機器と作業する手元が主役。
```

---

## B系: ラウンダー・補充・回収

### 事務用品ルート提案
```
取引先オフィスで、事務用品・消耗品を棚に補充しながら在庫を確認している様子。整った文具棚と手元が主役。
```

### 用具レンタル訪問提案
```
レンタル用具（清掃機材・什器など）を訪問先に運び、使い方を調整・説明している様子。用具と手元が主役。
```

### 業務用品ラウンダー
```
店舗の陳列棚を巡回し、業務用品を補充・整理・入れ替えしている様子。台車と整った棚が主役。
```

### リユース回収・提案
```
使用済み機器や什器を回収し、コンテナや台車に積み込んでいる様子。回収品と作業する手元が主役。
```

### 補充・提案
```
商品棚の在庫を確認し、伝票を見ながら次回の補充を段取りしている様子。棚と手元の伝票が主役。
```

### 買替ラウンダー
```
取引先を巡回し、旧型の備品と新型カタログを並べて買い替えを検討している様子。備品とカタログが主役（カタログの文字は写さない）。
```

---

## C系: 催事・イベント

### 催事イベント運営
```
屋内イベント会場で、テーブルや什器を配置し設営・準備をしている様子。広く明るい会場と作業する手元が主役。
```

---

## D系: 配送・納品

### ルート配送ご用聞き
```
ライトバンの後部から段ボールを取り出し、配送先へ荷物を届けている様子。車の荷室・台車・荷物が主役。
```

### レンタル納品・提案
```
社用のバンからレンタル機器を降ろし、納品先へ運び入れている様子。機器と台車、搬入口が主役。
```

---

## E系: 送迎・案内

### 送迎・案内
```
送迎用のミニバンのスライドドアを開けて乗客を迎え、車内へ案内している様子。車とドア付近が主役。
```

### 送迎ドライバー
```
ワゴン車の運転席まわりで出発前の準備をしている様子。ハンドル・車内・車体が主役。屋外の明るい駐車場。
```

---

## IT系

### ITルート営業
```
明るいオフィスで、PC・ネットワーク機器・サーバーラックの前で設定や打合せの準備をしている様子。機器と手元が主役。
（既存 public/images/it-office.jpg も流用可。ライブラリにアップすればID取得可）
```

---

## 使い方
1. 上記プロンプト＋共通制約で画像生成
2. シニアジョブ写真ライブラリにアップ → 発行された写真IDを控える
3. `photos.json` の該当職種の配列にIDを記入（例: `"設置点検・相談訪問": ["44230"]`）
4. `node scripts/seniorjob_plan_export.js` で再出力 → 職種別画像に切替
