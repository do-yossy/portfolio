## 新規作成が必要なテーマ（生成プロンプト）
各テーマ2〜3枚バリエーションを生成し、シニアジョブ写真ライブラリへアップ→発行IDを photos.json に記入。

### A. 機器点検・メンテナンス（割当: 設置点検・相談訪問 / 定期メンテ・提案訪問 / アフターサービス巡回 / 訪問機器取替）
```
日本のオフィスや店舗で、作業着を着た人物が業務用機器（複合機・空調・設備）を点検している様子。
手元と機器が主役。人物は後ろ姿または手元のみで顔は写さない。看板・ロゴ・文字・住所は一切写さない。
自然光の明るい室内、清潔感のある構図、実写風。
```

### B. ラウンダー・補充・回収（割当: 事務用品ルート提案 / 用具レンタル訪問提案 / 業務用品ラウンダー / リユース回収・提案 / 補充・提案 / 買替ラウンダー）
```
店舗や事業所の棚に商品・備品を補充・整理している様子。台車や在庫棚が写る。
人物は手元・後ろ姿のみで顔は写さない。ロゴ・商品名・文字・会社名・住所は写さない。
明るく整った屋内、実写風。
```

### C. 催事・イベント運営（割当: 催事イベント運営）
```
屋内イベント会場の設営・準備の様子。テーブルや什器の配置作業。
人物は後ろ姿・手元のみで顔は写さない。ブランド名・ロゴ・文字・住所は写さない。
広く明るい会場、実写風。
```

### D. 配送・納品（割当: ルート配送ご用聞き / レンタル納品・提案）
```
社用のライトバンから段ボールや機器を積み下ろし・納品している様子。台車や荷物が主役。
人物は後ろ姿・手元のみで顔は写さない。社名・ナンバー・ロゴ・文字・住所は写さない。
明るい屋外または搬入口、実写風。
```

### E. 送迎・案内（割当: 送迎・案内 / 送迎ドライバー）
```
送迎車（ミニバン・ワゴン）で乗客を迎える・案内する様子。車と車内・ドア付近が主役。
人物は後ろ姿・手元のみで顔は写さない。社名・ナンバー・ロゴ・文字・住所は写さない。
明るい屋外、清潔感のある実写風。
```

## photos.json 反映ルール
- 対応できる職種 → 既存ID（44214/44216）を配列に記入済み。
- 新規作成テーマ(A/B/C) → 生成・アップ後にIDを記入。それまでは `[]`（職種系フォールバックで掲載は継続）。
- ITルート営業 → it-office.jpg をライブラリへアップ後にID記入。
