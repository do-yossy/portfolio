# シニアジョブ 職種別 雛形（テンプレート）置き場

`seniorjob_plan_export.js` は、職種ごとに「実在の掲載済み求人」を雛形（153列）として複製し、
大阪50区市へ勤務地・タイトル・仕事内容・写真を差別化して展開します。

## 雛形の対応表

| 職種系 | 使う雛形ファイル | 状態 |
|---|---|---|
| 送迎 | `../ref_job.json`（ロケ同行ドライバー・既存） | 利用可 |
| 配送 | `../ref_job.json`（同上を流用） | 利用可 |
| 営業 | `templates/営業.json` | **要作成** |
| 企画 | `templates/企画.json` | **要作成** |

営業・企画の雛形が無い間は、その職種の行は自動でスキップされます（送迎・配送だけ生成）。

## 営業・企画の雛形の作り方（後で）

1. シニアジョブ管理画面で、営業（または企画）の求人を **実在の内容（給与・写真・仕事内容）で1件だけ** 作成し掲載する。
2. その求人を含むCSVを一括登録機能からダウンロードする（153列）。
3. ダウンロードCSVの「ヘッダー行」と「その求人の1行」を、次の形式で JSON 化して保存する:
   ```json
   { "headers": ["求人ID", "(必須)職種", ...], "ref": ["12345", "営業", ...] }
   ```
   ファイル名: `営業.json` / `企画.json`（このフォルダに置く）
4. あとは `node scripts/seniorjob_plan_export.js --group A` などで自動展開されます。

## 写真の差別化（任意）

`../photos.json` に職種別の写真IDプールを置くと、区ごとに1枚目をローテします:
```json
{ "営業": ["1001","1002"], "企画": ["1010"], "送迎": ["1020","1021"], "配送": ["1030"] }
```
未設定の場合は雛形の写真をそのまま使います。
