# 架電でつながった時間の記録
- `call-times.csv`：ユーザーが送ってくれた、つながった通話の開始時刻・通話時間・メモ（氏名・年齢は記録しない）。
- 記録の元：iPhoneのボイスメモの録音一覧（今日分のみ時刻が表示される）。
- 注意：録音は接続した通話のみ。不通を含む「時間帯別の接続率」は、通話履歴（発信時刻・通話時間）が手に入るまで出せない。
- 追記のルール：ユーザーから架電時間が届いたら、日付・開始時刻・通話時間・種類（接続）・メモを追記し、時間帯別（9〜12時台／13〜15時台／16〜19時台など）の件数を集計して報告する。件数が少ない時間帯は断定しない。
- 毎朝のIndeed掲載アナウンス・日次分析の際にも、このファイルを読み、直近の傾向を参照する。
- `daily-kpi.csv`：ユーザーが共有した日報（自社リスト：架電・提案・面談接続・タクシー訴求あり／シニアジョブ：架電・提案・接続依頼）。10/25までの8回分の累計は、架電673・提案63・接続24・タクシー4。
- 用語（ユーザー確認済み・10/29）：メモの「アポ」＝日報の「面談接続」と同じ意味（日報との差は数え方の違い）。タクシーの話をして断られた通話も、「タクシー訴求あり」に数える。
- 10/29のタクシー訴求あり：1件（日報提出時は0件。ユーザーの回答で1件に修正）。
