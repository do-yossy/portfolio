# シニアジョブ 運用ガイド（コンプライアンス準拠）

最終更新: 2026-06-29

シニアジョブ（成功報酬型の採用支援サービス）を、規約・法令を守って運用するための社内ガイド。
採用管理システム（ATS）の機能と対応づけて記載する。

---

## 0. 基本方針 ― 媒体の役割分担

シニアジョブは**成功報酬型（採用できて初めて課金）**のため、応募者の社外誘導・他社求人の掲載・人材紹介への橋渡しを**規約で厳しく禁止**している。

- 規約 第3条2項：応募者をシニアジョブ外へ誘導してはならない
- 規約 第7条1項：甲または甲以外の第三者の事業・サービスへ誘導した場合 ＝ 成功報酬＋遅延損害金10%＋**1人あたり300万円**＋社名公表
- 規約 第5条：不採用通知後も1年以内の採用は「シニアジョブ経由採用」とみなす（遡及）
- 規約 第13条：虚偽・誤認を招く求人記事の禁止（職業安定法の求人者明示義務・景品表示法にも抵触）
- 規約 第16条：取得情報の目的外利用・第三者提供の禁止

### 結論（媒体の使い分け）

| モデル | 使う媒体 | 理由 |
|---|---|---|
| **A. 人材紹介**（連絡先取得→架電→別求人紹介） | **Indeed・求人ボックス・自社サイト** | 連絡先取得・紹介・誘導が許される。成功報酬の縛りがない |
| **B. シニアジョブ** | **SQが実際に直接雇用する求人の採用専用** | 成功報酬型。社外誘導・他社求人・紹介は不可 |

> シニアジョブの応募者を人材紹介・他社へ流す運用は規約違反（1人300万円）。やるなら**シニアジョブ運営の書面許可が必須**（§C）。

---

## A. 人材紹介モデル（Indeed・求人ボックス）

連絡先を取得して自社（または提携人材紹介会社）でアプローチするモデル。**この媒体では適法**。

### フロー
1. Indeed / 求人ボックスに求人を掲載
2. 応募 → 連絡先（電話・メール）を取得
3. ATS「架電リスト」で管理（媒体＝Indeed/求人ボックス、会社を選択）
4. 架電 → ヒアリング → 充足等を理由に別求人を案内（人材紹介）
5. スプレッドシート連携で対応状況・架電結果を共有

### 順守事項
- 有料職業紹介として行う場合は**職業紹介事業の許可**を保持
- **求人者（実際の雇用主）を明示**し、虚偽・おとり求人にしない（職安法・景表法）
- 取得した個人情報は利用目的の範囲で扱う（個人情報保護法）

---

## B. シニアジョブ運用（SQの直接雇用求人 専用）

SQが**実際に雇用または業務委託**する求人のみを掲載し、シニアジョブ上で採用を完結する（成功報酬を支払う正規運用）。

### B-1. 求人掲載（CSV）
- ATS：**掲載管理タブ → 「🚃 シニアジョブ 求人掲載（CSVダウンロード）」**
- 会社を選択 → 件数・仕事内容を選び CSV をダウンロード → シニアジョブに取込
- 136駅をローテーション（毎日N件・重複防止）。一巡したら仕事内容テンプレを差し替え可
- 出力はShift-JIS・番地住所・駅コード付き（取込エラー対策済み）

### B-2. 応募者対応（電話面接フロー／採用代行が実施）

採用代行（人材紹介会社）が**「SQの採用担当＝委託先」**として、**SQ求人の選考のために**電話面接を行う（規約第8・19条で委託可）。

**前提**
- 採用代行と業務委託契約を締結（秘密保持・個人情報保護・サイト外誘導禁止／第18・19条）
- 連絡は原則シニアジョブ内メッセージ。**電話は「電話面接」の時のみ**（第3条）

**SLA（規約）**
- 応募受信 → 1週間以内に初回メッセージ（最低でも15日以内に必ず回答／第3条1項）
- 採否決定 → 速やかに運営へ通知（第4条。放置は「採用成立みなし」リスク）

**手順（応募後フロー）**
1. 応募受信（選考管理に表示）
2. ATS「架電リスト → 応募者の取込（コピペ）」で**会社=SQ**を選び取込（ステータス「新規」）
3. **1週間以内**に媒体メッセージで電話面接を案内（下記テンプレ）。
   **平日 10:30–14:00 または 17:00–19:00** で「曜日・時間」を**第3希望まで**依頼 → ステータス「対応中」
4. 応募者が候補を返信 → 候補から1つ選び、面談詳細を送信して日程確定：
   - 面接住所欄：`電話面接`
   - 緊急連絡先欄：`採用代行の面接用電話番号`（企業はメッセージで番号送付不可のためこの欄で伝える）
   - その他欄：`当日この番号で採用担当（委託先）が電話面接を行います`
   - 日時をシステムで確定（変更は「面接詳細変更」で再送可）
   - ※候補が時間帯外なら再調整を依頼／無返信なら15日以内に再連絡（第3条）
5. 確定日時に電話面接を実施（採用代行がSQ採用担当として・約15分）。内容は**SQ求人の選考**
6. 結果を媒体メッセージで通知 ＋ 運営へ採否通知（第4条）。ATSステータス更新（対応中→終了 等）

**チャット定型文（電話面接の案内）**
```
〇〇様

この度は「（応募求人名）」へご応募いただきありがとうございます。
選考にあたり、まずお電話で15分ほど面談（仕事内容・条件のご説明とご希望の確認）をさせてください。

▼電話面接について
・面接方法：電話面接（所要約15分）
・担当：弊社採用担当（採用業務の委託先が対応します）
・当日の連絡先：日程確定後にお送りする面談詳細の「緊急連絡先」に記載します

▼ご希望日時（平日のみ／下記いずれかの時間帯）
　・10:30〜14:00　または　17:00〜19:00
お手数ですが、ご都合の良い「曜日・時間」を第3希望までお知らせください。
（例）① 火曜 11:00　② 木曜 13:30　③ 金曜 17:30

いただいた候補をもとに日程を確定し、面談詳細をお送りします。
どうぞよろしくお願いいたします。
```

**電話面接トーク骨子（採用代行用）**
```
1. 名乗り：「SQ採用担当（委託先の△△）です。シニアジョブよりご応募の件で」
2. 御礼＋応募求人の確認
3. ヒアリング：希望条件（勤務地・雇用形態・給与）・就業時期・運転経験 等
4. 条件説明：仕事内容・給与・勤務時間・福利厚生
5. 意向確認 → 次の選考（最終面接等）を媒体メッセージで案内する旨を伝える
6. クロージング

【遵守事項】
・SQの求人の選考として行う
・面接以外で電話を使わない（連絡は媒体メッセージ）
・サイト外・他社・人材紹介への誘導はしない（規約第7条／1人300万円）
```

### B-3. ステータス運用（架電リスト）

| 状況 | ステータス |
|---|---|
| 取込直後 | 新規 |
| 面接案内〜実施中 | 対応中 |
| つながらない | 不通 |
| 完了（採用/見送り/辞退） | 終了 |

### B-4. スプレッドシート連携
- 「スプレッドシートへ反映」＝会社別タブに出力（項目ズレなし）
- シニアジョブ応募者は電話・メールが空 → シートで**手入力**
- 「スプレッドシートから取込」＝手入力した電話・メールをDBへ反映（正規化値も更新し重複判定に対応）

## C. シニアジョブ運営への確認メール（人材紹介をやる場合の唯一の正規ルート）

シニアジョブの応募者に対し人材紹介・別求人案内を行いたい場合は、**事前に運営の書面許可**が必要（規約の例外「運営の許可を受けた場合を除く」）。下記文面で `info@seniorjob.jp`（または担当窓口）へ確認する。

```
件名：選考後の他求人ご紹介（人材紹介）の可否についてのご確認

株式会社シニアジョブ ご担当者様

いつもお世話になっております。貴サービスを利用しております
株式会社Social Quality（担当：安藤）です。

選考運用について、規約解釈の確認をさせてください。

当社の応募者で、応募求人が不採用（充足等）となった方に対し、
ご本人の同意を得たうえで、当社グループ（提携の人材紹介会社）による
別求人のご紹介をご案内することは可能でしょうか。

規約第3条・第7条・第16条に照らし、可否および可能な場合の条件
（手続き・通知方法・成功報酬の扱い等）をご教示いただけますと幸いです。

何卒よろしくお願いいたします。
```

- 「可」の回答が書面で得られた場合のみ、その条件どおりに運用する。
- 「不可」または無回答の場合は、人材紹介は A（Indeed・求人ボックス）に限定する。

---

## 付録：絶対にやらないこと（違反＝1人300万円＋社名公表）
- シニアジョブの応募者を社外・他社・人材紹介へ誘導して採用する
- 他社の求人をSQ名義でシニアジョブに掲載する（虚偽求人）
- 面接時以外に電話で応募者とやり取りする
- 履歴書を郵送・メールで提出依頼する（媒体メッセージに添付で依頼）
