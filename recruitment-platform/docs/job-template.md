# 求人作成テンプレート

`/preview/jobs/:id`（新デザイン求人詳細ページ）の表示仕様に合わせたテンプレートです。
求人管理画面の各フィールドに、以下の内容をコピーして書き換えて使ってください。

---

## 各フィールドの対応

| 管理画面のフィールド | ページ上の表示場所 |
|---|---|
| タイトル | 最上部の黒帯タイトル |
| キャッチコピー | タイトル下の太字キャッチ（改行可） |
| 給与 | 基本情報テーブル「給与」＋お仕事情報「給与」 |
| 勤務地 | 基本情報テーブル「勤務地」・所在地 |
| 雇用形態 | 基本情報テーブル「雇用形態」 |
| タグ（カンマ区切り） | 「注目ポイント」の ✔ リスト |
| 仕事内容（説明文） | 【見出し】ごとにお仕事情報テーブルへ分解表示 |
| FAQ | 「よくある質問」Q&A |

## 7. 仕事内容（説明文）

【見出し】で区切ると、お仕事情報テーブルの行として表示されます。
以下の見出しは決まった位置に表示されます：

- 【仕事内容】または【お仕事内容】→「お仕事内容」行
- 【給与内訳】または【給与・待遇】→「給与」行に追記
- 【労働時間】【勤務時間】【シフト・勤務時間】→「シフト・勤務時間」行
- 【休日・休暇】または【休日】→「休日・休暇」行
- 【応募資格】【こんな方に向いています】→「応募資格」行
- 【福利厚生】【待遇・福利厚生】【待遇】→「待遇・福利厚生」行
- 【入社後の流れ】【研修】→「入社後の流れ」行
- それ以外の【見出し】→ そのままの見出し名で行が追加されます（例:【アクセス】【勤務期間】）


---

## 作成手順

1. 管理画面 → 求人管理 → 新規作成
2. 上記の各項目を求人に合わせて書き換えて貼り付け
3. 保存後 `/preview/jobs/:id` で表示確認（未公開でもプレビュー可能）
4. 問題なければ「公開」に切り替え
