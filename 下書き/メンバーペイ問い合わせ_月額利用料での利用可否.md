# メンバーペイへの問い合わせ（Webサービスの月額利用料に使えるか）

> ステータス：下書き（審査中。reviewer 2回目の差し戻しに対応）
> 作成日：2026-10-15
> 送り先：support@memberpay-help.zendesk.com（メンバーペイの特定商取引法に基づく表記に記載されている問い合わせ先。2026-10-15に確認）。公式ヘルプに問い合わせフォームがあれば、そちらから送ってもよい
> 送る人：オーナー（【】の部分を埋めてから送る）
> 目的：SNS予約投稿のWebサービス「SNSまとめて予約」の月額の決済をメンバーペイに切り替える前に、使ってよいかと、運用に必要な機能を確かめる。返事をもらうまでは、切り替えの作業（販売ページ・規約・特商法表記の書き換え）をしない。
>
> この問い合わせを送る理由（社内メモ。送る文には含めない）：
> - 公式ヘルプに「外部システムと会員情報・決済情報を自動連携する機能（開発者向けAPIおよびWebhook通知機能）は提供しておりません」とある（記事 5591386909342）。契約の反映は、運営者の手作業になる。
> - 公式サイトの利用例にWebサービス（SaaS）の利用料は無い。取扱禁止商品等に「オンライントラフィックまたはエンゲージメントの販売」と、包括的な項目（当社が適切ではないと判断したもの）がある。
> - 規約では、決済代行会社の審査に落ちると、それまでに入金された代金は販売者に支払われない。使えるかどうかと、審査の見通しを、先に確かめておく必要がある。
> - サービスの説明には、AIで作る機能と自動運用（確認なしで投稿する設定を含む）も、隠さずに書く（あとで「聞いていた内容と違う」と判断されないため）。

Webサービスの月額利用料での利用可否と、会員管理の機能についてのご質問

## 本文

▼ここからコピー

メンバーペイ ご担当者様

はじめてご連絡いたします。【会社名（登記どおりの表記）】の【お名前】と申します。
メンバーペイの利用を検討しており、販売者登録の前に、次の点を確認させてください。
特に1と2は、登録するかどうかの判断に必要なため、先にお教えいただけますと幸いです。

■ 販売を考えているサービス
・名称：SNSまとめて予約
・内容：SNS（Threads など）への投稿を、日時を決めて予約できるWebサービスです。利用者は、当社のWebサイトで会員登録とログインをして使います。
・利用者は、ご自身のSNSアカウントを、各SNSの公式の連携の仕組み（公式API）でつなぎ、ご自身で作った投稿、またはAIで作った投稿を、指定した日時に投稿します。
・AIの機能：利用者が入力したテーマをもとに、外部のAIサービスで投稿文や画像を作る機能があります（販売開始のときに提供するかは、検討中です）。AIで作った投稿は、通常は下書きに入れ、利用者が確認してから予約します。利用者が同意した場合は、確認なしでそのまま投稿する設定も選べます（1つの設定につき、決めた時刻に1日3回まで。設定は1人5つまで作れます）。利用者がご自身のAI（ChatGPT など）で作った文章を貼り付けて使うこともできます。
・ほかに、利用者ご自身が、API や AIアシスタント（MCP）から、予約などの操作をする機能もあります。
・フォロワー・いいね・再生回数などの販売や、自動でのフォロー・いいね・コメントなどは行いません。
・料金：月額1,100円（税込）の定額。1か月ごとの自動更新で、いつでも解約できます。

■ ご質問
1. 上のようなWebサービスの月額利用料の決済に、メンバーペイの月額定額プランを利用することは可能でしょうか。AIで作った投稿を自動で予約・投稿する機能を含めて、取扱禁止商品等の「オンライントラフィックまたはエンゲージメントの販売」などに当たらないかを、確認させてください。
2. 販売者登録のあとに行われる決済代行会社の利用審査で、このようなWebサービスが否認されることはありますか。また、販売を始めたあとに、サービスの内容を理由として、あらためて審査が行われ、決済機能が止められることはありますか。
3. 当社の会員と、メンバーペイの会員を紐付ける方法についてです。会員登録時の入力項目に、当社のログインID（メールアドレス）などの項目を追加できますか。または、プランの購入ページのURLに、当社の会員IDなどを付けて渡すことはできますか。
4. 新規登録・解約のときに販売者に届く通知メールには、どの情報（会員ID・メールアドレス・プラン名など）が入りますか。また、次の場合について教えてください。
　(1) 更新決済に失敗したときに、販売者に通知は届きますか。
　(2) カード・PayPal の更新決済に失敗したあと、自動での再決済はありますか。支払われないままの場合、一定期間で自動的に解約されますか。
　(3) コンビニ・ペイジーの支払期限切れで自動的に解約になった場合も、販売者に通知は届きますか。
5. 管理画面で、会員ごとの次回の更新日（または契約の満了日）を確認できますか。会員の一覧を、CSVなどで書き出すことはできますか。また、売上管理の個別決済情報のCSVには、どの項目（会員ID・メールアドレス・プラン名・決済日など）が入りますか。
6. 購入が完了したあとに、購入者を当社のWebサイトなど、指定したURLへ移動させる設定はありますか。
7. 外部のシステムと連携するための API や Webhook は、現在は提供されていないとヘルプで拝見しました。今後、API・Webhook、または Zapier・Make などとの連携を提供するご予定はありますか。
8. 販売者が管理画面から会員を解約したとき、解約はすぐに有効になりますか。それとも、契約期間の満了日に有効になりますか。
9. 当社のWebサイトには、ほかの決済サービス（クレジットカード決済）で申し込める仕組みもあります（まだ販売は始めていません）。メンバーペイと並行して、ほかの決済サービスで同じサービスを販売することは、利用規約上問題ないでしょうか。

お忙しいところ恐れ入りますが、ご確認のほど、よろしくお願いいたします。
