## 0. 送る前に必ず確かめること（これが済むまで送らない）

1. **相手が自分のSNSをつないで、実際に使えるか。** Metaのアプリの審査が通っていない間は、Threads・Instagram は、テスターに追加した人しか連携できない。つなげないのに、感想や紹介を頼むと、相手が試せず、事実と違う紹介になる。
   - 確かめ方：LPの「対応SNS」の表示だけでは、審査の状況は分からない。運営者画面（/admin/service）の「設定の確認」と、テスターの権限のないアカウントでの実機（連携 → 予約 → 投稿）で確かめる。
   - 相手が使うSNS（候補は、おもにInstagram）が、いま一般の人につなげるまで、送らない。
   - Instagramは、プロアカウント（ビジネス／クリエイター）が対象で、画像（JPEG）かリール動画だけが投稿できる。相手がプロアカウントかも確かめる。
   - 「報酬を払う人を、テスターにして先に使ってもらう」運用は、Metaの規約上、問題がないかを確かめていない。基本は、審査が通ってから送る。
2. **文中の事実を、送る時点で確かめる。**
   - 「Threads・Instagram・TikTok・Facebook・YouTubeにまとめて予約投稿できる」：送る時点で、一般の人がつなげるSNSだけに書き直す。
   - 「1回の入力で…まとめて予約投稿できる」「写真や動画が必要」：LPの確認済みの事実（下）には無い。実機かLPで確かめた表現だけ残す。
   - 「AIアプリとつないで、チャットで予約を頼める」：実機で確かめた組み合わせだけを書く（このセッションで確かめたのは Claude Code からの接続だけ。ChatGPTは、個人向けの有料プランで書き込みができるかを確かめていない）。確かめられていないAIアプリの名前は書かない。
3. **オーナーが決める【】**（決まっていないものを、推測で書かない）
   - 【会社名】：登記どおりの表記（リポジトリには「株式会社Social Quality」と「株式会社ソーシャルクオリティ」の両方がある。LPの特商法表記は「株式会社Social Quality」）
   - 【送る人の名前】
   - A（有償）：10,000円が税込か税別か（オーナーの文面は「税込」）／掲載の時期／お支払いの方法と時期
   - A・B：**相手がサービスを試す方法と、その費用の負担**（LPの標準は「初めての方は7日間無料。カード等の登録が必要で、8日目から自動で有料」。標準のトライアルにするか、運営者が無料で付与するか）
   - **Bのオーナー文面の「カードの登録も料金もかかりません。自動で料金がかかることもありません」は、LPの標準（カード登録が必要で、8日目から自動で有料）と食い違う。** 運営者側でカード不要の無料枠を実際に付けられると確かめるまで、案(a)は使わない。確かめられない間は案(b)（標準のトライアル）にする。
   - 標準のトライアルにする場合は、A・BのDMに「7日間の無料トライアル（お支払い方法の登録が必要で、8日目から自動で有料になります）」と書く。「無料」とだけ書かない。
   - 【】の入れ方の例（A「サービスを試していただく方法は、…です」）：(標準) 「7日間の無料トライアルです（お支払い方法の登録が必要で、8日目から自動で有料になります）」／(運営者が付与) 「こちらで無料の利用枠をご用意します（費用はかかりません）」。後者は、実際に付与できると確かめてから使う。
4. **投稿の表示の準備（A・B。送る前の必須）**：「タイアップ投稿」（有料パートナーシップ）の表示は、@michishirube_jp 側で、パートナーシップ広告の承認の設定が必要。相手が投稿しても、承認していないと表示が付かないことがある。Instagramのアプリで、先に設定を確かめる。
5. **相手を、オーナーが実際に見てから送る。** 「個別の一文」は、見た相手にだけ使う。見ていない相手には、その一文を外す。プロフィールに「お仕事のご依頼はメールへ」とあれば、DMではなく、そちらへ送る。
6. **税務**：個人への報酬は、源泉徴収やインボイスの扱いが変わる場合がある。支払う前に、税理士に確認する。
7. **差し込み候補**（本文の【】に入れる完成文。判断材料は本文に入れず、ここで選ぶ）
   - 【つなげるSNS】：送る時点で一般の人がつなげるSNSだけを並べる（例：Threads・Instagram）
   - 【素材】：実機で確かめた範囲だけ（例：画像）。Instagram・TikTok・YouTube に写真や動画が必要かは、確かめてから書く。確かめていなければ「画像」など確実なものだけにする
   - 【AI連携の一文】：実機で確かめた組み合わせだけ。例：「Claude とつないで、チャットで予約を頼むこともできます。」確かめられなければ、この文ごと外す（「1回の入力で」などLPにない言い方もしない）
   - 【お試しの内容】（B）：(a) カード不要の無料枠を付けられると確かめた場合のみ「◯日間、無料でお使いいただく（カードの登録も料金もかかりません。自動で料金がかかることもありません）」／(b) 標準のトライアル「7日間の無料トライアルでお使いいただく（お支払い方法の登録が必要で、8日目から自動で有料になります）」
   - 【お試しの方法】（A）：上の「入れ方の例」（標準／運営者が付与）から選ぶ
   - 【表示の文言】：(a) の場合「PR」「無料で提供を受けて使用」／(b) の場合「PR」「無料トライアルで使用」（8日目から有料になる場合に「無料で提供を受けた」と書くと、事実と合わない）

## 2. 依頼の共通ルール

- **広告であることの表示をお願いする**（有償でも、無料でサービスの提供を受ける場合でも、運営者が関わる紹介は、広告として扱われる。いわゆるステマ規制）。初回のDMに、表示の方法を書く。
- **内容は、実際に使った事実だけにしてもらう。** 収入や成果、「必ず」「誰でも」「稼げる」などの断定・誇大な表現、LPにない機能の説明は、しないでもらう（初回のDMには、収入や成果に触れないことを書く。そのほかの禁止表現は、条件の連絡で伝える）。
- **直しをお願いするのは、次の場合だけ。** サービスの機能・価格などの事実と違う点があるとき、効果を言い切る表現があるとき。その点だけ。感想や評価そのものは、修正をお願いしない。良い評価も求めない。
- 依頼を断られた・返事がない場合は、追いかけない。追いDMは、4日後に1回だけ（6章）。それでも返事がなければ、終わりにする。
- 不特定多数へ同じ文を送らない（1人ずつ確かめて、文面を変える。1日数件まで）。

## 6. 送り方の見直し（20件に送って反応がなかった結果を受けて）
