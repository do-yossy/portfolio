はじめに

こんにちは！このガイドを手に取ってくれてありがとうございます。

Claude Codeとは、Anthropicが作ったAIプログラミングアシスタントです。ターミナル（黒い画面）の中でAIと会話しながら、コードを書いてもらったり、アプリを作ったりできるツールです。

「え、ターミナルって何？」という方も大丈夫。私も最初はそこからスタートしました。

このガイドを読み終わる頃には、こんなことができるようになっています：

  • Claude Codeを自分のパソコンにインストールできる
  • ターミナルで基本的なコマンドを打てる
  • AIに「Webアプリ作って」と頼んで、実際に動くものを作れる
私はプログラマーではありません。何度も失敗して、エラーに泣かされながら試行錯誤してようやくセットアップを完了しました。だからこそ、「ここで詰まる」というポイントを全部知っています。そのポイントを全部このガイドに詰め込みました。

公式ドキュメントを読んでもわからなかった方、エラーが出て止まってしまった方、ぜひ最後まで読んでみてください。

必要なものを確認しよう

MacとWindowsの違いについて

Claude Codeは MacでもWindowsでも使えます。ただし、セットアップの手順が少し違います。このガイドでは両方の手順を書きますので、自分のパソコンに合った方を読んでください。

Macの方が少しだけセットアップは楽です。 Windowsの方は「WSL」という追加の設定が必要になることがあります（後ほど詳しく説明します）。

必要なもの

絶対に必要なもの：

  1. Anthropicのアカウント
- [claude.ai](https://claude.ai) でアカウントを作ります - Claude Pro（月額約20ドル） か、APIキー（従量課金） のどちらかが必要です - 「どっちがいいの？」という方へ：最初はClaude Proがわかりやすいです。たくさん使うならAPIキーの方がお得になることもあります
  1. ターミナル（コマンドプロンプト）
- Mac：最初から入っています。Spotlight検索（Command+Space）で「ターミナル」と打てば出てきます - Windows：「コマンドプロンプト」か「PowerShell」を使います。スタートメニューで検索してください

あると望ましいもの：

  • メモリ：8GB以上（4GBでも動くことはありますが重いです）
  • ストレージ：空き容量5GB以上
  • 安定したインターネット接続

Step 1: Node.jsのインストール

Claude CodeはNode.jsというソフトウェアの上で動きます。まずこれをインストールします。

Macの場合

まず「Homebrew（ホームブルー）」というMac用のパッケージ管理ツールをインストールします。これがあると、あとからいろんなソフトを簡単に入れられるようになります。

ターミナルを開いて、以下のコマンドをコピー＆ペーストしてEnterを押してください：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

パスワードを求められたら、Macのログインパスワードを入力してください（入力しても画面に何も表示されませんが、ちゃんと受け付けています）。

Homebrewのインストールが終わったら、Node.jsをインストールします：

brew install node

Windowsの場合

  1. ブラウザで [https://nodejs.org](https://nodejs.org) を開く
  2. 「LTS（推奨版）」と書かれたボタンをクリックしてダウンロード
  3. ダウンロードされた .msi ファイルをダブルクリックしてインストール
  4. 「Next」を押し続けて完了させる

インストールの確認

インストールが終わったら、ターミナルで以下のコマンドを打ってバージョンを確認します：

node --version

こんな感じで表示されればOKです：

v20.11.0

数字は多少違っても大丈夫ですが、18以上であることを確認してください。

よくある問題：

  • 「command not found: node」と出る（Mac）：Homebrewのインストール後にターミナルを一度閉じて、新しく開き直してから試してみてください
  • バージョンが古い（17以下）：一度アンインストールして、最新版を入れ直してください。Macなら brew upgrade node、Windowsなら公式サイトから最新版を落として上書きインストール
  • Windowsでインストール後もコマンドが使えない：コマンドプロンプトを一度閉じて、新しく開き直してください。それでもダメなら再起動

Step 2: Claude Codeのインストール

Node.jsが入ったら、いよいよClaude Code本体をインストールします。

ターミナルで以下のコマンドを実行してください：

npm install -g @anthropic-ai/claude-code

-g は「グローバルにインストールする（どこからでも使えるようにする）」という意味です。

インストールが終わったら、ちゃんと入ったか確認します：

claude --version

バージョン番号が表示されればインストール成功です！

インストールに失敗した場合：

よくあるのが EACCES: permission denied というエラーです。これはMacでよく起きます。次のコマンドで解決できることが多いです：

sudo npm install -g @anthropic-ai/claude-code

sudo をつけると管理者権限で実行できます。パスワードを求められたらMacのパスワードを入力してください。

それでもダメな場合は、Step 5のエラー対処法を参照してください。

Step 3: ログインと初期設定

インストールが完了したら、Anthropicのアカウントにログインします。

claude login

このコマンドを打つと、こんな感じの質問が出てきます：

? How would you like to authenticate?
❯ Sign in with Claude.ai (recommended)
  Enter API key

初めての方には「Sign in with Claude.ai」をおすすめします。

Enterを押すと、ブラウザが自動で開いてClaude.aiのログイン画面が表示されます。

  1. claude.aiのメールアドレスとパスワードでログイン
  2. 「Claude Codeを許可しますか？」という画面が出るので「許可」をクリック
  3. ブラウザに「認証が完了しました」と表示される
  4. ターミナルに戻ると「Logged in successfully」と表示されている
これでログイン完了です！

APIキーを使う場合：

claude.aiの設定画面 → 「API Keys」からAPIキーを生成して、「Enter API key」を選んで貼り付けます。APIキーは sk-ant- で始まる長い文字列です。

Step 4: 最初のプロジェクトを作ってみよう

ログインできたら、実際に使ってみましょう！まずは作業用のフォルダを作ります。

mkdir my-first-app
cd my-first-app
  • mkdir は「フォルダを作る」コマンド
  • cd は「そのフォルダの中に移動する」コマンド
フォルダに移動できたら、Claude Codeを起動します： 
claude

するとこんな画面が出てきます：

╭─────────────────────────────────────────────╮
│ ✻ Welcome to Claude Code!                   │
│                                             │
│   /help for help                            │
╰─────────────────────────────────────────────╯

claude>

この claude> のあとに、日本語でお願いを打ち込めます。試しにこう入力してみてください：

シンプルなHello Worldのウェブページを作ってください。ボタンを押したら「こんにちは、世界！」とアラートが出るようにしてください。

Enterを押すと、Claude Codeが考えて、コードを書いて、ファイルを作ってくれます。

完了したら、フォルダの中に index.html などのファイルができているはずです。それをブラウザで開くと、実際に動くウェブページが表示されます！

うまくいったサインは：

  • ターミナルにファイル名が表示されて「✓ Created」とか「✓ Done」と出る
  • ls コマンドを打つとファイルが作られているのが確認できる
  • Claude Codeが「こんなものを作りました」と説明してくれる

Claude Codeを終了するときは Ctrl+C か /exit と打ちます。

Step 5: よくある初期エラーと解決法（6種類）

ここが一番大事なセクションです。私が実際にハマったエラーと、その解決法をまとめました。

エラー1：「command not found: claude」（インストール後なのに使えない）

エラーメッセージ：

zsh: command not found: claude

原因： インストールはできているのに、パソコンがclaudeコマンドの場所を知らない状態です。

解決法：

まず、ターミナルを完全に閉じて、新しく開き直してから試してください。それでもダメなら：

Macの場合、.zshrc というファイルにパスを追加します：

echo 'export PATH="$PATH:$(npm prefix -g)/bin"' >> ~/.zshrc
source ~/.zshrc

その後、もう一度 claude --version を試してください。

エラー2：パーミッションエラー（Mac）

エラーメッセージ：

Error: EACCES: permission denied, mkdir '/usr/local/lib/node_modules'

原因： npmがシステムの保護されたフォルダに書き込もうとしているためです。

解決法（おすすめ順）：

方法A：sudoをつけて実行する

sudo npm install -g @anthropic-ai/claude-code

方法B：npmのデフォルトディレクトリを変更する（根本的な解決策）

mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc
npm install -g @anthropic-ai/claude-code

方法Bの方が長期的には安定しています。

エラー3：Node.jsのバージョンが古い

エラーメッセージ：

error: The engine "node" is incompatible with this module.
Expected version ">=18.0.0". Got "16.x.x"

解決法：

Macの場合：

brew upgrade node

Windowsの場合：
[https://nodejs.org](https://nodejs.org) から最新のLTS版をダウンロードして上書きインストール。

インストール後、ターミナルを再起動してから node --version で確認してください。

エラー4：ログインループ・認証失敗

症状： ブラウザで認証したはずなのに、ターミナルに戻るとまたログインを求められる。もしくはずっと「Waiting for authentication...」のまま止まっている。

解決法：

まず既存のログイン情報をリセットします：

claude logout

その後、もう一度ログインを試みます：

claude login

ブラウザが自動で開かない場合は、ターミナルにURLが表示されているはずです。そのURLをコピーしてブラウザに貼り付けて開いてください。

それでも解決しない場合、APIキー方式に切り替えるのが確実です。claude.aiの設定からAPIキーを発行して claude login でAPIキーを選んでください。

エラー5：「EACCES: permission denied」（npm install時）

エラーメッセージ：

npm warn checkPermissions Missing write access to /usr/local/lib/node_modules
npm error code EACCES
npm error syscall access
npm error path /usr/local/lib/node_modules

これはエラー2と似ていますが、少し違うケースです。

解決法：

sudo chown -R $(whoami) /usr/local/lib/node_modules
npm install -g @anthropic-ai/claude-code

このコマンドは「node_modulesフォルダの所有者を自分に変更する」という意味です。これで sudo なしでインストールできるようになります。

エラー6：WSL関連の問題（Windows）

WindowsでWSL（Windows Subsystem for Linux）を使っている場合、ブラウザ認証がうまくいかないことがあります。

症状： claude login を実行してもブラウザが開かない、または開いても認証が完了しない。

解決法：

WSL環境ではAPIキーを使う方法が安定しています。

  1. Windows側のブラウザで [https://console.anthropic.com](https://console.anthropic.com) にアクセス
  2. APIキーを発行（sk-ant- で始まる文字列）
  3. WSLのターミナルで：
export ANTHROPIC_API_KEY="sk-ant-ここにあなたのAPIキーを貼り付け"

毎回設定するのが面倒な場合は：

echo 'export ANTHROPIC_API_KEY="sk-ant-あなたのキー"' >> ~/.bashrc
source ~/.bashrc

これでWSLを起動するたびに自動でAPIキーが設定されます。
