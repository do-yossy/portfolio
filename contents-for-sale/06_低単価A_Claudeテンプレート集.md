## 【システム作成系】10選

### 1. ログイン機能を追加する
```
このNode.jsプロジェクトにログイン機能を追加してください。
・ユーザー名とパスワードでログイン
・セッションで認証状態を保持（7日間）
・未ログイン時は/loginにリダイレクト
・パスワードはSHA256でハッシュ化して保存
・初期ユーザー: admin / admin123
SQLiteを使っています。server.jsに実装してください。
```

```
【要件】
・顧客は複数のタグを持てる
・カテゴリで分類できる
・作成日・更新日を自動で記録する

CREATE TABLE文を書いてください。
```

## 【エラー修正系】8選

### 11. エラーメッセージをそのまま渡す（基本形）
```
以下のエラーが出て動きません。原因と修正方法を教えて、直してください。

【エラーメッセージ】
（ここにエラーをそのまま貼り付け）

【やろうとしていたこと】
（何の操作をしたらエラーになったか）

【関連するファイル】
server.js の ○○ 関数あたりだと思います。
```

### 12. 「Cannot read properties of undefined」系
```
以下のエラーが出ています。

TypeError: Cannot read properties of undefined (reading '○○')

このエラーはどこで起きていますか？
undefinedになる原因を調べて、適切なnullチェックを追加してください。
エラーが出ても処理を止めずに続けられるようにしてください。
```

### 13. データベースのエラー
```
SQLiteでエラーが出ています。

【エラー】
（エラーをそのまま貼り付け）

【実行しようとしたSQL】
（SQLを貼り付け）

テーブル定義を確認して、エラーの原因を特定して直してください。
```

### 14. CORSエラー
```
フロントエンドからAPIを呼ぶとCORSエラーが出ます。

Access to fetch at 'http://localhost:3001/api/...' from origin 'http://localhost:3000' has been blocked by CORS policy

server.jsにCORSの設定を追加してください。
開発環境（localhost）と本番環境（Fly.io）の両方で動くようにしてください。
```

### 15. ポートが使われているエラー
```
サーバーを起動しようとすると以下のエラーが出ます。

Error: listen EADDRINUSE: address already in use :::3001

前のプロセスを終了させて、サーバーを起動する方法を教えてください。
Mac/Windowsそれぞれのコマンドを教えてください。
```

### 16. JSONパースエラー
```
APIを呼ぶとエラーになります。

SyntaxError: Unexpected token < in JSON at position 0

レスポンスがJSONじゃなくHTMLが返ってきているようです。
原因を調べて直してください。
APIのエラーハンドリングも見直してください。
```

### 17. 文字化けの修正
```
CSVをインポートすると文字化けします。

【状況】
・Windowsで作ったCSVファイルをアップロード
・文字コードはShift-JIS（CP932）の可能性がある

UTF-8とShift-JISを自動判定して読み込めるようにしてください。
TextDecoderを使った実装でお願いします。
```

### 18. 本番環境だけ動かない
```
ローカルでは動くのにFly.ioにデプロイしたら動きません。

【エラー】
（Fly.ioのログを貼り付け: fly logs で確認）

【環境の違い】
・ローカル: Mac, Node.js 20
・本番: Fly.io, Docker

原因を特定して修正してください。
```

## テンプレートを使うコツ

### コツ1：具体的なファイル名を伝える
「server.jsに追加して」「index.htmlを修正して」のように、
どのファイルを触るか明示すると精度が上がります。

### コツ2：既存の実装を前提として伝える
「SQLiteを使っています」「認証済みユーザーのみ」など、
すでにある仕組みをClaudeに教えると、整合性が取れた実装をしてくれます。

### コツ3：エラーはそのまま全文貼る
一部だけ貼るより、エラーメッセージ全文をコピペする方が
原因を正確に特定してくれます。

### コツ4：「全部やって」は使える
「DBの設計から実装まで全部やってください」という指示が
Claude Codeでは有効です。ChatGPTと違って実際にやってくれます。
