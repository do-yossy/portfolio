    最初、私はChatGPTで業務を自動化しようとしました。

    毎日くり返す単純作業──データの整理、ファイルの仕分け、リストの出力。これをAIに任せられたら、どれだけ楽になるだろうと。

    ChatGPTは確かにコードを書いてくれました。Pythonのコードも、自動化のスクリプトも、聞けば出してくれる。

    ChatGPTがコードを出してくれても、それをどこに貼り付けて、どう実行するのかがわからない。

    「このコードをターミナルで実行してください」と言われても、ターミナルって何？という状態。

    実行するとエラーが出る。そのエラーをChatGPTに貼ると、別の解決策が返ってくる。それを試すとまた別のエラー。

    少し複雑なことをやろうとすると、ファイルが複数になる。「このファイルのここを直して、あっちのファイルのここも直して」という作業を、ChatGPTとの会話の中で人間が手作業でやらないといけない。

    ここで私は、一度完全に諦めました。

    「やっぱり、コードが書けない人間に自動化は無理なんだ」と。

    ---

    諦めかけていたとき、Claude Codeの存在を知りました。

    ChatGPTが「コードを教えてくれるAI」なら、でした。

    ここが決定的に違いました。

    | 項目 | ChatGPT | Claude Code | |------|---------|-------------| | コードを書く | ◯ | ◯ | | | ✕（コピペが必要） | ◯（自動で編集） | | | ✕（人間が手作業） | ◯（自動で横断） | | | ✕（会話で往復） | ◯（自分で修正） | | | ✕ | ◯ |

    ChatGPTは「コードの部品工場」。 Claude Codeは「プロジェクト全体を見るエンジニア」。

    ---

    私がClaude Codeで実際に作って、自動化できたことを紹介します。

  • やったことは、「こういうものを作りたい」と日本語で伝えただけ。

    あとはClaude Codeが、コードを書いて、実行して、エラーが出たら自分で直して、完成させてくれました。

    ---

    ここからは、実際に私がやった手順を、未経験者向けに解説します。

    Claude Proプラン（月額約3,000円）に加入すると、Claude Codeが追加料金なしで使えます。ChatGPT Plusと同じ価格帯で、コーディングに特化した機能が手に入ります。

    ここがコツです。専門用語は不要。

    「毎日CSVファイルを開いて、名前と電話番号だけを別のファイルにまとめる作業を自動化したい」

    このレベルの日本語でOK。

    あとは待つだけ。Claude Codeがファイルを作り、コードを書き、動かして、確認します。

    「エラーが出た」と伝えるだけ。Claude Codeがエラーの原因を調べて、自分で修正します。

    ---

    逆説的ですが、

    なぜなら、ChatGPTで「何ができて、何ができないか」を体感しているから。

    Claude Codeを使うと、「ChatGPTでできなかったこれが、こんなに簡単にできるのか」という感動があります。

    ---

    私は、本当にただの未経験者でした。

    ターミナルって何？という状態から、Claude Codeを使って業務システムを丸ごと自動化できるようになりました。

    特別な才能は一切いりません。必要なのは、「日本語で伝える力」だけ。
