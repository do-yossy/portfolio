## 設計・コンプライアンスの方針

- **読者は読むだけで完結**：記入欄・ワークシート・チェックリスト記入・計算欄を置かない。必要な計算はすべて教材側でモデルケースとして提示。
- **公的制度は最新の公的情報を優先**：厚生労働省・ハローワーク・全国健康保険協会（協会けんぽ）・日本年金機構・国税庁・各自治体（確認日 2026-08-08）。基本手当日額の上限（令和7年8月〜）、国民年金保険料（令和8年度 月額17,920円）、傷病手当金の計算方法・支給期間などを反映。
- **断定・保証表現の禁止**：「誰でも／必ず／絶対もらえる」「退職すれば◯万円」「月◯万円稼げる」等は使用しない。金額は【制度上の計算方法】と【教材上のモデル計算】を区別し、モデルは「実際の支給額を保証しない」と明記。
- **EC事業者資料の扱い**：EC事業者（資料上の運営会社表記：fedick／サービス名「ECショップオーナー」）から提供された資料の内容は「事業者提供資料の記載」として紹介し、教材側で収益・報酬・契約条件・費用を保証・断定しない。詳細は専門担当者へ確認する導線とする。
- **デザイン**：白ベース＋ボルドー／ワインレッドのアクセント、ベージュ・淡いグレーを補助色。A4縦、表紙・目次・PART扉・章見出し・図表・囲み枠・CASE STUDYカード・STEPフロー図・ページ番号・ヘッダー。

## 生成方法

`docx`（npm, v9系）を使用します。`content/fp00.json`〜`fp11.json` が本文データ、`build_docx.js` がレンダラーです。

```bash
mkdir -p build && cd build
npm install docx@9
NODE_PATH="$PWD/node_modules" node ../build_docx.js ../content ../CAREER_RESET_SIDE_BUSINESS_実践ガイド.docx
```

> 目次のページ番号は、Word で開いて「フィールドの更新」を行うと反映されます。
