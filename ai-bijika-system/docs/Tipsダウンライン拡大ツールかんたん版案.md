# Tipsダウンライン拡大ツールかんたん版案：APIキー不要のダウンライン拡大ツール

## 背景

「SNS自動投稿ツールは無理だと思うが、APIキーが不要なタイプもそれぞれつくれるか」という指示を受けて作成した。既存の「ダウンライン拡大ツール」（`/tools/kanyu`、1,480円）は購入者自身のAIプロバイダ（OpenAI・Anthropic）APIキーが必要だが、本商品（`/tools/kanyu-kantan`）はAPIキーの用意・入力を一切不要にした別商品として新設した。設計方針・費用負担の考え方は`docs/Tips集客接客ツールかんたん版案.md`（集客・接客ツールのかんたん版）と同じで、本書ではダウンライン拡大ツール固有の論点のみを扱う。

## 設計方針

- **既存の1,480円商品を書き換えず、別商品にした理由・運営者の共有APIキーを使う理由・1日の生成上限を設けた理由**：`docs/Tips集客接客ツールかんたん版案.md`と同一（APIキー不要化に伴う運営者の費用負担という性質上の変化のため独立商品にし、購入者ごとに使用量を区別できないため1日あたりの合計生成回数で費用の上限を予測可能にしている）
- **価格を1,980円にした理由**：既存の1,480円商品（APIキー要）より利便性が高く運営者側の費用負担も伴う点に加え、もともと1,480円商品自体が980円商品より専門性・法令対応の重要度が高いという価格差を踏襲し、かんたん版同士でも同じ価格差（+500円）を維持した
- **法令遵守要素は`/tools/kanyu`のものをそのまま引き継ぐ**：APIキーの要・不要という提供方法の違いのみで、ツール内の5モードのプロンプト文面（特定商取引法上の開示義務への対応、クーリング・オフの説明等）は、既存の1,480円商品と完全に同一のものを使っている（新規創作ではない）

## 前提・確認事項（必ず購入者に伝えるべき点）

- 価格1,980円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- **本商品は法律専門家による助言ではない**。実際の勧誘にあたっては、特定商取引法（連鎖販売取引に関する規定）・該当する業界ガイドライン等を、購入者自身の責任で確認すること
- **本商品は、購入者が扱うネットワークビジネスが、特定商取引法上の連鎖販売取引として適正に運営されていることを前提としている**。物品・サービスの販売を伴わず、新規加入者からの金銭のみで上位者が利益を得る仕組み（無限連鎖講＝ネズミ講）は「無限連鎖講の防止に関する法律」で明確に禁止されており、本商品はそうした仕組みでの使用を想定していない
- **1日あたりの生成回数に上限がある**（既定30回。全購入者共通の上限で、個人ごとの上限ではない）。上限に達すると、日付が変わるまで生成できない
- APIキーの用意・入力は一切不要
- パスワードは全購入者共通の1つを運用する設計で、購入者ごとの個別発行・失効はできない。漏洩等が疑われる場合は、運営者が環境変数（`KANYU_KANTAN_TOOL_PASSWORD`）を変更して再デプロイすれば一斉に無効化できる

## 出品〜運用の流れ（運営者向け）

1. 上記①をTipsの出品ページ作成画面にそのまま貼り付け、価格1,980円で出品する
2. 購入が入ったら、上記②の本文をTipsの「購入後に表示するコンテンツ」欄に設定する
3. 購入者から`/contact`経由で連絡が来たら、Tipsの購入履歴と照合して本人確認のうえ、ツールのURL（`https://aipro.social-quality.com/tools/kanyu-kantan`）とパスワード（環境変数`KANYU_KANTAN_TOOL_PASSWORD`の値）を案内する
4. パスワードは全購入者共通の1つを運用する設計（個別の発行・失効はできない）。漏洩等が疑われる場合は、環境変数を変更して再デプロイすれば一斉に無効化できる
5. `SHARED_AI_API_KEY`の利用料は運営者が負担する。想定を超える利用が続く場合は、`KANYU_KANTAN_DAILY_LIMIT`環境変数で1日の上限を調整できる
6. 問い合わせが来たら、`docs/商談トークスクリプト.md`の流れで対応する
