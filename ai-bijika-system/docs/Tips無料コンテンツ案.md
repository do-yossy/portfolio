# Tips無料コンテンツ案

## 背景

「tipsで無料コンテンツを販売して最後にメッセージをしてもらう形にしたい。無料コンテンツは量産した方がいいと思うので実際にタメになる商品をつくって」という依頼を受けて作成。

既存の`docs/Tips窓口商品案.md`（商品のタネ診断シート、500円）とは別に、**価格0円の無料コンテンツを複数出品**し、入口を増やす設計にした。無料にすることで購入のハードルを下げ、各コンテンツの最後から問い合わせに繋げる。

問い合わせ先は`docs/Tips窓口商品案.md`での調査結果を踏まえ、確実に機能する`/contact`フォームを使う（Tipsのメッセージ機能は出品者→購入者の一方向のみで購入者から連絡できないため。個別チャット機能の実際の稼働有無は運営者確認待ち。確認でき次第、両方の案内に更新できる）。

## 前提・確認事項（未確認のまま進めている点）

- Tipsで価格0円の出品が可能かどうか・無料コンテンツの出品数に制限がないかは未確認。出品前にTips側の規約を確認すること
- 3本の内容は、このセッションで新規に作成したオリジナル文章であり、実在の購入者の声・実績数字は一切含めていない
- 「怪しい副業を見抜く完全チェックリスト」の④〜⑦は、特定の法律・規約の条文に基づくものではなく、一般的な消費者保護の観点からの注意喚起として作成している

## 無料コンテンツ①：怪しい副業を見抜く完全チェックリスト

### 出品ページ用の文章

```
タイトル：怪しい副業を見抜く完全チェックリスト｜始める前に確認したい7つのポイント
価格：無料（0円）

■ こんな方向けです
・副業を探しているけど、怪しいものに引っかからないか不安
・勧誘された副業や、SNSで見かけた副業が信頼できるか迷っている

■ これは何か
副業・サイドビジネスを探すときに確認しておきたい7つのチェックポイントをまとめたリストです。読んだその場で、気になっている副業と照らし合わせて確認できます。

■ お伝えしておきたいこと
このチェックリストは一般的な注意点をまとめたものであり、特定の副業・企業を評価したり、法律的な判断を行うものではありません。最終的な判断はご自身で行ってください。
```

### 本文（購入後に届く内容）

```
【怪しい副業を見抜く完全チェックリスト】

副業を探していると、残念ながら怪しいものも混ざってきます。
以下の7つのうち、当てはまる項目がないか確認してみてください。

────────────────

① 商品の中身より、人を誘うことばかり強調してくる
商品・サービス自体の説明より先に「紹介すれば稼げる」という話が出てくる場合は要注意です。

② 自分が誘った人がさらに人を誘うと、自分にも報酬が入る仕組みになっている
いわゆる「ねずみ講」「マルチ商法」の典型的な構造です。

③ 人を勧誘しないと使えない・稼げない仕組みになっている
商品・サービス単体の価値ではなく、勧誘することが前提になっているものは危険です。

④ 「誰でも必ず稼げる」「絶対に失敗しない」などの断定的な表現を使っている
成果には個人差があるのが当然です。断定的な表現は誇張の可能性があります。

⑤ 運営者・会社の実在性（会社名・所在地・連絡先）を確認できない
正式な会社名・所在地・連絡先が明記されているか確認しましょう。検索して実在するかも調べられます。

⑥ 「今だけ」「今日中に」などと契約や支払いを急かしてくる
冷静に考える時間を与えずに契約させようとするのは、よくある手口です。

⑦ 返金・返品に関する説明がどこにも書かれていない
有償の商品・サービスであれば、返金条件の記載があるのが基本です。

────────────────

【チェックの仕方】

当てはまる項目が1つでもあったら、契約・支払いの前に一度立ち止まって、信頼できる人に相談したり、会社名で検索したりすることをおすすめします。

逆に言えば、これらに当てはまらないからといって、必ず安全というわけでもありません。あくまで最初の確認材料として使ってください。

【次の一歩】

経験を活かして自分の商品を作る方法に興味がある方、もう少し詳しく話を聞いてみたい方は、お気軽にご連絡ください。
https://sq-ai-bijika.fly.dev/contact
```

## 無料コンテンツ②：自分に合う副業の見つけ方｜4タイプ診断ガイド

### 出品ページ用の文章

```
タイトル：自分に合う副業の見つけ方｜4タイプ診断ガイド
価格：無料（0円）

■ こんな方向けです
・副業に興味はあるけど、何から始めればいいか分からない
・自分にどんな副業が向いているのか知りたい

■ これは何か
副業のタイプを4つに分けて整理したガイドです。自分が今持っているものに当てはめて読むことで、どのタイプが向いていそうか考える手がかりになります。

■ お伝えしておきたいこと
このガイドは副業のタイプを整理するためのものであり、特定の副業・収入を保証するものではありません。
```

### 本文（購入後に届く内容）

```
【自分に合う副業の見つけ方｜4タイプ診断ガイド】

副業と一口に言っても、自分が何を持っているかによって向いているタイプは変わります。
4つのタイプに分けて整理しました。当てはまりそうなものを探してみてください。

────────────────

■ タイプ1：経験・知識を活かすタイプ
今までの仕事や生活の中で得た経験・知識がある人向け。
例：ブログ・記事執筆、オンライン相談、知識をまとめた資料の販売など
向いている人：特定の分野で人に相談されたことがある、説明するのが得意

■ タイプ2：スキル・技術を活かすタイプ
特定の作業スキル（デザイン、文章作成、事務作業など）がある人向け。
例：クラウドソーシングでの受注作業、スキルシェアサービスでの出品
向いている人：資格や実務経験がある、手を動かす作業が苦にならない

■ タイプ3：時間を活かすタイプ
まとまった時間を確保しやすい人向け。
例：データ入力、簡単な作業の代行
向いている人：コツコツ続ける作業が得意、特別なスキルより時間で貢献したい

■ タイプ4：興味・発信を活かすタイプ
好きなこと・関心のあることを発信するのが好きな人向け。
例：SNSでの情報発信、趣味を軸にしたコンテンツ作成
向いている人：人に何かを伝えるのが好き、継続して発信することが苦にならない

────────────────

【使い方】

複数のタイプに当てはまる人もいると思います。その場合は、一番時間をかけずに始められそうなタイプから試してみるのがおすすめです。

どのタイプも、最初から完璧を目指す必要はありません。小さく始めて、反応を見ながら直していく方が結局早く進みます。

【次の一歩】

特にタイプ1（経験・知識を活かすタイプ）に興味を持った方、自分の経験を商品にする具体的な手順を知りたい方は、お気軽にご連絡ください。
https://sq-ai-bijika.fly.dev/contact
```

## 無料コンテンツ③：AI初心者のための「商品化、はじめの一歩」ガイド

### 出品ページ用の文章

```
タイトル：AI初心者のための「商品化、はじめの一歩」ガイド
価格：無料（0円）

■ こんな方向けです
・AIに興味はあるけど、使ったことがほとんどない
・AIを使って何か商品を作れると聞いたけど、何から始めればいいか分からない

■ これは何か
ChatGPTなどのAIをまだ使ったことがない人向けに、商品化に向けた最初の一歩を具体的に説明するガイドです。専門知識は不要です。

■ お伝えしておきたいこと
このガイドはAIの使い方の第一歩を案内するものであり、商品化の成功や収入を保証するものではありません。
```

### 本文（購入後に届く内容）

```
【AI初心者のための「商品化、はじめの一歩」ガイド】

「AIを使えば商品化できるらしいけど、何から始めればいいか分からない」
そんな方のために、最初の一歩だけに絞って説明します。

────────────────

■ ステップ1：まずはAIに触れてみる

ChatGPT（無料版でOK）にアクセスして、アカウントを作るところから始めます。
難しい設定は不要で、メールアドレスがあれば数分で使い始められます。

■ ステップ2：自分の経験をAIに話してみる

いきなり「商品を作って」と聞くのではなく、まずは自分の経験を話しかけてみてください。

例えば、こんな聞き方です。
「私は◯◯の仕事を5年やっています。私の経験で、誰かの役に立ちそうなことを教えてください」

AIが想像で答えを作ってしまうこともあるので、出てきた答えが本当に自分の実感と合っているかは、必ず自分で確認してください。

■ ステップ3：出てきた答えを深掘りする

AIの答えの中で「これは確かにそうかも」と思うものがあれば、さらに聞いてみてください。
「それを商品にするとしたら、どんな形が考えられますか？」

一度で正解が出なくても大丈夫です。何度もやり取りしながら、一緒に形にしていくのがAIの使い方のコツです。

────────────────

【最初のうちによくあるつまずき】

・AIの回答がしっくりこない → 「もっと具体的に」「◯◯向けに言い換えて」と頼み直せばOK
・何を話せばいいか分からない → 完璧な答えを用意する必要はなく、思いついたことをそのまま話しかけて大丈夫

【次の一歩】

この続き（経験の整理の仕方、商品アイデアの出し方、実際に形にする手順）まで体系的に知りたい方は、お気軽にご連絡ください。
https://sq-ai-bijika.fly.dev/contact
```

## 出品〜運用の流れ

1. 3本それぞれを、Tipsの出品画面で価格0円で出品する（無料出品の可否は事前に確認する）
2. 問い合わせが来たら、`docs/商談トークスクリプト.md`の流れで対応する
3. 無料コンテンツは反応を見ながら本数を増やしてよい。その際も、本書と同じ構成（出品ページ文章→本文→次の一歩）で作成する
4. 既存の有料窓口商品（`docs/Tips窓口商品案.md`、500円）とは役割が異なる：無料コンテンツは入口を広げる役割、有料窓口商品はより具体的な体験を提供する役割として、両方並行して出品してよい
