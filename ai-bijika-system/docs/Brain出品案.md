# Brain出品案

## 背景

「各媒体でコピペでやることをだして」という依頼を受け作成。考え方は`docs/Tips窓口商品案.md`と同じ（窓口商品→オンライン相談→本商品案内）で、商品の中身（5つの質問による「商品のタネ診断」）も同じものを使っている。Brainは文章主体の長めのセールスページが一般的なため、ページ構成をBrain向けに書き直した。

## 出品にあたっての前提・確認事項（未確認のまま進めている点）

- **価格は500円を提案**している。`Tips窓口商品案.md`と同額にそろえた提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- Brain側の手数料率・出品規約・アフィリエイト機能の利用有無は未確認。出品前に確認すること
- 本書の文章は新規のオリジナル文章であり、実在の購入者の声・実績数字は一切含めていない

---

## ①タイトル

```
自分の経験、実は商品になる？「商品のタネ」が見つかる診断シート
```

## ②価格

500円（税込）

## ③セールスページ本文

```
■ こんなことで悩んでいませんか？

「自分の経験なんて、誰かの役に立つとは思えない」
「商品を作ってみたいけど、何を商品にすればいいか分からない」
「AIを使えば何か作れそうだけど、最初の一歩が踏み出せない」

もしひとつでも当てはまったら、このシートを読んでみてください。

■ これは何か

5つの質問に答えるだけで、あなたの中にある「商品のタネ」（商品化できそうな経験・知識）を一緒に見つける診断シートです。

専門知識は必要ありません。今のあなたの経験・今まで生きてきた中で得たことだけで答えられます。

■ 所要時間

3〜5分

■ なぜこのシートを作ったか

商品化の最初のつまずきは、多くの場合「作り方」ではなく「何を商品にするか決められないこと」です。このシートは、作り方の前段階、「自分には何があるのか」を整理するためのものです。

■ 購入後にお届けするもの

5つの質問と、答えを見てタネがあるかどうかを自分で振り返るためのガイド（テキスト）

■ お伝えしておきたいこと

この診断は「商品のタネがありそうか」を一緒に確認するためのものです。診断の結果が、実際に売れることや収入を保証するものではありません。

■ もっと先に進みたい方へ

見つけた経験を実際の商品にして、販売まで進めたい方には、無料のオンライン相談もご案内しています（購入後にご案内します）。
```

## ④購入後に届く本文

`docs/Tips窓口商品案.md`の「②購入後に届く本文（診断シートの中身）」とまったく同じものを使う（二重管理を避けるため、ここでは繰り返さない）。Brain側の「購入後コンテンツ」欄に、そのまま貼り付ける。
