# SNS自動投稿セット販売戦略案：集客ツールセット・ダウンライン拡大セットをどう売るか

## 背景

「販売方法やテキストでのアプローチ方法を考えて」という指示を受けて作成した。`docs/SNS自動投稿ツールアプローチ文面案.md`で作った2本のメッセージは「既に接点がある相手」への声かけ文面だったが、それだけでは新規の見込み客には届かない。本書では、2つのセット商品（`docs/Tips集客ツール+SNS自動投稿セット案.md`・`docs/Tipsダウンライン拡大+SNS自動投稿セット案.md`）を、新規の見込み客も含めてどう売るかという、接点作りからクロージングまでの一連の流れを整理する。

新しい仕組みを作るのではなく、このリポジトリに既にある資産（無料ツール・既存の営業文書）を、2つのセット商品の販売という目的のためにどう組み合わせるか、という整理である。

## 全体の流れ（発見→信頼構築→声かけ→クロージング）

| 段階 | やること | 使うもの |
|---|---|---|
| ①発見 | 新規の見込み客と最初の接点を作る | Threadsでの発信、既存のTips無料コンテンツ |
| ②信頼構築 | 「役に立つ人・会社だ」と思ってもらう | `/tools/jikoshoukai`・`/tools/fukugyou`（無料ツール） |
| ③声かけ | セット商品を知ってもらう | `docs/SNS自動投稿ツールアプローチ文面案.md`の①②、本書のフォローアップ文面 |
| ④商談 | 疑問点を解消し、購入の後押しをする | `docs/商談トークスクリプト.md` |
| ⑤購入後 | 実際に使い始めてもらう | 各セット商品の②購入後本文 |

①②は、このセッション内で既に構築済みの「まず無料で役立つものを渡す」という導線（`docs/Tips無料コンテンツ案.md`、`/tools/jikoshoukai`・`/tools/fukugyou`）をそのまま使う。③〜⑤も同様に既存の資産を使う。本書で新しく整理するのは、①（新規の見込み客とどう出会うか）と、③の後にもう一押しするためのフォローアップ文面の2点。

## ①新規の見込み客との接点の作り方

既存の接点（知人・過去の問い合わせ）だけに頼らず、新しい相手と出会うための具体策を2つの対象ごとに整理する。いずれも、プラットフォームの規約に反する自動化（自動フォロー・自動いいね・自動DM等）は使わない（`docs/SNS自動投稿連携案.md`参照）。

### ビジネス初心者向け

- **Threadsでの定期発信**：副業・経験の言語化・商品化に関する、役立つ内容の投稿を定期的に行う。投稿文の作成に時間を取られないよう、将来的には購入前の体験として`/tools/jidoutoukou`自体のデモ（実際にこのツールで予約投稿している様子）を見せる投稿も交える。反応してくれた相手に、無料ツール（`/tools/jikoshoukai`の通常モード・`/tools/fukugyou`）を案内する
- **既存の無料コンテンツ経由の流入**：Tips上の無料コンテンツ（`docs/Tips無料コンテンツ案.md`）・300円→無料化した経験紹介文プロンプト集（`docs/Tips低価格商品案.md`、`/tools/fukugyou`に統合済み）を見た人からの問い合わせに、セット商品を次の一歩として案内する

### MLMでパートナー募集したい方向け

- **既存のアポミー経由LINEリストの掘り起こし**：`docs/アポミー再アプローチ文面案.md`で過去に接触し、その後も関係が続いている相手に対して、まず`/tools/jikoshoukai`のMLMモード（無料）を案内し、使ってもらったうえで本セットを案内する
- **Threadsでの定期発信**：ネットワークビジネスの仲間集めに役立つ内容（誠実な声かけの大切さ、法令上の注意点等）を定期的に発信し、関心を持った相手に`/tools/jikoshoukai`のMLMモードを案内する

## ②フォローアップ文面（最初のメッセージに反応が無い場合）

`docs/SNS自動投稿ツールアプローチ文面案.md`の①②を送っても、すぐに反応が無いことは珍しくない。1週間ほど間を空けて、売り込み色を薄めた形で1回だけ再度触れることを推奨する（何度も催促しない）。

## 前提・確認事項

- 本書は販売の進め方の提案であり、効果を保証するものではない。実在の反応率・成約率等の数字は含めていない
- フォローアップは1回のみとし、繰り返し送らない（しつこい勧誘という印象を避けるため）
- Threadsでの定期発信の具体的な投稿文は、`docs/Tips低価格商品案.md`・`/tools/fukugyou`・`/tools/jikoshoukai`で作成できる。発信自体の継続的な運用は、今後`/tools/jidoutoukou`での予約投稿を活用できる
