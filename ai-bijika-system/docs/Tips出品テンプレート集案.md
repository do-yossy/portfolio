# Tips出品テンプレート集案：そのまま使える「副業商品」出品テンプレート集

## 背景

「副業をこれから始める人に向けて売る商材になったり、マネタイズできる商品を出品したい」という依頼を受けて作成。

既存の300円（AIプロンプトで文章生成）・980円（AIプロンプトが連動するミニシステム）はいずれも「AIに聞きながら考える」ための商品だった。これに対し本商品は、**買った人がその場で自分の商品として出品できる、埋めるだけの完成形テンプレート**を3種類まとめたもの。AIを使わなくても完成させられる点が既存2商品との違い。

## 設計方針

- **「AIプロンプト」ではなく「テンプレート」にした理由**：「売る商材になる」という依頼に直接応えるため、AIに質問して出力を待つのではなく、埋めればそのまま出品できる完成形のフォーマットを用意した
- **3種類にした理由**：副業の入り口としてよくある3つの商品形式（相談・診断・ミニ講座）をカバーすることで、自分の経験がどの形式に向いているか分からない人でも、3つの型から選べるようにした
- **価格を1,480円にした理由**：300円（単発の文章生成）・980円（AIプロンプトの連動システム）より高く、2,980円（7パターンの事例集）より低い価格帯とした。テンプレートが3種類・即座に出品できる完成度であることから、980円のシステム商品より高い価格を設定した

## 前提・確認事項

- 価格1,480円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- テンプレートの文面はすべて新規に書いたオリジナルであり、`seeds/prompts.js`の文面は含めていない
- 「売る商材になる」という表現を受けて作成したが、実際に売れることや収入を保証するものではない旨を出品ページ・本文の両方に明記している
- テンプレートはあくまで型であり、埋める内容（自分の経験・専門性）は購入者自身が用意する必要がある。内容を伴わない「空のテンプレートを埋めるだけで自動的に売れる」という誤解を避けるため、この点も明記している

## ①Tips出品ページ用の文章

```
タイトル：そのまま使える「副業商品」出品テンプレート集｜3つの型で、今日から出品できる
価格：1,480円（税込）

「副業を始めたいけど、何を・どう出品すればいいか分からない」
そんな方のために、埋めるだけで出品ページが完成する3つのテンプレートをご用意しました。

■ こんな方向けです
・副業をこれから始めたいが、何を売ればいいか形が決まっていない
・自分の経験はあるが、商品としてどう見せればいいか分からない
・今日・今週中に、何か1つでも出品してみたい

■ これは何か
「①オンライン相談」「②診断・チェックリスト」「③ミニ講座・ノウハウ提供」という、副業でよく使われる3つの商品形式について、タイトルの型・出品文の構成・価格設定の考え方をまとめたテンプレート集です。空欄に自分の経験を当てはめるだけで、出品ページの下書きが完成します。

■ お伝えしておきたいこと
テンプレートは型であり、中身（あなたの経験・知識）はご自身でご用意いただく必要があります。埋めるだけで自動的に売れることを保証するものではありません。
```

## ②購入後に届く本文

```
【そのまま使える「副業商品」出品テンプレート集】

ご購入ありがとうございます。

テンプレートはあくまで「型」です。埋める中身（あなたの経験・知識）はご自身でご用意いただく必要があり、埋めるだけで自動的に売れることや収入を保証するものではありません。

以下の3つのテンプレートは、それぞれ違う商品の形（型）です。
自分の経験に合いそうなものを1つ選んで埋めてみてください。複数選んでも構いません。
【　】の部分に、ご自身の経験・考えを当てはめてください。

────────────────

■ テンプレート1：オンライン相談サービス

自分の経験について、人と話しながら相談にのる形式です。

【タイトルの型】
「【分野】の相談、お聞きします｜【時間】分【価格】円」
例：「子育ての悩み、お聞きします｜30分3,000円」

【出品文の構成】
■ こんな方へ
→【自分の経験から考えて、悩んでいそうな人を2〜3個書く】

■ 相談でできること
→【話を聞くだけか、アドバイスもするか、一緒に考える形かを書く】

■ 相談の流れ
①事前に簡単なヒアリング内容をお送りいただきます
②オンライン（ビデオ通話等）で【時間】分お話しします
③相談後、簡単な振り返りメモをお送りします

■ こんな方には合わないかもしれません
→【正直に、向かない相手も書いておく（誠実さが伝わり、かえって信頼されます）】

────────────────

■ テンプレート2：診断・チェックリスト

5つ程度の質問に答えてもらい、気づきを提供する形式です。

【タイトルの型】
「【テーマ】かどうかが3〜5分でわかる診断シート」
例：「今の仕事、転職すべきかが3〜5分でわかる診断シート」

【出品文の構成】
■ こんな方へ
→【このテーマで迷っている人を書く】

■ これは何か
→【質問数・所要時間・何が分かるかを書く】

【本文の構成（購入後に届ける内容）】

質問は、次の5つの役割に沿って作ると、答えやすく・診断として成立しやすくなります。

Q1（現状確認）：→【今、相手がどんな状況にいるかを聞く質問】
　例の型：「今、◯◯についてどのくらい△△していますか？」

Q2（悩みの核心）：→【相手が何に迷っている・困っているかを聞く質問】
　例の型：「◯◯について、一番迷っていることは何ですか？」

Q3（具体的な分岐）：→【「もし◯◯だったら」という具体的な場面を聞く質問】
　例の型：「もし◯◯という状況だったら、あなたはどうしますか？」

Q4（理想の確認）：→【本当はどうなりたいかを聞く質問】
　例の型：「もし何も制約が無いとしたら、理想はどんな状態ですか？」

Q5（まとめ）：→【ここまでの回答を振り返ってもらう質問】
　例の型：「Q1〜Q4を振り返って、一言でまとめると？」

【診断の見方】：→【質問に答えた結果、何が分かるか、どう受け止めればいいかを書く（例：「Q1〜Q3で◯◯と書いた方は△△の傾向があります」等）】
【次の一歩】：→【さらに詳しく知りたい人向けの案内（相談・問い合わせ先等）を書く】

────────────────

■ テンプレート3：ミニ講座・ノウハウ提供

自分の知識・経験を、まとまった形で伝える講座形式です。

【タイトルの型】
「【テーマ】を【期間】でできるようになるミニ講座」
例：「初めてでも伝わるSNS投稿文を1週間で書けるようになるミニ講座」

【出品文の構成】
■ こんな方へ
→【このテーマを学びたい人を書く】

■ 講座の内容（3章構成の型）
第1章：【基本の考え方・心構え】
第2章：【具体的なやり方・手順】
第3章：【よくあるつまずきと対処法】

■ 受け取り方
→【テキスト・動画・PDF等、どの形で届けるかを書く】

────────────────

【価格設定の考え方】

最初から高い価格をつける必要はありません。まずは自分が心理的に出品しやすい価格（数百円〜数千円程度）から始め、反応を見ながら調整するのがおすすめです。

【次の一歩】

どのテンプレートが自分に合うか分からない方、埋める内容（自分の経験の整理）から相談したい方は、お気軽にご連絡ください。
https://aipro.social-quality.com/contact
```
