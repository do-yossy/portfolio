**社外秘**

## 概要（一言で）

既存のミチシルベ（AI×商品化プログラム、GATE1〜10）を学ぶ教材として使いながら、SNS運用を軸に人（講師）が伴走指導する月額制サービスを新設する。加入者には、講師が別途用意する新規商材を販売する権利を付与し、販売実績に応じてアフィリエイト報酬を支払う。

## 背景・目的

「ミチシルベを使って講師が伴走型でオンラインスクールでAIに関することやSNS集客を教えてくれる形にできそうです」という発案から具体化した。既存のミチシルベ本体（500,000円・税別、一括購入）とは別に、月額制で始められる低価格帯の接点を作ることで、新規顧客層の獲得と、既存のアポミー経由の接点（MLM従事者等）への提案の幅を広げることを狙う。

詳細な設計の経緯・検討内容は `ai-bijika-system/docs/伴走型オンラインスクール案.md` を参照（本稟議書はその要点をまとめたもの）。

## 事業内容

### プラン・料金（SocialX社の料金体系を参考に設定）

| | ライト | プロ |
|---|---|---|
| 月額（税込・提案） | 5,500円 | 11,000円 |
| サポート内容 | 月1回・60分のグループQ&A | 週1回・30分の個別1on1＋チャット質問し放題＋SNS投稿文の個別添削 |

どちらのプランも、講師が用意する商材（新規開発・価格未定）を販売する権利を、追加費用なしで含む。

### 伴走カリキュラム（SNS運用を軸に具体化）

1. **STEP1：アカウントの土台づくり** — SNSアカウントのプロフィール・世界観整備
2. **STEP2：投稿づくり** — 悩み共感型＋商材紹介型の投稿作成（AIプロンプトを活用）
3. **STEP3：商材の売り方** — 個別対応から商談・購入に繋げる流れ
4. **STEP4：運用・改善** — 投稿の反応を見ながらの継続的な改善、週次・月次の進捗確認

### アフィリエイト報酬

加入者が商材を販売した場合、成約額の20%（提案）をアフィリエイト報酬として支払う。多段階（ダウンライン型）の報酬は設けず、単層のみとする。

## 収支・コストの見込み

- 月額収入：ライト5,500円・プロ11,000円（いずれも税込・提案）
- 主なコスト：講師（運営者）の稼働時間（1on1・グループQ&A・添削対応）
- **懸念事項**：プロプラン（週1回30分の個別対応＋チャット対応＋添削）は、月換算で相応の稼働時間がかかる一方、月額11,000円という価格設定では、講師1人あたりの採算が厳しくなる可能性がある。試験運用で実際の工数を計測し、価格・提供内容（添削範囲・稼働人数の上限）を見直す前提で進める
- 商材自体がまだ存在しないため、アフィリエイト報酬を含めた正確な収支試算は、商材の企画・価格確定後にあらためて行う

## スケジュール（概算）

1. 商材の企画・開発
2. 申込み導線・利用規約の整備
3. 試験運用（少人数）で工数・反応を計測
4. 本格募集開始

具体的な時期は未定（商材の開発状況に依存）。

## リスクと対応

- **採算性のリスク**：上記「収支・コストの見込み」の通り、プロプランの価格と講師稼働コストのバランスに懸念がある。試験運用後に価格・提供内容を見直す
- **商材が未確定であることのリスク**：販売対象の商材がまだ存在しないため、実際の収益性・需要は未検証。企画・試作段階で需要を確認してから本格投入する
- **解約・返金ルールが未整備であることのリスク**：既存の利用規約（`legal/利用規約_案.md`）との整合を取った上で、販売する権利の扱い（解約後の取り扱い等）を明文化する必要がある
