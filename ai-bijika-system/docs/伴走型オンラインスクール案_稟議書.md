**社外秘**

## 概要（一言で）

既存のミチシルベ（AI×商品化プログラム、GATE1〜10）を学ぶ教材として使いながら、SNS運用を軸に、外部の講師の方（Instagram・X・Threads・TikTokの運用・集客と、そのAI活用を指導）が伴走指導する月額制サービスを新設する。受講者には、講師の方がお持ちの商材を販売する権利を付与し、売れた商材の売上は講師の方と受講者で分ける形を考えている。

## 背景・目的

「ミチシルベを使って講師が伴走型でオンラインスクールでAIに関することやSNS集客を教えてくれる形にできそうです」という発案から具体化した。既存のミチシルベ本体（500,000円・税別、一括購入）とは別に、月額制で始められる低価格帯の接点を作ることで、新規顧客層の獲得と、既存のアポミー経由の接点（MLM従事者等）への提案の幅を広げることを狙う。

詳細な設計の経緯・検討内容は `ai-bijika-system/docs/伴走型オンラインスクール案.md` を参照（本稟議書はその要点をまとめたもの）。

## 事業内容

### プラン・料金（SocialX社の料金体系を参考に設定）

| | ライト | プロ |
|---|---|---|
| 月額（税込・提案） | 5,500円 | 11,000円 |
| サポート内容 | 月1回のオンラインミーティング＋チャット質問し放題 | 週1回・30分の個別1on1＋チャット質問し放題＋SNS投稿文の個別添削 |

どちらのプランも、講師の方がお持ちの商材を販売する権利を、追加費用なしで含む。

### 伴走カリキュラム（SNS運用を軸に具体化）

対象SNSはInstagram・X・Threads・TikTok。各SNSの運用でのAI活用も教える。受講者が選んだSNSに合わせて指導する。

1. **STEP1：アカウントの土台づくり** — SNSアカウントのプロフィール・世界観整備
2. **STEP2：投稿づくり** — 悩み共感型＋商材紹介型の投稿作成（AIプロンプトを活用）
3. **STEP3：商材の売り方** — 個別対応から商談・購入に繋げる流れ
4. **STEP4：運用・改善** — 投稿の反応を見ながらの継続的な改善、週次・月次の進捗確認

### 売上の分配（アフィリエイト報酬）

受講者が商材を販売した場合、その売上は講師の方と受講者で分ける。受講者の取り分（アフィリエイト報酬）は成約額の20%（提案）で、残りが講師の方の取り分とする。分け方の割合は確定ではなく、お金の受け渡しの経路も未確定。多段階（ダウンライン型）の報酬は設けず、単層のみとする。

## 収支・コストの見込み

- 月額収入：ライト5,500円・プロ11,000円（いずれも税込・提案）。月額料金は講師の方が受け取る形を考えている
- 運営側の収益：教材・仕組みを提供する運営への対価の有無・額は未確定。決済手数料の扱いとあわせて、現時点では運営側の収支は試算できない
- 主なコスト：運営による教材・申込み・決済の仕組みの提供、講師の方の稼働時間（1on1・オンラインミーティング・チャット対応・添削対応）
- **懸念事項**：プロプラン（週1回30分の個別対応＋チャット対応＋添削）は、月換算で相応の稼働時間がかかる一方、月額11,000円という価格設定では、講師の方1人あたりの採算が厳しくなる可能性がある。試験運用で実際の工数を計測し、価格・提供内容（添削範囲・稼働人数の上限）を見直す前提で進める
- 商材は講師の方がお持ちのもので、内容・価格は講師の方との合意で決める。売上の分配割合などが未確定のため、アフィリエイト報酬を含めた正確な収支試算は、条件の合意後にあらためて行う

## スケジュール（概算）

1. 講師の方の選定と条件の合意（売上の分配割合、各お金の経路、運営への対価）
2. 申込み導線・利用規約の整備
3. 試験運用（少人数）で工数・反応を計測
4. 本格募集開始

具体的な時期は未定（講師の方との条件合意の状況に依存）。

## リスクと対応

- **採算性のリスク**：上記「収支・コストの見込み」の通り、プロプランの価格と講師の方の稼働コストのバランスに懸念がある。試験運用後に価格・提供内容を見直す
- **商材の需要が未検証であることのリスク**：商材は講師の方がお持ちのものだが、受講者が実際に販売できるかという需要は未検証。試験運用で反応を確認してから本格投入する
- **講師の方との条件が未合意であることのリスク**：売上の分配割合、各お金の経路、運営への対価が未確定。条件を合意してから試験運用に入る
- **解約・返金ルールが未整備であることのリスク**：既存の利用規約（`legal/利用規約_案.md`）との整合を取った上で、販売する権利の扱い（解約後の取り扱い等）を明文化する必要がある
