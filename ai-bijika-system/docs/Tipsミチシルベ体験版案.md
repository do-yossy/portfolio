# Tipsミチシルベ体験版案：GATE1・3だけを7日間、実際に動かしてみる

## 背景

「ツールそのものを販売できるか」という質問を受けた。ミチシルベ本編（`ai-bijika-system`、500,000円）は既に実在する稼働中のWebアプリであり、購入時のメールアドレスを`/admin/licenses`に登録すると自動的に使えるようになる仕組みが既にある。本編をそのまま低価格で売ると500,000円商品の価値を大きく下げてしまうため、「範囲・期間限定の体験版をTipsで販売する（本編への橋渡しとして機能させる）」という方向で運営者の承認を得た。

承認を受けて、`ai-bijika-system/db.js`・`server.js`に、期間（日数）・アクセス可能GATEを限定できる体験版ライセンスの仕組みを実装した（既存の本編購入者には一切影響しない。詳細はREADME.mdの「ライセンス管理」節、および同コミットのコミットメッセージ参照）。本書は、その体験版を実際にTipsで売るための出品文章・運用手順をまとめたもの。

## 設計方針

- **既存のTips文章商品群（300円〜2,980円＋単品680円×7本）との違い**：既存商品はいずれも「読んで、自分でAIに貼り付ける」テキストのガイド・プロンプト集である。本商品は唯一、実際にブラウザで動くWebアプリ（ミチシルベ）そのもの（進捗管理・GATE判定の記録・AIの実行ボタン等）を、期間・範囲を限定して提供する点が異なる。テキストで学ぶ商品群と競合しない、別の価値を提供する
- **価格を9,800円にした理由**：既存のTipsコンテンツの最高額（2,980円）よりかなり高いが、「文章ではなく実際に動くツールを体験できる」「本編500,000円の意思決定材料になる」という価値から、意図的にTipsコンテンツ群から独立した価格帯にした。500,000円の本編と比べれば十分に低価格で、かつTipsの中では高価格帯という位置づけにすることで、本気度の高い見込み客を絞り込む
- **GATE1（商品選定）・GATE3（商品コンセプト）に絞った理由**：本編10GATEのうち、外部の補足資料を必要とせず単体で完結しているGATEを選んだ。これにより、体験版だけでも「経験の中から商品アイデアを選ぶ→誰のどんな悩みを解決する商品かを固める」という一連の流れを、途中で説明が欠けることなく完結して体験できる
- **期間を7日間にした理由**：じっくり試せる期間を確保しつつ、「期限を決めて今すぐ行動してもらう」という後押しにもなる長さとした
- **ライセンス発行方法**：既存の本編と同じ、購入時のメールアドレスを運営者が`/admin/licenses`で手動登録する方式をそのまま使う。コードやパスワードの発行・送付は発生しない

## 前提・確認事項

- 価格9,800円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 体験版の期間・対象GATEは、`db.js`/`server.js`に実装した汎用の仕組み（`allowed_emails.trial_expires_days`・`trial_gates`）で設定している。運営者の判断で、別の期間・GATE組み合わせに変更して別の体験版商品として出品することもできる
- AI利用料は購入者自身のAPIキーで負担する方式（本編と同じ）。運営側に追加コストは発生しない
- 体験の結果、商品化・収益化を保証するものではない

## 出品〜運用の流れ（運営者向け。他のTips商品と違い、購入ごとに手動でのライセンス登録が必要）

1. 上記①をTipsの出品ページ作成画面にそのまま貼り付け、価格9,800円で出品する
2. 購入が入ったら、上記②の本文をTipsの「購入後に表示するコンテンツ」欄に設定する
3. 購入者から`/contact`経由でメールアドレスの連絡が来たら、`https://aipro.social-quality.com/admin/licenses`の「メールアドレスを許可する」フォームに、そのメールアドレス・メモ（例：Tips体験版・購入日）・「体験版の期間（日数）」に`7`・「体験版でアクセスできるGATE」に`1,3`を入力して登録する
4. 登録後、購入者へ（教えてもらったメールアドレス宛に直接メールで、またはTipsのメッセージ機能で）「登録が完了しました。https://aipro.social-quality.com/signup からご登録ください」と案内する
5. 7日間経過後は自動的に利用できなくなるため、運営者側の追加作業は不要。延長・本編移行の問い合わせが来たら`docs/商談トークスクリプト.md`の流れで対応する
