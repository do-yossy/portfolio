# MLM従事者に刺さるSNS投稿文案：Threads等での定期発信用

## 背景

「MLMやってる人に刺さる文章を作って」という指示を受けて作成した。`docs/SNS自動投稿セット販売戦略案.md`の「①新規の見込み客との接点の作り方」で触れた「Threadsでの定期発信」の具体的な投稿文にあたる。既存の文面（`docs/アポミー再アプローチ文面案.md`・`docs/SNS自動投稿ツールアプローチ文面案.md`）が「既に接点がある相手へのDM」だったのに対し、本書は**不特定多数が見るSNS上の投稿**であり、特定の相手に向けた勧誘・営業メッセージではない。

## 設計方針

- **「刺さる」の中身＝相手が実際に抱えていそうな悩みへの共感**：ネットワークビジネスをしている人が実際に直面しやすい悩み（声かけの心理的ハードル、「怪しい」と見られることへの不安、SNS投稿のネタ切れ、本業・家庭との両立の忙しさ、誠実にやりたいのに勧誘っぽくなってしまうジレンマ）に共感する内容にした。これらは一般に知られた傾向であり、実在する特定の個人の発言・証言ではない
- **実績・数字・お客様の声は一切含めない**：`CLAUDE.md`の絶対ルールに従い、成約率・収入額・「〇〇さんの声」のような実在性を装う引用は含めていない
- **ほとんどの投稿は商品・ツールに触れない**：7本のうち5本は純粋に「あるある」への共感のみで完結させ、売り込み色を出さない。ツールへの言及は2本のみに留め、それも「気になる人には」という弱い導線に留めた
- **新規勧誘そのものではない**：本書の投稿は、見ている人に何かへの入会・購入を呼びかけるものではなく、ネットワークビジネスを既にしている人の悩みに共感する内容に限定しているため、特定商取引法上の連鎖販売取引の勧誘には該当しないと整理している
- **文字数はThreadsの上限（500字）を目安に収めた**：`/tools/jidoutoukou`での投稿を想定し、1本ずつ単独の投稿として使える長さにした

## 前提・確認事項

- 実在の収入額・成約率・お客様の声等の数字は一切含めていない
- 投稿頻度・組み合わせ方に決まりは無い。`docs/SNS自動投稿セット販売戦略案.md`の運用に沿って、定期的に（例：週1〜2本）投稿することを想定
- `/tools/jidoutoukou`（または`/tools/jidoutoukou-gift`）でそのまま投稿本文として使える

## ①声かけの心理的ハードルへの共感

```
ネットワークビジネスの「声かけ」が一番しんどい、という人は多いと思う。

断られたらどうしよう、嫌な顔をされたら、と考えるだけで一日が終わる日もある。

でも実は、最初に「誰で、何の話で、なぜ連絡しているか」をちゃんと伝えるだけで、相手の身構え方はだいぶ変わる。遠回りに見えて、一番早い道だったりする。
```

## ②「怪しい」と見られることへの不安

```
ネットワークビジネスをしてるというだけで「怪しい」と思われがち。

でも実際は、法律でルールが決まっている合法な取引のかたち。胡散臭く見えるとしたら、たぶん中身より「伝え方」の問題であることが多い。

隠さず、誠実に伝えれば、ちゃんと伝わる人には伝わる。
```

## ③SNS投稿のネタ切れ

```
SNSで発信を続けようと思っても、「今日は何を書こう」で手が止まる日、ありませんか。

完璧な1投稿より、まず出し続けることの方が大事だったりする。ネタを考える時間そのものを減らす工夫、もっとあっていいと思ってます。
```

## ④本業・家庭との両立の忙しさ

```
ネットワークビジネスを本業や家庭と両立してる人、本当に尊敬します。

隙間時間で声かけの文章を考えて、投稿のネタも考えて…正直、時間が全然足りない。

「考える時間」を少し減らせるだけで、続けやすさはだいぶ変わる気がしてます。
```

## ⑤誠実にやりたいのに勧誘っぽくなるジレンマ

```
誘ってる感は出したくないけど、きちんと伝えるべきことは伝えたい。

このバランス、地味に難しい。

結局、最初に正直に「これは何の話か」を伝えるのが、遠回りなようで一番誠実だし、後から気まずくならない方法な気がしてます。
```

## ⑥継続の孤独感

```
ネットワークビジネスって、一人で黙々と続けてる時間が長い。

うまくいかない日も、誰かに愚痴れないまま次の日を迎えることも多いんじゃないかと思う。

同じように頑張ってる人がいる、というだけで少し楽になることもある。
```

## ⑦ゆるい導線あり（ツールへの言及）

```
「声かけの文章を考えるのに毎回時間がかかる」「複数のSNSに同じ内容を1つずつ投稿するのが地味に大変」

そんな悩みを減らせるツールを作りました。法令上の開示義務にも対応した文章を、場面を選んで入力するだけでAIが作ってくれます。

気になる方はDMください。
```

## 運用の流れ（運営者向け）

1. 上記①〜⑦から、その時の気分・タイミングに合わせて1本を選ぶ（毎回⑦を使わない。売り込み色が強くならないよう①〜⑥を中心にする）
2. `/tools/jidoutoukou`（または無料プレゼント先には`/tools/jidoutoukou-gift`）の投稿本文欄にそのまま貼り付け、Threads等へ投稿する
3. 反応があった相手には、`docs/アポミー再アプローチ文面案.md`・`docs/SNS自動投稿ツールアプローチ文面案.md`の個別アプローチ文面、または`docs/商談トークスクリプト.md`の流れで対応する
