# Tips業務効率化ツール案：副業の問い合わせ対応 即レス文例集

## 背景

「購入したら商品を使えるようにするのがよい」「例えば何か業務効率を上げる為のツールなど」「副業をする人にとってメリットがあるもの」という一連の依頼を受けて作成。

既存の商品（300円・980円・1,480円）は、いずれも「自分の経験を言葉にする」「商品を考える・出品する」という、商品を**準備する**段階を助けるものだった。本商品は視点を変え、副業が実際に**動き出した後**に繰り返し使える、問い合わせ対応の文例集（ツール）にした。穴埋めではなく、名前や日時など最小限の書き換えだけで即座に送れる、完成済みの文面を揃えている。

## 設計方針

- **「ツール」にした理由**：既存商品は主に「読む」「AIに聞く」「埋める」ものだったのに対し、本商品は「繰り返し参照して使う」実用ツールとして設計した。副業の問い合わせ対応は、多くの人が実際につまずくポイント（`docs/商品アイデアの参考事例.md`等でも、仕組み作り以降の運用面の悩みが示唆されている）であり、業務効率に直結する
- **購入後すぐ使える設計にした理由**：他の商品は経験の言語化やAIとのやり取りが前提だが、本商品は名前・日時等の最小限の書き換えだけで送信できる完成文面にし、「購入したらすぐ使える」という要望に応えた
- **価格を480円にした理由**：AIプロンプトや連動システムを伴わない、シンプルな文例集のため、既存の300円商品よりは内容量が多いが、980円・1,480円の商品よりは手軽な価格帯とした

## 前提・確認事項

- 価格480円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 文例はすべて一般的な場面を想定したオリジナル文章であり、実在のやりとり・特定のお客様の事例ではない
- 文例はあくまで型であり、実際の状況に応じて内容を調整する必要がある旨を明記している
- 法律的な助言（契約・返金等のトラブル対応の正式な文言等）を目的としたものではなく、日常的なやりとりの文例である旨も明記している

## ①Tips出品ページ用の文章

```
タイトル：副業の問い合わせ対応 即レス文例集｜8つの場面でそのまま使える
価格：480円（税込）

「お客様にどう返信すればいいか、毎回悩んでしまう」
「対応に時間がかかって、本業や作業の時間が削られる」
そんな方のための、副業でよくある8つの場面の返信文例集です。

■ こんな方向けです
・副業を始めたばかりで、お客様対応に慣れていない
・毎回の返信を考えるのに時間がかかっている
・失礼にならない言い方に自信が持てない

■ これは何か
問い合わせから対応後のフォローまで、副業でよくある8つの場面（初回返信・内容説明・予約確定・日程変更・お礼/感想依頼・リピート案内・価格相談・お断り）の返信文例です。名前や日時など最小限の書き換えだけで、そのまま送信できます。

■ お伝えしておきたいこと
文例は一般的な場面を想定したオリジナルの型であり、実際の状況に応じて内容を調整してお使いください。契約・返金トラブル等の法律的な対応を目的としたものではありません。
```

## ②購入後に届く本文

```
【副業の問い合わせ対応 即レス文例集】

ご購入ありがとうございます。

以下の8つは、副業でよくある場面の返信文例です。
【　】の部分だけご自身の内容に書き換えれば、そのまま使えます。
内容はあくまで型です。実際の状況に合わせて調整してお使いください。

────────────────

①問い合わせへの初回返信

「【お客様のお名前】様

このたびはお問い合わせいただき、ありがとうございます。
【問い合わせ内容】についてですね。【期限】までに詳細をご案内いたします。

ご不明な点がございましたら、お気軽にご返信ください。
よろしくお願いいたします。」

────────────────

②内容・料金の説明

「【お客様のお名前】様

お問い合わせいただいた件について、ご案内いたします。

【内容】：
【料金】：
【所要時間】：

ご検討のほど、よろしくお願いいたします。」

────────────────

③予約・日程の確定連絡

「【お客様のお名前】様

ご予約ありがとうございます。以下の内容で確定いたしました。

【日時】：
【内容】：
【場所・方法】：

当日はどうぞよろしくお願いいたします。」

────────────────

④キャンセル・日程変更への対応

「【お客様のお名前】様

ご連絡ありがとうございます。日程変更の件、承知いたしました。

改めて、ご都合の良い日時を2〜3件ほど教えていただけますでしょうか。
よろしくお願いいたします。」

────────────────

⑤対応後のお礼・感想のお願い

「【お客様のお名前】様

本日はありがとうございました。
少しでもお役に立てていましたら嬉しいです。

もしよろしければ、感想を一言いただけると今後の励みになります。
今後ともよろしくお願いいたします。」

────────────────

⑥リピート・次回利用のご案内

「【お客様のお名前】様

その後、いかがお過ごしでしょうか。
またお手伝いできることがございましたら、いつでもお気軽にご連絡ください。」

────────────────

⑦価格のご相談への返信（お断りする場合）

「【お客様のお名前】様

ご相談ありがとうございます。
申し訳ございませんが、現在の料金は内容に見合った形で設定しており、一律とさせていただいております。
もし【条件を変えた代替案】でしたら、別のご案内ができるかもしれません。」

────────────────

⑧対応できないご依頼をお断りする返信

「【お客様のお名前】様

お問い合わせありがとうございます。
申し訳ございませんが、今回のご依頼内容は対応範囲外のため、お力になれそうにありません。
お役に立てず申し訳ございません。」

────────────────

【使い方のコツ】

・そのまま使わず、普段の自分の話し方に近い言葉に少し調整すると、より自然になります
・特に⑦⑧のような断りの文面は、変に長く説明しようとせず、短く丁寧に伝える方が角が立ちにくいです

【次の一歩】

自分の商品に合わせた対応フローを、もう少し詳しく相談したい方は、お気軽にご連絡ください。
https://aipro.social-quality.com/contact
```

## 出品〜運用の流れ

1. 上記①をTipsの出品ページ作成画面にそのまま貼り付け、価格480円で出品する
2. 購入が入ったら、上記②の本文をTipsの「購入後に表示するコンテンツ」欄に設定する
3. 問い合わせが来たら、`docs/商談トークスクリプト.md`の流れで対応する
