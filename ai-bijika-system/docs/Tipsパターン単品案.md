# Tipsパターン単品案：7パターンを1つずつ単品で購入できる商品にする

## 背景

「パターン１～７までをひとつずつマネタイズできるじょうたいにして」という指示を受けて作成。既存の`docs/Tips中価格帯商品案.md`（2,980円）は、7つのパターンを1つの実践ガイドにまとめた「まとめ買い」型の商品だった。本書では、その7つのパターンそれぞれを**単品で購入できる、独立したTips商品**として切り出した。

## 設計方針

- **2,980円の実践ガイドは廃止しない**：単品7本を揃えた上でも、2,980円の実践ガイドはそのまま「7パターンまとめ買い」の商品として並行して出品を続ける。単品7本をすべて買うと680円×7＝4,760円になり、2,980円の方が約37%安いため、2つ以上のパターンに興味を持った人には自然に2,980円へ案内できる（本書の各単品①②には、2,980円をすでに購入済みの方への重複購入の注意書きを入れている。逆方向の案内〔2,980円側の出品ページ・購入後本文に単品の存在を追記するか〕は運営者の判断に委ねており、本書執筆時点では未反映。詳細は本書末尾「出品〜運用の流れ」3.を参照）
- **単品の価格を680円にした理由**：既存の480円商品（4つの場面で使えるプロンプト集）より、1つのビジネスモデルを最初から最後まで実践できる内容量が多い。一方、980円商品（4ステップが連動するミニシステム）は準備・出品フェーズを一から体験する設計で、本書（すでに決まった1パターンを深く実践する内容）とは役割が異なる。980円よりは単一パターンに絞られている分、680円という価格帯にした
- **内容が2,980円と重複することについて**：各単品は、2,980円の実践ガイドの該当パターンと同じ内容（ステップ・考え方）を使っている。これは他の商品間で問題視されていた「意図しない重複」とは異なり、「同じ内容を単品でも買えるようにしてほしい」という今回の依頼そのものに基づく、意図的な重複である。単品であることが分かるよう、各単品の冒頭に短い導入を追加し、他のパターンやまとめ買いへの案内も明記している
- **パターン1のみ、無料コンテンツ⑥との関係を明記**：パターン1（AI×診断・鑑定系サービス）は、無料コンテンツ⑥「知識ゼロから始める『AI診断サービス』の作り方」の応用編という位置づけ。単品で購入した方が⑥を読んでいなくても迷わないよう、⑥の基本4ステップを簡潔に引用した上で、応用の3つの視点を紹介する構成にした

## 前提・確認事項

- 価格680円（7単品共通）は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 各単品の内容は`docs/Tips中価格帯商品案.md`の該当パターンをもとにしており、情報源の扱い（個人を特定できる経歴・年齢・収入額・プラットフォーム上のハンドル等を外し、再現可能な方法のみを一般化して抽出する方針）も同じ方針を引き継いでいる。情報源は`docs/商品アイデアの参考事例.md`の事例1〜7（運営者が実際に共有したYouTube動画をもとに、既に社内で審査・記録済みの実例資料）
- 実在の収入・成果を示す数字は一切含めておらず、同じ結果を保証するものではない
- パターン4（事例4）は他のパターンより性質が異なり難易度も高いため、`docs/Tips中価格帯商品案.md`と同様に単品ページ内でも「応用編」として明示している
