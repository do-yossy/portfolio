# Tips窓口商品案：商品のタネ診断シート

## 背景

運営者が既にTips（tips.jp）のアカウントを持っており、「そこでマネタイズまでもっていって」という依頼があった。`docs/販売手法案_チャネル別パターン.md`の「プラットフォーム出品型」「Tipsでの実践プラン」で既に方針化していた、低価格の窓口商品をTipsに出品し、購入者をオンライン相談（`商談トークスクリプト.md`）経由でミチシルベ本体（500,000円）に案内する流れを、実際に出品できる完成形まで仕上げたもの。

Tips上での購入・決済・ダウンロード提供の仕組みはTips側に任せる前提（運営者が実際にTipsの出品画面で、以下の文章をコピーして登録する）。

## 出品にあたっての前提・確認事項（未確認のまま進めている点）

- **価格は500円（税込）を提案**している。Tipsでの低価格帯コンテンツの相場観に基づく提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- **Tips側の手数料率・出品規約は未確認**（`販売手法案_チャネル別パターン.md`でも既に「要確認」として記録されている論点）。出品前にTips側の規約・手数料を確認することを推奨する
- 本書の診断シートの内容は、このセッションで新規に作成したオリジナル文章であり、実在の購入者の声・実績数字は一切含めていない
- **【再訂正】Tipsの問い合わせ手段について、2段階の調査で分かったことと、まだ確認できていないこと**：
  1. 「メッセージ機能」（[Tips公式のお知らせ](https://tips.jp/u/tipsinfo/a/PiR4HQeY)、2021年公開）は出品者→購入者の一方向のみで、購入者からの返信・連絡はできない。これは確認できた事実
  2. その後、Tipsには別に「個別チャット」（[Tips公式のお知らせ](https://tips.jp/u/tipsinfo/a/8fwaGcAT)、2022年公開）という機能があり、公式の説明文では「ライターと購入者との間で直接メッセージのやりとりができる機能」「有料コンテンツを購入することで利用できる」とされている。文言上は双方向に読め、もしこれが実際に機能していれば、購入者側からも出品者へ連絡できる可能性がある
  3. ただし②は運営者自身のTipsアカウント上での動作を確認できておらず、**出品ページ上に実際に個別チャットへの導線が表示されているか、購入者側からの送信が実際にできるかは未確認**。初版（「購入者がメッセージ機能で連絡する」という前提）・再訂正版（「購入者からは一切連絡できない」という前提）のいずれも、確証のないまま断定していた可能性がある
  
  このため、本書の案内文では確実に機能する`/contact`フォーム（ログイン不要で送信可能）を問い合わせ先として使う。**運営者には、Tipsの出品者ダッシュボードで「個別チャット」が自分の出品ページに表示されているか一度確認してもらいたい**。表示されている場合は、`/contact`と個別チャットを併記する案内文に差し替えることもできる。既にTips・Brainへ出品済みの文面（「こちらのメッセージ機能から」という初版の案内）は、個別チャットの実態が確認できるまでの暫定措置として、ひとまず本書の`/contact`版に貼り替えることを推奨する

## ①Tips出品ページ用の文章（購入前に表示する部分）

### タイトル

```
自分の経験、実は商品になる？3〜5分でわかる「商品のタネ」診断シート
```

### 価格

500円（税込）

### 本文（紹介文）

```
「自分には人に売れるようなものなんてない」
そう思っている方にこそ、試してほしい診断シートです。

■ こんな方向けです
・AIを使って何か商品を作ってみたいけど、何を商品にすればいいか分からない
・副業や自分の商品づくりに興味はあるが、最初の一歩が踏み出せない
・自分の経験に価値があるなんて思えない

■ これは何か
5つの質問に答えるだけで、あなたの中に眠っている「商品のタネ」（商品化できそうな経験・知識）を見つけるための診断シートです。むずかしい知識は不要で、今のあなたの経験だけで答えられます。

■ 所要時間
3〜5分

■ 購入後にお届けするもの
5つの質問と、答えを見てタネがあるかどうかを自分で振り返るためのガイド（テキスト）

■ お伝えしておきたいこと
この診断は「商品のタネがありそうか」を一緒に確認するためのものです。診断の結果が、実際に売れることや収入を保証するものではありません。

もっと本格的に、見つけた経験を実際の商品にして販売まで進めたい方には、無料のオンライン相談もご案内しています（購入後にご案内します）。
```

## ②購入後に届く本文（診断シートの中身）

```
【商品のタネ診断シート】

ご購入ありがとうございます。
以下の5つの質問に、思いついたことをそのまま書き出してみてください。
うまく書こうとしなくて大丈夫です。短い言葉でOKです。

────────────────

Q1. 今の仕事や日々の生活の中で、「これは人より詳しいかも」と思うことは何ですか？
（例：経理の仕事を5年やっている、毎日お弁当を作っている、など）

→ 

Q2. 誰かに「それ教えて」「それ手伝って」と頼まれたことはありますか？
（仕事でもプライベートでも。小さなことでOKです）

→ 

Q3. 昔すごく苦労したけど、今思えば「コツ」が分かることはありますか？
（例：転職活動、子育て、資格の勉強、人間関係など）

→ 

Q4. Q1〜Q3で書いたことを、もし誰かに伝えるとしたら、どんな人の役に立ちそうですか？
（例：「経理の知識」→「副業を始めたいけどお金の管理が苦手な人」）

→ 

Q5. Q1〜Q4を振り返って、あなたの「得意」や「人に話せる経験」を一言でまとめると？

→ 

────────────────

【診断の見方】

Q1〜Q3のうち、2つ以上に具体的に書けた方は、商品のタネがすでにある可能性が高いです。
「具体的に書けた」というのは、立派な実績でなくても大丈夫です。あなた自身の実体験であれば十分です。

1つしか書けなかった、またはどれも漠然としている場合も、心配はいりません。
多くの人は、最初は「こんなの誰の役にも立たない」と思うところからスタートします。質問の角度を変えて何度も考え直すことで、タネが見つかることはよくあります。

【次の一歩】

ここで見つけたタネを、実際に「売れる商品」の形にして、販売まで進める手順と、商品化に使えるAIプロンプトをセットにした仕組み（ミチシルベ）をご用意しています。

もう少し詳しく話を聞いてみたい方は、無料のオンライン相談も行っています。
ご希望の方は、下記からお問い合わせください。
https://aipro.social-quality.com/contact
```

## 出品〜運用の流れ

1. 上記①をTipsの出品ページ作成画面にそのまま貼り付け、価格500円で出品する
2. 購入が入ったら、上記②の本文をTipsの「購入後に表示するコンテンツ」欄に設定する（出品時にまとめて登録できる場合は事前設定でよい）
3. 購入者からオンライン相談の希望が来たら、`docs/商談トークスクリプト.md`の流れで対応する
4. 出品後の反応（閲覧数・購入数・相談への転換数）は、`seeds/prompts.js` No.23・24と同じ考え方（追うべき数字を決め、実際の数字を見て改善する）で運営者自身が確認・記録するとよい

## ③ハッシュタグ（10個）

```
#商品化 #副業 #AI副業 #自分の経験を商品に #商品のタネ #スキルシェア #経験を活かす #AI活用 #自己診断 #在宅ワーク
```

収入・収益を断定的に想起させる語（「稼げる」等）は含めていない。Tips側のタグ上限・形式（スペース区切り／カンマ区切り等）に合わせて調整すること。

## ④サムネイル画像

`lib/ui.js`の配色（Midnight & Champagne：紺`#0E1A22`・ゴールドグラデーション）・書体（Shippori Mincho B1 / Cormorant Garamond）・クレスト（星型ロゴ）をそのまま使い、1200×1200pxの正方形サムネイルを作成した（HTML+Chromiumでの描画。AI画像生成ではなく既存デザインシステムをそのまま再利用しているため、文字の誤字・崩れのリスクが無い）。ファイルは運営者に別途送付する。Tips側の推奨サイズと異なる場合は、同じ生成方法で再書き出しできる。
