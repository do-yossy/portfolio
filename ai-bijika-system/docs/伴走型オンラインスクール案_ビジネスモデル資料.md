# 伴走型オンラインスクール ビジネスモデル（講師の方向け）

## 一言でいうと

講師が「SNS運用・集客」を受講者に教え、受講者は講師の商材をSNSで販売する。講師は、その商材の売上と、受講者の月額料金からの取り分を得る、という仕組みです。

## 登場人物

- **運営**：教材（AI×SNS集客を学べる全10ゲート・AIプロンプト34本）と、申込み・決済などの仕組みを用意する
- **講師**：受講者にSNS運用・集客を教え、ご自身の商材を受講者に渡す
- **受講者**：月額料金を払って学び、講師の商材をSNSで紹介・販売する
- **お客様**：受講者の発信を見て、商材を購入する人

## お金とサービスの流れ

1. **受講者 → 運営**：月額料金を払う（ライト5,500円／プロ11,000円・いずれも税込・提案）
2. **運営 → 講師**：月額料金の一部を、講師の取り分としてお渡しする（少額。率・金額は未確定）
3. **講師 → 受講者**：SNS運用・集客のレクチャーを行い、ご自身の商材を渡して販売できるようにする
4. **受講者 → お客様**：SNSで発信し、商材を紹介・販売する
5. **お客様 → 講師**：商材の代金を支払う
6. **講師 → 受講者**：売れた分の成果報酬（アフィリエイト）として、成約額の20%（提案）を受講者に払う。この報酬を誰がどう負担するかは、講師の商材の価格や利益に関わるため、ご相談のうえ決めたい

## 講師にとっての収入のもと

- **講師の商材の売上**：受講者が商材を販売できた場合に生じる（受講者がどれだけ販売できるかは、確約できるものではありません）
- **月額（サブスク）の取り分**：少額ですが、受講者が払う月額料金から得られる形を考えています（条件は未確定）

## 講師にお願いすること

**主にやっていただきたいのは、SNSの運用・集客のレクチャーです。** アカウントの土台づくり、投稿づくり、商材の売り方、運用・改善の4段階で、受講者を支えていただきます。

| | ライト | プロ |
|---|---|---|
| 面談 | 月1回・60分（合同グループQ&A） | 週1回・30分の個別1on1 |
| その他の対応 | なし | チャット質問し放題、SNS投稿文の個別添削 |

プロは個別対応の分、工数がかかります。まず少人数で試験運用し、実際の時間を測ったうえで、担当人数や条件を決めます。

## まだ決まっていないこと

- 月額料金からの講師の取り分（率・金額）
- 受講者への成果報酬（成約額の20%・提案）の負担のしかた
- 講師の商材の受講者への渡し方
- 一人で担当できる受講者の人数
- 試験運用の開始時期・人数
