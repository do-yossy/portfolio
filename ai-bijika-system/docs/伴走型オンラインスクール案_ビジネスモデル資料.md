# 伴走型オンラインスクール ビジネスモデル（講師の方向け）

## 一言でいうと

講師が「SNS運用・集客」を受講者に教え、受講者は講師の商材をSNSで販売する。講師は、受講者が払う月額料金の全額と、受講者が販売した商材の売上のうち講師の取り分を得る形を考えています（売上は確約できるものではなく、分け方の割合は未確定です）。

## 登場人物

- **運営**：教材（AI×SNS集客を学べる全10ゲート・AIプロンプト34本）と、申込み・決済などの仕組みを用意する
- **講師**：受講者にSNS運用・集客を教え、ご自身の商材を受講者に渡す
- **受講者**：月額料金を払って学び、講師の商材をSNSで紹介・販売する
- **お客様**：受講者の発信を見て、商材を購入する人

## お金とサービスの流れ

1. **受講者 → 講師**：月額料金を払う（ライト5,500円／プロ11,000円・いずれも税込・提案）。講師が全額を受け取る形を考えています
2. **運営 → 講師**：教材と、申込み・決済などの仕組みを提供する
3. **講師 → 受講者**：SNS運用・集客のレクチャーを行い、ご自身の商材を渡して販売できるようにする
4. **受講者 → お客様**：SNSで発信し、商材を紹介・販売する
5. **お客様 → 講師**：商材の代金を支払う（受け取りの経路は未確定）
6. **売上を講師と受講者で分ける**：売れた商材の売上は、講師と受講者で分ける形を考えています。受講者の取り分（成果報酬・アフィリエイト）は成約額の20%を提案していて、残りが講師の取り分です（分け方の割合は確定ではなく、支払いの経路は未確定です）

## 講師にとっての収入のもと

- **月額（サブスク）料金の全額**：受講者が払う月額料金を、講師が受け取る形を考えています（金額は受講者の人数とプランによって変わります）
- **受講者が売った商材の売上の一部**：受講者が商材を販売できた場合に、その売上を講師と受講者で分け、講師は自分の取り分を受け取る形を考えています（受講者がどれだけ販売できるかは、確約できるものではありません）

## 講師にお願いすること

**主にやっていただきたいのは、SNSの運用・集客のレクチャーです。** アカウントの土台づくり、投稿づくり、商材の売り方、運用・改善の4段階で、受講者を支えていただきます。

| | ライト | プロ |
|---|---|---|
| 面談 | 月1回・60分（合同グループQ&A） | 週1回・30分の個別1on1 |
| その他の対応 | なし | チャット質問し放題、SNS投稿文の個別添削 |

プロは個別対応の分、工数がかかります。まず少人数で試験運用し、実際の時間を測ったうえで、担当人数や条件を決めます。

## まだ決まっていないこと

- 商材の売上を講師と受講者で分ける割合（受講者の取り分は成約額の20%を提案）
- 月額料金の入金経路、商材の代金の受け取り経路、受講者の取り分の支払い経路
- 教材・仕組みを提供する運営への対価の有無
- 講師の商材の受講者への渡し方
- 一人で担当できる受講者の人数
- 試験運用の開始時期・人数
