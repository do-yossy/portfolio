# Tips低価格商品案：AIプロンプト3つで作る、あなたの「経験紹介文」

## 背景

「購入者を作る為に商品を作って。売れそうな商品にして」という依頼を受けて作成。

これまでの無料コンテンツ①〜⑥・診断シート（`docs/Tips窓口商品案.md`での提案価格は500円だが、運営者からの報告により、2026-10-05時点ではすべて無料で出品されていることを確認している。この無料化がスプリント期間中の一時的な運用か、恒久的な変更かは本書執筆時点で未確認）は、Tips上での閲覧自体は発生しているが（運営者から共有された実データ、2026-10-05時点：PV最大38・ユーザー最大24）、問い合わせ（メッセージ）は0件という状況だった（いずれも運営者からの報告に基づく）。これは主に「知人への声かけがまだ実行段階」であることが原因と考えられるが、それとは別に、**見ず知らずの相手（Tips上の閲覧者）が実際に対価を払って「購入者」になる経路が、現状まったく無い**（すべて0円のため）という点も課題として挙がった。

本商品は、知人への声かけとは独立に、Tips上の見知らぬ閲覧者でも購入しやすい、低価格（300円）・即完結型の商品として設計した。「ビジネス初心者に向けて」という指定を受け、対象を副業・商品販売の経験が無い層に絞り込んでいる。

## 設計方針（なぜこの内容・価格にしたか）

- **価格を300円にした理由**：既存の診断シート（本来500円）より低く設定し、購入の心理的ハードルを最小化した。見ず知らずの相手に対しては、価格の低さが最も確実に効く変数であるため
- **「診断・自己理解」ではなく「具体的な成果物」にした理由**：①〜⑥・診断シートは、いずれも「自分の経験を振り返る」「気づく」というプロセス型の内容。本商品は対照的に、入力すればその場で使える文章（自己紹介文等）という**完成品が手に入る**設計にすることで、既存ラインナップとの重複を避け、「今すぐ使えるものが欲しい」という即時的なニーズを狙った
- **「経験紹介文」という切り口にした理由**：既存の無料コンテンツで「自分の経験に価値があるかもしれない」と思った人が、次に直面する壁は「それをどう言葉にすればいいか分からない」という点だと考えられる。診断シート・無料コンテンツの購入者にとって自然な次の一歩になる
- **ビジネス初心者に対象を絞った理由**：`lib/personas.js`の4属性のうち、`docs/販売手法案.md`が優先ターゲットと位置づける「ビジネスもAIもはじめて」「AIは使えるが商品販売ははじめて」の2層を意識し、出品ページ・本文とも「ビジネスの専門知識は不要」「難しい言葉は使わない」ことを明記して、初心者が怖気づかない書き方にした

## 前提・確認事項

- 価格300円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 「売れそうな商品」という依頼に対し、価格を下げる・即完結型にするという方向で応えたが、これはあくまで一つの仮説であり、実際に売れることを保証するものではない
- 本文中の3つのAIプロンプトは、`seeds/prompts.js`の実際の文面を転載したものではなく、本書のために新規に書いたオリジナルの簡易プロンプト

「SNSのプロフィールや自己紹介、何を書けばいいか分からない」
そんなビジネス初心者のための、コピペで使えるAIプロンプト集です。

・副業や商品販売はこれからだけど、まず自分の経験を言葉にしてみたい

■ お伝えしておきたいこと
AIが生成する文章の内容は、入力する情報によって変わります。生成された文章は必ずご自身で読み、事実と異なる部分があれば修正してからお使いください。

## 出品〜運用の流れ

1. 上記①をTipsの出品ページ作成画面にそのまま貼り付け、価格300円で出品する
2. 購入が入ったら、上記②の本文をTipsの「購入後に表示するコンテンツ」欄に設定する
3. 既存の無料コンテンツ（①〜⑥）・診断シートの本文末尾に、「文章にするのが苦手な方には、こちらのプロンプト集（300円）もあります」といった一言を追記すると、既存の閲覧者からの購入導線になりうる（追記するかどうかは運営者の判断。現時点では未反映）
4. 問い合わせが来たら、`docs/商談トークスクリプト.md`の流れで対応する
