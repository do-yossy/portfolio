# Tips集客ツール+SNS自動投稿セット案：ビジネス初心者向けのまとめ買いセット

## 背景

「SNS自動投稿ツールと集客ツールをビジネス初心者とMLMでパートナー募集したい方に販売するためのアプローチテキストと商品を作って」という指示を受け、まず「集客・接客ツール（`/tools/shukyaku`、980円）とSNS自動投稿ツール（`/tools/jidoutoukou`、1,980円）をセットで案内する」という構成で用意した。その後「一つにまとめて販売」という指示を受け、2つを別々に案内するのではなく、**1つのセット商品**として作り直した。

対象は、ビジネス初心者（MLMの既存客対応にもSNS発信にも使える、`/tools/shukyaku`と同じ想定読者）。`docs/SNS自動投稿ツールアプローチ文面案.md`の①アプローチ文面から本商品を案内する。

## 設計方針

- **「セット」の中身**：商品としては1つだが、実体は既存の`/tools/shukyaku`（集客・接客ツール）と新設の`/tools/jidoutoukou`（SNS自動投稿ツール）という、独立した2つのツールへのアクセス権をまとめて案内する形にした。新しいツール・ページを作るのではなく、既存2ツールのパスワードを両方案内する運用にした理由は、(a) 2つのツールは「文章を作る」「SNSへ配信する」という役割が異なり無理に1画面へ統合する必要が無い、(b) `/tools/shukyaku`は既にreviewer合格・監査役承認済みの実装である。一方`/tools/jidoutoukou`はreviewerの条件付き承認（1回目）に留まり、修正コミット`d9167a0`は未再審査・監査役審査も未実施のため、本セット文書とは別に`/tools/jidoutoukou`本体の審査を完結させる必要がある
- **価格を2,480円にした理由**：単体の合計（980円＋1,980円＝2,960円）から、まとめ買い割引として480円を引いた額。ダウンライン拡大セット（下記`Tipsダウンライン拡大+SNS自動投稿セット案.md`）とも同じ480円引きで揃え、割引ロジックを統一した
- **単体商品は残す**：本セットは「2つまとめて欲しい人」向けの新しい選択肢であり、既存の`/tools/shukyaku`単体（980円）・`/tools/jidoutoukou`単体（`docs/TipsSNS自動投稿ツール案.md`、1,980円）の出品は残す。どちらか一方だけで足りる購入者向けの選択肢として維持する

## 前提・確認事項

- 価格2,480円（および単体980円・1,980円）は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 購入後は、`/tools/shukyaku`・`/tools/jidoutoukou`それぞれのパスワードを案内する（2つのツールは別々のログインで、統合アカウントではない）
- `/tools/jidoutoukou`の利用には、購入者自身のポストメッシュアカウント（月額2,200円〜）が別途必要（`docs/TipsSNS自動投稿ツール案.md`と同じ前提）
- AIでの文章生成・下書き作成には、購入者自身のAIプロバイダ（OpenAI・Anthropic）のAPIキーが必要（両ツール共通）
- パスワードは全購入者共通の1つを運用する設計（個別の発行・失効はできない）。既存2ツールと同じ運用

5. 問い合わせが来たら、`docs/商談トークスクリプト.md`の流れで対応する
