# Threads実行用投稿案

## 背景

「スレッズをつかったマネタイズもやって」という依頼を受け、`docs/販売手法案_チャネル別パターン.md`の「実行プラン：最初の2週間（SNS×Tips）」にあった4つの切り口の一行例を、実際にそのまま投稿できる完成形まで展開した。Threads自体は直接の決済の場ではなく、「信頼を作って興味を持ってもらう場所」として、`docs/Tips窓口商品案.md`の診断シート（500円）とLPへの橋渡し役を担う。

実績・具体的な収入額の記載は一切していない（`商談トークスクリプト.md`・`販売手法案_チャネル別パターン.md`と同じ方針）。

## ①プロフィール文（案）

```
経験を商品にして売るための仕組み「ミチシルベ」を作ってます📍
AIプロンプトと10のステップで、自分の経験・知識を形にする手順をまとめています。
まずは3〜5分の診断シートで「商品のタネ」を探してみませんか？（プロフィールのリンクから）
```

※実際の文字数・絵文字の使用可否はThreadsのプロフィール欄の仕様に合わせて調整する。No.19（SNS集客プロンプト）を使えば、AIにこの方向性でさらに複数案を出してもらうこともできる。

## ②投稿本文（8本、そのまま投稿できる文面）

投稿する順番と目安の間隔を添えている。曜日・時刻は指定しない（既存のNo.20の設計方針と同じ）。

### 1本目（投稿初日）・過程の実況型

```
今日はAIに「自分の経験から商品アイデアを30個出して」とお願いしてみた。

出てきた案の中に、自分では思いつかなかった切り口がいくつかあって地味に驚いた。
「これ商品になるんだ」という発見、やってみないと分からないものですね。
```

添付画像：投稿文の要点を「自分の経験から、商品アイデアが30個。」という体言止めの見出しに言い換えた引用風カード（1080×1080px、逐語の引用ではなく要約）。補足文「AIに聞いたら、気づかなかった切り口がいくつか出てきた。」は投稿文の「いくつか」という表現をそのまま使い、誇張方向の言い換えが起きないようにしている。`docs/Tips窓口商品案.md`のサムネイルと同じデザインシステム（`lib/ui.js`の配色・書体・クレスト）をHTML+Chromiumで再利用しており、実在しない実績数値は含まない。画像ファイル自体はリポジトリ外（運営者に送付済み）。2本目以降も、投稿のたびに同じ形式でカードを作れる。

### 2本目（3日後）・過程の実況型

```
AIに自分の経験を聞かれて、仕事・趣味・失敗・成功…と6カテゴリで質問されたんだけど、
「人から相談されたこと」を聞かれて初めて、自分では当たり前すぎて気づいてなかった
得意なことに気づいた。

人に聞かれて初めて分かる「自分の普通」、ありますよね。
```

添付画像：投稿文の文言をそのまま使った引用カード（1080×1080px）。見出し「人に聞かれて初めて分かる『自分の普通』。」は本文末尾の文（末尾の「、ありますよね。」のみ除く）と完全一致。補足文は「仕事・趣味・失敗・成功…と6カテゴリで質問された」を軽く言い換えたもの。

### 3本目（6日後）・つまずきポイント共有型

```
商品化で一番つまずきやすいのは、実は「何を作るか」じゃなくて
「誰の、どんな悩みのためか」を先に決めないこと、という話。

先に悩みを決めてから形を考えると、驚くほど迷わなくなります。
```

添付画像：見出し「先に悩みを決めてから形を考えると、驚くほど迷わなくなります。」は本文末尾の文と完全一致（逐語）。補足文「商品化で一番つまずきやすいのは『誰の、どんな悩みのためか』。」は本文冒頭を要約した言い換え。

### 4本目（9日後）・つまずきポイント共有型

```
AIを使うと商品化のスピードはかなり上がる。
目次を作るのも、文章の下書きも、販売ページの原稿も。

ただ唯一AIが代わりにできないのが「経験そのもの」。
ここだけは、自分にしかない財産だなと思う。
```

添付画像：見出し「AIが代わりにできないのは、『経験そのもの』。」・補足文「ここだけは、自分にしかない財産だと思う。」は、いずれも本文末尾2文の言い換え（「ただ唯一」等の接続語を省略した以外は原文のまま）。

### 5本目（12日後）・問いかけ型

```
もし家にいながらできる副収入があったら、
月にどれくらい増えたら「嬉しいな」と思いますか？

金額は人それぞれだと思うので、よかったらコメントで教えてください。
```

添付画像：見出しは本文の問いかけ文の言い換え（「『嬉しいな』と思いますか？」を「嬉しいですか？」に語尾を簡略化、改行位置も調整）。補足文「金額は人それぞれ。コメントで教えてください。」は本文末尾を短縮した言い換え。金額の具体的な数字はAI側・運営者側のどちらからも提示していない。

### 6本目（15日後）・問いかけ型

```
自分が普通にやってきたことを人に話したら
「それ初めて聞いた」「もっと詳しく知りたい」と言われたこと、ありますか？

それ、実は商品のタネかもしれません。
```

添付画像：見出し「『それ初めて聞いた』と言われたこと、ありますか？」・補足文「それ、実は商品のタネかもしれません。」は、いずれも本文の該当箇所の言い換え（本文冒頭の前置き部分と、2つ目の引用句「『もっと詳しく知りたい』」を省略している。内容を狭める方向の省略であり、誇張ではない）。

### 7本目（18日後）・仕組み紹介型

## ②-2 ためになるTips投稿（5本、副業を探している人向け）

「副業を探している人に対して為になる投稿がいい」という依頼を受けて作成。上記8本が「実況・気づき・問いかけ」型（運営者自身の体験ベース）なのに対し、こちらは最初から独立して読める実用情報型で、5本ともミチシルベの宣伝を目的にしていない（reviewer指摘を受け、ミチシルベへの橋渡し文は含めない方針に統一した）。本数・投稿間隔は上記8本と別枠として扱い、運営者の判断で組み合わせて使う。

### Tips-1：副業選びで最初に決めること

```
副業を探すとき、「何を売るか」から考え始めると迷いやすい。

先に決めるべきは「誰の、どんな悩みを解決するか」。
形（文章・動画・相談・テンプレート…）は、そのあとで選んでも遅くない。
```

### Tips-2：怪しい副業を見分ける3つのサイン

```
副業を探していると、怪しいものも混ざってくる。判断材料の一つとして。

①商品の中身より、人を誘うことばかり強調してくる
②自分が誘った人がさらに人を誘うと、自分にも報酬が入る仕組みになっている
③人を勧誘しないと使えない・稼げない仕組みになっている

どれか一つでも当てはまったら、一度立ち止まって調べた方がいい。
```

### Tips-3：経験がなくても始めやすい副業の考え方

```
「専門知識がないから副業は無理」と思われがちだけど、
今はAIが知識・技術面を補ってくれる時代。

経験や興味があるだけで、診断・鑑定・解釈・相談系のような
サービスも形にできるケースが増えている。

足りないのは知識より、最初の一歩を踏み出す勇気だったりする。
```

### Tips-4：副業が続く人・続かない人の違い

```
副業が続くかどうかは、才能より
「最初から完璧を目指さないこと」で決まることが多い。

一度に全部やろうとせず、今日できることを1つだけ決めて進める。
小さく始めて、反応を見ながら直していく方が、結局早い。
```

### Tips-5：副業の初期費用、実はそんなに高くない

```
副業というと高額な初期投資をイメージされがちだけど、
今は無料〜低価格のAIツールだけで始められるものも多い。

大きな初期費用より、継続するための「仕組み」があるかどうかの方が重要。
```

いずれも実在しない収入額・実績・お客様の声は含めていない。

Tips-2の3つのサインは、`docs/対面営業トークスクリプト.md`で整理したマルチ商法との構造的な違いの3条件に、1つずつ対応させて作り直した（①＝勧誘自体が目的になっていないか／②＝上の人が下の人の勧誘で儲かる仕組みになっていないか／③＝勧誘しないと使えない・稼げない仕組みになっていないか）。特定の企業・商品を名指ししていない。初版は②に「実績を聞いても『人による』としか答えが返ってこないか」を挙げていたが、これはミチシルベ自身の「収入や売上を保証するものではなく、結果は本人の取り組み方次第」という説明方針（`対面営業トークスクリプト.md`）と構造的に似てしまい、自社に跳ね返るリスクがあったため、上の人が下の人の勧誘で儲かる仕組みかという、マルチ商法によりストレートに対応する内容に差し替えた。

Tips-3は`seeds/prompts.js` No.4に追記した「AIが専門知識や技術面を補う」という視点に基づく。

Tips-5は初版でミチシルベ（500,000円）への橋渡し文を含んでいたが、「初期費用は高くない」という文脈で高額商品に言及すると実態と異なる安価な印象を与えかねないため、橋渡し文を削除し、独立した実用情報のみの投稿にした。
