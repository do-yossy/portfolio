# TipsSNS自動投稿ツール案：複数SNSへまとめて投稿・予約配信できるツール

## 背景

「SNS自動投稿ツールと集客ツールをビジネス初心者とMLMでパートナー募集したい方に販売するためのアプローチテキストと商品を作って」という指示を受けて作成した。`/tools/jidoutoukou`（外部サービス[ポストメッシュ](https://post-mesh.com/)のAPIを中継し、複数SNSへの投稿・予約配信ができるツール。詳細は`docs/SNS自動投稿連携案.md`参照）を、Tipsで販売する商品として仕立てたもの。

販売先として想定しているのは、本商品単体の購入者に加え、既存の有料ツール「集客・接客ツール」（`/tools/shukyaku`、980円、ビジネス初心者・MLMの既存客との接客向け）「ダウンライン拡大ツール」（`/tools/kanyu`、1,480円、MLMパートナー募集向け）を既にお持ちの方、またはこれから両方をまとめて検討する方。2者それぞれへの売り込み文面は`docs/SNS自動投稿ツールアプローチ文面案.md`を参照。

## 設計方針

- **価格を1,980円にした理由**：既存の980円（集客・接客ツール）・1,480円（ダウンライン拡大ツール）はいずれもAIへのプロンプトを組み立てるだけのツールだが、本商品は外部サービス（ポストメッシュ）と連携し、実際に複数のSNSへ投稿・予約配信まで行える点で、提供する機能の幅が広い。一方で、購入者側にポストメッシュの月額費用という追加の負担が生じる（後述）ため、既存の最高価格帯（1,480円）より一段上の1,980円とした
- **「ツール単体」で出品した理由**：`/tools/shukyaku`・`/tools/kanyu`とは目的が異なる（文章を作る、ではなく実際に投稿する）独立した機能のため、既存の2商品とバンドルせず単体の商品として出品する。ただし購入導線としては、既存2商品の購入者・検討者への「次の一歩」としての案内（アップセル）を重視し、`docs/SNS自動投稿ツールアプローチ文面案.md`で個別の文面を用意した
- **パスワード認証にした理由**：既存の`/tools/shukyaku`・`/tools/kanyu`と同じ、`makeToolGate()`による依存ゼロの簡易パスワード認証（`JIDOUTOUKOU_TOOL_PASSWORD`環境変数）を採用し、購入確認後に`/contact`経由でパスワードを案内する運用とした。3つのツールのログインはそれぞれ独立している
- **エンゲージメント自動化（いいね・フォロー・コメント自動返信）を含めなかった理由**：SNS各社の規約に抵触しやすく、`CLAUDE.md`の「プラットフォームの自動巡回・自動応募は実装しない」という既存方針と同じ理由で、意図的に対象外とした。詳細は`docs/SNS自動投稿連携案.md`参照

## 前提・確認事項（必ず購入者に伝えるべき点）

- 価格1,980円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- **本ツールの利用には、購入者自身のポストメッシュアカウントが別途必要**（月額2,200円〜、年払いの場合2,000円〜、7日間無料トライアルあり）。SNSアカウントの連携も、ポストメッシュのダッシュボードで購入者自身が行う。運営者側はポストメッシュのアカウント管理に一切関与しない
- 本ツールはテキスト投稿のみに対応している。ポストメッシュの仕様上、テキスト投稿が行えるのはX・Threads・Facebookの3つで、画像・動画が前提のInstagram・TikTok・YouTubeは投稿先の選択肢に含まれない
- AIでの下書き作成機能（任意）を使う場合は、購入者自身のAIプロバイダ（OpenAI・Anthropic）のAPIキーも別途必要（有料・使った分だけの少額課金）。この機能を使わず、自分で書いた文章をそのまま投稿することもできる
- いいね・フォロー・コメント自動返信などのエンゲージメント自動化の機能は含んでいない（意図的な対象外）。投稿の作成・予約配信・ステータス確認のみ
- 投稿内容は、選んだすべてのSNSアカウントに同じ文面で送られる（プラットフォームごとに文面を出し分ける機能は無い）
- 投稿データはこのツール側には保存されず、ポストメッシュ側で管理される。ポストメッシュの契約を解約すると、投稿履歴も参照できなくなる
- **パスワードは全購入者共通の1つを運用する設計**で、購入者ごとの個別発行・失効はできない。漏洩等が疑われる場合は、運営者が環境変数（`JIDOUTOUKOU_TOOL_PASSWORD`）を変更して再デプロイすれば一斉に無効化できる
