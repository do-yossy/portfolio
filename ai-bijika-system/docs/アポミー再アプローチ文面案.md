# アポミー再アプローチ文面案：既存接点（ネットワークビジネス従事者）への再アプローチ

## 背景

「今までにアポミーでやり取りした個人でMLMなどをされている方にアプローチして面談で売る方法は」という相談を受けて作成。既に`docs/TipsMLM集客接客プロンプト案.md`（980円）・`docs/Tips無料コンテンツ案.md`無料コンテンツ⑦・`docs/販売手法案_チャネル別パターン.md`「ネットワークビジネス（MLM）従事者向けの導線」を整備済みだが、これらはTips上での新規の見知らぬ閲覧者向けの導線だった。本書は、**アポミーで過去にやり取りした、すでに関係性がある相手**に対して、同じ導線（無料コンテンツ→オンライン面談→ミチシルベ案内）への再アプローチを行うための文面を扱う。

その後、「プロンプトをあげるのではなくて集客ツールそのものをあげたい」「一旦は相手の方が役に立つと思ってもらう物をプレゼントしたい」という指示を受け、最初に渡す無料の自己紹介文を、コピペ用のプロンプトのテキストから、ログイン不要でその場で結果が出るツール（`/tools/jikoshoukai`、実装の詳細は`ai-bijika-system/README.md`参照）へのリンクに変更した。

さらにその後、「無料でプレゼントするのは集客・接客ツール、ダウンライン拡大ツール、SNS自動投稿ツールです」という指示を受け、無料で渡すものを、本来は有料の3ツール（`/tools/shukyaku`＝980円・`/tools/kanyu`＝1,480円・`/tools/jidoutoukou`＝1,980円、いずれも`ai-bijika-system/README.md`参照）そのものに差し替えた。アポミーで既に関係があるという、Tips上の見知らぬ閲覧者より一段強い接点を持つ相手に対しては、より本格的な価値を渡すことで信頼構築を強める狙い。

当初は、3ツールとも通常のTips購入者と同じ共有パスワードを無償案内する案で作成したが、「URLを今設定されているものから変更はできるのか、例えば無料でつかえるURL」という確認を受け、**購入者版とは別URL・別パスワードの「ギフト版」**（`/tools/shukyaku-gift`・`/tools/kanyu-gift`・`/tools/jidoutoukou-gift`、パスワードは`SHUKYAKU_GIFT_PASSWORD`・`KANYU_GIFT_PASSWORD`・`JIDOUTOUKOU_GIFT_PASSWORD`）を新設し、無料プレゼントにはこちらのURL・パスワードを案内する方式に変更した。ツール本体（文章生成等の機能）は購入者版と完全に同じものを使うが、ログイン画面・ツール画面の案内文は「ご購入者様専用」ではなく「無料プレゼント」向けの表示になる。ギフト版のパスワードは購入者版とは独立した環境変数のため、流出・乱用が疑われる場合もギフト版だけを変更すればよく、購入者版やその利用者には一切影響しない。

## 前提・確認事項（未確認のまま進めている点）

- 連絡はLINEで行う想定（アポミーのメッセージ機能は使わない）。運営者からの確認により、対象の相手とはアポミーでの出会いの後、個人のLINEで繋がっている関係であることを前提としている。アポミー自体の利用規約（同プラットフォーム経由でのメッセージ送信に関する制約）は、LINEでの個人間のやり取りには適用されないと考えられる
- 同じ文面をそのまま一括送信（コピペでの大量送信）することは想定していない。相手ごとに、以前のやり取りの内容を踏まえて個別にカスタマイズする前提の「型」として作成した
- 既にアポミーでの本来の商談が不成立・断られている相手、または連絡を望んでいない意思表示があった相手には送らない
- 本文中に実在の収入額・成功率等の数字は一切含めていない
- **3ツールとも、無料プレゼントの相手には、購入者版とは別URL・別パスワードの「ギフト版」**（`/tools/shukyaku-gift`等、パスワードは`SHUKYAKU_GIFT_PASSWORD`等）を案内する。文章生成などツール本体の機能は購入者版と同じため、無料で案内した相手も、有料購入者と同じ範囲の機能を使える点は変わらない。ギフト版のパスワードは全ての無償案内の相手で共通の1つ（個別の相手だけに発行・失効する仕組みは無い）だが、購入者版とは別URL・別の環境変数のため、**流出・乱用が疑われる場合はギフト版のパスワードだけを変更すればよく、購入者版・既存の有料購入者には一切影響しない**。無償で案内する人数が増えるほど、有料で購入した既存客との公平感（お金を払った人と同じ機能を無料でもらった人がいる状態）という論点は引き続き生じうるため、誰に無償案内するかは運営者が個別に判断すること
- 集客・接客ツール・ダウンライン拡大ツールは、利用に購入者自身のAIプロバイダ（OpenAI・Anthropic）APIキーが必要。SNS自動投稿ツールは、さらに購入者自身のポストメッシュアカウント（外部有料サービス、月額2,200円〜）も必要。「無料」なのはツールの利用権のみで、これら外部サービスの費用は無償提供の対象外であることを、渡す相手に明確に伝えること

## 設計方針

- **「売り込み」ではなく「再接触＋無料の価値提供」から始める理由**：既存の接点はあるが、今回の用件（MLM従事者向けの別商品）は当時の面談の目的とは異なる可能性が高い。いきなり本題（ミチシルベ・面談の打診）に入らず、まず本来は有料の3ツール一式を無償で渡すことで、売り込みではなく「お役に立てるかもしれない価値の提供」から入る設計にした
- **「本業・ネットワークビジネスを辞める・乗り換える話ではない」と明記する理由**：`docs/販売手法案_チャネル別パターン.md`の既存方針（相手の活動を否定しない）と同じ。再アプローチというデリケートな場面では、この一文が無いと「商材の乗り換え営業」と誤解されやすいため、最初のメッセージの時点で明記する
- **面談の案内はオンライン・任意参加を明記する理由**：`docs/対面営業トークスクリプト.md`と同じ考え方で、対面でのその場契約は特定商取引法上のリスクがあるため、オンラインの既存フローに橋渡しする
- **面談本体の進め方は新たに書かず、既存の`docs/商談トークスクリプト.md`を使う理由**：面談に入った後の流れ（ヒアリング→ミチシルベ案内）は既存の客層と変わらない。MLM従事者向けの橋渡し文言（「本業・ネットワークビジネスとは別の収入源」）は既に`docs/販売手法案_チャネル別パターン.md`に記載済みのため、重複して書き直さない

## 面談本体の進め方

上記②で面談が決まった後の進め方は、既存の`docs/商談トークスクリプト.md`の流れに沿う。ミチシルベを案内する際は、`docs/販売手法案_チャネル別パターン.md`「ネットワークビジネス（MLM）従事者向けの導線」に記載済みの方針（本業・ネットワークビジネスを否定しない、断定的な収入約束はしない）をそのまま適用する。

## 運用の流れ

1. アポミーでやり取りした相手のうち、今回の用件で再アプローチして問題が無いと判断できる相手を運営者自身が選ぶ（前提・確認事項を参照）
2. 選んだ相手ごとに、上記①の【　】部分を実際のやり取りの内容に合わせて書き換える。パスワード欄には、各ツールの**ギフト版**環境変数（`SHUKYAKU_GIFT_PASSWORD`・`KANYU_GIFT_PASSWORD`・`JIDOUTOUKOU_GIFT_PASSWORD`）の現在の値を記入し、LINEで送る（一括送信はしない）。URLも必ずギフト版（`-gift`が付くもの）を案内し、購入者版のURL・パスワード（`SHUKYAKU_TOOL_PASSWORD`等）は案内しないこと
3. 返信があり興味を示された場合、上記②で日程調整する
4. 面談当日は`docs/商談トークスクリプト.md`の流れで対応する

※ ギフト版のパスワードは、無償案内した相手すべてに共通の1つ（ツールごとに1つ、購入者版とは別物）を運用している。無償で案内した相手にも、有料購入者と同じ範囲の機能がそのまま使えることになる点を踏まえて、誰に案内するかを判断すること。

※ ギフト版パスワードの流出・意図しない拡散が疑われる場合は、該当ツールのギフト用環境変数（例：`SHUKYAKU_GIFT_PASSWORD`）だけを新しい値に変更して再デプロイすれば、そのパスワードのみ無効化できる。購入者版のURL・パスワードは変わらず、既存の有料購入者には影響しないため、無料プレゼント運用のために購入者側へ変更の連絡をする必要はない。
