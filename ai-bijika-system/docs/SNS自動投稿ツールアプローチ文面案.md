# SNS自動投稿ツールアプローチ文面案：ビジネス初心者・MLMパートナー募集希望者への売り込み文面

## 背景

「SNS自動投稿ツールと集客ツールをビジネス初心者とMLMでパートナー募集したい方に販売するためのアプローチテキストと商品を作って」という指示を受けて作成した。新設した`/tools/jidoutoukou`（SNS自動投稿ツール、1,980円。商品としての詳細は`docs/TipsSNS自動投稿ツール案.md`参照）を、既存の2つの有料ツールとセットで案内する2種類のアプローチ文面を用意した。

- **ビジネス初心者向け**：既存の「集客・接客ツール」（`/tools/shukyaku`、980円）とセットで案内する
- **MLMでパートナー募集したい方向け**：既存の「ダウンライン拡大ツール」（`/tools/kanyu`、1,480円）とセットで案内する

いずれも「文章を作る」ツールに「実際に複数SNSへ配信する」ツールを組み合わせることで、SNS運用全体の時間を減らせる、という価値提案で統一している。

## 送り先についての前提

本文面は、既に接点がある相手（無料ツール`/tools/jikoshoukai`・`/tools/fukugyou`経由で接触した方、既存の問い合わせ対応者、既存の集客・接客ツール／ダウンライン拡大ツールの購入者・検討者など）への送付を想定している。見ず知らずの相手への不特定多数への一斉送信（スパム的な送り方）は想定していない。送り先ごとに、名前や直前のやり取りに合わせて書き出しを調整することを推奨する。

## 法的な整理について

本文面は「自社が開発したSNS自動投稿ツール・集客用ツールという商品を販売する」ための営業文面であり、相手をMLM（連鎖販売取引）そのものへ勧誘する文面ではない。そのため、特定商取引法が連鎖販売取引の勧誘に課す開示義務（勧誘に先立っての氏名・勧誘目的の明示等、`docs/TipsMLMダウンライン拡大プロンプト案.md`参照）は、本文面には直接適用されない。ただし、実在しない実績・断定的な収入表現を含めないという`CLAUDE.md`の絶対ルールは、他の全ての対外文書と同様に適用している。

## 前提・確認事項

- 価格（980円・1,480円・1,980円）はいずれも提案であり、確定した実績データに基づくものではない
