# SNS自動投稿ツールアプローチ文面案：ビジネス初心者・MLMパートナー募集希望者への売り込み文面

## 背景

「SNS自動投稿ツールと集客ツールをビジネス初心者とMLMでパートナー募集したい方に販売するためのアプローチテキストと商品を作って」という指示を受けて作成した。新設した`/tools/jidoutoukou`（SNS自動投稿ツール、単体1,980円。商品としての詳細は`docs/TipsSNS自動投稿ツール案.md`参照）を、既存の2つの有料ツールと組み合わせて案内する2種類のアプローチ文面を用意した。

当初は「既存ツール＋SNS自動投稿ツールを2つ別々に案内する」構成で作成したが、「一つにまとめて販売」という指示を受け、それぞれ**1つのセット商品**として案内する内容に作り直した。

- **ビジネス初心者向け**：「集客ツール＋SNS自動投稿セット」（`docs/Tips集客ツール+SNS自動投稿セット案.md`、2,480円）を案内する
- **MLMでパートナー募集したい方向け**：「ダウンライン拡大＋SNS自動投稿セット」（`docs/Tipsダウンライン拡大+SNS自動投稿セット案.md`、2,980円）を案内する

いずれも「文章を作る」ツールに「実際に複数SNSへ配信する」ツールを組み合わせることで、SNS運用全体の時間を減らせる、という価値提案で統一している。

## 送り先・渡し方についての前提

本文面は、既に接点がある相手（無料ツール`/tools/jikoshoukai`・`/tools/fukugyou`経由で接触した方、既存の問い合わせ対応者、既存の集客・接客ツール／ダウンライン拡大ツールの購入者・検討者など）への送付を想定している。見ず知らずの相手への不特定多数への一斉送信（スパム的な送り方）は想定していない。送り先ごとに、名前や直前のやり取りに合わせて書き出しを調整することを推奨する。

渡し方（送信チャネル）は、相手との接点がどこにあるかによって使い分ける。新しいチャネルを本書のために新設するのではなく、既存の導線をそのまま使う。

- **LINEで繋がっている相手**（アポミー経由で知り合いLINEに移行した方など）：`docs/アポミー再アプローチ文面案.md`と同じ考え方で、LINEで個別に送る。一括送信はせず、直前のやり取りに合わせて書き出しを変える
- **Threadsで接点がある相手**（Threadsのフォロー・やり取りがある方）：`docs/Threads初対面アプローチ文面案.md`と同じ考え方で、ThreadsのDMで送る
- **`/contact`経由で問い合わせてきた方**：本人が記載したメールアドレス宛に返信する形で送る。`docs/商談トークスクリプト.md`の流れに沿って、まず用件を確認してから案内する
- **既存の集客・接客ツール／ダウンライン拡大ツールの購入者**：購入時に`/contact`経由でやり取りした際の連絡手段（メール・LINE等、実際にやり取りした手段）をそのまま使う

いずれの場合も、本文面はそのままコピペで送るのではなく、相手の名前・直前のやり取りの内容に合わせて書き出しと結びを調整してから送ることを推奨する。

## 法的な整理について

本文面は「自社が開発したSNS自動投稿ツール・集客用ツールという商品を販売する」ための営業文面であり、相手をMLM（連鎖販売取引）そのものへ勧誘する文面ではない。そのため、特定商取引法が連鎖販売取引の勧誘に課す開示義務（勧誘に先立っての氏名・勧誘目的の明示等、`docs/TipsMLMダウンライン拡大プロンプト案.md`参照）は、本文面には直接適用されない。ただし、実在しない実績・断定的な収入表現を含めないという`CLAUDE.md`の絶対ルールは、他の全ての対外文書と同様に適用している。

- 実在の収入額・成約率等の数字は一切含めていない
