# 1週間売上スプリント計画（2026-10-02〜2026-10-08）

## 背景

「1週間以内に2件売る為の計画と実行して」という依頼を受けて作成。

## 目標の定義と、その理由（正直な前提）

**この計画のフロア目標**：7日間で、有料の接点（Tips/Brainの診断シート500円、またはココナラのオンライン相談2,980円）を**合計2件**成立させる。

**ストレッチ目標**：うち1件以上がミチシルベ本体（500,000円）の相談・成約まで進む。

### なぜ「ミチシルベ本体2件」を直接の目標にしなかったか

現時点でThreads・Tips・Brain・ココナラのいずれも配信実績がゼロ（アカウント開設・出品したばかり）からのスタートです。実績のない新規アカウントが、7日間で単価50万円の商品を初対面の相手に売るのは、確認できた実績としては見込めません。「必ず売れる」という前提で計画を作ると、絶対ルール（確認できていない数字を断定しない）に反するため、ここでは正直に「まず現実的に動く接点を2件作り、そこからミチシルベへの相談につなげる」設計にしています。

達成確率を最も上げる手段は、見ず知らずの読者ではなく、**本人が既に知っている相手（知人・友人・過去の仕事関係者）への直接の声かけ**です。SNS・プラットフォームへの投稿は並走させますが、この1週間に限っては知人への声かけを計画の中心に据えます。

## 追うべき数字（`seeds/prompts.js` No.23・24と同じ考え方）

- 知人への声かけ人数・返信数
- Tips/Brain診断シートの購入数
- ココナラ相談の申込数
- 問い合わせ件数・返信までの時間

実際の数字は本人が記録する（AIはSNS・決済APIに接続していないため自動取得できない。既存の制約事項と同じ）。

## 知人への声かけテンプレート（3種）

いずれも実在しない実績・収入は書いていない。本人が実際に送れる文面に調整してよい。

### テンプレA：初回・軽め（Day1〜2）

```
急にごめん！最近、自分の経験を活かして商品を作る取り組みを始めていて、
その中でAIを使った簡単な自己診断シートを作ったんだけど、

[診断シートのURL]

気が向いたらやってみてもらえたら嬉しいです。感想もらえたらなお嬉しい！
```

### テンプレB：診断シートへの直接案内（Day4）

```

自分の経験や強みが、実は人に売れる商品のタネになるかもっていう

[診断シートのURL]

よかったら覗いてみてもらえたら嬉しい。

※「前にちょっと話した」のように事前の会話を前提にした書き出しは、初めて連絡する相手に送ると事実と異なるため使わない。実際にこの話題で以前話したことがある相手には、本人が一言加えてよい。

忙しかったら全然スルーで大丈夫、気が向いたときにでも。
```

## 問い合わせが来たときの対応フロー

1. 当日中に返信する（返信文の下書きは`seeds/prompts.js` No.35で作れる）
2. 診断シートの感想・興味度に応じて、`docs/商談トークスクリプト.md`の流れでオンライン相談に案内する
3. 相談の中で、ミチシルベ本体（500,000円）が合いそうだと本人が判断した場合のみ案内する。合わなそうな相手に無理に勧めない

## 正直な見通しと代替案

知人への声かけは最も確率が高い手段ですが、送った相手が実際に購入するかは相手の反応次第であり、2件を確実に達成できると保証するものではありません。

Day4（10/5）までに声かけの反応が乏しい場合の代替案（判断は本人が行う）：

- 診断シート（500円）を、声をかけた最初の数名に限り無料で提供し、感想と口コミをもらう（実際に無料にする場合のみ記載してよい。実施しない数字は書かない）
- ココナラのオンライン相談を、同様に最初の1〜2名限定で無料相談として案内する

いずれも「実施すると決めた場合に初めて対外的な文言に反映する」運用とし、まだ決めていない段階では告知文に書かない。

## Day7時点でやること

この計画と同じ形式で、実際の数字（声かけ人数・返信数・購入数）を記録し、何が反応につながったかを振り返る。反応が良かった投稿・声かけ文面があれば、次週はそれを中心に組み直す（`seeds/prompts.js` No.23・24と同じ運用ループ）。
