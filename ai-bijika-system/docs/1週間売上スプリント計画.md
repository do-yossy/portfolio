# 1週間売上スプリント計画（2026-10-02〜2026-10-08）

## 背景

「1週間以内に2件売る為の計画と実行して」という依頼を受けて作成。「2件」はミチシルベ本体（500,000円）の成約を指す。

## 目標

7日間で、**ミチシルベ本体（500,000円）の成約を2件**達成する。

### 導線（本人指定）

Tipsの無料コンテンツ（3本、`docs/Tips無料コンテンツ案.md`）を広める → 読んだ人が興味を持ったら`/contact`からメッセージをもらう → オンラインで相談する → ミチシルベ本体を提案し、成約につなげる。

### 正直に付け加えること

実績ゼロの新規アカウントからの7日間で、単価50万円の商品の成約を2件確実に達成できると保証はできません（絶対ルール：確認できていない数字を断定しない）。ただし目標として掲げられた以上、この導線——無料コンテンツで興味を持ってもらい、メッセージをもらい、相談で提案する——を最大化することに全力を注ぎます。

達成確率を最も上げる手段は、見ず知らずの読者ではなく、**本人が既に知っている相手（知人・友人・過去の仕事関係者）への直接の声かけ**です。SNS・プラットフォームへの投稿は並走させますが、この1週間に限っては知人への声かけを計画の中心に据えます。

## 追うべき数字（`seeds/prompts.js` No.23・24と同じ考え方）

- 知人への声かけ人数・返信数
- Tips無料コンテンツの閲覧数・入手数
- 問い合わせ（メッセージ）件数・返信までの時間
- オンライン相談の実施数
- **ミチシルベ本体の成約数（最終目標）**
- (参考)Tips/Brain診断シート・ココナラ相談の件数

実際の数字は本人が記録する（AIはSNS・決済APIに接続していないため自動取得できない。既存の制約事項と同じ）。

## 知人への声かけテンプレート（3種）

いずれも実在しない実績・収入は書いていない。本人が実際に送れる文面に調整してよい。

### テンプレA：初回・軽め（Day1〜2）

```
急にごめん！最近、自分の経験を活かして商品を作る取り組みを始めていて、
その中で無料で読める診断ガイドを作ったんだけど、

### テンプレB：無料コンテンツ＋相談への案内（Day4）

```

## 問い合わせが来たときの対応フロー

1. 当日中に返信する（返信文の下書きは`seeds/prompts.js` No.35で作れる）
2. 興味度に応じて、`docs/商談トークスクリプト.md`の流れでオンライン相談に案内する
3. 相談の中で、ミチシルベ本体（500,000円）を提案する（今回の目標そのものであるため、提案自体は毎回行う）。ただし無理な勧誘はせず、`商談トークスクリプト.md`に沿って、合わない相手には合わない理由を正直に伝える

---

## 正直な見通しと代替案

知人への声かけは最も確率が高い手段ですが、送った相手が実際にメッセージをくれるか、相談がミチシルベの成約まで進むかは相手の反応と相談の内容次第であり、2件を確実に達成できると保証するものではありません。

Day4（10/5）までに問い合わせがほとんど来ていない場合の代替案（判断は本人が行う）：

- 知人への声かけを追加で広げる（声をかけられる人数に余裕があれば）
- 無料コンテンツを送った知人に対し、メッセージを待つのではなく「読んでみてどうだった？」と本人から一声かけて相談につなげる
- SNS投稿の内容を、反応が良かったものに絞って再投稿する

いずれも価格や商品内容を変更するものではなく、既存の導線（無料コンテンツ→メッセージ→オンライン相談→ミチシルベ提案）を広げる・押す施策に限定する。
