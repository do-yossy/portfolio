# TipsMLM集客接客プロンプト案：ネットワークビジネスの「集客・接客」を助けるAIプロンプト集

## 背景

「MLMをしている人に向けた商品はつくれるか」という相談を受けた。MLM（ネットワークビジネス）は、合法な連鎖販売取引から、規制に抵触するものまで幅が広く、特に「新規メンバーの勧誘・ダウンライン拡大を助ける文面」は特定商取引法上の開示義務・誇大広告規制が関わり法的リスクが高いため、方向性を確認した。「集客・接客を助けるAIツール」（勧誘・ダウンライン拡大は対象外）という方向で運営者の承認を得て、本商品を作成した。

対象は、既に（合法に）ネットワークビジネスの活動をしている方。新規メンバーの勧誘ではなく、既存のお客様・見込み客とのSNS発信・接客の場面で使える文章作成を支援する。

## 設計方針

- **「集客・接客」限定にした理由**：新規メンバーの勧誘・ダウンライン拡大を支援する文面は、特定商取引法上の開示義務（勧誘時に氏名や勧誘目的を明示する義務等）・誇大広告の禁止など法的リスクが高く、勧誘される側に心理的な負担を与えやすい。本商品では、既に商品を持っている方が、既存のお客様・見込み客との関係を誠実に築くための文章作成のみに焦点を当て、勧誘・ダウンライン拡大の文面は意図的に対象外とした
- **連動システムではなく独立した5つのプロンプトにした理由**：`docs/Tips商品化システム案.md`（980円）等は「新しい商品を考える」ための連動プロンプトだが、本商品は「すでにある商品を、日々のいろいろな場面で誠実に伝える」ための文例集である。使う場面（SNS投稿・フォロー・お断り対応・自己紹介・イベント案内）ごとに独立して使えるプロンプト集にした
- **価格を980円にした理由**：5つの独立したプロンプトという内容量は、既存の980円商品（4つの連動プロンプト）と同程度の価値があると考え、同価格帯とした
- **タイトルに「勧誘なし」と明記した理由**：MLM向けという訴求だけでは「勧誘・ダウンライン拡大の文面」を期待される可能性があるため、対象外であることを出品ページの時点で明確にし、購入後のトラブルを避ける

## 前提・確認事項

- 価格980円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 本商品は、既にネットワークビジネス（MLM）の活動をしている方の「集客・接客」のみを対象とする。新規メンバーの勧誘・ダウンライン拡大のための文面は含んでいない（意図的な対象外）
- 特定の企業・商品・ビジネスモデルを推奨・保証するものではなく、その活動が合法であるか、特定商取引法上の連鎖販売取引の規制（勧誘時の氏名等の明示義務、誇大広告の禁止等）を遵守しているかは、購入者自身の責任で確認いただく前提
- 化粧品・健康食品等を扱う場合、効果・効能に関する表現には薬機法（医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律）上の制約があるため、AIが生成した文章についても、効果を保証するような表現になっていないか必ずご自身で確認すること
- 本文中の5つのプロンプトは、本書のために新規に書いたオリジナルの文面であり、`seeds/prompts.js`の内容とは無関係
