# TipsMLM集客接客プロンプト案：ネットワークビジネスの「集客・接客」を助けるAIツール

## 背景

「MLMをしている人に向けた商品はつくれるか」という相談を受けた。MLM（ネットワークビジネス）は、合法な連鎖販売取引から、規制に抵触するものまで幅が広く、特に「新規メンバーの勧誘・ダウンライン拡大を助ける文面」は特定商取引法上の開示義務・誇大広告規制が関わり法的リスクが高いため、方向性を確認した。「集客・接客を助けるAIツール」（勧誘・ダウンライン拡大は対象外）という方向で運営者の承認を得て、本商品を作成した。

対象は、既に（合法に）ネットワークビジネスの活動をしている方。新規メンバーの勧誘ではなく、既存のお客様・見込み客とのSNS発信・接客の場面で使える文章作成を支援する。

その後「プロンプトをあげるのではなくて集客ツールそのものをあげたい」「ダウンライン拡大プロンプト集と集客・接客プロンプト集は価値を感じない。誰でも作れる」という指摘を受け、コピペ用のテキストのプロンプト集から、実際に動くAIツール（`/tools/shukyaku`、パスワード制）に作り直した。プロンプトの文面自体（勧誘禁止文言を含む）は変更していない。

## 設計方針

- **「集客・接客」限定にした理由**：新規メンバーの勧誘・ダウンライン拡大を支援する文面は、特定商取引法上の開示義務（勧誘時に氏名や勧誘目的を明示する義務等）・誇大広告の禁止など法的リスクが高く、勧誘される側に心理的な負担を与えやすい。本商品では、既に商品を持っている方が、既存のお客様・見込み客との関係を誠実に築くための文章作成のみに焦点を当て、勧誘・ダウンライン拡大の機能は意図的に対象外とした
- **連動システムではなく独立した5つの場面にした理由**：`docs/Tips商品化システム案.md`（980円）等は「新しい商品を考える」ための連動プロンプトだが、本商品は「すでにある商品を、日々のいろいろな場面で誠実に伝える」ためのツールである。使う場面（SNS投稿・フォロー・お断り対応・自己紹介・イベント案内）ごとに独立して選べるモードにした
- **価格を980円にした理由**：5つの独立したモードという内容量は、既存の980円商品（4つの連動プロンプト）と同程度の価値があると考え、同価格帯とした。テキストからツールへ作り直した今回の変更は、価格を上げず同じ980円のまま価値を上げる改善として行った
- **タイトルに「勧誘なし」と明記した理由**：MLM向けという訴求だけでは「勧誘・ダウンライン拡大の機能」を期待される可能性があるため、対象外であることを出品ページの時点で明確にし、購入後のトラブルを避ける
- **ツール化にあたりパスワード認証にした理由**：無料で提供している`/tools/jikoshoukai`とは異なり、本商品は有料のため購入者だけが使えるようにする必要がある。既存の`/admin/inquiries`と同じ依存ゼロの簡易パスワード認証（`SHUKYAKU_TOOL_PASSWORD`環境変数）を採用し、購入確認後に`/contact`経由でパスワードを案内する運用とした（ミチシルベ体験版等、既存の「購入確認後に手動で案内する」運用パターンを踏襲している）

## 前提・確認事項

- 価格980円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 本商品は、既にネットワークビジネス（MLM）の活動をしている方の「集客・接客」のみを対象とする。新規メンバーの勧誘・ダウンライン拡大のための機能は含んでいない（意図的な対象外）
- 特定の企業・商品・ビジネスモデルを推奨・保証するものではなく、その活動が合法であるか、特定商取引法上の連鎖販売取引の規制（勧誘時の氏名等の明示義務、誇大広告の禁止等）を遵守しているかは、購入者自身の責任で確認いただく前提
- 化粧品・健康食品等を扱う場合、効果・効能に関する表現には薬機法（医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律）上の制約があるため、AIが生成した文章についても、効果を保証するような表現になっていないか必ずご自身で確認すること
- ツール内の5モードのプロンプト文面は、本書のために新規に書いたオリジナルの文面であり、`seeds/prompts.js`の内容とは無関係
- **パスワードは全購入者共通の1つを運用する設計**で、購入者ごとの個別発行・失効はできない。漏洩等が疑われる場合は、運営者が環境変数（`SHUKYAKU_TOOL_PASSWORD`）を変更して再デプロイすれば一斉に無効化できる
- ツールでのAI生成には、購入者自身のAPIキー（OpenAI・Anthropic、有料・使った分だけの少額課金）が必要。コピペ用プロンプトだった前バージョンでは無料のChatGPT画面で完結していたが、ツール化によってこの前提が変わった点は、出品ページ・購入後本文の両方に明記する
