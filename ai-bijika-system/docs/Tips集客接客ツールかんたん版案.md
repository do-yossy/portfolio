# Tips集客接客ツールかんたん版案：APIキー不要の集客・接客ツール

## 背景

「SNS自動投稿ツールは無理だと思うが、APIキーが不要なタイプもそれぞれつくれるか」という指示を受けて作成した。既存の「集客・接客ツール」（`/tools/shukyaku`、980円）は購入者自身のAIプロバイダ（OpenAI・Anthropic）APIキーが必要だが、本商品（`/tools/shukyaku-kantan`）はAPIキーの用意・入力を一切不要にした別商品として新設した。

SNS自動投稿ツール（`/tools/jidoutoukou`）については、ポストメッシュという外部サービスへの連携そのものが前提のため、運営者側だけで完結する「APIキー不要版」は作れない（外部サービスとの連携を省略した場合、SNSへの投稿自体ができなくなり商品として成立しない）。一方、集客・接客ツール・ダウンライン拡大ツールはAIによる文章生成のみのツールのため、運営者自身のAPIキーをサーバー側で使う形にすれば、購入者側のAPIキー不要化が可能と判断した。

## 設計方針

- **既存の980円商品を書き換えず、別商品にした理由**：APIキー不要化は「購入者の手間を減らす」というプラスの変更だが、運営者が全購入者分のAI利用料を負担する（後述）という性質上の変化を伴う。既存の980円商品の前提を変えると意図しない運用になるため、独立した新商品とした
- **運営者の共有APIキーを使う設計にした理由**：購入者ごとに別々のAPIキーを用意する手段が無い以上、運営者自身のAPIキー（`SHARED_AI_API_KEY`環境変数）をサーバー側で使うほかない。既存の`lib/aiproxy.js`・`runPrompt()`をそのまま再利用し、呼び出し元が購入者のキーか運営者のキーかだけが異なる
- **1日あたりの生成回数に上限を設けた理由**：購入者ごとに使用量を区別できないため、何も制限が無いと、パスワードが漏洩した場合などに運営者のAPIキーが無制限に使われ、費用が青天井になるリスクがある。ツールごとに1日の合計生成回数の上限（`SHUKYAKU_KANTAN_DAILY_LIMIT`環境変数、既定30回）を設け、運営者の費用負担の上限を予測可能にした。失敗した生成（APIキー不備・プロバイダ側エラー等、実際には課金が発生しなかったもの）はカウントを消費せず、成功した生成のみを数える設計にしている（依存ゼロのメモリ内カウンタで、日付（UTC）が変わるとリセットする。サーバー再起動でもリセットされる）
- **価格を1,480円にした理由**：既存の980円商品（APIキー要）より、購入後すぐに使い始められる利便性が高く、運営者側の継続的な費用負担も伴うため、既存のダウンライン拡大ツール（1,480円）と同じ価格帯とした
- **既存の980円商品も残す理由**：自分のAPIキーをすでに持っている・自分で管理したい購入者向けの選択肢として、`/tools/shukyaku`（980円）もそのまま出品を続ける。2つの商品は価格・パスワードとも完全に独立している

## 前提・確認事項（必ず購入者に伝えるべき点）

- 価格1,480円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- **1日あたりの生成回数に上限がある**（既定30回。全購入者共通の上限で、個人ごとの上限ではない）。上限に達すると、日付が変わるまで生成できない
- APIキーの用意・入力は一切不要。ご自身でAPIキーを取得する手間が無い
- パスワードは全購入者共通の1つを運用する設計で、購入者ごとの個別発行・失効はできない。漏洩等が疑われる場合は、運営者が環境変数（`SHUKYAKU_KANTAN_TOOL_PASSWORD`）を変更して再デプロイすれば一斉に無効化できる
- 新規メンバーの勧誘・ダウンライン拡大のための機能は含んでいない（意図的な対象外。既存の980円商品と同じ前提）
- ツール内の5モードのプロンプト文面は、既存の980円商品（`docs/TipsMLM集客接客プロンプト案.md`）と全く同じものを使っている（新規創作ではない）

## 出品〜運用の流れ（運営者向け）

1. 上記①をTipsの出品ページ作成画面にそのまま貼り付け、価格1,480円で出品する
2. 購入が入ったら、上記②の本文をTipsの「購入後に表示するコンテンツ」欄に設定する
3. 購入者から`/contact`経由で連絡が来たら、Tipsの購入履歴と照合して本人確認のうえ、ツールのURL（`https://aipro.social-quality.com/tools/shukyaku-kantan`）とパスワード（環境変数`SHUKYAKU_KANTAN_TOOL_PASSWORD`の値）を案内する
4. パスワードは全購入者共通の1つを運用する設計（個別の発行・失効はできない）。漏洩等が疑われる場合は、環境変数を変更して再デプロイすれば一斉に無効化できる
5. `SHARED_AI_API_KEY`の利用料は運営者が負担する。想定を超える利用が続く場合は、`SHUKYAKU_KANTAN_DAILY_LIMIT`環境変数で1日の上限を調整できる
6. 問い合わせが来たら、`docs/商談トークスクリプト.md`の流れで対応する
