# ミチシルベ伴走型オンラインスクール案

## 背景

「ミチシルベを使って講師が伴走型でオンラインスクールでAIに関することやSNS集客を教えてくれる形にできそうです」という発案を受け、ミチシルベに既に組み込まれているGATE1〜10のカリキュラムを土台に、人（講師）による伴走を乗せたサービスとして具体化した。

ページ構成・プラン設計の考え方は、競合参考として共有された[SocialX](https://socialx.jp/lp/flow)（X・Instagram・Threads投稿の一元管理AIツール）を参考にしている。SocialXは「悩み提示→Before/After→主な機能→操作手順→お客様の声→料金・FAQ」という構成と、「スタート／プロの2プラン、差は機能ではなく連携数・クレジット量（＝量の差）」という料金設計を採用しており、両方をそのまま取り入れた。

## 位置づけ（既存のミチシルベ本体との関係）

運営者からの指示を受け、位置づけを修正した。**月額伴走プランの加入者が販売する「商材」は、ミチシルベ本体ではない。** ミチシルベ本体（500,000円・税別）は、あくまで伴走の中でAI×SNS集客を学ぶための**教材**として使うのみで、個人利用権の無料付与も、本体そのものの販売権の付与も行わない。

加入者が得るのは、**講師の方がお持ちの商材（本体とは異なるもの）を受け取り、他の人に販売する権利**である。講師の方は運営者本人ではなく、運営とは別の立場でSNS運用・集客を教える方を想定する。追加の仕入れ費用等は発生せず、月額費用だけでこの販売する権利を持てる。

- 「ミチシルベを使って」という発案の趣旨は、**学ぶ教材としてミチシルベのGATE1〜10・AIプロンプト集を使う**という形で維持する。本体そのものを売買の対象にはしない
- 加入者は、学んだ内容を活かして、講師の方がお持ちの商材を他の人に販売し、売上のうち受講者の取り分（アフィリエイト報酬）を受け取れる（詳細は次節）
- ミチシルベ本体を単体で500,000円・一括で買う既存の導線（`docs/商談トークスクリプト.md`）には一切影響しない。別事業として並行する

対象は、ミチシルベにこれから触れる人・アポミー経由の既存接点を含め、「一人だと読んでも進まない」層、かつ「学びながら自分でも販売して収入を得たい」層。

## 伴走の中身：SNS運用カリキュラム（具体化）

運営者からの指示を受け、伴走で教える内容を「SNS運用」を軸に具体化した。加入者が自分のSNSアカウントで発信しながら、商材を売れるようになることをゴールにする。対象SNSはInstagram・X・Threads・TikTokで、各SNSの運用でのAI活用も教える（受講者が選んだSNSに合わせて指導する）。

### STEP1：アカウントの土台づくり

- 商材を紹介する用のSNSアカウントのプロフィール・世界観を整える
- 投稿の頻度・トーンの基本ルールを決める

### STEP2：投稿づくり（悩み共感型＋商材紹介型）

- フォロワーとの関係構築を目的にした「悩み共感型」の投稿の作り方（`docs/MLM従事者に刺さるSNS投稿文案.md`で確立した「大半は共感のみ、商材への言及は一部に留める」という型を踏襲する）
- 商材そのものを紹介する投稿の作り方（押し売り感を出さない伝え方）
- AIプロンプトを使った投稿文の下書き作成（ミチシルベに含まれるプロンプト・`SHUKYAKU_MODES`等の考え方を教材として使う）

### STEP3：商材の売り方

- 投稿に反応してくれた人への個別対応（DM等）の型
- 興味を持った人を、商談・購入に繋げるまでの流れ
- 断定的な収入表現をしない等、既存の法令遵守の考え方（`docs/販売手法案_チャネル別パターン.md`等）をそのまま踏襲する

### STEP4：運用・改善

- 投稿への反応（いいね・コメント・DM数等）を見ながらの改善
- 週次（プロ）・月次（ライト）の進捗確認で、講師が投稿内容・売れ行きを一緒に見直す

## 売上の分配とアフィリエイト報酬の仕組み

運営者からの指示を受け、月額伴走プランの加入者が、付与された販売する権利を使って**講師の方がお持ちの商材（ミチシルベ本体とは別のもの）**を他の人に販売した場合、**その売上を講師の方と受講者で分け、受講者はアフィリエイト報酬として取り分を受け取る**仕組みとした。

- **対象**：月額伴走プラン加入者（ライト・プロどちらも対象）
- **商材**：講師の方がお持ちの、ミチシルベ本体とは別の商材。内容・価格は講師の方との合意で決める
- **報酬の対象**：加入者の販売・紹介で、この商材が新規に成約した場合
- **報酬率（提案）**：成約額の20%。他の高額商材のアフィリエイトプログラムの一般的な水準（10〜30%）を踏まえた提案で、確定した実績データに基づくものではない。商材自体の価格が未定のため、金額換算した具体例は示さない
- **講師の方の取り分**：売れた商材の売上のうち、受講者の取り分（提案：20%）を除いた残りを講師の方の取り分とする形を考えている。分け方の割合は確定ではなく、お金の受け渡しの経路も未確定
- **単層のみ**：加入者本人が販売・紹介した成約に対してのみ報酬が発生する、**単純な紹介制（アフィリエイト）**とする。加入者が販売した相手がさらに別の人に販売した場合の報酬（多段階・ダウンライン型の報酬）は設けない
- **顧客は月額伴走プランへの勧誘対象にしない**：加入者が商材を販売した相手（顧客）は、商材を購入するだけの一般消費者であり、その後、月額伴走プラン自体への加入を勧誘することは一切行わない
- **支払いのタイミング・方法**：未確定（商材の決済確認後、月締めで支払う運用を想定。詳細は未確定事項に記載）

## 前提・確認事項（未確認のまま進めている点）

- 価格・報酬率は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 講師は運営者本人ではなく、外部の講師の方を立てる前提とする。運営は教材と、申込み・決済などの仕組みを提供する。講師の方の収入は、月額料金（運営への対価・決済手数料の扱い次第で変わる可能性があり、入金の経路も未確定）と、商材の売上のうち講師の方の取り分
- 実際の伴走にかかる工数（1on1の準備・添削にかかる時間）は、試験的に数名運用してから見直すことを推奨する
- **商材は講師の方がお持ちのもの**：内容・価格は講師の方との合意で決める。受講者が実際に販売できるかという需要は未検証で、試験運用で確認する。アフィリエイト報酬（成約額の20%・提案）を含む収支は、講師の方との条件が決まるまで試算できない
- **経済性の懸念**：月額収入（ライト5,500円・プロ11,000円）自体が、講師の稼働コストに対して採算が厳しい可能性がある点は、商材の内容に関わらず懸念として残る（上記「価格の考え方」参照）

## ページ構成（SocialXを参考）

1. **悩み提示**（5つ）：経験や知識はあっても商品化できない／情報はあっても迷って挫折する／一人でやり切るのが難しい／SNS投稿のネタが尽きる／何から手をつければいいか分からない
2. **Before/After比較**：自己流でやる場合 vs 伴走プランを使う場合
3. **主な機能**：GATE1〜10のカリキュラム構造をカード形式で紹介（ミチシルベ本体のプレゼン資料と同じ構成を流用）
4. **伴走の中身**：SNS運用カリキュラム（STEP1〜4。詳細は「伴走の中身：SNS運用カリキュラム」節を参照）
5. **操作手順**（3ステップ）：申込み→初回面談（現状のヒアリング）→週次・隔週の伴走開始
6. **お客様の声**：現時点では未確認のため掲載しない（実績ができてから追加）
7. **料金・FAQ**

## プラン（SocialX方式：2プラン、差は量のみ）

講師の方がお持ちの商材（本体とは別）を**販売する権利**は、ライト・プロどちらに加入しても追加費用なしで付与される。プラン間の差は、SocialXと同じく機能ではなく**サポートの量**のみ。

| | ライト | プロ |
|---|---|---|
| 月額（税込・提案） | 5,500円 | 11,000円 |
| サポート内容 | 月1回のオンラインミーティング＋チャットでの質問対応し放題 | 週1回・30分の個別1on1＋チャットでの質問対応し放題＋SNS投稿文の個別添削 |
| 想定対象 | 自分のペースで進めつつ、たまに相談したい人 | 一人だと止まりやすく、継続的な伴走がないと最後までやり切れない人 |

### 価格の考え方（提案の根拠）

- 運営者の判断により、SocialXと同額（ライト5,500円・プロ11,000円、いずれも税込）に揃えた
- 懸念点：SocialXは人件費がかからないSaaSツールであるのに対し、本サービスのプロ（週1回30分の個別1on1＋チャット対応し放題＋添削）は人（講師）の稼働時間が直接乗る。月換算で約2時間の通話に加え、チャット対応・添削の時間を足すと、11,000円では講師1人あたりの採算が厳しくなる可能性が高い。試験運用で実際の工数を計測し、採算が合わない場合は価格・提供内容（添削の範囲や稼働人数の上限）の見直しを検討すること
- どちらのプランも解約自由（月単位）とし、SocialXの「全機能利用可・差は量のみ」という分かりやすさを踏襲した
- 初月無料や割引キャンペーンは、実際に募集を始める段階で別途検討する

## 運用の流れ（運営者向け）

1. 月額伴走プランの申込みがあったら、初回面談（現状のヒアリング）を実施し、ライト／プロのどちらが合うか一緒に確認する
2. 契約確定後、講師の方がお持ちの商材を販売する権利を付与する
3. プロの場合は週1回、ライトの場合は月1回、SNS運用カリキュラム（STEP1〜4）に沿って進捗確認を行う。ヒアリングの考え方は`docs/商談トークスクリプト.md`を踏襲する
4. SNS投稿の添削は、`ai-bijika-system`の各種プロンプト（`SHUKYAKU_MODES`等）で作った下書きを講師が確認する形で行う
5. 加入者の販売・紹介で商材が新規に成約した場合、決済確認後、売上を講師の方と受講者で分け、受講者の取り分（提案：成約額の20%）を月締めで支払う（支払いの経路は未確定）

## 未確定事項（次に決めること）

1. 講師の方の選定と条件の合意（商材の内容・価格、売上を分ける割合、運営への対価の有無、月額料金・商材代金・受講者の取り分の各経路）
2. 講師の稼働上限（同時に何人まで担当できるか）
3. 申込みの導線（既存のアポミー接点に案内するか、新規にLP等を作るか）
4. 解約・返金ルールの明文化（`legal/利用規約_案.md`との整合）。特に、解約時に販売する権利をどう扱うか（解約後は販売不可にする等）
5. アフィリエイト報酬の支払い方法（銀行振込か、次月以降の月額費用との相殺か）・支払いタイミングの明文化
6. 想定継続期間・紹介発生率の目処（経済性の懸念の節を参照）
7. 加入者が学習教材としてミチシルベ本体をどこまで体験できるか（個人利用権は付与しない方針のため、学習用のアクセス方法を別途決める必要がある）
