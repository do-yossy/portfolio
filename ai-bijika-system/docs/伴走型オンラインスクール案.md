# ミチシルベ伴走型オンラインスクール案

## 背景

「ミチシルベを使って講師が伴走型でオンラインスクールでAIに関することやSNS集客を教えてくれる形にできそうです」という発案を受け、ミチシルベに既に組み込まれているGATE1〜10のカリキュラムを土台に、人（講師）による伴走を乗せたサービスとして具体化した。

ページ構成・プラン設計の考え方は、競合参考として共有された[SocialX](https://socialx.jp/lp/flow)（X・Instagram・Threads投稿の一元管理AIツール）を参考にしている。SocialXは「悩み提示→Before/After→主な機能→操作手順→お客様の声→料金・FAQ」という構成と、「スタート／プロの2プラン、差は機能ではなく連携数・クレジット量（＝量の差）」という料金設計を採用しており、両方をそのまま取り入れた。

## 位置づけ（既存のミチシルベ本体との関係）

運営者からの指示を受け、位置づけを修正した。**月額伴走プランに加入しても、本体（ミチシルベ）そのものの個人利用権が無料で付与されるわけではない。** 加入者が得るのは、**講師（運営者）が持つ商材＝ミチシルベを、他の人に販売する権利**である。追加の仕入れ費用等は発生せず、月額費用だけでこの販売する権利を持てる。

- 「ミチシルベを使って」という発案の趣旨（既存の教材を土台にする）は維持し、伴走の中ではGATE1〜10・AIプロンプト34本という本体の「仕組み」を教材として使う
- 加入者は、学んだ内容を活かして本体を他の人に販売し、成約ごとにアフィリエイト報酬を受け取れる（詳細は次節）
- 本体を単体で500,000円・一括で買う既存の導線（`docs/商談トークスクリプト.md`）は残す。本体をまず一括で買いたい人（利用者として）と、月額で伴走を受けながら販売する側に回りたい人の、両方の選択肢を用意する形になる

対象は、ミチシルベにこれから触れる人・アポミー経由の既存接点を含め、「一人だと読んでも進まない」層、かつ「学びながら自分でも販売して収入を得たい」層。

## アフィリエイト報酬の仕組み（新規）

運営者からの指示を受け、月額伴走プランの加入者が、付与された販売する権利を使ってミチシルベ本体を他の人に販売した場合、**販売1件につきアフィリエイト報酬**を受け取れる仕組みを追加した。

- **対象**：月額伴走プラン加入者（ライト・プロどちらも対象）
- **報酬の対象**：加入者の販売・紹介で、ミチシルベ本体（500,000円・税別）が新規に成約した場合
- **報酬率（提案）**：成約額の20%（＝1件あたり100,000円）。他の高額商材のアフィリエイトプログラムの一般的な水準（10〜30%）を踏まえた提案で、確定した実績データに基づくものではない
- **単層のみ**：加入者本人が販売・紹介した成約に対してのみ報酬が発生する、**単純な紹介制（アフィリエイト）**とする。加入者が販売した相手がさらに別の人に販売した場合の報酬（多段階・ダウンライン型の報酬）は設けない
- **支払いのタイミング・方法**：未確定（本体の決済確認後、月締めで支払う運用を想定。詳細は未確定事項に記載）

**本仕組みが特定商取引法上の連鎖販売取引に該当するかどうかは、本書の時点では未確認である。** 特定商取引法の連鎖販売取引の定義（特定の負担を伴う加入＋他者を紹介・勧誘することで得られる特定の利益による誘引）は、報酬が多段階（ダウンライン型）であることを要件にしていない。本仕組みは「月額費用（特定の負担）→販売する権利の付与→販売・紹介による報酬（特定の利益）」という構造を持つため、単層の紹介制であっても連鎖販売取引の定義に該当する可能性があり、単層であることをもって非該当と判断することはできない。**本商品は法律専門家による助言ではない。実際に募集を始める前に、弁護士等の専門家に本仕組み全体（月額費用・販売する権利の付与・アフィリエイト報酬の組み合わせ）を確認し、連鎖販売取引に該当する場合は、特定商取引法が定める開示義務（氏名・特定負担の内容の明示等）・クーリング・オフ制度等への対応を別途検討すること。**

## 前提・確認事項（未確認のまま進めている点）

- 価格・報酬率は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 講師を運営者自身が務めるか、別の人を立てるかは未確定。本書は運営者自身が講師を務める前提で記載している
- 実際の伴走にかかる工数（1on1の準備・添削にかかる時間）は、試験的に数名運用してから見直すことを推奨する
- **経済性の懸念**：加入者に本体そのものを無料で渡すわけではなく「販売する権利」を渡す設計のため、本体1本あたりの提供コストを無料でかぶるという問題は生じない。ただし、成約1件につき成約額の20%（100,000円）をアフィリエイト報酬として支払うため、**本体の実質的な取り分は500,000円から100,000円を引いた400,000円になる**。月額収入（ライト5,500円・プロ11,000円）自体は、講師の稼働コストに対して採算が厳しい可能性がある点は変わらず懸念として残る（上記「価格の考え方」参照）

## ページ構成（SocialXを参考）

1. **悩み提示**（5つ）：経験や知識はあっても商品化できない／情報はあっても迷って挫折する／一人でやり切るのが難しい／SNS投稿のネタが尽きる／何から手をつければいいか分からない
2. **Before/After比較**：自己流でやる場合 vs 伴走プランを使う場合
3. **主な機能**：GATE1〜10のカリキュラム構造をカード形式で紹介（ミチシルベ本体のプレゼン資料と同じ構成を流用）
4. **伴走の中身**：講師が具体的に何をするか（進捗確認・壁打ち・SNS投稿の個別添削）
5. **操作手順**（3ステップ）：申込み→初回面談（現状のヒアリング）→週次・隔週の伴走開始
6. **お客様の声**：現時点では未確認のため掲載しない（実績ができてから追加）
7. **料金・FAQ**

## プラン（SocialX方式：2プラン、差は量のみ）

ミチシルベ本体（GATE1〜10・AIプロンプト34本）を**販売する権利**は、ライト・プロどちらに加入しても追加費用なしで付与される。プラン間の差は、SocialXと同じく機能ではなく**サポートの量**のみ。

| | ライト | プロ |
|---|---|---|
| 月額（税込・提案） | 5,500円 | 11,000円 |
| サポート内容 | 月1回・60分のグループQ&A（他の受講者と合同） | 週1回・30分の個別1on1＋チャットでの質問対応し放題＋SNS投稿文の個別添削 |
| 想定対象 | 自分のペースで進めつつ、たまに相談したい人 | 一人だと止まりやすく、継続的な伴走がないと最後までやり切れない人 |

### 価格の考え方（提案の根拠）

- 運営者の判断により、SocialXと同額（ライト5,500円・プロ11,000円、いずれも税込）に揃えた
- 懸念点：SocialXは人件費がかからないSaaSツールであるのに対し、本サービスのプロ（週1回30分の個別1on1＋チャット対応し放題＋添削）は人（講師）の稼働時間が直接乗る。月換算で約2時間の通話に加え、チャット対応・添削の時間を足すと、11,000円では講師1人あたりの採算が厳しくなる可能性が高い。試験運用で実際の工数を計測し、採算が合わない場合は価格・提供内容（添削の範囲や稼働人数の上限）の見直しを検討すること
- どちらのプランも解約自由（月単位）とし、SocialXの「全機能利用可・差は量のみ」という分かりやすさを踏襲した
- 初月無料や割引キャンペーンは、実際に募集を始める段階で別途検討する

## 運用の流れ（運営者向け）

1. 月額伴走プランの申込みがあったら、初回面談（現状のヒアリング）を実施し、ライト／プロのどちらが合うか一緒に確認する
2. 契約確定後、本体（ミチシルベ）を販売する権利を付与する。加入者自身が本体をどこまで体験できるか（学習・販売デモ用のアクセス方法）は未確定事項を参照
3. プロの場合は週1回、ライトの場合は月1回、`docs/商談トークスクリプト.md`のヒアリングの考え方を踏襲しつつ進捗確認を行う
4. SNS投稿の添削は、`ai-bijika-system`の各種プロンプト（`SHUKYAKU_MODES`等）で作った下書きを講師が確認する形で行う
5. 加入者の販売・紹介で本体が新規成約した場合、決済確認後にアフィリエイト報酬（提案：成約額の20%）を月締めで支払う

## 未確定事項（次に決めること）

- 申込みの導線（既存のアポミー接点に案内するか、新規にLP等を作るか）
- 加入者自身が本体（ミチシルベ）をどこまで体験できるか：販売するために加入者自身が中身を知っておく必要があるが、本体の個人利用権そのものは付与しない方針のため、学習・販売デモ用にどの範囲まで見せるか（`ai-bijika-system/server.js`側の実装方法も含め）を別途決める必要がある
- 解約・返金ルールの明文化（`legal/利用規約_案.md`との整合）。特に、解約時に販売する権利をどう扱うか（解約後は販売不可にする等）
- アフィリエイト報酬の支払い方法（銀行振込か、次月以降の月額費用との相殺か）・支払いタイミングの明文化
- 想定継続期間・紹介発生率の目処（経済性の懸念の節を参照）
- 本仕組みが特定商取引法上の連鎖販売取引に該当するかどうかの、弁護士等専門家への確認（アフィリエイト報酬の仕組みの節を参照）
