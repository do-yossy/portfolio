# TipsMLMダウンライン拡大プロンプト案：仲間集め・説明会案内に使えるAIツール

## 背景

「MLMをされている人向けの内容はMLMの役に立たないようで」という指摘を受けた。既存の`docs/TipsMLM集客接客プロンプト案.md`（980円）は、新規メンバーの勧誘・ダウンライン拡大を特定商取引法上のリスクの高さを理由に意図的に対象外としており、「既存のお客様・見込み客との集客・接客」のみに限定していた。この点について運営者に確認したところ、「新規メンバーの勧誘・ダウンライン拡大も対象にする」という明確な方向付けを得たため、本商品を作成した。

本商品は既存の980円商品（タイトルに「勧誘なしで使える」と明記）とは対象範囲が異なるため、既存ファイルを書き換えず、**別商品として新規作成**した。

その後「プロンプトをあげるのではなくて集客ツールそのものをあげたい」「ダウンライン拡大プロンプト集と集客・接客プロンプト集は価値を感じない。誰でも作れる」という指摘を受け、コピペ用のテキストのプロンプト集から、実際に動くAIツール（`/tools/kanyu`、パスワード制）に作り直した。プロンプトの文面自体（法令上の開示要件を組み込んだ指示文を含む）は変更していない。

## 情報源の扱いについて（法的な前提）

連鎖販売取引（ネットワークビジネス、いわゆるMLM）は、特定商取引法で規制されているが、日本では合法な取引形態である（法が禁止しているのは、物品の販売を伴わず金銭のみが上位者に流れる「無限連鎖講」＝ネズミ講であり、両者は別物）。ただし特定商取引法は、連鎖販売取引の**勧誘**について、他の取引には無い特別な規制を課している。本商品は、そのうち主要なもの（勧誘に先立っての氏名・勧誘目的の明示義務、誇大広告・不実告知の禁止、クーリング・オフ制度）を踏まえて作成したが、**全ての法的要件を網羅したものではなく、弁護士等の専門家による確認を代替するものではない**。

## 前提・確認事項（必ず購入者に伝えるべき点）

- **本商品は法律専門家による助言ではない**。実際の勧誘にあたっては、特定商取引法（連鎖販売取引に関する規定）・該当する業界ガイドライン等を、購入者自身の責任で確認すること
- **本商品は、購入者が扱うネットワークビジネスが、特定商取引法上の連鎖販売取引として適正に運営されていることを前提としている**。物品・サービスの販売を伴わず、新規加入者からの金銭のみで上位者が利益を得る仕組み（無限連鎖講＝ネズミ講）は「無限連鎖講の防止に関する法律」で明確に禁止されており、本商品はそうした仕組みでの使用を想定していない。購入者自身が、自分の扱うビジネスの適法性を確認する責任を負う
- 価格1,480円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 実在の収入額・成功率等の数字は一切含めていない。AIが生成する文章にも、断定的な収入の保証表現が含まれていないか、使用前に必ず確認すること
- ツール内のモード1（最初の声かけ文）は、特定商取引法が求める「勧誘に先立って、氏名・連鎖販売取引である旨・商品名を明示する」という要件を満たすように設計しているが、実際に使う際は、相手に確実に伝わる形になっているかを購入者自身で確認すること
- **パスワードは全購入者共通の1つを運用する設計**で、購入者ごとの個別発行・失効はできない。漏洩等が疑われる場合は、運営者が環境変数（`KANYU_TOOL_PASSWORD`）を変更して再デプロイすれば一斉に無効化できる
- ツールでのAI生成には、購入者自身のAPIキー（OpenAI・Anthropic、有料・使った分だけの少額課金）が必要。コピペ用プロンプトだった前バージョンでは無料のChatGPT画面で完結していたが、ツール化によってこの前提が変わった点は、出品ページ・購入後本文の両方に明記する

## 設計方針

- **既存の980円商品を書き換えず、別商品にした理由**：既存商品はタイトル・本文で「勧誘なし」を明示しており、既存の購入者・今後の購入者に対してその前提を変えると誤解を招く。対象範囲が本質的に異なる（客への接客 vs. 新規勧誘）ため、別商品として独立させた
- **「誠実な開示」を軸にした理由**：特定商取引法が義務付けている開示（氏名・勧誘目的・連鎖販売取引である旨）を後回しにせず、最初の声かけの時点で明確に伝える設計にした。これは法令遵守のためであると同時に、後から「勧誘だと知らされていなかった」と相手に感じさせないための、長期的な信頼関係づくりでもある
- **クーリング・オフの説明モードを含めた理由**：入会を決めた相手にクーリング・オフ制度を説明することは特定商取引法上の義務であり、省略すると購入者自身が法令違反のリスクを負う。実務上必要な機能として含めた
- **価格を1,480円にした理由**：既存の980円商品（客への接客、5モード）より専門性・実務上の重要度が高く、法令対応も含む内容のため、既存のテンプレート集商品（1,480円）と同じ価格帯とした。テキストからツールへ作り直した今回の変更は、価格を上げず同じ1,480円のまま価値を上げる改善として行った
- **ツール化にあたりパスワード認証にした理由**：無料で提供している`/tools/jikoshoukai`とは異なり、本商品は有料のため購入者だけが使えるようにする必要がある。既存の`/admin/inquiries`と同じ依存ゼロの簡易パスワード認証（`KANYU_TOOL_PASSWORD`環境変数）を採用し、購入確認後に`/contact`経由でパスワードを案内する運用とした。980円ツール（`/tools/shukyaku`）とはログインが独立しており、片方の購入者がもう片方のツールに入ることはできない
