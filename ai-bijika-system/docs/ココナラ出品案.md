# ココナラ出品案

## 背景

「各媒体でコピペでやることをだして」という依頼を受け、`docs/販売手法案_チャネル別パターン.md`の「プラットフォーム出品型」の考え方（窓口商品→オンライン相談→本商品案内）を、ココナラ向けに作成した。ココナラはダウンロード型コンテンツよりも「相談・サービス」出品が中心のプラットフォームのため、Tipsの診断シート（読み物）とは違い、**オンライン相談そのものを出品サービスにする**形にしている。

実際の相談の進め方は、新規に作らず既存の`docs/商談トークスクリプト.md`をそのまま使う（二重管理を避けるため）。

## 出品にあたっての前提・確認事項（未確認のまま進めている点）

- **価格は2,980円（30分）を提案**している。ココナラの相談系サービスの相場観に基づく提案で、確定した実績データに基づくものではない。運営者の判断で変更してよい
- ココナラの出品カテゴリ・手数料率（ここでは詳細未確認）は出品前に確認すること
- 本書の文章は新規のオリジナル文章であり、実在の購入者の声・実績数字は一切含めていない

## ①サービスタイトル

```
「経験はあるのに商品化できない」を一緒に整理する壁打ち相談（オンライン30分）
```

## ②価格・提供形式

- 価格：2,980円（30分）
- 提供形式：ビデオ通話（Zoom等。詳細はご購入後にご案内）

## ③サービス内容（出品ページ本文）

```
■ こんな方におすすめ
・自分の経験や知識を商品にしてみたいが、何から手をつければいいか分からない
・副業や自分の商品づくりに興味はあるけど、一人で考えていても堂々巡りになる
・一度誰かに話を聞いてもらいながら、頭の中を整理したい

■ ご提供する内容
オンラインで30分、あなたの経験・得意なことをヒアリングしながら、商品になりそうな切り口を一緒に探します。無理に商品を決めつけることはせず、今の時点で分かることを一緒に整理する時間です。

■ 当日の流れ
①今気になっていること・悩んでいることを伺います
②今までの経験・得意なことについていくつか質問します
③出てきた話から、商品化できそうな切り口があれば一緒に整理します

■ お伝えしておきたいこと
この相談は、商品化の方向性を一緒に考えるためのものです。相談時間内で必ず商品が決まることや、将来の収入を保証するものではありません。

■ ご希望があれば
もっと本格的に、経験を商品にして実際に販売まで進める手順と、商品化に使えるAIプロンプトをセットにした仕組み（ミチシルベ）もご案内できます。相談の中でご興味があれば触れる程度にとどめ、強い勧誘は行いません。
```

## ④ご購入後の流れ（出品ページ下部に記載）

```
ご購入後、メッセージにて実施日時の候補をいくつかお送りください。日程を確定後、ビデオ通話のURLをご案内します。
```

## 相談当日の進め方（運営者向けメモ・出品ページには載せない）

当日のヒアリングの進め方・想定問答・実績が無いことの伝え方は、`docs/商談トークスクリプト.md`をそのまま使う。このサービス自体が、同資料の「窓口商品→オンライン相談→本商品案内」という流れにおける窓口商品にあたる（オンライン相談そのものを、ここではココナラ経由の窓口商品にしている）。
