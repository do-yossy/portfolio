# Tips商品化システム案：AIと作る「経験→商品化」ミニシステム

## 背景

「システムを作れるようなものにして」という依頼を受けて作成。

`docs/Tips低価格商品案.md`（300円）は3つの独立したプロンプト（自己紹介文の生成）だったのに対し、本商品は前のプロンプトの出力を次のプロンプトの入力として使う、**4つが連動する一連の流れ（システム）**として設計した。「経験を棚卸しする」→「商品アイデアを選ぶ」→「出品文章を作る」→「告知文を作る」という、経験から実際に売り出すところまでの一連のプロセスを、自分で手を動かしながら体験できる商品にした。

ミチシルベ本体（GATE1〜10、AIプロンプト36個）の考え方を参考にしているが、実際のプロンプト文面は転載せず、本商品のために新規に書いた簡易な4ステップに再構成している。

## 設計方針

- **価格を980円にした理由**：`docs/Tips低価格商品案.md`（300円、単発の文章生成）と`docs/Tips中価格帯商品案.md`（2,980円、事例集）の間を埋める価格帯とした。4ステップが連動する分、単発プロンプトより価値は高いが、まだ「仕組みを体験する」段階の商品のため、中価格帯商品より低く設定した
- **ミチシルベとの関係を正直に書いた理由**：本商品は「ミチシルベの考え方を参考にした簡易版」であり、ミチシルベ本体（GATE1〜10、36個のAIプロンプト、進捗管理機能等）そのものではない。購入者が誤解しないよう、出品ページ・本文の両方に明記している

## 前提・確認事項

- 価格980円は提案であり、確定した実績データに基づくものではない。運営者の判断で変更してよい
- 本文中の4つのAIプロンプトは、`seeds/prompts.js`の実際の文面を転載したものではなく、本書のために新規に書いたオリジナルの簡易プロンプト
- 「システム」という言葉は、本文内では「プロンプトが連動する一連の流れ」という意味で使っており、ITシステムの構築・プログラミングを指すものではない（念のため本文にも明記している）

## ①Tips出品ページ用の文章

```
タイトル：AIと作る「経験→商品化」ミニシステム｜4つの連動プロンプトで経験を商品にする
価格：980円（税込）

「自分の経験を商品にしてみたいけど、何から手をつければいいか分からない」
そんな方のために、経験の棚卸しから出品文章・告知文の作成まで、4つのプロンプトが連動する一連の流れ（ミニシステム）をご用意しました。

■ こんな方向けです
・自分の経験を商品にする一連の流れを、実際に手を動かして体験してみたい
・単発の文章生成だけでなく、もう少しまとまった形で進めたい
・ビジネス経験が無くても、順番通りに進めれば形になるものが欲しい

■ これは何か
4つのプロンプトを順番に使うことで、「①経験の棚卸し→②商品アイデアの選定→③出品文章の作成→④告知文の作成」という一連の流れを、AIと一緒に進められるプロンプト集です。前のプロンプトの出力を次のプロンプトに使う、連動する設計になっています。

■ お伝えしておきたいこと
本商品は、弊社が提供する本格的な商品化支援の仕組み「ミチシルベ」（AIプロンプトと10のステップで経験を商品化する仕組み）の考え方を参考にした簡易版であり、ミチシルベ本体そのものではありません。「システム」という言葉は、プロンプトが連動する一連の流れという意味で使用しており、ITシステムの構築やプログラミングを指すものではありません。AIが生成する内容は入力情報によって変わり、同じ結果を保証するものではありません。
```

## ②購入後に届く本文

```
【AIと作る「経験→商品化」ミニシステム】

ご購入ありがとうございます。

これから紹介する4つのプロンプトは、順番に使うことで意味を持つ「連動するシステム」です。
①の出力を②に、②の出力を③に、③の出力を④に、という形で使っていきます。
1つずつ順番に進めてください。途中で止めても、後から再開しても大丈夫です。

────────────────

■ ①経験の棚卸し

以下をそのままコピーしてAIに貼り付けてください。

「あなたは経験の棚卸しをサポートするコーチです。これから私に3つの質問をしてください。1つずつ質問し、私の回答を聞いてから次の質問に進んでください。

質問は次の3つです。
・今までの人生で、一番時間を使ってきたことは何か
・誰かに相談されたり、頼られたりしたことは何か
・自分では当たり前だと思っているが、人より詳しいかもしれないことは何か

それでは、1つ目の質問からお願いします。」

AIとのやり取りが終わったら、出てきた内容をメモしておいてください。②で使います。

────────────────

■ ②商品アイデアの選定

以下をそのままコピーしてAIに貼り付けてください。【　】には①でまとめた内容を入れてください。

「あなたは商品企画のプロです。以下の経験をもとに、商品アイデアを5つ提案してください。それぞれのアイデアに『誰向けか』『どんな形式か（相談・講座・テンプレート・診断など）』を添えてください。

【①でまとめた経験】：

出してもらった5つの中から、自分が気になるものを1つ選んでください。③で使います。」

────────────────

■ ③出品文章の作成

以下をそのままコピーしてAIに貼り付けてください。【　】には②で選んだ商品アイデアを入れてください。

「あなたはプロのコピーライターです。以下の商品アイデアをもとに、販売ページに使える『タイトル』『対象者』『商品説明（200字程度）』を作ってください。

【②で選んだ商品アイデア】：」

────────────────

■ ④告知文の作成

以下をそのままコピーしてAIに貼り付けてください。【　】には③で作った商品説明を入れてください。

【③で作った商品の概要】：」

────────────────

【ここまでできたこと】

①〜④を順番に進めると、「経験」から「出品文章」「告知文」まで、商品化の一連の流れを一通り体験したことになります。
出てきた内容はすべて下書きです。そのまま使わず、ご自身の言葉で事実と異なる部分が無いか確認してから使ってください。
```
