# Threads初対面アプローチ文面案：初対面への声かけ

## 背景

「スレッズで初対面にアプローチする文章も」という相談を受けて作成。続けて「副業初心者も」という指示を受け、対象をMLM（ネットワークビジネス）従事者向け・副業初心者（一般層）向けの2パターンに分けた。いずれも`docs/アポミー再アプローチ文面案.md`と役割は同じだが、アポミー文面は**既に関係がある相手への再接触**だったのに対し、本書は**面識の無い相手への初接触**（Threads上で見つけた相手へのDM）を扱う。

## 前提・確認事項（未確認のまま進めている点）

- Threadsでの初対面DMについて、同プラットフォーム（Meta）の利用規約・スパム判定基準は本書では未確認。同一文面の一括送信は規約違反・スパム報告のリスクがあるため、**相手ごとに個別にカスタマイズする前提**で作成した
- 可能であれば、DMを送る前に相手の投稿へ自然な反応（いいね・コメント等）をしておくと唐突さを減らせる（必須ではない、任意の工夫として記載）
- 実在の収入額・成功率等の数字は一切含めていない
- **A（MLM従事者向け）のみ**：新規メンバーの勧誘・ダウンライン拡大のための文面は含んでいない（`docs/TipsMLM集客接客プロンプト案.md`と同じ方針）。声をかける相手は、プロフィール・投稿内容から「すでにネットワークビジネスの活動をしている」と判断できる人を、運営者自身の目で個別に選ぶ想定で、この判断の精度は運営者自身の確認に依存する

## 設計方針

- **`docs/アポミー再アプローチ文面案.md`との違い**：アポミー文面は既に関係がある相手への「再接触」だったが、本書は面識の無い相手への「初接触」であるため、(a)自己紹介を丁寧に行う、(b)相手の投稿・プロフィールの具体的な内容を参照する一文を入れる、(c)「突然のご連絡失礼いたしました」等、初対面であることへの配慮を明記する、という3点を加えた
- **AとBで渡す無料プロンプトを分けた理由**：Aは`docs/Tips無料コンテンツ案.md`無料コンテンツ⑦（`docs/TipsMLM集客接客プロンプト案.md`のプロンプト4と同一）、Bは`docs/Tips低価格商品案.md`（300円）のプロンプト1（SNS用の短い自己紹介文）を、それぞれの客層に合わせて無償の入口として使う。両方とも既存の商品から転用したもので、本書のための新規創作ではない
- **Aのみ勧誘禁止文言・「別の収入源」の言い回しを残した理由**：`docs/TipsMLM集客接客プロンプト案.md`・`docs/販売手法案_チャネル別パターン.md`で確立した、MLM従事者向けに必要な安全面の配慮（勧誘対象外、相手の活動を否定しない）をそのまま踏襲した。Bの対象（副業初心者）にはこの配慮は不要なため含めていない
- **②面談の日程調整メッセージをA・B共通にした理由**：面談が決まった後の文面は、相手がMLM従事者か副業初心者かによって変える必要が無いため、重複して2つ作らず共通化した

## A. MLM（ネットワークビジネス）従事者向け｜①初回のDM文面

```
はじめまして、【　自分の名前　】と申します（株式会社ソーシャルクオリティ）。

【　相手の投稿・プロフィールで気になった具体的な内容を一言（例：○○の投稿を拝見しました、など）　】を拝見して、ご連絡させていただきました。

実は、すでにネットワークビジネスをされている方向けに、誠実な印象のSNS自己紹介文をAIで作れるプロンプトを無料でご用意しています。もしよろしければ、お役に立つかもしれないので共有させてください（押し売りではないので、ご不要であれば読み流していただいて大丈夫です）。

────────────────

以下をそのままコピーして、ChatGPTなどのAIに貼り付けるだけで使えます。

「あなたはプロのコピーライターです。以下の情報をもとに、SNSのプロフィール欄に使える自己紹介文を作ってください。資格・肩書きを誇張せず、誠実な印象になるようにしてください。新しい会員・ビジネスパートナーの募集を目的とした内容は含めないでください。

【自分の経験・大切にしていること】：
【扱っている商品・サービスの分野】：」

────────────────

もしご興味があれば、AIを使って自分の経験を「本業・ネットワークビジネスとは別の収入源」にしていく仕組みについて、15〜20分程度オンラインでお話しさせていただくこともできます。今のお仕事を辞める・乗り換えるというお話ではなく、並行して考えられる話です。

突然のご連絡失礼いたしました。ご興味がありそうでしたら、お返事いただけると嬉しいです。
```

## ②面談の日程調整メッセージ（A・B共通）

```
【　お名前　】様

ご連絡ありがとうございます。ぜひお話しさせてください。

以下のいずれかでご都合の良い日時はございますか？オンライン（ビデオ通話）で15〜20分ほどを想定しています。
【　候補日時を2〜3個　】

当日は、まず今の状況やお考えを伺いながら、お役に立てそうな部分をご案内する形で進めます。何かを無理にお勧めするようなことはしませんので、気になることがあれば率直にお聞きください。
```

## 面談本体の進め方

いずれも既存の`docs/商談トークスクリプト.md`の流れに沿う。Aの相手にミチシルベを案内する際は、`docs/販売手法案_チャネル別パターン.md`「ネットワークビジネス（MLM）従事者向けの導線」の方針（本業・ネットワークビジネスを否定しない、断定的な収入約束はしない）を適用する。Bの相手には、通常の`商談トークスクリプト.md`の流れをそのまま使う。

## 運用の流れ

1. Threads上で、A（MLM従事者）・B（副業初心者）いずれかに当てはまると判断できる相手を運営者自身が選ぶ
2. （任意）相手の投稿に自然な反応をしてから、該当する①の【　】部分を実際の投稿内容に合わせて書き換え、DMで送る（一括送信はしない）
3. 返信があり興味を示された場合、②で日程調整する
4. 面談当日は`docs/商談トークスクリプト.md`の流れで対応する
