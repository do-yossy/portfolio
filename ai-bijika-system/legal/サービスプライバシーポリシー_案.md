### 2. 取得する情報

1. **アカウント情報**：メールアドレス、パスワード（暗号化して保存し、平文では保存しません）
2. **契約情報**：契約の状態、次回の更新日、決済代行会社の顧客ID・契約ID。カード番号などの決済情報は、運営者は取得・保存しません（決済代行会社が管理します）。
3. **SNS連携情報**：連携したSNSのアカウントID・表示名、連携に使うトークン（暗号化して保存します）。SNSのパスワードは取得しません。契約が終了すると、連携に使うトークンは削除します。
4. **投稿の情報**：利用者が作成・予約した投稿の本文（ツリーの各投稿を含みます）、投稿先、日時、投稿の結果、TikTok・YouTubeの公開範囲などの設定、下書き
5. **アップロード・取り込み・生成された画像・動画**：投稿のために保存します。予約・下書きに使っているファイルは、その投稿が終わるか取り消されるまで保存し（下書きに使っている間は、下書きを削除するまで保存します）、投稿が終わってから2日後以降に自動で削除します。どの投稿にも使わなかったファイル（AIで作ったものを含みます）は、作成から1日後以降に自動で削除します。各SNSが取得するため、保存している間、ファイルは、推測できない長いURLで、外部から取得できる状態になります。
6. **AIによる生成の情報**：利用者が入力したテーマ・指示、生成の回数、自動運用の設定（投稿先・テーマ・時刻・運用の方法）
7. **APIとAIアシスタントとの接続の情報**：APIキー（ハッシュ化した値と、先頭の一部だけを保存します）、接続を認めたアプリの名前と戻り先のURL、接続に使うトークン（ハッシュ化して保存します）、最終利用日時
8. **URLからの取り込み**：利用者が指定したURL（取り込みのためだけに使い、保存しません）
9. **お問い合わせ内容**：お問い合わせフォームに入力された内容
10. **Cookie等**：ログイン状態を維持するためのセッションID。広告目的のトラッキングには使用しません。
11. **アクセス元のIPアドレス**：ログインの試行回数の制限など、不正利用の防止に使います（サーバーのメモリ上で一時的に扱い、データベースには保存しません。ただし、ホスティング事業者のアクセス記録に残る場合があります）。
12. **画面の表示に使う外部の文字（フォント）**：画面の表示に Google Fonts（Google LLC）を使っているため、ページを開くと、閲覧者のIPアドレスや閲覧中のブラウザの情報が Google に送信されます。

### 4. 第三者への提供・委託

1. 運営者は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。
2. 次の事業者のサービスを利用します。

   - Meta Platforms, Inc.（Threads・Instagram・Facebook）・X Corp.（X）・TikTok社（TikTok）・Google LLC（YouTube）：利用者が連携したSNSへの投稿（利用者の許可に基づくもの）。投稿する画像・動画は、各社が取得できるようにします。

4. 利用者がAPIキーを発行し、またはアプリ（AIアシスタント等）の接続を認めた場合、運営者は、利用者の指示に基づいて、そのアプリに、連携しているSNSのアカウント名・投稿の内容・契約の状態などを提供します。どのアプリに接続を認めるかは利用者が選び、マイページからいつでも解除できます。

### 4-2. Googleのユーザーデータ（YouTube）の取り扱い

YouTubeとの連携で、Google APIから受け取る情報（チャンネルID・チャンネル名、投稿に使うトークン）は、利用者が指定した動画をYouTubeに投稿するためだけに使います。これらの情報を、広告や、本サービスの提供以外の目的に使うことはなく、第三者に販売・提供しません。本サービスによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Limited Use（限定的な使用）の要件を含む「Google API Services User Data Policy」に従います。利用者は、マイページ、またはGoogleアカウントの設定（https://myaccount.google.com/permissions）から、いつでも連携を取り消せます。

### 4-4. 安全管理のための措置

運営者は、個人情報の漏えい等を防ぐため、次の措置を講じます。

1. パスワードは、元に戻せない形（ハッシュ）で保存します。SNSの連携に使うトークンは暗号化して保存し、APIキーとAIアシスタントとの接続のトークンは、ハッシュ化した値だけを保存します。
2. 通信は暗号化（https）します。運営者向けの画面は、パスワードで保護します。
3. 委託先は、個人情報の保護の体制を確認して選び、必要な範囲の情報だけを渡します。
4. 漏えい等が発生した場合は、法令に従い、個人情報保護委員会への報告と、ご本人への通知を行います。

### 5. SNS連携の取り消し

利用者は、マイページから、いつでもSNSの連携を解除できます。解除すると、保存していた連携のトークンを削除します。各SNSの設定画面からも、連携を取り消せます。APIキーと、AIアシスタントとの接続も、マイページからいつでも無効にできます。

### 6. 保存期間

個人情報は、アカウントが存在する期間中保存します（契約が終了しても、アカウントは残ります）。ただし、SNSの連携に使うトークンは、契約が終了した時点で削除し（APIキーとAIアシスタントとの接続も、同時に無効にします）、アップロードされた画像・動画は、上記の時期に自動で削除します。アカウントの削除などのご要望は、お問い合わせフォームからご連絡ください。ただし、法令により保存が必要な情報は、その期間保存します。

### 7. 開示・訂正・削除等の請求

利用者ご本人からの、個人情報の開示・訂正・削除などの請求には、本人確認のうえ、法令に従って対応します。お問い合わせフォームからご連絡ください。
