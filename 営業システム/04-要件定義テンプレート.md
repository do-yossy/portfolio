# 04 要件定義テンプレート（役割4）

ヒアリング（03）確定後に作成。これが制作管理（役割5）の入力になる。

## 出力フォーマット
```
■ プロジェクト：{案件名}　/　目的：{目的}　/　納期：{納期}

■ サイトマップ
- トップ
- {ページ2}
- {ページ3}
- お問い合わせ

■ ページ構成（各ページのセクション）
- トップ：FV / 強み3点 / 実績 / お客様の声 / CTA
- {ページ}：…

■ CTA設計
- 主CTA：{例：無料相談}（全ページ追従ボタン＋FV内）
- 副CTA：{例：資料DL / LINE登録}

■ SEO設計
- 主要KW：{KW}／ページ別タイトル・ディスクリプション方針
- 構造化：見出し階層・内部リンク・表示速度・スマホ最適化

■ 必要機能：{フォーム / 予約 / 決済 / CMS …}

■ 制作順序（依存関係）
  1. 文章・素材確定 → 2. デザイン → 3. コーディング → 4. フォーム/機能 → 5. SEO → 6. 検収・修正
```

## 制作管理への分解（役割5の入力）
| 工程 | 担当 | 依存関係 | 主なリスク |
|---|---|---|---|
| 文章・画像 | 顧客 or ライティングOP | デザイン前に確定 | 素材遅延で全体遅延 |
| デザイン | 制作 | 文章・参考サイト確定後 | 方向性のズレ → 中間確認で吸収 |
| コーディング | 制作 | デザイン確定後 | レスポンシブ崩れ |
| フォーム/機能 | 制作 | コーディング後 | 送信不達・バリデーション漏れ |
| SEO | 制作 | 実装後 | メタ未設定・速度 |
| 修正 | 制作 | 検収後 | “仕様変更”混入 → 追加見積もりで線引き |

## 納品前チェック（役割6への引き継ぎ）
誤字脱字 ／ スマホ表示 ／ 表示速度 ／ フォーム送信 ／ CTA動作 ／ SEOメタ ／ リンク切れ。
