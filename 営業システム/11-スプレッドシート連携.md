# 11 スプレッドシート連携（方式B：既存シートに書き戻す）

サービスアカウント方式で、Googleスプレッドシートを**読み書き**する連携。
「Claudeがスプレッドシートに入力する」を、SA（サービスアカウント）経由で実現する。

## 仕組み
```
[案件リスト シート]
 B列:募集本文（人が貼る）
      │  sales-platform/scripts/sync-sheet.js（デプロイ先で実行）
      ▼  役割1で採点 + 提案文生成
 C〜G列に書き戻し（案件名/スコア/優先度/予測受注率/提案状況）  ← 既存シートに直接入力（方式B）
      ＋ 管制塔(DB)にも候補として登録
```

## 実行できる場所（重要）
- ✅ **デプロイ済みバックエンド（Fly.io 等・ネットワークあり）**
- ❌ Claude開発サンドボックス（外部ネット遮断のためGoogle APIに到達不可）
- 鍵（SA秘密鍵）は**チャット/リポジトリに貼らない**。`fly secrets` で渡す。

## セットアップ（1回）
1. **シートをSAに共有**：対象シートを開く → 共有 → `calllist@list-498317.iam.gserviceaccount.com` を**編集者**で追加
2. **SAの鍵JSONを用意**（Google Cloud → サービスアカウント → キー）。`service-account.json` として手元に保存（コミット禁止）
3. **環境変数を設定**（本番は fly secrets）：
   ```bash
   fly secrets set GOOGLE_SERVICE_ACCOUNT_JSON="$(cat service-account.json)"
   fly secrets set SHEET_ID="1I9ZQlt6RgzMZBMavaLcmXeDznLUrvveXsK9WrhHB4qM"
   ```
   （`SHEET_RANGE` は既定 `A2:I200`）
4. **依存**：`googleapis`（Dockerfile の `npm install` で自動導入）

## 実行
```bash
# デプロイ先のシェル等で
node scripts/sync-sheet.js     # or: npm run sync
```
- B列に新しく貼られた案件（D列スコアが空の行）だけを採点
- 同じ行 C〜G に結果を書き戻し、管制塔(DB)にも候補登録
- 定期実行したい場合は cron / fly machines run / スケジューラから `npm run sync`

## シート列の対応
| 列 | 内容 | 記入者 |
|---|---|---|
| A | 媒体（ランサーズ/クラウドワークス） | 人（プルダウン） |
| B | 募集本文 | **人（ここだけ）** |
| C | 案件名 | 自動 |
| D | スコア | 自動 |
| E | 優先度 | 自動 |
| F | 予測受注率 | 自動 |
| G | 提案状況（応募推奨/見送り） | 自動 |
| H | 結果 | 人 |
| I | メモ | 任意 |

## セキュリティ
- SA秘密鍵は **fly secrets のみ**。`.env` や Git にコミットしない（`.gitignore` 済み）。
- 共有はその1シートに限定（SAに余計なファイルを共有しない）。
