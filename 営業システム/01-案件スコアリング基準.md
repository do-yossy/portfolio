# 01 案件スコアリング基準（役割1）

案件を**数値で**評価し、応募可否と優先度を機械的に決める。属人的な「なんとなく良さそう」を排除する。

## 出力フォーマット（この形で返す）
```
【案件分析】
案件名：
推定受注率：__%
利益率（想定）：__%
工数（想定）：__h
継続可能性：高 / 中 / 低
スコア：__/100（優先度 S / A / B / 見送り）

【応募判断】応募する / 応募しない
【理由】（点数の根拠と除外フラグの有無）
【応募文】→ 02テンプレートから生成
```

## 加点項目（最大100点）

### ① 予算 — 25点（利益率の源泉）
| 提示予算 | 点 |
|---|---|
| ¥250,000 以上 | 25 |
| ¥120,000〜250,000 | 18 |
| ¥50,000〜120,000 | 10 |
| ¥50,000 未満 | 3 |

### ② テンプレ流用可能性 — 20点（工数＝利益率＆再現性）
14本の制作テンプレ（カフェLP / 法律事務所 / EC / 予約 / 請求書 / 勤怠 / 在庫 / AI添削 / Excel自動化 / LINE / スクレイピング / 介護 / 要件定義 / AI面接）への一致度。
| 流用度 | 点 |
|---|---|
| 直マッチ（ほぼ流用で納品可） | 20 |
| 一部流用（5〜7割） | 12 |
| ほぼ新規 | 4 |

### ③ 仕様の明確さ — 20点（修正無限・要求過多リスク回避）
参考サイト・ページ数・必要機能の記載がどれだけ揃っているか。
| 明確度 | 点 |
|---|---|
| 明確（参考サイト＋ページ数＋機能が明記） | 20 |
| 一部のみ | 10 |
| 曖昧（「いい感じに」レベル） | 2 |

### ④ 継続・保守の見込み — 15点
| 見込み | 点 |
|---|---|
| 高（更新前提 / 複数フェーズ / 法人） | 15 |
| 中 | 8 |
| 単発で終わる | 3 |

### ⑤ 競合の少なさ × 募集人数 — 10点
| 状況 | 点 |
|---|---|
| 競合少（提案数少）＋複数採用 | 10 |
| 普通 | 5 |
| 競合多数 or 1名のみ採用 | 2 |

### ⑥ 締切の近さ — 10点（即着手で受注率↑）
| 締切 | 点 |
|---|---|
| 適度に近い（着手金→数日で動ける） | 10 |
| 普通 | 6 |
| 遠い / 未定 | 3 |

## 除外フラグ（避ける案件 — 該当で減点 or 即見送り）
| フラグ | 処理 |
|---|---|
| 修正回数の上限・追加費用条項が無く「納得いくまで」系 | −15 |
| 仕様未確定でヒアリングにも応じない | −15 |
| 予算に対し機能過多（要求過多） | −15 |
| 短納期 × 高工数（テンプレ流用不可 × 3日以内 等） | −20 |
| 極端な低単価（下記の時給換算で割れる） | **即・応募しない** |
| 著作権・偽装請負・前金不可など契約リスク | **即・応募しない** |

## 判定閾値
| スコア | 優先度 | アクション |
|---|---|---|
| 75〜100 | **S** | 即応募。提案文は実績訴求＋具体提案フル版（02テンプレA系） |
| 55〜74 | **A** | 応募（テンプレ流用前提・工数管理を明記） |
| 40〜54 | **B** | 不足情報をヒアリング（03）してから再判定 |
| 〜39 / 除外フラグ | 見送り | 応募しない（理由を一言記録して学習に回す） |

## 方針：全件提案（スコアはゲートにしない）
ユーザー方針により、**原則すべての案件に「提案文＋成果物」を作成**する（応募の最終判断は人）。
- スコア/優先度は「応募可否のゲート」ではなく「**優先順位＋注意喚起**」として使う（上から提案。低スコアでも提案は出す）。
- ただし**次は必ずフラグして判断を仰ぐ**（提案文は作るが、赤字・リスクを明記する）：
  - 契約リスク（著作権/偽装請負/前金不可 等）
  - 規約違反を招く要求
  - 極端な低単価で**確実に赤字**（実効時給が著しく低い）
- 上記フラグ以外は、スコアに関わらず**提案文＋成果物を提示**する。

## 時給換算チェック（低単価フィルタ）
```
実効時給 = 受注額 ×(1 − 手数料率) ÷ 想定工数h
```
- 目標：**実効時給 ¥4,000 以上**（利益率50%の目安ライン）
- 下回る案件はスコアに関わらず原則見送り（実績作り目的の例外のみ A以下で許容）
- 手数料率は媒体依存 → `05-見積もりロジック.md` 参照
