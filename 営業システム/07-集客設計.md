# 07 集客設計（自社メディア・インバウンド）

Lancers依存（手数料16.5%・競合・応募工数）から、**自社サイトに問い合わせが来る**構造へ。
直契約は**手数料0%＝利益率が跳ね上がり**、再現性も高い（仕組みが資産になる）。

## インバウンド・ファネル（4段）
```
① 集客   SEO / 実績(デモ) / SNS         → 見つけてもらう
② 着地   index.html（LP）               → 信頼させる（実績・料金・保証）
③ 転換   お問い合わせ.html（=ヒアリング）→ 問い合わせさせる（CV）
④ 商談   営業システム（03→04→05）       → 受注（手数料0%・高利益率）
```
各段のKPI：①流入数 ②直帰率 ③**問い合わせ率(CVR)** ④受注率。最重要は③。

## いま塞いだ穴（重要）
- 旧 `index.html` のCTAは全て `crowdworks.jp` / `lancers.jp` の**ホームに流出**＝訪問者を他社媒体に送り、自社で問い合わせを取れていなかった。
- → 主要CTAを **`お問い合わせ.html`（自社フォーム）** に向け直し。プラットフォーム経由希望者向けにランサーズ実プロフィールを副導線として残置。

## 転換最適化（役割7と連動）
- **フォーム＝ヒアリングシート**：`お問い合わせ.html` の入力項目＝役割2の9項目（業種/目的/予算/納期/機能/素材/参考サイト/相談内容）。問い合わせが来た時点で要件が揃い、商談が速い＝工数削減。
- ファーストビュー：「修正無制限・短納期」＋料金明示（¥50,000〜）で離脱を防ぐ。
- 信頼：実績（14デモ）・24h返信・仮払い/直契約の安心・FAQ。
- 摩擦低減：必須項目は最小（メール・依頼内容・相談内容のみ）。30秒で送れる。

## SEOキーワードマップ（ページ→狙うKW）
| ページ | 主要KW（例） | 意図 |
|---|---|---|
| index.html | Web制作 オンライン / LP制作 修正無制限 / ホームページ制作 格安 | 総合・指名前 |
| カフェLP / 各デモ | 〔業種〕 LP制作 / 〔業種〕 ホームページ 制作事例 | 業種×実績で集客 |
| 予約管理ツール 等 | 予約システム 制作 / 在庫管理 ツール 開発 受託 | 業務システム需要 |
| AI添削/面接 | AIツール 開発 受託 / 業務自動化 AI 制作 | 高単価・差別化 |
| LINE構築 | LINE公式アカウント 構築 代行 | 継続収益 |
| （新規コラム） | ホームページ制作 費用 相場 / 作り方 / 選び方 | 比較検討層を集める |

> 技術的SEO（実装済/今回）：`<title>`/`description`、OGP/Twitterカード、canonical、JSON-LD（ProfessionalService＋料金）、`sitemap.xml`、`robots.txt`、モバイル最適化、内部リンク。

## コンテンツ計画（更新するほど集客が伸びる）
1. **サービス別ランディング**：LP制作／ホームページ制作／業務ツール／AIツール／LINE構築（各KW最適化＋CTA）。
2. **実績の言語化**：各デモに「課題→施策→結果」の短い解説を付け、事例ページ化。
3. **コラム（比較検討層の獲得）**：制作費の相場、依頼の流れ、失敗しない選び方、AI活用事例。月2〜4本。

## 計測と学習ループ接続
- 問い合わせは **`channel:"self-media"`（手数料0%）** として受注ログに記録 → `集計.js` でLancers経由と**利益率・実効時給を比較**。
- インバウンドCVRと受注率を `学習/インサイト.md` に蓄積。刺さったFV・オファー・FAQを継続改善（役割7）。
- アクセス解析（Google Analytics / Search Console）を index に設定し、流入KWと離脱を可視化（次タスク候補）。

## 月商100万への寄与
- 直契約1件＝手数料0%。例：プレミアム¥250,000はLancers経由(手数料約13%)比で**+約32,500円/件**が丸ごと利益に。
- インバウンドは件数が積み上がるほど**応募工数ゼロで受注**が増える＝KPI「工数最小化」「再現性」に直結。
