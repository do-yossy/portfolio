# 05 見積もりロジック

`事業まとめ.html` の料金表を計算ルール化。**手数料と工数を逆算して利益率50%を守る**のが目的。

## ベースプラン
| プラン | 価格(税別) | 適用条件 | 標準納期 |
|---|---|---|---|
| ライト | ¥50,000 | LP・1ページ | 約1週間 |
| スタンダード | ¥120,000 | 5〜10ページ＋フォーム | 約2週間 |
| プレミアム | ¥250,000 | コーポレート＋CMS | 約3〜4週間 |
| システム | ¥200,000〜 | 予約・在庫・勤怠 等 | 要相談 |
| アプリ | ¥400,000〜 | iOS/Android | 要相談 |

### プラン自動選定ルール
- ページ数 1 → ライト ／ 2〜10 → スタンダード ／ 10超 or CMS必須 → プレミアム
- 業務ロジック（予約 / 在庫 / 決済 / 管理画面）あり → システム以上

## 保守（継続収益）
ライト ¥10,000 ／ スタンダード ¥20,000 ／ プレミアム ¥40,000（月額・税別）。
**全案件で必ず提案**（積み上げが月商100万の安定化に直結）。

## 手数料の逆算
受取額 = 受注額 − 手数料。
| 媒体 | 手数料 |
|---|---|
| クラウドワークス | 段階制：〜10万部分20% ／ 10〜20万部分10% ／ 20万超部分5% |
| ランサーズ | 一律16.5% |
| CWテック（法人直請け） | 0% |

CW実効手数料の例：
- ¥120,000 → 約18.3%（受取 ¥98,000）
- ¥250,000 → 約13%（受取 ¥217,500）
- ¥500,000 → 約9%（受取 ¥455,000）

→ **高単価ほど手取り効率が良い**。同額なら CWテック ＞ ランサーズ ＞ CW。

## 利益率チェック（必須）
```
実効時給 = 受取額 ÷ 想定工数h
利益率   = (受取額 − 直接コスト) ÷ 受注額
```
- 目標：実効時給 ¥4,000 以上、利益率 50% 以上
- 下回るなら：スコープ縮小 / プラン変更 / オプション化 / 辞退 のいずれか
- テンプレ流用案件は工数が小さく利益率が跳ねる → `01` スコアの②を重視する理由

## 月商100万の逆算モデル（推奨＝高単価型）
| 構成 | 受注額 |
|---|---|
| プレミアム ¥250,000 × 2 | ¥500,000 |
| システム ¥200,000 × 2 | ¥400,000 |
| 保守（数件積み上げ） | ¥100,000 |
| **合計** | **¥1,000,000 / 月（4〜5件）** |

件数を絞るほど工数・手数料・修正リスクが下がり、**利益率と納期遵守率が上がる**。
量産型（LP¥50k×20件）は手数料・修正リスク・工数で不利 → 原則とらない。
