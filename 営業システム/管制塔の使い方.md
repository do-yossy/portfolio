# 管制塔の使い方（無料・1サイトで完結）

営業の作業は、できる限り **この管制塔（1サイト）だけ** で完結させます。
APIキーは不要・課金ゼロ。あなたが外に出るのは「ランサーズで応募ボタンを押す」時だけ。

## 毎日の流れ（3ステップ）
1. **貼る**：ランサーズの募集本文をコピーして、管制塔の「候補に取込」に貼る → 自動で採点
2. **見る**：カードの「📝」を押す → **提案文＋成果物が表示**（そのまま使える完成形）
3. **応募**：提案文をコピー → ランサーズの応募欄に貼る → 成果物（実績デモのURL／記事構成案）を添えて送信

これで1案件の準備が数十秒で終わります。

## ボタンの意味
| ボタン | 内容 | 料金 |
|---|---|---|
| 候補に取込 | 採点して候補に追加 | 無料 |
| 📝 | 提案文＋成果物を表示（無料テンプレ） | 無料 |
| ✨生成 | （任意）Claudeで高品質に作り直す。APIキー未設定なら自動で無料テンプレを返す | 無料／要APIキー |
| ▶ | 次のステージへ進める（応募→打合せ→…） | 無料 |
| 🗑 | 削除 | 無料 |

## 成果物の中身（自動で付きます）
- **Web系（LP/コーポ/EC/システム/AI/LINE）**：最も近い実績デモのURL＋ポートフォリオ＋ランサーズ実績
- **ライティング**：サンプル記事の構成案（タイトル・リード・H2/H3）。本文サンプルが要る時だけ追加で用意

## 指定フォーマットがある案件
文字数・文体・キーワード・構成の指定があれば、提案文に「指定に準拠して即着手します」と添えて応募。実際の本番成果物（Word記事など）が必要な場合だけ、別途用意します。

## もっと自動にしたくなったら（任意・有料）
「自分が関わらず、AIが高品質な提案文＋本文サンプルまで自動で」が必要になったら、`ANTHROPIC_API_KEY` を設定して ✨生成 を使います（1件¥2〜30）。まずは無料運用で十分です。
