# 学習ループ（案件をこなすほど賢くなる）

AIが案件をこなしながら **受注率・単価・利益率を上げていく自己改善ループ** の中核。

## 大前提：リポジトリ＝長期記憶
AIの記憶はセッションを跨ぎません。**このリポジトリが長期記憶**です。
だから「学習」とは——
1. 全応募の結果を `応募ログ.jsonl` に**記録**し、
2. `集計.js` で**データ化**し、
3. `学習プロトコル.md` のルールで **01の配点 / 02の文面 / `インサイト.md`** を**更新**する。

次のセッションは、更新後の知識（`インサイト.md`）から始まります。これが「成長」の実体です。

## ループ図
```
 ① 応募        02テンプレで提案・01でスコア・「予測受注率」も記録
   ↓
 ② 記録        応募ログ.jsonl に結果(受注/失注/返信なし)＋実績値を追記
   ↓
 ③ 集計        node 集計.js → 受注率・利益率・予測vs実績のズレ・改善提案
   ↓
 ④ 更新        学習プロトコル.md に従い 01配点・02文面・インサイト.md を更新
   ↓
 ⑤ 次案件は更新後の基準で処理 → ①へ（以後ループ）
```

## 売上を上げる3レバー（このループが最適化する対象）
| レバー | 効かせ方 | 見る指標 |
|---|---|---|
| 受注率↑ | ターゲティング精度（01）＋提案文の質（02）を実データで磨く | タイプ別/テンプレ別 受注率 |
| 単価・利益率↑ | 勝てる高単価タイプを特定し応募を寄せる／保守を必ず付ける | タイプ別 平均単価・利益率・MRR |
| 工数↓ | 受注に効いた要素だけ再利用、効かない応募を減らす | 実効時給・予測との乖離 |

## ファイル
| ファイル | 役割 |
|---|---|
| `応募ログ.jsonl` | 全応募の記録（学習データ・追記式・1行1案件） |
| `集計.js` | ログ → KPI・キャリブレーション・改善提案を算出（週次レポート＝役割8兼用） |
| `学習プロトコル.md` | データから 01/02/インサイト を更新するルール（＝学習アルゴリズム） |
| `インサイト.md` | 蒸留された知識。**セッション開始時に必読** |

## 応募ログのスキーマ（`応募ログ.jsonl` 1行＝1 JSON）
| キー | 意味 | 例 |
|---|---|---|
| `id` | 連番ID | "2026-0001" |
| `date` | 応募日 | "2026-06-04" |
| `channel` | 媒体 | "crowdworks" / "lancers" / "cwtech" |
| `title` | 案件名 | "美容サロンLP" |
| `industry` | 業種 | "美容" |
| `type` | 種別 | "LP"/"corp"/"ec"/"system"/"ai" |
| `budget` | 提示予算 | 50000 |
| `proposed_price` | こちらの提示額 | 50000 |
| `est_hours` | 想定工数h | 6 |
| `score` | 01スコア | 78 |
| `priority` | 優先度 | "S"/"A"/"B"/"skip" |
| `pred_win_rate` | **予測受注率%（後で実績と照合）** | 62 |
| `template` | 使用テンプレ | "A"/"B"/"C"/"D" |
| `outcome` | 結果 | "applied"/"pending"/"won"/"lost"/"no_reply"/"declined" |
| `actual_price` | 受注額（受注時） | 50000 |
| `actual_hours` | 実工数h（完了時） | 6 |
| `profit_rate` | 利益率%（完了時） | 70 |
| `maintenance` | 月額保守（取れたら） | 10000 |
| `win_factors` | 受注の決め手 | "FVに予約導線を明記" |
| `loss_factors` | 失注の原因 | "価格負け" |
| `notes` | メモ | "" |

> `example:true` の行は集計から除外（書式見本）。実データは `example` を付けない。

## 運用規律（これが崩れると学習が止まる）
- **全応募を必ずログ**（受注しそうに無くても）
- 結果が出たら**必ず追記**（受注/失注/返信なし＋実績値）
- **10応募ごと or 週次**で `集計.js` → 更新 → `インサイト.md` 追記
