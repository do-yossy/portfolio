# Apps Script：スプレッドシート自動採点（デプロイ不要）

`案件採点.gs` を Google スプレッドシートに埋め込み、**B列の募集本文を Claude が採点して同じ行に書き戻す**。サーバー/Fly/サービスアカウント不要。Claude APIキーだけ。

## セットアップ（5分）
1. 案件シートを開く → **拡張機能 → Apps Script**
2. `案件採点.gs` の中身を全部貼り付けて保存
3. 左の **歯車（プロジェクトの設定）→ スクリプト プロパティ** に追加：
   - `ANTHROPIC_API_KEY` = `sk-ant-...`（Claudeのコンソールで発行）
4. 上部の関数選択で `scoreNewRows` を選び **▶実行** → 初回は権限を**許可**
5. シートを開き直すと **「Claude採点」メニュー** が出る → **新規行を採点**

## 手作業ゼロにする（自動化）
- Apps Scriptの **時計アイコン（トリガー）** → `scoreNewRows` を **時間主導・5分おき** で追加
  （または関数 `createTimeTrigger` を1回実行）
- 以後、**B列に貼るだけ**で、5分以内に C〜G・J 列へ採点結果が自動で入ります。

## 列の対応
A=媒体 / B=募集本文(入力) / C=案件名 / D=スコア / E=優先度 / F=予測受注率 / G=提案状況 / J=提案文
（C〜G・J はスクリプトが記入。J列に「提案文」ヘッダを付けると分かりやすい）

## モデル/コスト
既定は `claude-opus-4-8`（最高品質）。大量処理で安くしたいときは `案件採点.gs` の
`var MODEL` を `claude-haiku-4-5`（最安・高速）や `claude-sonnet-4-6` に変更。

## 注意
- 自動化（トリガー）は UrlFetch を使うため **インストール型トリガー**が必要（簡易onEditは不可）。手動メニューはそのまま使えます。
- APIキーはスクリプトプロパティのみに保存（コード/シートに書かない）。

# 媒体メール通知（`媒体メール通知.gs`）— 返信が必要なメッセージを管制塔に通知

ランサーズ / ココナラ / クラウドワークス から届く**メッセージ通知メール**を5分おきにGmailで検知し、
管制塔の `/api/inbound` に送って **「要返信」登録＋返信下書きの自動生成**を行う（メールは送らない）。

## セットアップ（5分）
1. <https://script.google.com> で**新規プロジェクト** → `媒体メール通知.gs` の中身を貼り付けて保存
2. 左の **歯車（プロジェクトの設定）→ スクリプト プロパティ** に2つ追加：
   - `API_BASE` = `https://sq-sales-tanto20.fly.dev`
   - `INBOUND_TOKEN` = **管制塔のログインパスワード**（＝ADMIN_PASSWORD。専用トークンを使う場合のみ別の値）
3. （任意）専用トークンにしたい時だけ：`fly secrets set INBOUND_TOKEN="その文字列"`。未設定ならログインPWが使われる。
4. 関数 `checkMediaMail` を **▶実行** → 初回は権限を**許可**
5. 時計アイコン（トリガー）→ `checkMediaMail` を **時間主導・5分おき** に追加（または `createTrigger` を1回実行）

## 動き
- 媒体メッセージ → 5分以内に管制塔の **🔔ベルが「🔴 要返信」** を表示（バッジに件数）
- 同時に **返信下書き**が自動生成（ベルの行クリックで開く）
- 返信したら **「✓返信済み」** で要返信を解除
- 二重送信は Gmail ラベル「管制塔通知済み」で防止
- 検知対象の絞り込みは `SUBJECT_HINTS`（件名キーワード）で調整可能
