# 「家にあるお金」── 調査結果と、開発を止めた判断

作成：2026-08-28

## 結論

**製品としての開発は止める。** 競合に勝てないため。
ただし「自分の家の不用品を洗い出す道具」としては動くので、削除はしない。

---

## 1. 競合（着手後に調査。順序を誤った）

「売りたい物が決まっていない人向けは空いている」という前提で作ったが、**空いていなかった**。

| サービス | 内容 |
|---|---|
| **おいくら** `/cg_matome/` | **「まとめて片付け・カテゴリ不明商品」の専用ページが既に存在**。近隣リサイクルショップへ一括査定依頼 |
| **カシャリ** | ガイドに沿って**撮影するだけ**で査定依頼。結果がアプリに届く。手数料無料 |
| **おまかせネコの手** | 「**家にある不用品をまとめて査定してほしい人**」向けと明記 |

3つ目は、こちらが想定した利用者を同じ言葉で書いている。

### 決定的な差

```
競合：  写真を撮る → 業者が見る → 実際の査定額（本物の金額）
自作：  43問に答える → 推定額（幅3.2倍の目安）
```

利用者が欲しいのは**実際にいくらもらえるか**であって、目安ではない。
撮るだけで本物の金額が出るサービスがある以上、質問に答えてもらう理由がない。

「忘れている物を思い出させる」という差別化も、冷静に見れば弱い。
押し入れを開けるのにツールは要らない。

## 2. 収益モデル（こちらは有望。次の案でも使える）

買取系アフィリエイトは、これまで検討したどの収益源より条件が良い。

| 項目 | 内容 |
|---|---|
| 成果報酬の実例 | **ザ・ゴールド 4,500円（税抜）** |
| 成約率の実例 | **平均CVR 10.5%** |
| 提携先 | 買取王子＝アクセストレード／バイセル＝複数ASP／もしもアフィリエイトにも中古買取の高単価案件 |

### 必要な集客量

```
4,500円 × 月22件 = 月10万円
CVR 10.5%  → 必要クリック 月210件
クリック率15% → 必要訪問者 月1,400人
```

**月1,400人で10万円**。比較のため、これまでの試算を並べる。

| 収益モデル | 月10万円に必要な訪問者 |
|---|---:|
| **買取アフィリエイト** | **約1,400人** |
| LIFE CHOICE（買う前チェック） | 約10,800人 |
| SNS×アフィリエイト | 約45,000人 |

**桁が違う。** 入り口さえ見つかれば、この収益モデルは有効。

## 3. この件から得た教訓

**着手前に競合を調べること。**

今回「広め方を先に決める」とは言ったが、**競合の確認を後回しにした**。
その結果、作ってから「勝てない」と分かった。作業は数時間で済んだので損失は小さいが、
順序としては誤り。

正しい順序：

```
1. 競合を調べる      ← ここが先
2. 勝てる一点を決める
3. 広め方を決める
4. 作る
```
