# 家にあるお金

家に眠っている不用品の売却見込み額を、場所ごとに見ていって出す道具。

> **開発は止めています。** 競合（おいくら・カシャリ等）に勝てないと判断したためです。
> 経緯は [docs/調査結果と中止の判断.md](docs/調査結果と中止の判断.md) を参照。
> 自分用の棚卸しには使えるので、削除せず残してあります。**公開・宣伝はしません。**

---

## 使う

`start.bat` をダブルクリック。ブラウザが開きます。

```bash
# コマンドから
cd 家にあるお金
node serve.mjs        # http://localhost:3500/
```

`index.html` を直接開いても動きません（ESモジュールと `fetch` を使っているため）。

---

## 何をするか

クローゼット → 引き出し → 押し入れ → リビング → 本棚 → キッチン → 玄関 の順に、
「ありませんか？」と問いかけていきます。忘れられやすい高額品から先に聞きます。

チェックを入れたら、

- 買ったときの値段（4段階）
- 今の状態（4段階）
- 点数（既定は1点）

を答えると、その場で見込み額が出ます。最後に合計・場所ごとの内訳・売る順番が出ます。

---

## 金額について

**すべて推定です。実勢を確認したものではありません。**

- 必ず幅で表示します（1つの数字に丸めません）
- 実際の買取価格は状態・年式・ブランド・時期・お店で大きく変わります
- 査定額を保証するものではありません
- 買取業者への案内は実装していません（特定の業者を推奨しない状態です）

入力内容はブラウザ内にのみ保存され、どこにも送信されません。

## 開発

```bash
node tests/estimate.js     # 査定ロジック 463件
node tests/page.js         # 画面と絞り込み 97件
node tools/build-items.mjs # 品目データの再生成
```

依存パッケージなし。ビルド不要。

```
data/      品目と場所（JSON）
lib/       査定の計算。UIを含まない
tests/     テスト。フレームワークは使わない
tools/     データ生成
docs/      調査結果と判断の記録
```

品目を足す・金額を直す場合は `tools/build-items.mjs` を編集して再生成してください。
