## 1. 結論（要旨）

AI動画生成ツール **Higgsfield** を用いて、**①AI教育コンテンツ（歴史の解説動画）** と **②AIペットメモリアル** の2案を、**まず月1万円規模・約1か月の小規模検証**として立ち上げたい。両案とも**生成原価がほぼゼロ**で、失敗しても損失は軽微、当たれば高粗利で伸ばせる。実物の体験デモ（別紙）まで用意済みであり、あとは「小さく試して数字で判断する」段階である。**本稟議では、この検証着手と少額の費用枠をご承認いただきたい。**

## 2. 稟議事項（ご承認いただきたいこと）

1. **Higgsfield 有料プランの契約**（まず無料トライアルで検証 → 継続時 PLUS 約4,500円/月 または ULTRA 約1.1万円/月。**月1.1万円を上限**とする）。
2. **2案（教育・ペットメモリアル）の試作・検証フェーズ（〜約1か月）への着手**。
3. **監修・法務確認の外部費用枠（上限 5万円）**（教育＝著作権確認・歴史監修／メモリアル＝グリーフケア・獣医監修の文言確認）。
4. 検証終了後、**あらかじめ定めるKPI・撤退基準に基づき、次段階（本格展開）の可否を再判断**すること。

> ※ 承認対象は上記の**少額・短期の検証**である。本格展開・追加投資は、検証結果を踏まえ改めて起案する。

## 3. 背景・目的

- 当社では「個人 × AI」で立ち上げ可能な新規事業を複数検討している。その中で Higgsfield は、**画像・動画・音声・3D・ナレーションを一気通貫で量産**でき、**1本あたりの生成原価が数十円規模**という特長を持つ。
- 従来は「制作費が高く、量を作って検証できない」ことが動画コンテンツ事業の壁だった。AIにより **「量産して当たりを見つける」** が現実的になった。
- この特長が最も活きるのが、**教育コンテンツ（暗記科目の解説動画）** と **ペットメモリアル（思い出の映像化）** の2領域である。いずれも「映像にする価値が高く、支払い意欲がある」。
- 目的は、**低リスクで市場性を検証**し、当たりを見極めてから投資を拡大すること。

## 4. 提案内容

### 案A：AI教育コンテンツ（歴史の解説動画）

- **概要**：教科書の「文章では分かりにくい」内容を、小中学生が**"見て理解できる"映像**に変換した短尺の学習動画を量産する。歴史の出来事を再現映像で見せる、布陣や地図の変化・仕組みをアニメーションで示す等、抽象的な文章を具体的な映像に置き換える。台本はAIで整理し、ナレーション＋再現映像・図解＋一貫キャラ（先生役）で構成する。歴史を起点に、理科・地理・古典など暗記科目全般へ展開できる。
- **核となる価値**：「読んで覚える」を「**見て分かる**」に変える。暗記を「情景としての記憶」にし、学びのハードルを下げる。
- **提供形態**：YouTubeシリーズ公開（認知・広告収益）→ 動画教材のサブスク → 塾・学校向けB2B・教材販売。

### 案B：AIペットメモリアル

- **概要**：飼い主が持つペットの写真・動画を素材に、見送り後の**追悼ムービー・3Dモデル**を制作して提供する。当社で検討中の「ペット看取り伴走」アプリの**自然な延長・上位オプション**にもなる。
- **提供形態**：追悼ムービー／AR・3Dプリント用の3Dモデル／思い出の再構成。
- **重要な線引き**：**「思い出を形にするメモリアル」に限定**する。"生きているかのように振る舞う対話AI・完全再現"は悲嘆を長引かせる恐れがあるため行わない。**"再現"ではなく"表現"**と位置づけ、飼い主の意思とグリーフケア監修の下で提供する。

## 5. 市場と意義

| 案 | 市場（規模感） | 意義 | 競合と差別化 |
|---|---|:---:|---|
| A. 教育コンテンツ | 教育・EdTech（大）。暗記科目は挫折しやすく動画解説の需要が高い | ★★ | スタディサプリ／教育系YouTuber／NHK for School。**AIによる量産・網羅性・低コスト＋親しみやすい一貫キャラ**で差別化 |
| B. ペットメモリアル | ペット関連（拡大）。看取り・見送り期の飼い主向けは国内で手薄 | ★★★ | 写真プリント・葬儀サービス等はあるが**"映像・3Dで思い出を形にする"は空白**。看取りアプリと連動できるのが強み |

- **教育の意義**：文章が苦手な子でも映像なら直感的に理解できる。多言語吹き替えで海外の日本語学習者にも届く。
- **メモリアルの意義**：家族同然のペットを亡くした飼い主の心の支えになる。**感謝・支払い意欲がともに高い**領域。

## 6. 収益見込み（日本円）

いずれも**生成原価はほぼゼロ**（ツール月1.1万円の範囲内で両案を運用可能）。以下は安定期の目安。

### 案A：AI教育コンテンツ

| 収益源 | 条件 | 目安 |
|---|---|---|
| YouTube広告 | 再生数に連動 | 月 数万〜数十万円 |
| 動画教材サブスク | 月480〜980円 × 会員 | 会員1,000人で月48〜98万円 |
| 塾・学校 B2B | 1校 月2〜5万円 | 20校で月40〜100万円 |
| 教材販売（単発） | 1本〜パック単位 | スポット収入 |

→ 立ち上げ期はYouTubeで認知と実績をつくり、その後サブスク／B2Bで収益化。動画は**公開後も残り続けるストック資産**になる。

### 案B：AIペットメモリアル

| 商品 | 単価（想定） | 補足 |
|---|---|---|
| 追悼ムービー | 1点 1〜3万円 | 素材（写真・動画）から制作 |
| 3Dモデル（AR/3Dプリント用） | 1点 1.5〜5万円 | 高付加価値オプション |
| 看取りアプリの上位プラン | 月額 or 都度 | アプリと連動時 |

→ 受注 **月20件 × 平均2万円 ＝ 月商 約40万円** を初期目安。原価は生成費（数百円）＋作業時間のみで**粗利率が極めて高い**。

## 8. スケジュール（制作期間の前提：Claude Code 24時間稼働）

本2案は「大規模開発」ではなく**「サービス（ワークフロー整備＋事例づくり）」**であり、短期で開始できる。付随ツール（投稿用LP等）の開発は Claude Code 24h稼働で **Proプラン 約1〜2週／Maxプラン 約1週**。

| フェーズ | 期間 | 内容 |
|---|---|---|
| フェーズ0：品質検証 | 数日 | 無料トライアルで試作数本を生成し、映像の質・所要時間・原価を確認 |
| フェーズ1：試作・公開 | 1〜2週 | 教育＝歴史動画3〜5本をYouTube公開／メモリアル＝サンプル制作・提供メニュー化 |
| フェーズ2：展開（条件付き） | 以降 | 反応を見てサブスク／B2B営業／受注開始。**KPI達成が前提** |

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| **著作権**（教育） | 教科書の文章・図版は複製しない。**歴史的事実・学習指導要領（学ぶ範囲）は著作権の対象外**であり、"教科書に沿ったオリジナル"として作図する |
| **正確性・時代考証**（教育） | AI生成の歴史画像はアナクロ（時代のズレ）が起きうる。**公開前に人が監修・確認**することを必須工程にする |
| **グリーフケアの線引き**（メモリアル） | "思い出のメモリアル"に限定し、"生きているフリの対話AI"は行わない。飼い主の意思確認＋専門家監修 |
| **品質のばらつき**（メモリアル） | 仕上がりは素材の量・質に依存。**"再現"でなく"表現"**と位置づけ、受注前に期待値を明示する |
| **広告表示・景表法／ステマ規制** | スポンサー動画等は"広告"と明示。誇大・優良誤認の表現をしない |
| **プラットフォーム依存**（Higgsfield／YouTube） | 台本・素材・生成データは自社保管。チャネルを複数に分散し、単一依存を避ける |
| **収益の不確実性** | 小さく始め、下記の撤退基準で早期に見極める |

## 11. 投資対効果・撤退基準（スモールベット）

- **最大リスク**：ツール費 月約1万円＋監修 数万円＋既存工数。**損失は軽微**。
- **上振れ**：生成原価ほぼゼロで高粗利。教育は**動画が残り続けるストック資産**、メモリアルは**感謝・高単価**。当たれば投資対効果が大きい。
- **撤退／縮小の基準（例）**：
  - **教育**：フェーズ1開始から3か月で、YouTube反応（登録・再生）・サブスク仮申込・B2B商談が目標に届かなければ縮小または撤退。
  - **メモリアル**：試作サンプルへの反応・受注見込みが立たなければ、独立事業化せず**看取りアプリのオプション扱い**に留める。
