# 事業計画書（全案まとめ）— 個人×AI 事業案

株式会社ソーシャルクオリティ ／ 社内提案資料 ／ 2026年8月

---

## 結論（先に要点）

- **推奨**：まず **スタンプ工房**（Maxプランで1〜2日・最小コストで"売れるか"を即検証できる入口）で着手し、並行して本命の **デジタル弟子（B2B技術承継）** を取引先1社で試験導入（PoC）する**二段構え**を提案します。
- **理由**：デジタル弟子はB2B月額で**収益が最も堅く（3年目 月400〜1,500万目安）**、当社のHR・事業の人脈が最も活きるため。
- **社会的意義を最優先する場合**：**ペット看取り伴走**（日本に存在せず、感謝が最も深い。海外に確立した手本あり）。
- **見送り／要覚悟**：投資分析支援（株価・財務データの商用ライセンスが関門）、マッチング（超レッドオーシャン＋高い顧客獲得コスト）。
- **法務・ライセンスの壁は全案とも突破可能**（"やらないで回避"／届出・eKYC／データ契約。詳細は末尾ガイド）。
- **広め方の共通原則**：個人向けは「まず自分で使って結果を発信→口コミ」、法人向けは「1社の成功事例をつくり同業・団体へ」。

## この企画について

動画「個人×AI」の着想と競合検証から生き残った候補を、1ファイルで比較・判断できるようにまとめた資料です。各案に **市場／意義／競合／広め方・営業／制作期間／収益見込み／必要な事／結論** を統一フォーマットで記載しています。

> ※ 数値は 2026年8月時点の仮試算（要検証）。法務・ライセンスの突破法は末尾の「法務・ライセンス 突破ガイド」を参照。

## この計画書の「制作期間」の前提

**「Claude Code（AI）で24時間、開発を回した場合のMVP完成目安」**で書いています。
- **Proプラン**：利用上限が低めなので連続稼働が途中で頭打ち＝**遅め**。
- **Maxプラン**：上限が高く24時間回しやすい＝**速い（体感 Pro の2〜3倍のスピード）**。
- ⚠️ ただし**「コード以外」**（届出・データ契約・eKYC・専門家監修・テスト・公開・最初の顧客集め）は、AIでは終わらず**別途カレンダー時間**が必要。ここが実際の律速になります。

## 作った後、どう広める・営業する？（基本のき）

アプリは**作っても、知られなければ誰も使いません**。広め方は「誰向けか」で2つに分かれます。

### A. 個人向け（toC：ペット看取り・マッチング・スタンプ・投資）
お金をかけずに広める順番👇
1. **自分で使って結果を出し、SNS・ブログで発信**（「使ったらこうなった」が一番の宣伝＝信用になる）
2. **悩んでる人が集まる場所で伝える**（X／Instagram／該当コミュニティ／掲示板／LINEオープンチャット）
3. **検索で見つけてもらう**（悩みで検索する人向けに"解決記事"を書く＝SEO）
4. **口コミ・紹介の仕組み**（紹介したら特典＝友達が友達を呼ぶ）
5. **広告は最後**（お金がかかるので、無料施策で手応えが出てから）
- コツ：**狭い一群に深く刺す**（万人向けにしない）。最初の熱いファンが口コミを生む。

### B. 法人向け（toB／B2B2C：デジタル弟子・障害児）
1. **まず1社に無料or低額で試してもらう**（＝成功事例を作るのが最優先）
2. **その事例を"証拠"に、同業・団体へ広げる**（商工会議所・業界団体・金融機関・自治体経由＝信用を借りる）
3. **既存客からの紹介**（B2Bは紹介が最強・成約率が高い）
4. **セミナー・展示会**で見込み客に直接会う
- コツ：広告より**「1社の成功事例」**。それが次の10社を連れてくる。

## 1. デジタル弟子（B2B技術承継／自分の分身AI）★本命

- **概要**：ベテランの判断（暗黙知）をAI対話で吸い出し、後任が根拠つきで相談できる分身に。中小の現場・専門職の技能承継に特化。
- **市場**：日本は事業承継クライシスのど真ん中。技術伝承AIは大手SIer向けに市場化済み＝**需要は実証済み**。中小・現場向けの安価な受け皿が空く。
- **意義**：**日本の中小の技術・技能が、引退とともに消えるのを防ぐ**。地域産業・ものづくりの継承に直接貢献。
- **競合**：NTTデータ／三菱総研 匠AI／NEC／Airion（大企業向け激戦）、Delphi／オルツ（クローン系）。→ **中小×現場×安価×根拠つき**で差別化。
- **広め方・営業**（toB）：**取引先1社でPoC → "技能が継げた"事例化 → 商工会議所・業界団体・事業承継を支援する金融機関経由**で横展開。あなたのHR・事業の人脈が最も効く。
- **制作期間**：コア開発（Claude Code 24h）＝**Pro 約3〜4週／Max 約2週**。＋コード以外（セキュリティ設計・PoC先確保・現場監修）で+数週。
- **収益見込み**：B2B月額（1社 月3〜5万＋導入支援費）。3年目に **30〜100社 → 月400〜1,500万** を目安。単価が高く少数で成立。
- **必要な事**：LLM＋RAG（根拠つき）、**セキュリティ最優先**（機密・データ所有権を顧客に）、B2B営業。※許認可は不要。
- **正直な結論**：技術伝承AIは激戦だが、大企業向け高額の隙間（中小・安価）は空く。**収益が最も堅く、あなたの人脈が最も効く**。勝負は現場導入と営業。

## 2. ペット看取り伴走 ★感謝最大

- **概要**：シニア期からQOLを毎日スコア記録→変化を可視化して"その時"を客観判断→家族で合意→見送り後のグリーフケアまで伴走。医療判断はしない。
- **市場**：ペット関連は拡大基調。健康記録・葬儀・異常検知は飽和だが、**"看取り期の飼い主向けツール"は日本に無い**（海外に手本＝作り方明確）。
- **意義**：**家族同然のペットの最期の判断の後悔を減らし、飼い主の心を守る**。人生で最も苦しい判断を支える＝感謝が最も深い。
- **競合**：ペットノートPlus（健康記録）・PetVoice（異常検知）等は別領域。看取り期は空白。
- **広め方・営業**（toC＋病院B2B2C）：①飼い主向けにSNS・体験談で発信 ②**緩和ケア・往診の動物病院に配布してもらう**（病院は説明工数を削減できる）。
- **制作期間**：コア開発（Claude Code 24h）＝**Pro 約2〜3週／Max 約1〜2週**。＋獣医・グリーフケアの**文言監修**（安全性の要）で+数週。
- **収益見込み**：フリーミアム＋月額＋病院向け月額。3年目に **月数百万** を目安（会員数と病院提携数次第）。
- **必要な事**：**獣医師＋グリーフケアの監修者確保**（言葉の安全性）、慎重なUX、要配慮情報の扱い。
- **正直な結論**：日本に無く感謝が最大。弱点は収益（看取り期は数ヶ月〜1年で短い）だが、**シニア期からの伴走＋病院B2B2C**で設計的に解ける。

## 3. スタンプ工房 ★即検証

- **概要**：AI生成画像を、LINEスタンプ/SUZURI等の入稿規格へ一括変換し申請ZIPを出力。量産の手作業を消す。
- **市場**：AI画像の普及で"作り手"は急増。ただし**支払い意欲は低め**（無料/安価ツールに慣れている）。市場は広いが単価が低い。
- **意義**：個人が創作で少額でも稼ぐ入口を広げる。※社会的意義は小さめ。
- **競合**：Canva／汎用リサイズ、スタンプメーカー、プラットフォーム純正機能。入稿規格特化は手薄だが**堀は薄い**。
- **広め方・営業**（toC）：**自分で作って売り、売上と工数を公開**（＝宣伝）→ 同じことをしたい層にツール開放 → 制作代行。
- **制作期間**：コア開発（Claude Code 24h）＝**Pro 約3〜5日／Max 約1〜2日**（ブラウザ完結で軽い）。
- **収益見込み**：自社販売益＋有料版＋代行で **月数万〜数十万**。副収入〜小規模の域。
- **必要な事**：画像処理、各プラットフォームの入稿規格DB、決済。個人〜少人数で可。
- **正直な結論**：大きな事業にはなりにくいが、**最小コスト・最短で"売れるか"を検証できる入口**。ここで得た顧客理解を本命に活かす。

## 4. 投資分析支援

- **概要**：ファンダ×市場分析を統合スコア化→根拠つきスクリーニング→**正直なバックテスト**。勝率は保証せず、期待値・ドローダウンで戦う。
- **市場**：新NISA以降、個人投資家の裾野が拡大。ツールに月額を払う文化はある。ただし**無料の高機能ツール（証券会社）が基準**で有料化のハードルは高い。
- **意義**：個人投資家が**感覚でなく根拠で判断でき、無謀な損失を減らす**。金融リテラシー向上に寄与。
- **競合**：マネックス「銘柄スカウター」等が無料で強い、TradingView。→ 統合スコア×説明性×誠実さで差別化。
- **広め方・営業**（toC）：**自分の運用で"根拠で判断できる体験"を公開**→投資コミュニティ→口コミ。「当てない・誠実」という姿勢を訴求。
- **制作期間**：コア開発（Claude Code 24h）＝**Pro 約3〜4週／Max 約2週**。＋**データの商用ライセンス契約**（コード以外・最重要）で別途時間。
- **収益見込み**：月額サブスク。3年目に **会員数千 → 月数百万** を目安。※データ契約が固定費として重い。
- **必要な事**：**データの商用ライセンス（生命線・EDINET無料＋J-Quants Pro等）**、金商法の線引き（助言しない）、景表法。
- **正直な結論**：「勝率70%保証」は不可能・違法リスクで却下。**データライセンスが最初の関門**。通れば誠実さで狭く濃い有料層は取れる可能性。

## 5. マッチング（内面先行／釣り合い）

- **概要**：写真スワイプでなく価値観・会話から始め、AIが会話を支える。内部で釣り合いを考慮し相互マッチを成立させる（容姿スコアは非表示）。
- **市場**：国内マッチングは**利用者1000万人規模・市場は年1000億円超**とされる大市場。ただし**超レッドオーシャン**（大手が資本で支配）。
- **意義**：**見た目で消耗してきた人が、傷つかず出会える**。孤独・少子化への小さな貢献。
- **競合**：Pairs／Tinder／with／Omiai（超大手）、S'More（内面先行・撤退）。→ 特定層＋思想＋AI会話で差別化。
- **広め方・営業**（toC）：月額サブスク＋プレミアム。**口コミでCPAを下げる**のが生命線。相互マッチ率を武器にSNS実証。さらに、既に他のマッチングアプリを使っている「消耗した層」を狙って獲得（他アプリで疲れた人へSNS・コンテンツ・紹介で届く／紹介キャンペーンで流入）。※**他社アプリ内での直接勧誘・スクレイピングは各社規約違反・スパムのため、"他アプリ利用者という顧客層"へのマーケティングに限る**。
- **制作期間**：コア開発（Claude Code 24h）＝**Pro 約4〜6週／Max 約2〜3週**。＋**出会い系サイト規制法の届出・eKYC導入**（コード以外）で別途時間。
- **収益見込み**：月額（男性中心3,000〜4,000円）。**当たれば大きいが、高CPAで黒字化に時間**。不確実性が高い。
- **必要な事**：**出会い系サイト規制法の届出**（公安委員会・行政書士代行可）・eKYC・年齢確認・モデレーション、資金。
- **正直な結論**：超レッドオーシャン＋高CPA。勝負は獲得と継続。**覚悟がある場合のみ**。

## 6. 障害児 情報一元化

- **概要**：その子の特性・支援方法・医療を一箇所に蓄積し、相手別に出し分けて共有。親が毎回ゼロから説明する負担を消す。
- **市場**：障害児通所支援の利用者は増加が続く。本人向け支援アプリ・事業者システムは飽和だが、**"親が使う情報一元化・共有"は空白**（行政は紙のサポートブック）。
- **意義**：**障害・発達特性のある子の理解が、人が変わっても引き継がれる**。親の負担を減らす福祉的意義が大きい。
- **競合**：本人向けアプリ・事業者業務システムは多数だが、親向けの一元化は手薄。
- **広め方・営業**（B2B2C／B2G）：**相談支援・放デイに配布してもらう（事業者が月額）／自治体のデジタルサポートブックとして導入**。まず1事業所・1自治体でPoC→事例化。
- **制作期間**：コア開発（Claude Code 24h）＝**Pro 約2〜3週／Max 約1〜2週**。＋当事者ヒアリング・項目設計で+数週。
- **収益見込み**：B2B2C／B2G中心。3年目に **月数十万〜数百万**（事業所・自治体の導入数次第）。保護者直接課金は薄い。
- **必要な事**：**要配慮個人情報の扱い**（保護者同意・暗号化・削除権）、当事者ヒアリング、B2B2C/B2G営業。
- **正直な結論**：空いていて意義も大きいが、**個人課金が難しく収益はB2B2C/B2G前提**。"稼ぐ"優先ならペット看取りより難易度は高い。

## 7. 総括・意思決定の指針

- **収益で選ぶ → デジタル弟子**（B2B月額・強みが効く・3年で月数百万〜千万規模）。
- **意義で選ぶ → ペット看取り**（日本に空き・感謝最大・作り方明確）。
- **まず動かす → スタンプ工房**（Maxなら1〜2日でMVP・最小コストで検証）。
- 投資・マッチングは、それぞれ**データライセンス／高CPA**という重い前提クリアが条件。
- **推奨**：①スタンプ工房で即検証しつつ、②本命デジタル弟子（or 意義ならペット看取り）を1社PoCへ。**広め方は"自分で使って発信→口コミ／1社の成功事例"が全案共通の起点**。
