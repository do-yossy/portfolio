# 事業計画（案）— 個人 × AI

社内提案資料 ／ 2026年8月

---

## 結論（要約）

- **推奨**：まず「スタンプ工房」で市場性を最小コストで検証し、並行して本命の「**分身AI（技術承継）**」を取引先1社で試験導入（PoC）する二段構えを提案する。
- **理由**：分身AIはB2Bの月額モデルで、収益の見通しが最も安定するため（3年目の月商目安 400〜1,500万円）。
- **社会的意義を重視する場合**：「ペット看取り伴走」を推奨する（国内に同種サービスがなく、利用者の便益が大きい）。
- **見送り・要検討**：投資分析支援（株価・財務データの商用ライセンス取得が前提）、マッチング（競争が激しく顧客獲得コストが高い）。
- **法務・ライセンス**：いずれの案も対応可能（対象行為の限定による回避／届出・本人確認／データ契約。詳細は末尾のガイド）。
- **販売・普及の基本**：個人向けは自社利用実績の発信と口コミ、法人向けは先行導入事例の横展開。
- **低コスト・高粗利で即開始できる選択肢**：AI広告クリエイティブ 量産・運用代行（Higgsfield 活用）。商品URLから広告動画を量産し"勝ちパターン"を検証する。ツール費は月 約1万円〜（詳細は 7章）。

## 本資料について

動画「個人 × AI」を起点に検討した事業案のうち、競合調査を経て有望と判断した候補を、比較・判断できる形で整理したものである。各案について 市場／意義／競合／販売・普及方針／制作期間／収益見込み／必要な要件／総合評価 を記載する。

> ※ 数値は 2026年8月時点の暫定試算（要検証）。法務・ライセンスの対応方法は末尾の「法務・ライセンス 対応ガイド」を参照。

## 制作期間の前提

制作期間は「Claude Code（AI）を用いて24時間開発を継続した場合の MVP（最小構成）完成目安」として記載する。
- **Proプラン**：利用上限が低く連続稼働が制限されるため、相対的に長い。
- **Maxプラン**：利用上限が高く連続稼働に適するため短い（体感で Pro の2〜3倍の速度）。
- ※ 開発以外の工程（届出・データ契約・本人確認・専門家監修・検証・公開・初期顧客の獲得）は AI では完結せず、別途の期間を要する。実務上はこれらが律速となる。

## 販売・普及の方針

プロダクトは開発しても、認知されなければ利用されない。獲得手法は対象により異なる。
- **個人向け（toC）**：①自社での利用実績を SNS・記事で発信し信用を形成 ②対象ユーザーが集まる場での訴求 ③検索流入（SEO） ④紹介インセンティブによる口コミ ⑤広告は反応確認後に投下。特定セグメントへの集中を基本とする。
- **法人向け（toB／B2B2C）**：①先行1社での導入実績（事例）の獲得を最優先 ②業界団体・商工会議所・金融機関・自治体を経由した横展開 ③既存顧客からの紹介。事例が次の商談を生む。

## 1. 分身AI（技術・判断の承継）

- **概要**：熟練者の判断（暗黙知）を AI との対話で蓄積し、後任が根拠付きで参照・相談できる仕組み。中小企業の現場・専門職の技能承継に特化する。
- **市場**：国内は事業承継が喫緊の課題。技術伝承 AI は大手 SIer により市場化されており、需要は実証済み。中小・現場向けの安価な選択肢が不足している。
- **意義**：中小企業の技術・技能が引退とともに失われる問題を抑止し、地域産業・ものづくりの継承に寄与する。
- **競合**：NTTデータ、三菱総研（匠AI）、NEC、Airion 等（大企業向けが中心）、Delphi・オルツ（クローン系）。中小・現場・低価格・根拠付き回答で差別化する。
- **販売・普及方針**：取引先1社での PoC を起点に導入事例を形成し、業界団体・商工会議所・事業承継支援を行う金融機関を経由して横展開する。
- **制作期間**：コア開発（Claude Code 24h）＝ Pro 約3〜4週／Max 約2週。加えて開発以外（セキュリティ設計・PoC先確保・現場監修）に数週を要する。
- **収益見込み**：B2B 月額（1社 月3〜5万円＋導入支援費）。3年目に 30〜100社、月商 400〜1,500万円を目安。単価が高く、少数の導入で成立する。
- **必要な要件**：LLM＋RAG（根拠付き）、機密情報のセキュリティ設計（データ所有権を顧客に帰属）、法人営業。特別な許認可は不要。
- **総合評価**：技術伝承 AI は競争が激しいが、大企業向け高価格帯の外側（中小・低価格）に余地がある。収益の見通しが最も安定する。要諦は現場導入と営業。

## 2. ペット看取り伴走

- **概要**：シニア期からペットの QOL（生活の質）を日次で記録し、変化を可視化して判断を支援する。家族での合意形成、見送り後のグリーフケアまで一貫して支える。医療判断は行わない。
- **市場**：ペット関連は拡大基調。健康記録・葬儀・異常検知は飽和しているが、看取り期の飼い主向けツールは国内に存在しない（海外に確立した手本がある）。
- **意義**：家族同然のペットの最期に関する判断の後悔を軽減し、飼い主の精神的負担を和らげる。利用者の便益が大きい。
- **競合**：ペットノートPlus（健康記録）、PetVoice（異常検知）等は領域が異なる。看取り期は空白。
- **販売・普及方針**：飼い主向けに SNS・体験談で発信するとともに、緩和ケア・往診を行う動物病院に配布してもらう（病院側は説明工数を削減できる）。
- **制作期間**：コア開発（Claude Code 24h）＝ Pro 約2〜3週／Max 約1〜2週。加えて獣医師・グリーフケア専門家による文言監修を要する。
- **収益見込み**：フリーミアム＋月額＋病院向け月額。3年目に月数百万円を目安（会員数・提携病院数に依存）。
- **必要な要件**：獣医師およびグリーフケア専門家による監修（言葉の安全性の確保）、慎重な UX 設計、要配慮個人情報の管理。
- **総合評価**：国内に存在せず、利用者の便益が大きい。課題は収益期間の短さだが、シニア期からの利用と病院経由の展開で補える。

## 3. スタンプ工房

- **概要**：AI 生成画像を、LINEスタンプや SUZURI 等の入稿規格へ一括変換し、申請可能な形式で出力する。量産時の手作業を削減する。
- **市場**：AI 画像の普及により制作者は増加。ただし支払い意欲は低く、市場は広いが単価が低い。
- **意義**：個人が創作を収益化する入口を広げる（社会的意義は限定的）。
- **競合**：Canva・汎用リサイズ、スタンプメーカー、各プラットフォームの標準機能。入稿規格特化は手薄だが、参入障壁も低い。
- **販売・普及方針**：自社で制作・販売し、売上と工数を公開して訴求する。同様の取り組みを行う層へのツール提供、制作代行へと展開する。
- **制作期間**：コア開発（Claude Code 24h）＝ Pro 約3〜5日／Max 約1〜2日（ブラウザ完結で軽量）。
- **収益見込み**：自社販売益・有料版・代行で月数万〜数十万円。副収入〜小規模の規模。
- **必要な要件**：画像処理、各プラットフォームの入稿規格データ、決済。少人数で構築可能。
- **総合評価**：大規模事業には至りにくいが、最小コスト・最短で市場性を検証できる。得られた知見を本命案に活用する。

## 4. 投資分析支援

- **概要**：ファンダメンタルと市場分析を統合してスコア化し、根拠付きのスクリーニングと客観的なバックテストを提供する。勝率は保証せず、期待値・最大ドローダウンを主指標とする。
- **市場**：新NISA 以降、個人投資家層が拡大。ツールへの月額支払い文化はあるが、証券会社が高機能な無料ツールを提供しており、有料化のハードルは高い。
- **意義**：個人投資家が感覚でなく根拠に基づき判断でき、過度な損失の抑制に寄与する。
- **競合**：マネックス「銘柄スカウター」等の無料ツール、TradingView。統合スコア・説明性・検証の誠実さで差別化する。
- **販売・普及方針**：自社運用による「根拠に基づく判断」の実例を公開し、投資家コミュニティ・口コミで拡大する。
- **制作期間**：コア開発（Claude Code 24h）＝ Pro 約3〜4週／Max 約2週。加えて株価・財務データの商用ライセンス契約を要する（最重要）。
- **収益見込み**：月額サブスク。3年目に会員数千、月数百万円を目安。データ契約が固定費となる。
- **必要な要件**：データの商用ライセンス（EDINET＝無料、株価は J-Quants Pro 等）、金融商品取引法の線引き（助言を行わない）、景品表示法への配慮。
- **総合評価**：「勝率保証」は不可かつ違法リスクがあり不採用。データライセンスの取得が前提条件となる。

## 5. マッチング（内面先行・釣り合い）

- **概要**：写真中心ではなく価値観・会話から関係を始め、AI が会話を支援する。内部で釣り合いを考慮し相互マッチの成立率を高める（容姿の評価値は非表示）。
- **市場**：国内マッチングは利用者1000万人規模・市場は年1000億円超とされる大市場。ただし大手が資本で優位を占める、競争の激しい市場である。
- **意義**：外見で不利になりやすい層が、負担なく出会える場を提供する。孤独・少子化への一定の寄与。
- **競合**：Pairs・Tinder・with・Omiai（大手）、S'More（内面先行・撤退）。特定層・思想・AI 会話支援で差別化する。
- **販売・普及方針**：月額課金。口コミによる顧客獲得コストの低減が要点。相互マッチ率を訴求する。加えて、他のマッチングサービスの利用者層（既存サービスに疲れた層）に対し、SNS・コンテンツ・紹介で訴求する。※他社サービス内での直接勧誘・データ収集は各社の規約に反するため、当該層への一般的なマーケティングに限定する。
- **制作期間**：コア開発（Claude Code 24h）＝ Pro 約4〜6週／Max 約2〜3週。加えて出会い系サイト規制法の届出・本人確認（eKYC）の導入を要する。
- **収益見込み**：月額（男性中心 3,000〜4,000円）。当たれば大きいが、顧客獲得コストが高く黒字化に時間を要する。不確実性が高い。
- **必要な要件**：出会い系サイト規制法の届出（公安委員会・行政書士による代行可）、本人確認・年齢確認、監視体制、資金。
- **総合評価**：競争が激しく顧客獲得コストが高い。要点は獲得と継続であり、相応の投資判断を要する。

## 6. 障害児 情報一元化

- **概要**：子どもの特性・支援方法・医療情報を一元的に蓄積し、共有相手に応じて出し分けて提供する。保護者が繰り返し説明する負担を軽減する。
- **市場**：障害児通所支援の利用者は増加。本人向けアプリ・事業者向けシステムは飽和しているが、保護者が使う情報一元化・共有は空白（行政は紙のサポートブックで対応）。
- **意義**：障害・発達特性のある子どもの理解が、支援者が変わっても引き継がれる。保護者の負担軽減と福祉的意義が大きい。
- **競合**：本人向けアプリ・事業者システムは多数だが、保護者向けの一元化は手薄。
- **販売・普及方針**：相談支援事業所・放課後等デイサービスに配布してもらい事業者が月額を負担、または自治体のデジタルサポートブックとして導入する。1事業所・1自治体での PoC から事例化する。
- **制作期間**：コア開発（Claude Code 24h）＝ Pro 約2〜3週／Max 約1〜2週。加えて当事者ヒアリング・項目設計を要する。
- **収益見込み**：B2B2C／B2G 中心。3年目に月数十万〜数百万円（導入事業所・自治体数に依存）。保護者からの直接課金は限定的。
- **必要な要件**：要配慮個人情報の管理（保護者同意・暗号化・削除権）、当事者ヒアリング、B2B2C／B2G 営業。
- **総合評価**：空白領域であり意義も大きいが、個人課金が難しく、収益は B2B2C／B2G が前提となる。

## 7. AI広告クリエイティブ 量産・運用代行（Higgsfield 活用）

- **概要**：Higgsfield を用いて、EC・D2C・店舗向けに「成果の出る広告クリエイティブ」を量産・運用する。商品 URL から広告動画を自動生成し、UGC 風・CGI・ナラティブ等の形式で大量のバリエーションを作成、検証を通じて"勝ちパターン"を特定する。制作代行（単発）・月額運用代行（継続）・広告出稿の成果報酬型で提供する。
- **Higgsfield の要点（調査より）**：単なる動画生成ではなく、①商品 URL からの広告自動生成（Marketing Studio）②UGC 風など複数フォーマット ③Soul ID によるブランドの"顔（アバター）"の一貫化 ④100本規模のバリエーションを数分で出力 ⑤指示に沿ったスケジュール自動実行（夜間稼働）— の点で量産と検証に強い。
- **市場**：EC/D2C・ローカルビジネスの広告需要は拡大。従来はクリエイティブの制作費が高く大量検証ができなかったが、AI により「量で検証して勝ちを見つける」ことが可能になった。
- **意義**：中小・個人の EC が、大企業並みの広告クリエイティブの量産・検証を低コストで実施でき、販促の成果を底上げできる。
- **競合**：制作会社（高価格）、フリーランス、広告運用代行（クリエイティブは外注・手薄）、他 AI 動画ツール（ツール提供にとどまる）。差別化は「量産 × 勝ちクリエイティブの検証 × ブランド一貫（Soul ID）× 出稿運用まで」。
- **販売・普及方針**：自社・知人の EC で"成果の出た広告"（CVR・ROAS 改善）の事例をつくり公開 → EC・D2C 事業者へ営業 → 月額運用・成果報酬へ移行する。
- **制作期間**：本案は「開発」ではなく「サービス」。Higgsfield の習熟と事例づくりで約1〜2週間で開始可能（AI の習熟は Max プランで加速）。
- **経費（Higgsfield／2026年8月時点・1ドル≒155円換算、税別・変動あり）**：
  - ツール費：ULTRA 年払 約 $70/月（≒ 月 約1.1万円。3,000クレジット＝月あたり 動画 約500本 または 画像 約12,000枚）。小規模開始なら PLUS 年払 約 $29/月（≒ 月 約4,500円）。
  - **1案件で100本のバリエーションを検証しても、生成原価は数千円規模**。生成原価はほぼゼロに近い。
  - その他：自身の作業時間（指示・選定・出稿・分析）、広告出稿費（クライアント負担）。
- **収益見込み（例）**：
  - クリエイティブ制作：月10〜30本パック 5〜15万円。
  - 月額運用代行：1社 月5〜20万円（クリエイティブ量産＋出稿運用＋分析）。
  - 成果報酬：広告成果（ROAS 改善分）の一定割合。
  - 試算：運用5社 × 月10万円 ＝ **月商 約50万円**。経費はツール 約1万円＋作業時間で、**粗利率が極めて高い**。成果報酬を組めば上限はさらに高い。
- **必要な要件**：Higgsfield の操作習熟、広告運用（Meta／TikTok 等）の基礎、EC/D2C への営業。特別な許認可は不要。※景品表示法（誇大広告・優良誤認の禁止）、生成物の権利・第三者の肖像／商標、**ステマ規制（UGC 風広告は"広告"である旨の表示が必要）**に留意する。
- **総合評価**：生成原価がほぼゼロで、従来は制作費の制約でできなかった「大量検証による勝ちクリエイティブの発見」を実現できる。成果報酬まで組み込めば収益上限が高い。差別化は「量産 × 検証 × ブランド一貫 × 出稿運用」の実行力。

### Higgsfield の主な機能（できること）

- **画像生成**：多数のモデル（Nano Banana／Seedream／Flux 等）で高品質画像を量産。
- **動画生成**：テキスト・画像から動画（Kling／Veo／Seedance 等。4K・複数カットに対応）。
- **広告自動生成（Marketing Studio）**：商品 URL を貼るだけで広告を生成。
- **Soul ID**：一貫したブランドアバター／キャラクターを全動画で使い回し。
- **話すアバター（Speak）**：リップシンクで話す人物動画（UGC・解説・接客向け）。
- **音声・ナレーション／吹き替え（dubbing）／ボイスクローン**：多言語に対応。
- **3D 生成**：画像から 3D モデル（GLB）。
- **編集系**：アップスケール（2K/4K）、アウトペイント（画像拡張）、リフレーム（縦横比変換）、背景除去、モーション制御。
- **Web サイト／アプリ／ゲーム制作**、キャラクターシート、解説・ショート動画ワークフロー。
- **TikTok 連携**（投稿・トレンド音源）、**バズり予測**、動画分析。
- **エージェント型**：チャットで指示するだけで一気通貫、スケジュールで自動実行（夜間稼働）。

## 8. 総括

- 収益性を重視する場合は「分身AI（技術承継）」を推奨する（B2B 月額・収益の見通しが安定・3年で月数百万〜千万円規模）。
- 社会的意義を重視する場合は「ペット看取り伴走」を推奨する（国内に空白・利用者便益が大きい・実装の手本がある）。
- 着手のしやすさを重視する場合は「スタンプ工房」を推奨する（最小コスト・最短で市場性を検証）。
- 投資分析支援・マッチングは、それぞれデータライセンス・顧客獲得コストという前提条件のクリアが必要である。
- **提案**：スタンプ工房で市場性を検証しつつ、本命の分身AI（意義を重視する場合はペット看取り）を取引先1社で PoC する。販売・普及は全案共通で「自社利用実績の発信と口コミ」「1社の導入事例の横展開」を起点とする。
