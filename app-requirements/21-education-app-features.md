# AI教育コンテンツ アプリ 機能一覧（歴史 →暗記科目）

> 前提：小中学生向け・**映画風の解説動画**で「見て分かる」。**子どもは熱中／親が払う**。**マルチデバイス＋親アカウント**。課金は**フリーミアム**（壁は"広さ・快適さ・親の安心"に置く）。

**凡例**：`[無料]` 無料で使える ／ `[有料]` 課金の壁の内側 ／ `[MVP]` 検証フェーズで作る ／ `[将来]` 拡大フェーズ

---

## 1. 画面フロー（ユーザーの流れ）

```
[入口] 無料動画/Shorts・LP
        │  （まず"見て分かる"を体験）
        ▼
[題材えらぶ] 時代/単元/学年でフィルタ
        │
        ▼
[映画風で見る] 教科書(文字)→映像の対比 → 5シーン再生
        │
        ▼
[クイズで確認] 2問 → 正解でカード獲得
        │
        ▼
[図鑑/城が埋まる] 収集・進行（次の時代が解放）
        │
        ├─►（無料はここで入口の続きに"壁"）──► [有料]全時代見放題・広告なし
        │
        ▼
[保護者] 進捗レポート（何を見た・正答率・学習時間）＝"払う価値"を実感
```

## 3. 無料↔課金の線引き（フリーミアム）

| プラン | 内容 | 価格 |
|---|---|---|
| **無料** | 各時代の**入口エピソード**、基本クイズ、カード数枚、**広告あり**、1デバイス | 0円 |
| **有料（月額）** | **全時代・全単元 見放題／広告なし／図鑑コンプ／進捗レポート／家族プラン／オフライン** | **月480〜980円**（体系化で〜1,980円） |
| **買い切り** | 「時代パック」等の単元まとめ | 都度 |
| **将来B2B** | 塾・学校へライブラリ配信（GIGA端末で低学年にも到達） | 1校 月数万円 |

**壁の置き方の原則**
- ⭕ 置いていい壁：**広さ（全時代）・快適さ（広告なし・オフライン）・完成（図鑑）・親の安心（進捗）**
- ⚠️ 置かない壁：子どもを煽る**FOMO**、**射幸性ガチャ**、学習の**本編を人質**、時間ぶつ切り課金

## 4. MVP（検証フェーズで作る最小セット）
1. 映画風動画の**視聴**＋**題材えらぶ**（時代/単元）
2. 各動画の**クイズ**＋**カード獲得・簡易図鑑**
3. **無料↔有料の1段ゲート**（入口無料 → 全時代見放題は有料）
4. **親アカウント**（決済・広告なし・**進捗レポート閲覧**）
5. **マルチデバイス**（スマホ/タブレット/Web）＋ **YouTube/Shorts で集客**
   - ※まずは YouTube/Shorts＋LP で"刺さるか"を検証 → アプリは反応が出てから作り込む

## 5. 越えない線・注意（設計の前提）
- **払うのは親**：子どもに直接課金を迫らない。決済は親アカウント。
- **監修・著作権**：教科書は複製しない（事実・範囲は自作）。歴史は**時代考証を公開前に確認**。映画風は**不気味の谷・アナクロを出さない品質管理**。
- **端末実態**：低学年は自分のスマホ所有が少ない → **親端末＋リビングTV＋（将来）B2BのGIGA端末**で届ける。
- **規制**：子ども向け課金の炎上・射幸性規制・景表法/特商法・プラットフォームの子ども向けポリシーに配慮。
