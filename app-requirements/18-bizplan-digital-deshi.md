# 事業計画書：デジタル弟子（B2B技術承継／自分の分身AI）

> 熟練者・ベテランの判断（暗黙知）をAIとの対話で写し取り、後任がいつでも根拠つきで相談できる"分身"にする。**中小の現場・専門職の技能承継に特化**。
> 構想は [`01-digital-deshi.md`](./01-digital-deshi.md)。

⚠️ 数値は 2026年8月時点の**仮試算（要検証）**。

---

## 1. エグゼクティブサマリー

- **何を**：ベテランへのAI定期インタビューで判断・勘所を蓄積（RAG）、後任が自然文で質問→**根拠（元発言）つきで回答**。
- **誰に**：特定ベテランに技術が属人化した中小企業（製造・設備保守・建設・専門サービス）。
- **強み**：汎用クローン（Delphi/オルツ）や大企業向け技術伝承AI（NTTデータ/三菱総研）が狙わない**「中小・現場・安価」**に特化。
- **正直な結論**：**技術伝承AIは激戦カテゴリ**（大手SIerが先行）。だが**大企業向けで高額・重い**ため、中小・現場向けの安価な受け皿は空きうる。**B2B月額で収益は堅い**が、勝負は**営業と現場導入**。

## 2. 事業概要

| 項目 | 内容 |
|---|---|
| 課題 | 「あの人にしか分からない」が引退で消える／OJTが属人的／マニュアルは"なぜ"を残せない |
| 解決 | 判断（理由・例外・勘所）を吸い出し、根拠つきで後任に回答 |
| 対象 | 中小企業（従業員10〜300／特定ベテラン依存） |
| 形態 | B2B SaaS（Webアプリ） |

## 3. 市場（仮）

- 日本は高齢化・事業承継クライシスのど真ん中。中小の技能承継は**社会課題＝需要は切実**。
- ただし**中小はIT投資に慎重**で、導入の意思決定・現場協力が壁。

## 4. 競合

| 競合 | 強み | こちらの差別化 |
|---|---|---|
| NTTデータ／三菱総研 匠AI／NEC | 大企業向け・実績 | **中小・現場向けに軽く・安く** |
| Airion「技能継承くん」 | 会話→構造化→質問（近い） | 承継特化＋根拠つき回答＋中小価格 |
| Delphi／オルツ（クローン系） | 資金・汎用 | ファン対応でなく"引退時の承継"／現場の判断 |
| 社内wiki・議事録AI | 汎用・安価 | "判断の理由"を吸い出す問診設計 |

→ **中小×現場×安価×根拠つき**の組み合わせが差別化。大企業向け高額SIerとは客層が違う。

## 5. ビジネスモデル・売上の上げ方

- **B2B SaaS 月額**（ベテラン人数 or 従業員数で段階）＋**初期の吸い出し立ち上げ支援費**。
- 売上の上げ方：**取引先で1社PoC → "技能が継げた"事例化 → 商工会議所・業界団体・事業承継を支援する金融機関経由**で横展開（信頼を借りて中小に届ける）。
- 法人は月額を払う体力があり、承継は元々コンサル/研修で高額 → **単価は3案中で最も高い**。

## 6. 制作期間（目安・仮）

| フェーズ | 内容 | 期間 |
|---|---|---|
| 0. 設計 | 問診設計（判断を引き出す）・セキュリティ設計 | 3〜4週 |
| 1. MVP | 吸い出し（音声/写真）＋RAG＋根拠つきQ&A＋承継マップ | 8〜12週 |
| 2. PoC | 協力1社・ベテラン1名で価値検証 | 4〜6週 |
| **PoCまで** | | **約4〜5ヶ月** |

## 7. 必要な事

- **開発**：LLM＋RAG（根拠つき・DB外は生成しない設計）、音声書き起こし、認証・テナント分離。
- **セキュリティ（最重要）**：企業機密を扱う→暗号化・権限・**データ所有権の明確化**。
- **B2B営業**：中小への導入は営業・信頼が要。商工会議所・金融機関・業界団体との連携。
- **監修/現場知**：問診設計に現場理解。
- **体制**：エンジニア＋B2B営業（あなたの強みが効く）。

## 9. マイルストーン

1. **〜M1**：問診設計・セキュリティ方針・PoC先の確保。
2. **〜M4**：MVP完成。
3. **〜M5**：1社PoCで「後任の自己解決率」「承継期間短縮」を検証。
4. **〜M12**：事例化→商工会議所/金融機関経由で横展開、複数社導入。

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| 大手SIerとの競合 | 中小・現場・安価に特化、大企業案件は追わない |
| ベテランが協力しない | 負担最小（週1問1答・音声可）、"あなたの価値を残す"動機付け |
| 回答の正確性/ハルシネーション | 蓄積DBに基づくRAGのみ・必ず根拠表示・DB外は生成しない |
| データ流出＝致命傷 | セキュリティ最優先・データ所有権の明確化 |
| B2B営業の難度 | 商工会議所・金融機関・業界団体の信頼を借りる |

## 11. 正直な結論

- **技術伝承AIは既に激戦**（NTTデータ・三菱総研・Airion 等）。"世に無い"ではない。
- しかし**大企業向けで高額・重い**ため、**中小・現場向けに軽く安く**という受け皿は空きうる。
- **B2B月額で収益は3案中最も堅い**が、勝負は**現場導入と営業（信頼の借り方）**。あなたのHR/採用・事業の人脈が最も効く案。
