# 事業計画書：投資分析支援アプリ

> ファンダメンタル×市場分析を統合してスコア化し、**根拠あるスクリーニング＋正直なバックテスト**を返す分析支援。勝率は保証せず、期待値・ドローダウンで戦う。
> 構想は [`15-toushi-screening.md`](./15-toushi-screening.md)。

⚠️ 数値は 2026年8月時点の**仮試算（要検証）**。

---

## 1. エグゼクティブサマリー

- **何を**：ファンダ（実力）×市場（相場状態）を統合スコア化→条件で銘柄を根拠つきスクリーニング→その条件を**正直なバックテスト**（コスト込み・アウトオブサンプル）にかける。
- **誰に**：感覚でなく**根拠と期待値**で判断したい中級以上の個人投資家。
- **重要な前提**：「勝率70%保証」は不可能かつ違法リスク→**看板にしない**。主指標は期待値・リスクリワード・最大DD。
- **正直な結論**：**銘柄スカウター等の無料強豪がいるレッドオーシャン**。かつ**データの商用ライセンスが生命線**。差別化は"統合スコア×説明性×誠実さ"の執行力。

## 2. 事業概要

| 項目 | 内容 |
|---|---|
| 課題 | ファンダと市場が別ツールに分断／自分の根拠と期待値を把握できていない |
| 解決 | 統合スコア＋根拠つきスクリーニング＋正直なバックテスト |
| 対象 | 中級以上の個人投資家 |
| 形態 | Webアプリ（月額サブスク） |

## 3. 市場（仮）

- 個人投資家はツールに月額を払う文化がある（新NISA以降、裾野拡大）。
- ただし**無料の高機能ツール（証券会社提供）が基準**なので、有料で払わせるハードルは高い。

## 4. 競合（正直に）

| 競合 | 強み | こちらの差別化 |
|---|---|---|
| **マネックス「銘柄スカウター」** | 詳細な業績分析・**無料** | ファンダ×市場の"統合スコア"、説明性 |
| SBI/楽天 スクリーナー | 無料・口座連携 | 市場分析との統合、条件のバックテスト |
| TradingView 等 | 高機能バックテスト | ファンダ統合＋"過剰最適化を戒める"思想 |
| カビュウ 等 | 売買記録・分析 | 事前のスクリーニング側（`08-ai-toushi`は記録側） |

→ 個別機能は既存が強い。**統合と思想（誠実なバックテスト）**でしか差別化できない。

## 5. ビジネスモデル・売上の上げ方

- **月額サブスク**（条件保存数・バックテスト回数・アラートで段階）。**成果連動は取らない**（助言性が強まり規制に触れる）。
- 売上の上げ方：**自分の運用で実演し結果（＝当てる、ではなく"根拠で判断できる"体験）を公開**→投資コミュニティ→口コミ。「当てない・誠実」という姿勢自体を訴求。

## 6. 制作期間（目安・仮）

| フェーズ | 内容 | 期間 |
|---|---|---|
| 0. データ精査 | 財務/株価データの**商用ライセンス**確認・契約 | 2〜4週 |
| 1. スコア設計 | ファンダ/市場の指標→スコア化 | 3〜5週 |
| 2. スクリーニング＋バックテスト | コスト込み・アウトオブサンプル | 6〜10週 |
| **公開まで** | | **約4〜6ヶ月** |

## 7. 必要な事

- **データの商用ライセンス（最重要）**：財務（EDINET/IR/データAPI）・株価の**商用利用可否**。ここが解けないと事業にならない。
- **開発**：データパイプライン、指標計算、バックテストエンジン、Web。
- **コンプラ**：金商法（投資助言業の線引き＝推奨しない）、景表法（成績の断定禁止）。
- **体制**：エンジニア＋（望ましくは）金融/投資の知見者。

## 9. マイルストーン

1. **〜M1**：データの商用ライセンスを確定（GO/NO-GOの分岐点）。
2. **〜M5**：スクリーニング＋正直バックテストのMVP。
3. **〜M6**：少数の個人投資家で「根拠で判断できた」を検証。
4. **〜M12**：継続課金率でユニットエコノミクスを確認。

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| データのライセンス（商用不可） | 着手前に精査・正規購入前提、無理なら見送り |
| 無料強豪（銘柄スカウター等） | 統合スコア＋説明性＋誠実さで差別化、勝てないなら参入見送り |
| 投資助言業への抵触 | 推奨せず情報提供に限定、必要なら登録 |
| 「勝率保証」の期待ギャップ | 最初から期待値で戦うと明示・教育 |

## 11. 正直な結論

- **勝率保証は不可能**。「根拠と期待値で判断を助ける誠実なツール」に振り切るのが唯一の道。
- **データライセンスが最初の関門**。ここが通らなければ事業化不可。
- レッドオーシャンだが、**"誠実なバックテスト"という思想**に共感が集まれば、狭く濃い有料層は取れる可能性。参入判断はデータライセンス次第。
