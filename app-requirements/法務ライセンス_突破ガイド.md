# 法務・ライセンス 対応ガイド

各事業計画で「必要な事」に挙げた**法律・ライセンスの壁**について、"実際に突破できるのか／どうやって"を、整理する。

> ⚠️ 本書は一般的な整理です。実際の可否は案件で変わるため、着手前に**専門家（行政書士＝届出・許認可／弁護士＝規制解釈／社労士＝労務）に確認**してください。特に金商法・個人情報・出会い系規制はプロの確認必須。

---

## 総論：各案とも対応可能（制約は3類型）

| タイプ | 突破の考え方 | 例 |
|---|---|---|
| ①「やらない」で回避 | 規制対象の"行為"をしなければ、そもそも規制にかからない | 助言しない＝金商法回避／診断しない＝獣医師法回避 |
| ② 手続き・契約・実装で突破 | 届出・契約・本人確認などを"やれば"合法に通せる | 出会い系の届出／eKYC／個人情報の同意 |
| ③ お金の壁 | 技術ではなく費用。正規の有料サービスを買えば解決 | 株価・財務データの商用ライセンス |

技術的に対応不能な制約はほぼ存在しない。多くは設計上の回避、または手続き・費用による対応で解決する。

## 各案の対応方法

### 投資分析支援
- **投資助言業**：誤解されやすい点。「この株を買え」「今売れ」と**個別に薦めると登録が必要**。一方、**"利用者自身の過去の取引の統計"や"条件に合う銘柄の一覧＋根拠"を出すだけなら"助言"ではない**＝登録不要。→ **やり方次第で回避できる**。
- **データのライセンス**：唯一の"お金の壁"。株価や財務の生データを商用で使うには、**商用利用OKの有料データ**を買う必要がある（無料APIは大半が商用禁止）。財務は国の **EDINET** が使える。→ **お金を払えば突破できる（＝固定費になる）**。投資案の一番の関門はここ。

### マッチング
- **出会い系サイト規制法**：**"届出"制**（許可制ではない）。事業開始前に公安委員会へ届け出て、年齢確認を用意すれば合法。→ **手続きで突破できる**。
- **eKYC／年齢確認**：本人確認APIを入れるだけ。→ **実装で突破**。

### 分身AI
- 法規制の許認可は**不要**。壁は"信頼"＝顧客の機密をどう守るか。**契約（データは顧客のもの）＋セキュリティ設計**で解決。→ **法務ハードルが最も低い案**。

### ペット看取り
- **獣医師法**：診断・治療・安楽死の是非を"アプリが言う"とアウト。**記録・可視化・情報提供に徹し、判断は飼い主と獣医に委ねる**設計なら問題なし。→ **言葉の線引きで突破**。

### 障害児 情報一元化
- **要配慮個人情報**（障害・診断・服薬）：取得に**本人（保護者）の同意が必須**。同意取得・暗号化・削除権を設計に入れれば合法に扱える。→ **同意とセキュリティで突破**。

## まとめ

- **"突破できないから諦める"案は、実質ありません。**
- ただし突破の"重さ"が違います：
  - **軽い（ほぼ許認可なし）**：スタンプ工房・分身AI
  - **設計で回避**：投資（助言しない）・ペット（診断しない）
  - **手続きが要る**：マッチング（届出＋eKYC）
  - **お金が要る**：投資のデータライセンス（唯一の固定費の壁）
- 迷ったら、その分野に強い**専門家に相談**するのが最短。届出＝行政書士、規制解釈＝弁護士、労務＝社労士。

## 突破の実行プラン（具体・2026年8月時点の調査ベース）

> ⚠️ 最新の要件・可否・費用は各提供元／専門家に確認してください。

### 投資：データの商用ライセンス（唯一の"お金の壁"）
- **財務データ → EDINET（金融庁・無料・公開）** で取得。ファンダ分析はこれで賄える。
- **株価データ → 商用は"法人向け有償"が必要**。
  - **J-Quants API（JPX）は個人向け**で、**サービスに組み込む＝第三者提供は利用規約に抵触**。商用は **J-Quants Pro（JPX総研の法人向け有償版）** を契約する。
  - 無料版は「2年分・株価12週間遅延」なので、商用プロダクトには有償が前提。
  - 代替：kabuステ API 等の商用可データも検討。
- **突破プラン**：①財務=EDINET(無料)＋株価=J-Quantsで**MVP検証** → ②商用化時に **J-Quants Pro等の正規契約**へ。＝正規に買えば突破できる（＝月額の固定費になる）。ここが投資案の唯一の実質的な関門。

### 投資：投資助言業（金商法）→ 登録なしで突破
- **登録が要るのは**：助言契約を結び、分析に基づく"個別の投資判断の助言"をする場合。
- **登録不要にする設計**（金融庁の監督指針・行政書士解説より）：
  - 助言契約を結ばない／助言料を取らない。
  - **不特定多数向け**に、誰でもいつでも買える形で提供（＝個別の投資判断助言ではない）。
  - 個別銘柄の「買え・売れ」やシグナル配信をしない。**分析・情報提供・過去統計に限定**。
- → この設計なら**登録不要で突破**。将来、個別・具体の助言をするなら投資助言・代理業の登録が必要。

### マッチング：出会い系サイト規制法 → 届出で突破
- **届出**：本拠地を管轄する**警察署長を経由して都道府県公安委員会へ「事業開始届出書」**を提出（添付：本籍記載の住民票 等）。事業開始前。**行政書士に代行依頼可**。
- **年齢確認（義務）**：18歳未満の利用を確実に阻止する厳格な確認 → **eKYC（本人確認API）** を導入（公的身分証・クレカ・キャリア認証等）。
- その他：欠格事由・名義貸しの禁止、禁止誘引の閲覧防止措置。
- → **届出＋eKYCで突破**。

### 分身AI → 契約＋セキュリティで突破（許認可不要）
- SaaS契約に「データ所有権は顧客に帰属／学習・目的外利用しない」を明記。暗号化・権限・監査ログ。将来 ISO27001（ISMS）等で信頼を担保。

### ペット看取り → 言葉の線引き＋監修で突破
- 診断名・治療方針・安楽死の是非を**アプリが言わない**。記録・可視化・情報提供に限定＋「獣医に相談を」明示＋**獣医師の監修**。

### 障害児 情報一元化 → 同意＋セキュリティで突破
- 取得・第三者共有に**保護者の明示同意**＋**期限つき共有**＋暗号化＋**削除権**。

### 出典
- J-Quants API / Pro（日本取引所グループ）
- インターネット異性紹介事業の届出（警視庁）
- 投資助言業に該当しないケース（金融庁 監督指針・行政書士解説）
