## 2. 外国の事業者への情報の送信(Anthropic など)

プライバシーポリシー第3項に、次を書きました。

- 委託先(Stripe・Cloudflare・Anthropic・Resend)は、主に米国の事業者で、情報が米国その他の日本国外で取り扱われる場合があること。
- 米国の個人情報の保護に関する制度が、日本の個人情報保護法とは異なること。
- 各社が、それぞれの規約・プライバシーポリシーに基づいて情報を管理すること。
- AI機能では、Anthropic, PBC に送るのは、たたき台の作成に必要な条件だけで、個人が分かる情報の入力は禁止(規約第5条)であること。

**未確認:** 各社の所在国は、Resend を含め、根拠となる資料を残していません(だから「主に米国」としています)。公開前に、各社の規約・会社情報で確認して、確認できたら「いずれも」に戻すか、国名を正しく直してください。

**未確認:** Anthropic の API の入力が、同社のモデルの学習に使われるかどうかなどの取り扱いは、同社の最新の規約で、確認していません。公開前に、同社の規約を読んで、必要なら書き足してください。
