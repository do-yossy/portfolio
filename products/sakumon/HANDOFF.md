# サクモン 引き継ぎメモ(2026-10-16時点)

Web版/ローカルのClaude Codeや別のチャットで続きをするときの引き継ぎ。コードの正本は `README.md`、この資料は「決定事項・現状・保留事項」。先に `README.md` と、リポジトリ直下の `CLAUDE.md` のサクモンの節も読むこと。

## 何か
先生向けの文面ひな形集(学級通信・保護者向けお知らせなど)の月額サブスク。月額980円(税込)。AIは使わず、完成した文面のひな形を渡す。

## 方針(決定済み)
- AI の API(Anthropic)は使わない。さくらのVPSも使わない
- Cloudflare Workers + D1 の無料枠で動かす。固定費0円。npm依存ゼロ
- 決済は Stripe。会社が販売者になる前提で、Managed Payments は使わない
- **現在は非公開(2026-10-20、オーナー指示「一旦公開はステイ」で非公開に戻した)**: `LP_PUBLIC` と `LEGAL_PUBLIC` を "false" にしてデプロイ済み(トップは「準備中」、法務ページは404)。再公開は、オーナーの指示で2つを "true" にして `npx wrangler deploy`。注意: `/subscribe` と `/login` は、アドレスを直接開けば動く(`/subscribe` は本番の決済につながる)。直前の公開の経緯は次の項目
- (経緯)**公開した(2026-10-20、オーナー指示「B:すぐ公開」)**: `LP_PUBLIC` と `LEGAL_PUBLIC` を "true" にしてデプロイ。LP(https://sakumon.sakumon-app.workers.dev/)と法務3ページが公開され、`/subscribe` は本番の決済につながる。**公開時点で未了だった条件(オーナーがリスクを承知のうえ公開)**: ①メール(Resend)のログイン未設定=別端末・Cookie消去後は入れない(問い合わせフォームで対応) ②本番の通しテスト未実施(署名シークレット・ポータル権限・解約の挙動が未確認) ③法務の専門家確認 ④正式な監査役の審査。公開直後の優先作業: 通しテスト→メール設定→専門家確認。非公開に戻すには `wrangler.toml` の2つを "false" にして `npx wrangler deploy`
- **本番(live)への切り替え済み**(2026-10-17〜20): Cloudflare の秘密情報3つ(STRIPE_SECRET_KEY はサクモン専用の新規キー、STRIPE_WEBHOOK_SECRET は本番 Webhook `sakumon-worker-live` のもの、STRIPE_PRICE_ID は本番の価格)を本番に入れ替え済み。`/subscribe` は本番の決済画面(cs_live_)に転送される=**本物の決済が動く**。LP と法務は非公開のまま。決済画面は円表示(Adaptive Pricing を無効化)で、10月20日時点で初回¥371・翌月から¥980(2026年11月1日以降)と目視確認済み。**本番の通しテスト(オーナーのカードで支払い→会員ページ→ポータル→解約→返金)は未実施**。署名シークレットが本番のものかは、通しテストで Webhook の配信が200か確かめる
- 審査(2026-10-20): 独立した別エージェントによる審査で「条件付き承認」(`審査ログ/審査結果_2026-10-20_サクモン.md`)。正式な監査役(kansayaku)は起動できなかったため、公開前に正式な審査を通すこと。公開の必須条件: ①メール(Resend)の設定完了 ②通しテストで解約の挙動を確認 ③プライバシーポリシー・特商法・規約の専門家確認
- 請求方式(オーナー決定 2026-10-17): 申込月は日割り、翌月1日から毎月1日に自動継続。月末の2日以内の申込は日割りなし(初回は翌月1日)。LP・特商法・規約の文面もこの方式に合わせ済み。Stripeのテスト環境で、指定が受け付けられることは確認済み。決済画面に出る日割り金額の目視確認は未実施
- 「リンクを共有しないで」ではなく技術で担保する: 購入ブラウザのCookie会員証 + メールの確認コード。同じ契約で使える端末は最大3台
- メール送信は Resend の無料枠(月3,000通・1日100通)の予定。送信元は既存メール/HPに影響しない専用サブドメイン

- 会社ドメインの DNS などの設定変更は、そのつどオーナーの許可を取る
- 確認できていない数字・実績・お客様の声を、販促文面に書かない
- main へ直接 push しない。ブランチ→PR
- 販売開始は、メール送信、法務の公開、Stripe の本番審査、監査役のレビューが済んでから
