# 営業なし・時間なし・資金なしで始める3つ

> 作成：2026-08-25 ／ 条件：**営業・商談をしない／時間をほぼ使わない／資金ゼロ／AIを使う**
> 前提の整理：[人手ほぼゼロで売上を作る方法](人手ほぼゼロで売上を作る方法.md)

## 発想の転換

営業が要らない売り方は1つしかない。**自分から売りに行くのをやめて、人がすでに集まっている場所に置く**。プラットフォームが集客を肩代わりしてくれるので、**待っていれば買い手から来る**。

商談も不要（やり取りは全部テキスト）、在庫も不要、資金も不要。

## 3つの置き場所

| | 置き場所 | 営業 | 納品の手間 | 資金 | 現実的な月商 |
|---|---|---|---|---:|---|
| **1** | **BOOTH／Gumroad**（テンプレ販売） | **不要** | **自動（ゼロ）** | 0円 | 0〜3万円 |
| **2** | **ココナラ**（スキル出品） | **不要**（買い手から来る） | 都度あり | 0円 | 1〜10万円 |
| **3** | **Kindle出版（KDP）** | **不要** | **ゼロ** | 0円 | 数千〜3万円 |

---

## 1. BOOTH／Gumroad ── いちばん簡単

**14本のHTMLテンプレートを置くだけ。** 売れたら自動でダウンロードURLが渡るので、**納品作業がゼロ**。

| 項目 | 内容 |
|---|---|
| やること | 商品説明・サムネイル・価格・ライセンス文を用意してアップロード |
| **私がやる** | 説明文・サムネイル案・価格設定・ライセンス文・出品手順書を全部作る |
| **あなたがやる** | アカウント作成（本人確認）→ コピペ → アップロード |
| 初回の所要 | **1本30分／14本で7時間**（1日1本でも2週間で終わる） |
| 以降の手間 | **ゼロ**（問い合わせが来たときだけ） |
| 単価 | 1本 3,000〜5,000円 |

**完全に放置できるのはこれだけ。** 月に数本売れれば1〜3万円が何もせず入る。

## 2. ココナラ ── いちばん稼げる

**出品しておくと、買いたい人のほうから声がかかる。** 自分から営業する必要がなく、やり取りはテキストだけ。手数料22%。

2026年時点のAIカテゴリ相場：

| 出品内容 | 相場 |
|---|---|
| AIプロンプト作成 | 1,000〜5,000円 |
| ChatGPT・Claude Code の使い方レッスン | 3,000〜10,000円 |
| AI記事代行 | 5,000〜20,000円 |
| **AIエージェント・チャットボット開発** | **30,000〜100,000円** |
| Webサイト制作 | 出品47,000件超（対応範囲で大きく変動） |

**御社がそのまま出せるもの**：AIチャットボット構築（3〜10万円）、業務自動化スクリプト（Apps Script）、LP制作（テンプレ流用）、要件定義の代行。

**時間がない人向けの設計**：
- **テンプレで納品できるものだけ出す**（オーダーメイドは出さない）
- 納品物は既存の14テンプレ＋AIで作るので、1件あたり**1〜3時間**
- 「〇営業日以内」の日数を長めに設定しておけば、週末にまとめて処理できる

**弱点**：納品作業は発生する。ただし単価3〜10万円なので、**月2件でも6〜20万円**。

## 3. Kindle出版（KDP） ── 一度出せば売れ続ける

原稿をAIで書き、表紙もAIで作り、Amazonに出す。**出版費用ゼロ、在庫ゼロ、納品ゼロ、営業ゼロ**。

| 項目 | 内容 |
|---|---|
| ロイヤリティ | **70%**（KDPセレクト登録・価格250〜1,650円の場合）。配信コストとして1MBあたり1円が差し引かれる |
| 35%を選ぶ場合 | 価格の制約が緩い代わりに取り分が半分以下 |
| 書く内容 | **御社の実務そのもの**（AIで営業を仕組み化した話、採用業務の自動化、AIで制作を高速化する方法） |
| 初回の所要 | 1冊あたり**10〜15時間**（構成と原稿はAI、監修と事実確認が人） |
| 以降の手間 | **ゼロ** |

**副次効果が大きい**：出版実績があると、ココナラでも制作案件でも信用が上がる。「本を出している人」は営業しなくても選ばれやすい。

**注意**：AI生成コンテンツの乱造はAmazonの規約リスクがある。**実務ノウハウを1冊きちんと作る**形にする。

## 進め方（時間がない前提）

| 順 | やること | 所要 | 誰が |
|---:|---|---:|---|
| **1** | BOOTHのアカウント作成 | 15分 | あなた |
| 2 | テンプレ1本目の説明文・価格・サムネイル案 | — | **私** |
| 3 | 1本目をアップロード | 30分 | あなた |
| 4 | 残り13本を1日1本ずつ | 30分/日 | あなた（文面は私） |
| **5** | ココナラのアカウント作成＋出品文3本 | 1時間 | あなた（文面は私） |
| 6 | Kindle 1冊目の構成・原稿 | — | **私** |
| 7 | 原稿の確認と出版手続き | 3時間 | あなた |

**最初の1週間はBOOTHだけでいい。** 1日30分、テンプレを1本ずつ上げる。それだけで月1〜3万円の自動収入になる。

## 正直な天井

| 条件 | 現実的な月商 |
|---|---|
| **BOOTHだけ**（完全放置） | 0〜3万円 |
| ＋ココナラ（月2件納品） | **7〜23万円** |
| ＋Kindle | ＋数千〜3万円 |

**営業ゼロ・時間ほぼゼロなら、月1〜3万円が天井。** そこから増やすには「納品の時間」を少し出す（ココナラ）しかない。逆に言えば、**月2件・数時間の納品作業で月10万円前後**までは、営業なしで届く。
