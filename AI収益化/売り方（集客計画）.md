# 売り方（集客計画）

> 作成：2026-08-26 ／ 対象：[demo/](demo/) の6サービス
> 条件：**広告費ゼロ／営業なし／人の作業を最小化**

## 最初に、耳の痛い話

個人開発で最も多い失敗パターンは、**「プロダクト完成後に宣伝を考え始める」**こと。**今まさにその状態**です。

そして成功している個人開発者の時間配分は **開発4：サポート2：マーケティング4**。つまり**マーケに開発と同じだけの時間をかける**のが前提。これまで開発だけをやってきたので、**ここから同量の労力が要る**という認識が必要です。

ただし、**その労力の大半は私が肩代わりできます**。記事もSNS投稿も私が書けるので、人の作業は「投稿ボタンを押す」だけにできます。

**1〜4で初速を作り、6で本命を取る。** 5は自動で回る。

## 3. SEO：狙うキーワード

**競合が狙っていない「悩み系」のロングテールを取る。** 商品名の一般語（「カメラ 買取」等）は上場企業がいるので避けます。

### ① 買う前チェック 向け

| キーワード | 狙い |
|---|---|
| 〇〇 買うか借りるか | 判断に迷っている＝まさに顧客 |
| 〇〇 年に何回使う | 使用頻度で迷っている |
| 〇〇 買って後悔 | 失敗を避けたい層 |
| 〇〇 レンタル 購入 どっちが得 | 比較意図が明確 |
| 一度しか使わない 買うべきか | 汎用ワード |

### ② 買わなくていい物レーダー 向け

| キーワード | 狙い |
|---|---|
| 買わなくていい物 リスト | 一覧ページとして強い |
| 借りたほうが安い 家電 | 比較意図 |
| 損益分岐 レンタル 購入 | 計算したい層 |

### ③ いまから何する？ 向け

| キーワード | 狙い |
|---|---|
| 今から 遊べる ところ | 即時性が高い＝CVしやすい |
| 暇つぶし 一人 今から | 一人客 |
| 夜 やること ない | 時間帯特化 |
| 予約なし 今から 遊ぶ | **既存の予約サイトが取れていない語** |
| 22時 から 行ける | 時間帯の具体語 |

**③の「予約なし」「〇〇時から」は、予約サイトが構造的に取れない語。** ここが最大の穴です。

## 4. 私が書く記事のタイトル案（すぐ着手できます）

### 集客用（SEO）

1. 「高圧洗浄機は買うべきか借りるべきか。損益分岐は7回でした」
2. 「電動工具をレンタルしたら1日265円だった。買う必要がなかった話」
3. 「キャンプ用品は一式17,000円で借りられる。5回使うなら買ったほうが得」
4. 「22時から1,000円で遊べる場所、4つしかなかった」
5. 「予約サイトが教えてくれない『予約不要で今から行ける場所』」
6. 「買わなくていい物28選。損益分岐点を全部計算した」

### 開発記事用（Zenn / Qiita）

1. 「1ファイル完結のHTMLでPWAを6本作った話」
2. 「レンタル価格を推定で置いていたら実勢と2倍ずれていた。全部調べ直した記録」
3. 「アフィリエイトIDを1つ入れるだけで38品目のリンクを自動生成する設計」

**各記事の中に、対応するツールへのリンクを置く。** 記事が集客し、ツールが送客する構造。

## 5. Xの投稿テンプレート（実装済みの機能と連動）

ツール側に**結果のシェア機能を実装済み**なので、ユーザーが勝手に拡散する導線はできています。加えて、こちらから投稿する型：

```
「〇〇を買おうか迷ったので計算してみた」

購入 89,800円
中古 51,000円
レンタル 4,980円

年1回×3年なら → レンタルが84,000円お得

損益分岐は18回目でした。
[ツールのURL]
```

**数字が3つ以上並ぶ投稿は保存・引用されやすい。** 機能説明ではなく**結果**を出すのが要点です（失敗パターンの筆頭が「機能説明ばかりで価値を語らない」）。

| 週 | やること | 人の作業 |

| **W1** | ASP提携申請（Amazon新サイト登録・A8案件提携・楽天）／法務ページ記入 | **2〜3時間** |

**人の作業は初月合計で4〜5時間。** そのうち3時間はASP提携という一度きりの作業です。

## 7. 何をもって成功と見るか

**1ヶ月目に売上を見ても意味がない。** 見るべきはこちら。

| 指標 | 1ヶ月目の合格ライン |
|---|---:|
| 月間UU | **200以上** |
| 入力完了率（訪問→判定まで進む） | **30%以上** |
| 送客クリック率 | **10%以上** |
| 成果発生 | **1件でも出れば合格** |

**入力完了率が30%を切ったら、ツールの問題**（分かりにくい・重い）。
**クリック率が10%を切ったら、判定結果に納得感がない**。
**UUが200に届かなければ、集客の問題**——記事とSNSを増やす。

どこが詰まっているかで打ち手が変わるので、**計測タグは公開時に必ず入れます**。

---

## 8. 正直な話

**この売り方で月10万円に届くのは6ヶ月目**です。1ヶ月目は数百円〜1.5万円。

ただし**人の投下時間は初月4〜5時間、以降は月1時間以下**。時給換算は初月でも数千円になり、続ければ上がり続けます。**やめても損はしません**。

そして最も重要なのは、**記事とSNS投稿を止めた瞬間に伸びが止まる**こと。これは私が量産できるので、**続けるコストは人にとってほぼゼロ**にできます。そこがこのモデルの成立条件です。
