# 課題解決型サービス案 ── 「すでにお金が動いている場所」に入る

> 作成：2026-08-25 ／ 条件：B2C・B2Bどちらでも可／**顧客の課題解決がそのまま当社の収益になる**構造
> 前提：[セルフサーブSaaS 候補選定](セルフサーブSaaS_候補選定.md)

## 発想の基準

新しい需要を作ろうとすると営業が要る。**すでに顧客がお金を払っている支出を、AIで1/10にして奪う**なら、顧客は自分から探しに来る（＝検索する）。営業がいらない条件はここで満たされる。

さらに、**診断結果に金額が出るもの**は有料化率が跳ね上がる。

> 「あなたの会社は最大450万円の補助金が使えます」
> 「この就業規則は法改正に未対応です（是正しないと罰則）」
> 「この求人が応募されない理由は3つあります」

金額や損失が可視化された瞬間に、人は財布を開く。

---

## 1. 実際に動いているお金（調査結果）

| 課題 | 今、顧客が払っている金額 |
|---|---|
| 就業規則の作成 | **社労士に10〜40万円**（変更・改訂は5〜15万円） |
| 助成金・補助金の申請 | **成功報酬で受給額の15〜30%**（100万円受給なら15〜30万円） |
| 契約書のリーガルチェック | 弁護士に1件あたり数万円 |
| 求人広告の制作 | 代理店に1本数万円〜 |
| 記帳・確定申告 | 税理士に年5〜20万円 |

**2026年の経営課題は「人材強化」が90.2%でダントツ**（帝国データバンク調査）。次いで販路開拓。**小規模企業では6割超が資金繰りに危機感**。

→ **人材・売上・資金繰り**の3つが、金が動いている領域。

## 2. アイデア10案

### 【A】人材・労務（経営課題1位）

#### A-1. 就業規則 法改正チェックAI ★本命候補
| | |
|---|---|
| 課題 | 就業規則が古いまま。法改正に対応できているか分からない。是正勧告が怖い |
| 今の支出 | 社労士に**改訂5〜15万円／新規10〜40万円** |
| 当社の価格 | **無料診断**（貼り付け→未対応項目を指摘）→ **改訂案の生成 9,800円**／月額2,980円で継続チェック |
| なぜ売れる | 「未対応3項目あり」と出た瞬間に放置できなくなる |
| 法的注意 | **労基署への届出代行は社労士の独占業務**。当社は「作成支援ツール」に徹し、代行はしない |
| 競合 | 就業規則テンプレは多いが、**貼り付けて診断する型は薄い** |

#### A-2. 求人改善AI
[前回の選定](セルフサーブSaaS_候補選定.md)の2位。経営課題1位に直結。**当社の実務知識が参入障壁**になる唯一の案。

#### A-3. 退職・労務トラブル対応文AI
| 課題 | 問題社員への注意書、退職勧奨、ハラスメント調査報告書が書けない |
| 今の支出 | 社労士・弁護士へのスポット相談 2〜5万円 |
| 価格 | 月額2,980円 |
| 法的注意 | **法律判断はしない**。文書の下書き支援に限定 |

### 【B】資金（小規模企業の6割が危機感）

#### B-1. 使える助成金・補助金 診断AI ★本命候補
| | |
|---|---|
| 課題 | 「うちが使える助成金があるのか分からない」。制度が多すぎて探せない |
| 今の支出 | 社労士・行政書士に**成功報酬15〜30%**（100万円受給なら15〜30万円） |
| 当社の価格 | **無料診断**（業種・従業員数・やりたいことを入力→使える制度を提示）→ **申請書類の下書き 19,800円**／月額3,980円で新着通知 |
| なぜ売れる | **金額が出る**。「最大450万円」と表示された瞬間に動機が生まれる |
| 法的注意 | **申請代行は社労士・行政書士の独占業務**。当社は**制度の案内と下書き支援**に限定し、提出は本人が行う |
| 競合 | 補助金ポータルは情報提供のみ。**診断＋下書きまでやるものは薄い** |

#### B-2. 資金繰り表 自動作成AI ★穴が大きい
| | |
|---|---|
| 課題 | 銀行に出す資金繰り表を作るのが面倒。エクセルが分からない |
| 今の支出 | 税理士の顧問料に含まれるが、**急ぎだと対応してもらえない** |
| 当社の価格 | 月額1,980円 |
| なぜ売れる | 融資は期限がある。**銀行提出という締切がある課題**は後回しにできない |
| 法的注意 | **税務相談はしない**。表の作成支援のみ |
| 競合 | 会計ソフトの一機能として存在するが、**単体で手軽なものが無い** |

#### B-3. 値上げシミュレーターAI
| 課題 | 値上げしたいが、客が離れるのが怖くて踏み切れない |
| 価格 | 月額980円 |
| 出力 | 原価・客数・単価から、値上げ幅ごとの利益と離反リスクを試算 |

### 【C】売上・販路

#### C-1. Google口コミ返信AI（低価格帯）
競合あり（Localith 1,100円〜）。差別化するなら**月次分析レポート**（不満の傾向・競合比較）まで出す。

#### C-2. 営業設計AI
会社URLと商品を入れると「誰に・なぜ・何を・どう売るか」まで設計。競合は営業文生成止まりで、**設計まで踏み込むものは薄い**。

#### C-3. 業種特化AI見積
[前回の選定](セルフサーブSaaS_候補選定.md)の1位。小規模事業者向けの価格帯が空いている。

### 【D】個人向け（B2C）

#### D-1. 未払い残業代 診断
| 課題 | 「自分の残業代、ちゃんと払われているのか」 |
| 価格 | 無料診断 → 詳細レポート 1,980円 |
| なぜ売れる | **金額が出る**（「未払いの可能性:約48万円」） |
| 法的注意 | **非弁行為に触れないよう、請求の代行・交渉は一切しない**。計算と一般的な情報提供に限定。弁護士への相談を促す形にする |
| 競合 | 計算機は無数にあるが**無料**。有料化は難しい |

#### D-2. 相続 概算診断
| 課題 | 相続税がかかるのか、いくらか分からない |
| 価格 | 無料診断 → 詳細 2,980円 |
| 法的注意 | **税務代理・税務書類作成は税理士の独占業務**。計算ツールに限定 |
| 競合 | 税理士事務所の集客ツールとして無料版が多い |

## 4. 本命3案の理由

### 🥇 助成金・補助金 診断AI（86点）
**顧客が今まさに15〜30万円払っている**領域。しかも**診断結果に「最大450万円」という金額が出る**ので、無料→有料の転換が最も強い。当社は[補助金診断ツール](../補助金かんたん診断.html)を既に一度作っており、**中身の設計は済んでいる**。

**唯一の注意点**：申請代行は社労士・行政書士の独占業務。**制度の案内と書類の下書き支援に限定**し、提出は顧客自身が行う設計にする。

### 🥈 就業規則 法改正チェックAI（84点）
**経営課題1位（人材強化90.2%）に直結**し、支出も5〜40万円と大きい。「未対応3項目」と出れば放置できない。**貼り付けて診断する型の競合が薄い**。開発も単純（テキスト解析＋チェックリスト）。

### 🥉 資金繰り表 自動作成AI（80点）
**法的リスクがゼロ**なのが最大の強み。小規模企業の6割が資金繰りに危機感を持っており、**銀行提出という締切**があるので後回しにされない。会計ソフトの一機能としては存在するが、**単体で手軽なものが無い**。

## 5. 共通の設計ルール（守らないと詰む）

| ルール | 理由 |
|---|---|
| **代行はしない、支援ツールに徹する** | 社労士・税理士・行政書士・弁護士の独占業務に触れないため |
| **診断結果に必ず金額を出す** | 「45万円もらえる」「48万円損している」で有料転換率が変わる |
| **無料は1回、以降は課金** | 無制限にするとAPI原価で赤字 |
| **単価は1,980〜19,800円** | 980円だと必要人数が100人超になり、営業なしでは埋まらない |
| **専門家への導線も置く** | 診断だけで解決しない案件は士業に紹介 → **紹介料という第2の収益** |

**最後の1行が重要**：診断で終わらせず、**難しい案件は士業に紹介して紹介料を得る**設計にすれば、顧客の課題は確実に解決し、当社の収益も二重になる。これが「顧客の課題解決＝当社の収益」の一番きれいな形。
