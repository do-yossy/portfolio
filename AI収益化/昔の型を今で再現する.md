# 昔の型を今で再現する ── ツールで入口、人材紹介で回収

> 作成：2026-08-26 ／ 起点：**Instagram自動化ツールをサブスクで販売 → リファラルで顧客獲得 → 人材紹介につなげる**という過去の成功モデルを、2026年の規約・市場で再現できるか

## 結論（先に3行）

1. **同じ型を、すでに自社で回している。** `kyujinbox-platform` は求人ボックスへ自動投稿し、応募者に架電して**別求人を案内（人材紹介）**する導線まで実装済み。Instagram が求人媒体に変わっただけで、構造は当時と同一。
2. **足りないのは「外販してサブスクにする」ことだけ。** 今は自社のためだけに使っている。これを月額で他社に売れば、当時の型がそのまま復活する。
3. Instagram 自体での再現は**もう無理**。非公式の自動化ツールは Meta が即アカウント停止で、いいね・フォローの自動化は高確率でスパム判定される。入口の対象を変えるしかない。

---

## 1. 当時の型を分解する

| 要素 | 当時 | 果たしていた役割 |
|---|---|---|
| 自動化ツール | Instagram の自動化 | **入口**。相手の手間を実際に減らす |
| 課金 | サブスク | **関係の維持**。毎月接点があり、忘れられない |
| 営業 | リファラル | **獲得コストがゼロ**。紹介だから信用が最初から乗っている |
| 出口 | 人材紹介 | **本命の収益**。理論年収の30〜35% |

**この型の本質は「安いツールで関係を作り、高い紹介で回収する」二段構え。** ツール単体は儲からなくていい ── ここが普通のSaaSと決定的に違う。月額が安くても、1件の紹介が決まれば一気に回収できる。

## 2. Instagram では再現できない（2026年時点）

| 項目 | 現状 |
|---|---|
| 非公式の自動化ツール・RPA | Meta の利用規約違反。接続元を特定されると**即アカウント停止** |
| いいね・フォローの自動化 | Meta が特に嫌う。**高確率でスパム判定**（シャドウバン／停止） |
| 自動DM | 同一文面の大量送信でスパム報告が蓄積し、凍結確率が跳ね上がる |
| 生き残っている形 | **Meta公認の公式API を使ったチャットボット**のみ |

→ 当時のやり方をそのまま持ち込むと、顧客のアカウントを飛ばすことになる。**入口の自動化対象を、規約上クリーンなものに置き換える**のが唯一の道。

## 3. すでに持っているもの（ここが最大の発見）

| 当時の要素 | 現在の当社 | 状態 |
|---|---|---|
| 自動化エンジン | `kyujinbox-platform`（求人ボックスへ会社ごとに自動投稿）、`recruitment-platform` | **実装済み・稼働中** |
| 成果の計測 | `scripts/kyujinbox_metrics.py`、月次レポート自動生成 | **実装済み** |
| 出口（人材紹介） | 応募 → 架電 → ヒアリング → **別求人を案内**。「人材紹介求人」区分もシステムにある | **運用手順まで文書化済み** |
| サブスクで外販 | — | **これだけが無い** |
| リファラルの導線 | — | **これだけが無い** |

`recruitment-platform/docs/seniorjob-operations.md` のフローが、まさに当時の二段構えそのもの。

```
Indeed / 求人ボックスに掲載 → 応募 → 連絡先取得 → 架電・ヒアリング
→ 充足等を理由に別求人を案内（人材紹介）
```

**Instagram が求人媒体に変わっただけ。** そして求人媒体への投稿は、Instagram の自動フォローと違って規約上の位置づけが全く違う（自社の求人を自社アカウントで出す行為）。

## 4. 今の市場価格

| サービス | 相場 |
|---|---|
| スカウト代行（大手・定額制） | **月30〜50万円** |
| 同（オーダーメイド型の下限） | 月3万円〜 |
| 人材紹介の手数料 | **理論年収の30〜35%** |

**当社が入るなら月3〜5万円の下限帯。** 大手と同じ土俵で戦わず、「安いツール＋紹介で回収」の型を取れば価格競争にならない。これが当時と同じ勝ち方。

### 数字の見通し

| | 計算 | 月額換算 |
|---|---|---|
| ツール（サブスク） | 月3万円 × 20社 | 60万円 |
| 人材紹介 | 年収400万 × 30% ＝ 120万／件。20社から年6件 | 60万円 |
| **合計** | | **月120万円** |

**紹介が年6件出れば、ツール収入と同額になる。** そしてツール側は限界費用がほぼゼロ（既に動いているものを他社にも向けるだけ）。当時「ツール単体では儲からなくていい」と言えたのと同じ構造が再現できる。

## 5. リファラルを今も効かせるには

当時リファラルが回ったのは、紹介できる関係があったから。今も条件は同じで、**紹介が発生するのは「成果が数字で言えるとき」**。

「便利だよ」では紹介されない。「先月◯件応募が来た」なら紹介される。

→ `ファンを作る設計.md` の月次レポートが、ここに直結する。**レポートが紹介の材料そのものになる。** 顧客が自分の言葉で成果を語れる状態を作れば、リファラルは当時と同じように回る。

## 6. 法令・規約の線引き（必ず守る）

| 項目 | 内容 |
|---|---|
| **有料職業紹介事業の許可** | 資産（総資産−負債）**500万円以上**／現金・預貯金**150万円以上**。申請手数料5万円＋登録免許税9万円。有効期間は新規3年・更新後5年。事業報告書を毎年4月30日までに提出 |
| **2025年1月の職安法改正** | 自社が紹介して就職した求職者に、**就職から2年以内の転職勧奨が禁止**。架電リストの運用で該当者を除外する仕組みが要る |
| 求人者の明示 | 実際の雇用主を明示。おとり求人にしない（職安法・景表法） |
| 媒体の自動巡回・自動応募 | **やらない**（`CLAUDE.md` の恒久方針） |
| Instagram等のSNS | 非公式ツールでの自動化は**やらない**。顧客のアカウントを飛ばす |

## 7. 最初の一歩

**既存の採用支援先1社に、月額でツールを開放してみる。**

1. `kyujinbox-platform` にその会社のアカウントを追加（マルチアカウント対応済み）
2. 求人を登録して自動投稿、`kyujinbox_metrics.py` で成績を取る
3. 月末に月次レポートを送る（手書きの所見つき）
4. 応募者の中に**その会社では採らない人**が出たら、そこが人材紹介の入口

**3の時点で価格を決める必要はない。** まず「毎月レポートが届く」状態を作り、相手が価値を感じたところで月額を提示すれば、当時と同じく売り込まずに売れる。

## 8. 正直な注意点

- **紹介が出るまでの時間が読めない。** ツール月3万円だけでは、20社集めても月60万円。紹介が出て初めて型が完成する
- **許可の有無を最初に確認すること。** 人材紹介を出口にする以上、ここが前提。無許可で紹介手数料を取ることはできない
- **当時と違い、媒体側にもAI機能が載っている。** スカウト文面の自動生成などは媒体内で完結できてしまうので、そこで差別化しようとしない。当社の差は「自動投稿＋成果レポート＋紹介の出口」を一続きで持っていること
