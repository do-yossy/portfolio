# 「家の中の眠っている価値」発掘 ── 事業モデルまでの落とし込み

> 作成：2026-08-25 ／ 対象：[B2C案50件の評価](B2C案50件の評価.md) から派生した最有力案
> 検証項目：入力→判定→送客先→1件の収益→必要人数→競合との差→集客→資金ゼロで作れるか

## 結論（先に読む4行）

1. **1件あたりの収益は870〜8,000円**。買取アフィリエイトの実在単価。宅配査定申込1,000円／買取成立1,000〜4,865円／買取完了8,000円。
2. **月10万円は「査定申込100件」または「買取成立21件」**。逆算すると**月間1,700〜3,300UU**が必要。
3. **競合は上場企業クラス**。ヒカカク！は**月間300万人**（2024年7月）、ウリドキは上場、おいくらはマーケットエンタープライズ。**真正面では絶対に勝てない**。
4. **勝ち筋は入口の違いだけ**。競合は「**売りたい物が決まっている人**」向け。この案は「**家に何があるか分からない人**」向け。検索キーワードから顧客層まで別物にできる。

## 1. 1件いくらになるのか（実在する成果報酬）

| 成果地点 | 報酬 |
|---|---:|
| 宅配査定の申込 | **1,000円** |
| 特定ブランドの買取 | 870円 |
| 買取成立 | **1,000円** |
| 出張買取の申込後30日以内に買取成立 | **4,865円** |
| 買取完了 | **8,000円** |
| ブランド品10,000円以上の買取完了 | 3,850円 |

**「申込」で発生する案件と「成立」で発生する案件がある。** 申込地点なら単価は低いが発生率が高く、成立地点なら単価は高いが発生率が落ちる。**両方に提携して併用するのが定石**。

### 想定単価
現実的な期待値は**1件あたり1,500〜3,000円**（申込ベースの案件を主軸に、成立案件を混ぜる）。

## 2. 月10万円の逆算

| 前提 | 必要数 |
|---|---:|
| 平均単価 2,000円 | **月50件の成果** |
| 診断利用者→査定申込のCVR 15% | **月333人が診断を使う** |
| サイト訪問→診断利用のCVR 30% | **月間1,110UU** |
| （保守的にCVR 10%／20%で計算すると） | **月間2,500〜3,300UU** |

**必要なのは月間1,700〜3,300UU。** 個人が新規で立ち上げるサイトとしては、**SEOで6ヶ月〜、SNS併用で3〜4ヶ月**が現実的な到達期間。

> 3ヶ月で月10万円は厳しい。**6ヶ月で月10万円**を目標にするのが正直な線。

## 3. 競合との差 ── ここが生命線

### 競合の実力

| サービス | 規模 |
|---|---|
| **ヒカカク！** | **月間300万人**（2024年7月）／口コミ5万件／買取商品100万件／最大20社の一括査定 |
| **ウリドキ** | CtoBマッチング＋メディア一体型。**上場企業** |
| **おいくら** | マーケットエンタープライズ（**上場企業**）運営の老舗 |

**「買取価格を比較する」領域は、上場企業3社が押さえている。** 同じことをやれば確実に負ける。

### 唯一の差：入口が違う

| | 競合（ヒカカク・おいくら・ウリドキ） | **本案** |
|---|---|---|
| ユーザーの状態 | **売る物が決まっている** | **家に何があるか分かっていない** |
| 検索キーワード | 「カメラ 買取 相場」「ブランド 買取 おすすめ」 | **「断捨離 売れるもの」「実家 片付け 価値」「引越し 処分 もったいない」** |
| 競合度 | **激戦** | **比較的空いている** |
| 入力 | 品名・型番を打つ | **写真を撮るだけ** |
| 価値 | 一番高い店を教える | **そもそも売れる物を見つける** |

**「これ売ったらいくら？」ではなく「家にいくら眠っている？」。** この一語の違いが、競合との唯一の距離。

## 4. ユーザー体験と判定の中身

```
① 部屋の写真を3〜10枚アップロード
        ↓
② AIが写っている物を検出・分類
   （カメラ／ゲーム機／ブランド品／楽器／工具／家電／トレカ…）
        ↓
③ 売却候補として抽出、価格帯を推定
        ↓
④ 無料表示：
     現金化候補 7点
     推定合計 82,000〜126,000円
     優先順位 ①カメラ ②ゲーム機 ③ブランドバッグ
        ↓
⑤ 「売る」を押すと、品目ごとに最適な買取先へ送客
     → ここで成果報酬が発生
```

### 判定の限界（正直に）

| 課題 | 実態 | 対処 |
|---|---|---|
| **型番が読めない** | 写真から「カメラ」は分かっても「Canon EOS R5」までは特定できないことが多い | **価格は必ず幅で出す**。型番が読めた物だけ精度の高い金額を出す |
| 価格の正確性 | 「8万円」と出して実際3万円だとクレームになる | **「推定」「幅」「あくまで目安」を明示**。断定しない |
| 売れない物を売れると誤判定 | 信用を一発で失う | **確度の低いものは出さない**。件数より精度 |

## 5. 資金ゼロで作れるか

| 項目 | 費用 | 備考 |
|---|---:|---|
| ASP登録（A8.net・afb 等） | **0円** | 登録は無料。月額固定費は**広告主側**が払う |
| ドメイン | 年1,000〜2,000円 | ほぼゼロ |
| ホスティング | **0円** | 既存のFly.io または無料枠 |
| 開発 | **0円** | 1ファイル完結のHTML＋API。既存14本と同じ方式 |
| **画像判定のAPI原価** | **1回10〜30円** | **ここだけが変動費** |

### 唯一の落とし穴：無料診断のAPI原価

**無料で診断させる＝原価が先に出ていく。**

| 月間の診断数 | API原価（1回20円） | その月の収益（成果50件×2,000円） |
|---:|---:|---:|
| 100回 | 2,000円 | 立ち上げ期はほぼ0円 |
| 500回 | 10,000円 | 3〜6万円 |
| 1,000回 | 20,000円 | 10万円 |

**対策**：
- **無料は写真3枚まで**（それ以上は要登録 or 有料）
- 安価なモデルで一次判定 → 有望な物だけ高精度モデルで再判定
- 立ち上げ期の持ち出しは**月2,000〜10,000円**。資金ゼロと言い切れないが、許容範囲

## 6. 集客（営業なしでどう人を集めるか）

| 手段 | 内容 | 立ち上がり |
|---|---|---|
| **SEO（本命）** | 「断捨離 売れるもの」「実家 片付け 価値があるもの」「引越し 処分 もったいない」など、**競合が狙っていない悩み系キーワード** | 4〜6ヶ月 |
| SNS | 「家にあるこれ、実は◯円」系の投稿は拡散しやすい | 1〜3ヶ月 |
| 既存資産 | `www.social-quality.com` からの導線 | 即日 |
| 広告 | **使わない**（資金ゼロの条件から外れる） | — |

**この案の集客上の強み**：「**推定 348,000円**」という**数字が出る体験**は、そのままSNSのネタになる。スクリーンショットが拡散する構造を最初から組み込める。

## 7. 最初にやるべきは開発ではなく検証

**アプリを作る前に、3つを確かめる。**

| # | 確かめること | 方法 | 判断 |
|---:|---|---|---|
| 1 | **ユーザーは本当に部屋の写真を送るか** | LPだけ作って「写真を送ると診断します」で募集。**判定は手動でいい** | 10人集まらなければ需要なし |
| 2 | **診断結果を見て、実際に査定申込まで進むか** | 手動で送客リンクを送り、クリック率と申込率を測る | CVR 10%未満なら成立しない |
| 3 | **ASPの提携審査に通るか** | A8.net・afbに登録し、買取案件に提携申請 | **これは先に確認すべき**。提携できなければ収益ゼロ |

**3が最優先。** 提携できなければ、どれだけ良いものを作っても1円にもならない。**登録は無料で今日できる**。

## 8. 正直な評価

| 観点 | 評価 |
|---|---|
| 需要 | **○** 実在する（断捨離・実家の片付け・引越し） |
| 競合回避 | **△** 入口をずらせば戦えるが、上場企業3社が隣にいる |
| 収益化 | **○** 単価870〜8,000円が実在。仕組みは確立済み |
| 資金 | **△** ほぼゼロだが、API原価が月2,000〜20,000円 |
| 3ヶ月で月10万円 | **✕** 集客が間に合わない |
| **6ヶ月で月10万円** | **○** 現実的 |
| 自動化 | **◎** 判定も送客も課金も全自動 |

**総合：やる価値はある。ただし「3ヶ月で月10万円」は下方修正が必要。**

そして最も重要なのは、**開発より先にASPの提携審査を通すこと**。ここが通らなければ事業として成立しない。**無料で、今日できる。**
