## 結論（先に読む3行）

1. **6案とも、収益が発生する瞬間が実装されていない。** 送客リンクは全部 `alert()` のダミーで、**今のまま公開しても1円も入らない**。
2. **6案は3案に統合すべき。** ②は①の一機能、⑤は③の一機能。④⑥は供給側が集まらないので捨てる。
3. **売れるかどうかを決めるのは機能ではなく「検索で拾われるか」。** 現状は全デモとも**検索流入の受け皿がゼロ**。ここが最大の欠落。

## 1. 「売れる」の定義

ツールが商品になるには、4つが揃う必要がある。**現状はどれも1つしか満たしていない。**

| # | 条件 | 現状 |
|---|---|---|
| 1 | **人が来る**（検索・SNS） | **✕ 導線がゼロ** |
| 2 | **使ってもらえる**（入力が完了する） | ○ できている |
| 3 | **収益が発生する**（送客が成立する） | **✕ ダミーリンク** |
| 4 | **また来る**（リピート） | **△ 案による** |

**2しか満たしていない。** デモとしては正しいが、商品としては未完成。

## 5. 今回実装したもの

### 送客リンクの一元管理（`AFF` オブジェクト）

各デモの先頭に、送客先URLをまとめた設定を置いた。

```js
var AFF={
  ec:    '',   // ECアフィリエイト（未提携）
  used:  '',   // 中古サイト（未提携）
  rent:  '',   // レンタル各社（未提携）
  label: {...}
};
```

**空文字のままなら「提携準備中」と表示され、URLを入れた瞬間に本物のリンクになる。** コードを触らずに提携作業だけで公開できる。

### 結果のシェア機能

判定結果を1行のテキストにして、コピー／Xへの投稿ができるようにした。

> 例：「一眼レフを買おうと思ったけど、年1回×3年なら**レンタルが8.4万円お得**という判定でした」

**数字が入った具体的な結果はスクリーンショットで拡散しやすい。** 資金ゼロで集客する唯一の現実的な手段がこれ。

## 8. 追記（2026-08-26）：アフィリエイトIDによる自動リンク生成を実装

Amazon・A8・楽天のアカウントが既にあるとのことなので、**IDを1箇所入れるだけで全38品目のリンクが自動生成される**形に作り替えた。個別に広告リンクを貼る必要はない。

```js
var AFF={
  amazonTag:"",   // AmazonアソシエイトのトラッキングID（例 "yourname-22"）
  rakutenId:"",   // 楽天アフィリエイトID（例 "1a2b3c4d.5e6f7g8h"）
  a8Rent:"",      // A8で提携済みのレンタル系プログラムの広告URL
  a8Used:""       // A8で提携済みの中古・買取系プログラムの広告URL
};
```

**判定結果に応じて送客先が自動で切り替わる。**

| 判定 | 生成されるリンク |
|---|---|
| 買う | Amazon検索（商品名）／楽天検索（商品名） |
| 中古 | Amazon検索（商品名＋中古）／楽天検索（商品名＋中古）／A8の買取系 |
| レンタル | A8のレンタル系／楽天検索（商品名＋レンタル） |

生成例（`amazonTag="sqtest-22"` の場合）：
`https://www.amazon.co.jp/s?k=ミラーレス一眼カメラ&tag=sqtest-22`

**IDが空のままなら「準備中」と表示され、リンクは無効。** 設定した瞬間に全品目が有効になる。

### ⚠ Amazonの注意点

**Amazonアソシエイトは「リンクを貼るサイトのURL」を事前にアソシエイト・セントラルへ登録する必要がある。** 既存アカウントがあっても、**新しいサイトは追加登録と審査が必要**。以下は申請が却下される例として明示されている。

- コンテンツが少ない・未完成のサイト
- リンクの使用目的が不明確
- URLに "amazon" や "kindle" を含むもの

**未登録サイトでリンクを使うと規約違反**になるため、公開前に必ず登録すること。

## 9. 1ヶ月目の利益予想と作成時間

### 作成にかかる時間（残り）

**制作はほぼ終わっている。** 残っているのは提携と設定だけ。

| 作業 | 誰が | 所要 |
|---|---|---|
| ASP提携申請（Amazon新サイト登録／A8で案件提携／楽天） | **人** | **1〜2時間**＋審査待ち1〜7日 |
| 取得したIDを `AFF` に設定 | 私 | 10分 |
| 法務ページの事業者情報を記入 | **人** | **30分** |
| 公開設定（配置・HTTPS確認・sitemap） | 私 | 30分 |
| SEO記事の作成 | 私 | 1本1時間 × 必要数 |

→ **人の作業は合計2〜3時間**。あとは審査待ち。

### 1ヶ月目の利益予想

**正直に言うと、1ヶ月目はほぼ稼げない。** 集客がまだ存在しないため。

| 項目 | 1ヶ月目の見込み |
|---|---:|
| 月間UU（既存サイト導線＋SNS） | **200〜800** |
| 送客クリック（10〜15%） | 20〜120 |
| 成果発生（クリックの1〜8%） | **1〜10件** |
| 平均単価 | Amazon 約200円／A8申込系 1,000〜5,000円 |
| **1ヶ月目の収益** | **500円〜15,000円（中央値 約3,000円）** |

### なぜ1ヶ月では稼げないのか

- **SEOは新規ドメインで4〜6ヶ月かかる**。1ヶ月目の検索流入はほぼゼロ
- 集客は既存サイトからの導線とSNS投稿のみ
- 月10万円に必要な**月間1,700〜3,300UU**には遠く届かない

### 時間軸の目安

| 時期 | 月間UU | 月の収益 |
|---|---:|---:|
| 1ヶ月目 | 200〜800 | **500〜15,000円** |
| 3ヶ月目 | 500〜1,500 | 5,000〜40,000円 |
| **6ヶ月目** | 1,700〜3,300 | **50,000〜100,000円** |
| 9ヶ月目 | 3,000〜6,000 | 100,000〜200,000円 |

**このモデルは「1ヶ月で稼ぐもの」ではなく「積み上がる資産」。** 作る時間が2〜3時間で済むのは、稼げるまでが遅いことの裏返しでもある。

**逆に言えば、追加の投下時間がほぼゼロなので、放置していても損はしない。** カード転売（資金30万円＋月30時間）と決定的に違うのはここ。
