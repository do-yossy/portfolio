# 6案を「売れる」形にするための改修計画

> 作成：2026-08-26 ／ 対象：[demo/](demo/) の6デモ
> 現状：デモは動くが、**すべて「ツール」であって「商品」になっていない**

## 結論（先に読む3行）

1. **6案とも、収益が発生する瞬間が実装されていない。** 送客リンクは全部 `alert()` のダミーで、**今のまま公開しても1円も入らない**。
2. **6案は3案に統合すべき。** ②は①の一機能、⑤は③の一機能。④⑥は供給側が集まらないので捨てる。
3. **売れるかどうかを決めるのは機能ではなく「検索で拾われるか」。** 現状は全デモとも**検索流入の受け皿がゼロ**。ここが最大の欠落。

---

## 1. 「売れる」の定義

ツールが商品になるには、4つが揃う必要がある。**現状はどれも1つしか満たしていない。**

| # | 条件 | 現状 |
|---|---|---|
| 1 | **人が来る**（検索・SNS） | **✕ 導線がゼロ** |
| 2 | **使ってもらえる**（入力が完了する） | ○ できている |
| 3 | **収益が発生する**（送客が成立する） | **✕ ダミーリンク** |
| 4 | **また来る**（リピート） | **△ 案による** |

**2しか満たしていない。** デモとしては正しいが、商品としては未完成。

## 2. 6案それぞれの「売れない理由」と「効く一手」

### ① 買う前チェック

| 項目 | 内容 |
|---|---|
| **売れない理由** | **入口が閉じている**。品目がプルダウン選択なので、「ダイソン 買うべきか」で検索した人が着地できない |
| **効く一手** | **商品名の自由入力を追加**。検索キーワードとページが1対1で対応する構造にする |
| 収益 | 「買う」判定 → EC送客／「中古」→ 中古サイト／「レンタル」→ レンタル各社 |
| リピート | **高い**。買い物のたびに使う理由がある |
| 残る課題 | 「買うな」と言うほど儲からない利益相反 |

### ② 買わなくていい物レーダー

| 項目 | 内容 |
|---|---|
| **売れない理由** | **単体で使う理由がない**。一度見たら終わりで、リピートしない |
| **効く一手** | **①に統合し、SEOの入口として残す**。「買うか借りるか」の一覧は検索に強い |
| 判定 | 単体プロダクトとしては**廃止**。①の入口ページに格下げ |

### ③ いまから何する？

| 項目 | 内容 |
|---|---|
| **売れない理由** | **収益が発生する件数が少なすぎる**。47業態のうち要予約は7件。残り40件は送客しても1円にもならない |
| **効く一手** | 予約不要のものは**地図・営業時間リンク**で価値を出し、**要予約の商材を意図的に上位に混ぜる**。ただし出しすぎると信用を失うので**上位10件中2〜3件まで**と決める |
| リピート | **最も高い**。暇なときに毎回開く |
| 残る課題 | ①と同じ利益相反が、実は③にもある |

### ④ 今日だけ安い

| 項目 | 内容 |
|---|---|
| **売れない理由** | **店が投稿しないと画面が空**。供給を集めるには営業が必要で、前提と衝突 |
| **効く一手** | 無し。**捨てる** |

### ⑤ ソロマップ

| 項目 | 内容 |
|---|---|
| **売れない理由** | ③と7割重複。単体で集客する理由が薄い |
| **効く一手** | **③に「ひとり」モードとして統合**。ただし「一人で行きやすい店」は検索需要があるので、**SEO入口としては残す価値がある** |

### ⑥ 無料品レーダー

| 項目 | 内容 |
|---|---|
| **売れない理由** | **0円取引なので手数料が取れない**。ジモティーも巨大 |
| **効く一手** | 無し。**捨てる** |

## 5. 今回実装したもの

### 送客リンクの一元管理（`AFF` オブジェクト）

各デモの先頭に、送客先URLをまとめた設定を置いた。

```js
var AFF={
  ec:    '',   // ECアフィリエイト（未提携）
  used:  '',   // 中古サイト（未提携）
  rent:  '',   // レンタル各社（未提携）
  label: {...}
};
```

**空文字のままなら「提携準備中」と表示され、URLを入れた瞬間に本物のリンクになる。** コードを触らずに提携作業だけで公開できる。

### 結果のシェア機能

判定結果を1行のテキストにして、コピー／Xへの投稿ができるようにした。

> 例：「一眼レフを買おうと思ったけど、年1回×3年なら**レンタルが8.4万円お得**という判定でした」

**数字が入った具体的な結果はスクリーンショットで拡散しやすい。** 資金ゼロで集客する唯一の現実的な手段がこれ。
