# AI × 資金ゼロ の収益モデル

> 作成：2026-08-25 ／ 条件：**AIを使い、資金を使わず、収益を上げる**
> 関連：[副業ランキング](../物販リサーチ/副業ランキング.md)／[資金ゼロで始められる稼ぎ方](../物販リサーチ/資金ゼロで始められる稼ぎ方.md)／[カード転売の試算](../カード転売/README.md)

## 結論（先に読む3行）

1. **AI導入・業務自動化の受託が圧倒的**。月額顧問で**10〜30万円/社**、スポット診断で**5〜30万円**、自動化案件で**20〜100万円**。仕入れゼロ・在庫ゼロ・原価は自分の時間だけ。
2. **当社は「売るもの」が既に全部ある**。営業システム・採用システム・Apps Script・スクレイピングは、中小企業向けAI導入パッケージのプロトタイプそのもの。ゼロから作る必要がない。
3. 顧問2社で**月40万円・稼働16時間（時給25,000円）**。カード転売（資金30万・月30時間・5.2万円）の**8倍**。資金も在庫も要らない。

## 1. 市場の単価（2026年）

| メニュー | 相場 |
|---|---|
| **AI導入コンサル（月額顧問・伴走型）** | **月10〜30万円/社** |
| AI導入コンサル（プロジェクト型・PoC含む） | 50〜200万円 |

| AIライティング代行 | 1記事2,000〜5,000円（月3〜8万円） |
| AIクリエイティブ（画像・動画） | 画像10枚3,000円／動画込み5,000〜8,000円（月5〜12万円） |

**需要側**：生成AI関連の副業案件数は2023年比で**3〜4倍**。クラウドワークスの「AI活用」タグ案件は前年比**150〜200%**で推移。単純作業は減る一方、**「AIの精度を高めるための人間の判断」を売る仕事が増えている**。

## 3. 当社が「今すぐ売れるもの」の棚卸し

AI導入支援で最も時間を食うのは**提案資料と実装のプロトタイプ**。当社はそれを**もう作り終えている**。

| 既存資産 | そのまま売れるメニュー | 想定単価 |
|---|---|---|
| `営業システム/`（Markdownの業務OS＋学習ループ） | **「AIで営業を仕組み化する」導入支援** | 月20万円／構築50万円 |
| `recruitment-platform` `kyujinbox-platform` | **採用業務のAI自動化**（求人投稿・成績取得の自動化） | 月15万円／構築60万円 |
| `apps-script/` | **Google Workspace業務自動化** | 20〜50万円 |
| `スクレイピングダッシュボード.html` | **データ収集・可視化の自動化** | 30〜80万円 |
| `事業ダッシュボード.html`（管制塔） | **KPI管理の仕組み化** | 20〜40万円 |
| ルートの14本のHTMLテンプレート | Web制作の即納・テンプレート販売 | LP 5万円〜／テンプレ3,000〜30,000円 |
| `app-requirements/` | 要件定義の代行・テンプレート販売 | 10〜30万円 |

**強み**：「うちはこうやりました」という**実物のデモが全部ある**。AI導入支援は抽象論になりがちなので、動くものを見せられるのが決定的な差になる。しかも `www.social-quality.com` で公開済み。

## 4. 収支モデル（資金ゼロ）

### 立ち上げ期（1〜3ヶ月目）

| メニュー | 件数 | 単価 | 売上 | 稼働 |
|---|---:|---:|---:|---:|
| スポット診断（AI活用の現状分析＋提案書） | 2件 | 100,000円 | 200,000円 | 20h |
| Web制作（テンプレ流用・AI併用） | 2件 | 50,000円 | 100,000円 | 8h |
| **計** | | | **300,000円** | **28h** |

実効時給 **約10,700円**（媒体手数料16.5%を引いても約8,900円）。**必要資金0円**。

### 安定期（4ヶ月目以降）

| メニュー | 件数 | 単価 | 売上 | 稼働 |
|---|---:|---:|---:|---:|
| AI導入の月額顧問 | 2社 | 200,000円 | 400,000円 | 16h |
| 業務自動化の構築 | 0.3件/月 | 500,000円 | 150,000円 | 12h |
| デジタル資産の販売 | — | — | 30,000円 | 1h |
| **計** | | | **580,000円** | **29h** |

実効時給 **約20,000円**。**在庫ゼロ・仕入れゼロ・返品ゼロ**。

### カード転売との比較

| | 必要資金 | 月の稼働 | 月の売上 | 月の利益 | 実効時給 |
|---|---:|---:|---:|---:|---:|

ほぼ同じ稼働時間で、**利益は約10倍、必要資金はゼロ**。

## 5. 立ち上げ手順（30日）

| 週 | やること |
|---|---|
| W1 | **売るメニューを3つに絞る**（営業のAI化／採用のAI化／業務自動化）。既存資産をそのまま提案資料に転用する |
| W2 | **スポット診断メニュー（10万円）を作る**。現状ヒアリング→AI活用箇所の洗い出し→提案書、で稼働10時間の設計 |
| W3 | `営業システム/` のパイプラインに**新メニューを載せる**。ランサーズ・CWテック・自社LPで募集開始 |
| W4 | 既存顧客・知人企業に**スポット診断を無償または半額で1件**。**実績と事例を作る**のが目的 |

**最初の壁は営業**。単価が高い分、信用が要る。だから**スポット診断（低単価・短納期）から入り、そこから顧問契約に上げる**のが定石。

## 6. 注意点

| 誤解 | 実際 |
|---|---|
| 「AIを使えば楽に稼げる」 | **AIが減らすのは制作工数だけ。案件獲得（営業）は減らない。** 当社は `営業システム/` があるのでゼロからではない |
| 「AIで作った記事・画像を量産すれば稼げる」 | 誰でもできるので単価が下落する。**判断と責任を売るほうに寄せる** |
| 「AI導入支援は専門知識が要る」 | 要るのは**業務理解**。ツールの使い方（ChatGPT・Claude等）は2〜4週間で足りる。当社は既に実務で回している |
| 「実績がないと売れない」 | **この会社自体が実績**。営業・採用・制作をAIで仕組み化した実例を、動くデモ付きで見せられる |

**最大のリスクは、これをやらずにカード転売に30万円と月30時間を投じること。** 資金ゼロで10倍稼げる選択肢が手元にある。
