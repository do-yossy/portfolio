# セルフサーブSaaS 候補選定（競合調査＋8項目採点）

> 作成：2026-08-25
> 固定条件：**資金0円／営業なし／人と話さない／AIで開発／自動決済／月額課金／3ヶ月以内に月10万円**
> 前提の戦略：[人手ほぼゼロで売上を作る方法](人手ほぼゼロで売上を作る方法.md)／[売れるアイデア10案](売れるアイデア10案.md)

## 結論（先に読む3行）

1. **1位＝求人改善AI（81点）／2位＝業種特化AI見積（83点）**。素点は見積が上だが、**差別化が続くのは求人改善**（技術ではなく当社の実務知識が参入障壁になるため）。
2. **職務経歴書AIは即落とし**。無料ツールが乱立し、「求人に合わせて最適化」まで既存サービスが実装済み。勝ち目がない。
3. **最大の壁は集客の算数**。月10万円＝980円×102人。無料→有料のCVRを1〜3%とすると**累計3,400〜10,200人の無料利用者が必要**で、新規ドメインのSEOでは3ヶ月では届かない。**単価を上げるか、既存の接点を初速に使うかの二択**。

## 3. 本命2案の中身

### 【1位】業種特化AI見積 ── 作りやすさと競合の薄さで勝つ

建設・製造向けのAI積算は**月額数万〜数十万円のエンタープライズ製品**しかない。**一人親方・小規模事業者が月980〜4,980円で使えるものが存在しない**。

| 項目 | 内容 |
|---|---|
| 対象 | 外壁塗装／清掃／内装／リフォーム／Web制作 など**1業種に絞る** |
| 入力 | 条件を数個選ぶだけ（面積・階数・工程 など） |
| 出力 | 見積書＋提案書＋顧客に送るメール文（PDF） |
| 単価 | **月1,980円**（無料は月1件まで） |
| 月10万円 | **51人** |
| 開発の要点 | **単価マスタさえ用意すれば中身は単純**。AIは文章生成と項目の過不足チェックに使う |
| 弱点 | **業種ごとに単価マスタが要る**ので横展開に手間。検索需要も求人ほど大きくない |

### 【2位】求人改善AI ── 差別化が最も長持ちする

求人「生成」ツールは既に3つ以上ある。だが**「今出している求人を診断して、応募が来ない理由を指摘し、100点になるまで直す」**ものは見当たらない。

| 項目 | 内容 |
|---|---|
| 入力 | **求人URLを貼るだけ** |
| 処理 | 競合求人と比較 → 給与・休日・仕事内容を評価 → **応募されにくい理由を診断** → タイトル10案＋本文生成 → 再診断 |
| 出力 | スコア（例：63点）＋改善項目7つ＋改善版の求人文 |
| 単価 | **無料で1診断／有料 月980〜1,980円** |
| 月10万円 | 980円×102人 or 1,980円×51人 |
| **本当の強み** | **技術ではなく当社の実務知識が参入障壁になる**。`kyujinbox-platform`・Airwork運用・RPOで「何が応募を減らすか」を知っている。他社はツールは作れても採点基準が作れない |
| 弱点 | **求人URLの取得は各媒体の規約確認が必須**（スクレイピング不可の媒体がある）。→ **URLではなく求人票の本文を貼り付けてもらう方式**にすれば規約リスクを回避できる |

> **重要**：求人媒体のページを自動巡回・取得するのは規約違反になる媒体がある（`../CLAUDE.md` の方針とも一致）。**ユーザー自身に本文を貼り付けてもらう設計**にすること。競合比較は公開統計や求人検索の一般的な相場データで代替する。

## 4. ここが本当の壁 ── 集客の算数

**月10万円に必要な人数と、その裏で必要なアクセス数**

| 単価 | 必要な有料ユーザー | 無料→有料CVR 2%なら必要な無料利用者 | 必要な月間アクセス |
|---:|---:|---:|---:|
| 980円 | **102人** | 5,100人 | **数千〜1万UU** |
| 1,980円 | **51人** | 2,550人 | 2,000〜5,000UU |
| 4,980円 | **21人** | 1,050人 | **1,000〜2,000UU** |

**新規ドメインのSEOは評価が付くまで3〜6ヶ月**かかる。つまり**3ヶ月で月10万円をSEOだけで達成するのは無理**。

### 現実的な打ち手は3つ

| 打ち手 | 効果 |
|---|---|
| **① 単価を上げる** | 980円→**4,980円にすれば必要人数が102人→21人**。BtoB向けなら4,980円は普通に通る |
| **② 既存の接点を初速に使う** | `www.social-quality.com`・ポートフォリオ・過去の取引先・ランサーズのプロフィール。**ゼロからの集客ではない** |
| **③ 検索意図が強く競合が薄いキーワードを取る** | 「求人 応募が来ない 改善」「外壁塗装 見積書 テンプレート」など、悩みが具体的な語を狙う |

**→ 結論：980円ではなく1,980〜4,980円で設計する。** 安くしても人数の壁が上がるだけで、営業なしでは埋まらない。

## 5. 見落とすと赤字になる2つの設計

### ① AIのAPI原価

**月額固定で使い放題にすると、ヘビーユーザー1人で赤字になる。**

- 1回の生成にかかるAPI費用は数円〜十数円
- 月980円のプランで1人が100回使えば原価が数百〜千円超
- **必ず回数制限（月10回まで等）かクレジット制にする**

### ② 決済と特商法

| 項目 | 内容 |
|---|---|
| Stripe | **個人事業主でも法人でも利用可**。開業届がなくてもアカウント作成可。審査は自動で1〜2営業日 |
| 特商法表記 | **掲載が法律上の義務**。ただし住所・電話番号を**「請求があれば遅滞なく開示」**とする書き方でStripe審査を通過した事例がある |
| 実装 | サブスク課金はStripeの標準機能で完結。**コードはほぼ書かなくていい** |
