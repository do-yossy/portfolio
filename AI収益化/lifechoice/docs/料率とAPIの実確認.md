# 料率とAPIの実確認（`月間売上想定.md` の「要確認」を埋める）

確認日：2026-08-25 ／ 対象：`月間売上想定.md` で **仮定・要確認** としていた単価と、実装前に確定しておくべきAPIの条件

`月間売上想定.md` は売上モデルそのもの（1,000UUあたり約2,200円／月5万円には約2万UU）を扱う。本ファイルはその**入力値の裏取り**と、**実装に効くAPIの制約**だけを扱う。売上の再計算はしない。

## 1. Amazon 紹介料率（確認済み・公式）

`月間売上想定.md` では「2〜3%・カテゴリで異なる・要確認」としていた箇所の確定値。

| カテゴリ | 料率 | LIFE CHOICE での該当 |
|---|---:|---|
| **カメラ／PC／家電** | **2.00%** | カメラ、美容家電、調理家電 |
| その他すべての商品 | 2.00% | 大半の品目 |
| スポーツ用品／ベビー&マタニティ／工具・機械 | 4.00% | 自転車、キャンプ、ベビー用品 |
| ドラッグストア／ビューティー・コスメ | 5.00% | 消耗品 |
| 服&ファッション小物／シューズ&バッグ | 8.00% | 礼服・スーツ |

**注意点が2つある。**

1. **美容家電は5%ではなく2%で置くこと。** 「ビューティー・コスメ」ではなく「家電」に分類される商品が多い。ここを5%で計算すると売上想定が2.5倍ずれる。
2. **紹介料の上限（1商品1個あたり1,000円）は2024年8月7日に廃止済み。** 10万円のカメラなら満額2,000円が入る。`月間売上想定.md` の単価875円は、高額品ではむしろ保守的。

## 2. 楽天アフィリエイト（確認済み・公式）

- 成果報酬は **1商品1個の売上につき1,000円が上限**（楽天キャッシュ）。料率アップ対象商品は最大20%・上限なしの扱いがある。
- **高額品では Amazon が有利**（上限が無いため）。10万円のカメラは Amazon 2,000円 に対し 楽天は上限1,000円。

→ **実装への反映**：同じ商品で両方に在庫がある場合、**単価3.4万円を超えたらAmazonを先に出す**（2% × 34,000円 = 680円 …ではなく、上限1,000円に達する楽天の料率次第。楽天の料率が3%なら33,333円が分岐点）。分岐点は対象ジャンルの実料率が分かってから確定する。

## 3. Amazon API：2026年に廃止される（最重要）

**価格を出す機能の土台が、いま入れ替わりの最中にある。**

| 項目 | 内容 | 期限 |
|---|---|---|
| **PA-API（Product Advertising API）の廃止** | 新規受付は停止済み。**Creators API への移行が必須** | **2026年4月30日〜5月15日** |
| **Offers V1 の終了** | 価格・在庫の取得は **OffersV2**（Creators API 経由）へ | **2026年1月31日** |
| アソシエイト審査 | 登録後 **180日以内に適格販売3件** | 未達で提携解除 |
| API の継続利用条件 | 直近の売上実績が必要（公式の旧ポリシーは「過去30日以内に発送済みの売上」。二次情報では「直近30日で10件」） | 常時 |

### ここに鶏と卵がある

**価格を出すにはAPI → APIを保つには売上 → 売上を出すには価格表示。** ローンチ直後がいちばん通しにくい。対策は3つ。

1. **初期は楽天ウェブサービス（楽天市場API）を主軸にする。** 売上実績の縛りがゆるく、商品検索と価格取得が揃う。Amazonは後から足す
2. Amazon は当面**静的リンク**（価格を表示しない導線）に留め、適格販売3件をクリアしてからAPIを繋ぐ
3. 表示する価格は**「取得時点の参考値」と明示**し、最新価格は遷移先で確認させる。API規約の更新頻度要件を満たすため

**`data/products.json` の実勢価格を手で確認して持つ方式は、この移行期にはむしろ正しい。** APIが不安定な期間の保険になる。ただし価格の鮮度は落ちるので、**取得日を必ず併記**すること。

## 4. 中古の収益化（`月間売上想定.md` 2章の補強）

「64%が中古に流れるが、メルカリに一般向けの成果報酬が無い」という指摘はそのとおり。**送り先の候補は個人間フリマではなく中古専門店に寄せるのが現実的**で、こちらは成果報酬の枠組みがある。

| 送り先の候補 | 扱い | 備考 |
|---|---|---|
| 駿河屋／ゲオ／じゃんぱら／カメラのキタムラ 等の**中古専門店** | ASP経由の案件が存在 | 在庫が安定していて価格比較にも向く |
| ヤフオク（バリューコマース経由） | 提携あり | 相場が動くので価格表示は要注意 |
| メルカリ | **一般向けの成果報酬なし** | 送客しても収益にならない |

→ **中古を「専門店の在庫」に置き換えられれば、64%の導線がそのまま収益になる。** 個人間フリマにこだわらないことが、この事業でいちばん効く一手。
