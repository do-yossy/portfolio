# 公開方針 ── このディレクトリは公開しない

決定日：2026-08-26（依頼者の判断）

## 決定

**LIFE CHOICE は `www.social-quality.com` に公開しない。**
`AI収益化/demo/` の6デモについても同じ（2026-08-25 に決定済み）。

## 守ること

`www.social-quality.com` は GitHub Pages で、**`main` ブランチの中身がそのまま公開される**。
`robots.txt` は `Allow: /` なので、main に入った時点で検索エンジンにも拾われる。

したがって：

1. **`AI収益化/lifechoice/` と `AI収益化/demo/` を `main` にマージしない。**
   作業ブランチに置いたままにする。
2. `sitemap.xml` に追加しない。
3. ルートの `index.html` やポートフォリオ各ページからリンクしない。
4. 公開が前提の作業（提携申請、検索流入の施策）は行わない。

現在 `main` に入っているのは `AI収益化/*.md` の分析文書12件のみで、
`lifechoice/` も `demo/` も入っていない（2026-08-26 時点で確認済み）。

## この判断で変わること

| 項目 | 影響 |
|---|---|
| アフィリエイト収益 | **成立しない。** 訪問者が発生しないため |
| `guide/` の59ページ | 検索流入用に作ったが、その用途では機能しない |
| `docs/月間売上想定.md` | 前提が公開だったため、**現時点では無効** |
| `docs/収益構造の分析.md` | 同上。公開する場合に備えた分析として残す |

売上の見通し（12〜18ヶ月で月10万円）は、検索流入を前提にした試算だった。
公開しない以上、この数字は成立しない。

## 残る価値

1. **自分用の判断ツール**として動く。買う前に総額を比較できる
2. 将来公開する判断に変わった場合、**そのまま出せる状態**にしてある
3. `data/products.json` の実勢価格22品目は、公開の有無に関わらず使える資産

## 方針を変える場合

公開に切り替えるなら、次の順で行う。

1. `AI収益化/lifechoice/` を `lifechoice/` へ移動（URLを短くする）
2. `guide/sitemap-fragment.xml` を `sitemap.xml` に取り込む
3. アフィリエイトの提携申請（`docs/料率とAPIの実確認.md` の注意点を参照）
4. `main` へマージ

逆に、完全に取り下げる場合はブランチごと削除すればよい。
`main` には何も入っていないため、公開サイトへの影響は無い。
