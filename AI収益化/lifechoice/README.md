# LIFE CHOICE

買う前に「買う・中古・借りる」を金額で比べ、無駄な出費を減らすWebアプリ。

**このディレクトリは公開しない方針です。** 詳細は [docs/公開方針.md](docs/公開方針.md)。

---

## 起動する

`start.bat` をダブルクリックすると、サーバーが立ち上がってブラウザが開きます。

```
AI収益化/lifechoice/start.bat
```

コマンドから起動する場合：

```bash
cd AI収益化/lifechoice
node serve.mjs          # http://localhost:3400/
node serve.mjs 3401     # ポートを変える場合
```

**`index.html` を直接ダブルクリックしても動きません。**
ESモジュールと `fetch` を使っているため、`file://` では読み込みがブロックされます。
サーバーは `node:http` だけで書いてあり、追加のインストールは要りません。

## 何ができるか

| | 機能 | 内容 |
|---|---|---|
| ① | 買う前チェック | 買う／中古／レンタル／見送る を総額で判定 |
| ② | 買わなくていい物レーダー | 何回使えば買ったほうが得か（損益分岐点） |
| ③ | いまから何する？ | 今の時間・予算で間に合う場所を探す |
| ④ | 今日だけ安い | **サンプルデータのみ**。実データの供給元が無い |
| ⑤ | ソロマップ | 一人で入りやすい店をスコア順に |
| ⑥ | 無料品レーダー | **サンプルデータのみ**。同上 |

加えて：

- **統合検索**（`app/search.html`）… 「3万円くらいでキャンプを始めたい」の1文から、必要な物をまとめて比較
- **品目を追加**（`app/my-items.html`）… 同梱38品目に無い物を自分で足せる
- **設定**（`app/settings.html`）… 条件を1回入れれば4機能に反映。書き出して別端末に移せる
- **比較ページ**（`guide/`）… 品目38件・分野20件の静的ページ

## データ

| ファイル | 内容 | 出典 |
|---|---|---|
| `data/products.json` | 38品目 | レンタル価格は22品目、新品価格は14品目が確認済み。残りは推定 |
| `data/stores.json` | 47業態 | 一般的な水準からの推定。実在の個別店舗ではない |
| `data/rentals.json` | 38件 | 各社の掲載価格 |
| `data/activity-sets.json` | 20分野 | 「〜に必要な物」の対応表 |
| `data/deals.json` | 15件 | **すべてサンプル**（架空） |
| `data/free-items.json` | 14件 | **すべてサンプル**（架空） |

推定値は画面上で「推定価格」「相場からの推定」と明示しています。
サンプルデータには DEMO 印を付け、おすすめや合計金額の計算には使いません。

自分で追加した品目はブラウザ内（localStorage）にのみ保存され、
`products.json` は書き換えません。設定画面から書き出せます。

## 開発

```bash
# テスト（10スイート・6,018件）
cd AI収益化/lifechoice
for f in tests/*.js; do node "$f"; done

# 比較ページの再生成（data を変えたら実行する）
node tools/build-guide.mjs
```

依存パッケージはありません。ビルドも不要です（`guide/` の生成だけスクリプトを使います）。

### 構成

```
data/         同梱データ（JSON）
lib/          計算ロジック。UIを含まない
components/   画面部品
utils/        書式・DOM・保存
app/          各機能の画面
guide/        静的な比較ページ（tools/build-guide.mjs が生成）
tests/        テスト。フレームワークは使わない
docs/         分析と方針の記録
```

計算は `lib/` に集約してあり、画面側で同じ計算を書きません。
データ取得は `lib/data-provider.js` を通し、将来API等へ差し替えられる形にしてあります。

## 既知の制約

1. **④⑥は実用にならない**（掲載データが全てサンプル）
2. **エリア指定が絞り込みに使えない**（店舗を業態単位で持っており個別座標が無い）
3. **新品価格の24品目は推定**（14品目は確認済み）
4. **フォーマルの比較が公平でない**（レンタル価格には着付け等が含まれるが、中古購入には含まれない）

いずれも数字を作れば解消できますが、事実でない情報を出すことになるため
課題として記録するに留めています。
