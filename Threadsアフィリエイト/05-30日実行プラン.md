# 05 30日実行プラン

**着手日を D0 とした相対日程。** 「あれ始めるで」の合図が出た日に D0 を埋めて走り出せる形にしてある。

1日の稼働は **30〜40分**。これを超えたら設計が間違っているので手順を見直す。

---

## D0：セットアップ（90分・この日だけ長い）

| 時間 | やること | 参照 |
|---|---:|---|
| 15分 | 実施主体を決める（個人／法人）→ その楽天会員IDでアフィリエイト登録 | `03` §5 |
| 10分 | **楽天カードまたは楽天銀行を連携**（3,001円超の受取に必須） | `03` §1-4 |

| — | `03` の着手前チェックリストを全部潰す | `03` §6 |

**D0のゴール**：アカウントが立っていて、明日の朝に投稿1本目が出せる状態。

| D2 | 2本 | 1本 | リサーチの3条件（いいね100+／青リンク／PR）で10商品リスト化 |

| D5 | 2本 | 1本 | リンク直前のフック一言を3パターン試す |

**W1のゴール**：リンク付き1本を**10分以内**で作れる。投稿21本。

## W2（D8–D14）：リーチを取りにいく

| やること |
|---|
| W1で最も伸びた投稿の**型を3本に増やす**（同じ商品ではなく同じ型） |
| リンクなし投稿の質を上げる（失敗談・比較・質問形式を試す） |
| 商品リストを20件まで増やす（単価3,000〜6,000円のレビュー多数帯に絞る） |
| **初成果が出たら記録**（何日目・どの投稿から・金額） |
| D14：週次レビュー |

**W2のゴール**：投稿42本。**1投稿あたり平均インプレッションがW1比で伸びている**こと。

---

## W3（D15–D21）：商品選定を最適化する

| やること |
|---|
| クリックは来るが売れない商品を外す（**単価が高すぎる／レビューが少ない**が主因） |
| 逆に**成果が出た商品と同じ価格帯・同ジャンル**の商品を厚くする |
| フォロワーが増えていれば、リンクなし投稿の比率を少し下げる（7:3 → 6:4） |
| 楽天アフィリエイトのレポートで**「成果報酬」列**を確認（売上金額と取り違えない） |
| D21：週次レビュー |

**W3のゴール**：投稿63本。**リンククリック率1%以上**。

### 判定の読み方

| 状況 | 判断 |
|---|---|
| **平均IMP 1,000以上 かつ CTR 1%以上** | **Threadsでリーチが取れる**と確認できた。→ **アフィリは畳んで、同じ運用を求職者集客に転用**（`04` §7）。ここが本命 |
| 平均IMP 1,000以上だが CTR が低い | リーチは取れる。訴求（フック）の問題なので、あと30日だけ本文の型を変えて再試行 |
| **平均IMP 500未満** | Threadsで当社が人を集めるのは難しい。**撤退**。損失は作業20時間のみ |
| 報酬だけ出て IMP が伸びない | 単発のバズ依存。再現性がないので**継続しない** |

## 撤退基準（これに触れたら即やめる）

| 条件 | 対応 |
|---|---|
| 楽天アフィリエイトから警告を受けた | **即停止**。`03` を再確認 |
| Threadsアカウントに制限がかかった | **即停止**。リンク付き投稿の比率を疑う |
| 1日の稼働が40分を超える日が3日続いた | 手順が悪い。`01` の所要時間表に戻す |
| D14時点で平均インプレッションが100未満 | ジャンルかアカウント設計の失敗。**やり直すか撤退** |
| Web制作の稼働に食い込んだ | **即停止**。足切り¥4,000/hを守る（`04` §5） |
