# 06 収益構造とKPIの分解

**「Threadsでアフィリエイトする」は目的ではない。** 目的は下の式の各項を1つずつ測って、動く項だけに時間を使うこと。

---

## 1. 収益の恒等式

```
報酬 = Views × CTR × CVR × 1件あたり報酬
```

| 項 | 意味 | 支配しているもの | 動かせる幅 |
|---|---|---|---:|
| **Views** | 表示回数 | Threadsのアルゴリズム評価 | **37倍** |
| **CTR** | 表示 → リンククリック | 1行目のフックとリンク直前の一言 | 2.4倍 |
| **CVR** | クリック → 購入 | 商品側の信用（レビュー・価格）と**買うタイミング** | 3倍 |
| **単価** | 1件あたり報酬 | ジャンル料率 × 商品単価 × ついで買い | 3.8倍 |

**掛け算なので、どれか1つがゼロなら全部ゼロ。** 動画が「毎日3投稿」しか言わないのはViewsの項だけを見ているから。実際にはViews以外の3項も同じだけ効く。

---

## 2. ファネルの全段

投稿してから報酬になるまで、**6段ある**。各段の脱落率を測らないと、どこが壊れているか分からない。

```
① 表示 (Views)
     ↓ エンゲージ率        ← アルゴリズムがここを見て②以降の配布量を決める
② 反応 (いいね・返信・保存)
     ↓ CTR
③ リンククリック
     ↓ 到達率              ← ここは商品ページの問題
④ 商品ページ到達
     ↓ カート投入率        ★ クリック後24時間以内が条件
⑤ カート投入
     ↓ 購入完了率          ★ 89日以内でよい（＝すぐ買わなくても成果になる）
⑥ 購入完了 → 成果報酬（料率 × 単価、1商品1個あたり1,000円上限）
```

### 各段の目安と、詰まったときの打ち手

| 段 | 健全な水準 | 詰まっている時の原因 | 打ち手 |
|---|---:|---|---|
| ① Views | 1投稿1,000以上 | ジャンル不一致／外部リンク連投／初速が弱い | `08-投稿設計.md` |
| ② エンゲージ率 | 2%以上 | 1行目が弱い／返信の余地がない | 質問で終える型に変える |
| ③ CTR | 1.0%以上 | リンク直前のフックがない／情報を出しすぎ | 「色展開が最高すぎる」型 |
| ④→⑤ カート投入 | — | 商品の価格帯が高すぎる／レビューが薄い | 商品選定をやり直す（3,000〜6,000円帯へ） |
| ⑤→⑥ 購入完了 | — | **買い回りイベント外** | 投稿タイミングを変える（下記） |

## 3. タイミング設計 ← 動画が一切触れていない最大のレバー

楽天は**買い回りイベント中にCVRとついで買いが跳ねる**。

| イベント | 頻度 | 期間 |
|---|---|---|
| **お買い物マラソン** | **毎月2〜3回**（12月除く） | 数日間 |
| **楽天スーパーSALE** | **年4回（3・6・9・12月）** | 4日20:00 〜 11日01:59 |

ユーザーが「ショップ買い回り」でポイント倍率を上げようとまとめ買いするため、**通常時よりアクセス数・転換率とも大幅に上昇する**。

### これが効く理由（成果条件との噛み合わせ）

成果条件は「**クリック後24時間以内にカート投入 → 89日以内に購入完了**」。

- 買い回り中のユーザーは「**あと2ショップ買いたい**」状態でカートを開いている
- そこにリンクを踏ませれば、カート投入率が跳ね上がる
- さらに**同時購入した他店の商品も成果対象**になる（ついで買い係数が1.3 → 2.0近くまで伸びうる）

### 運用ルール

```
マラソン開始2日前  … 商品紹介投稿を仕込む（認知）
マラソン初日〜2日目 … リンク付き投稿を通常の2〜3倍に増やす ★ここに全力
マラソン終盤        … 「買い忘れ」訴求
マラソン期間外      … リンクなし投稿でアカウントを育てる
```

**月の投稿本数は同じでも、配分を変えるだけで報酬が変わる。** 毎日均等に3投稿するのは、この構造を知らない人のやり方。

## 4. バズる投稿と稼げる投稿は別物

ここを混同すると、伸びているのに1円にもならない状態になる。

| | バズる投稿 | 稼げる投稿 |
|---|---|---|
| 届く相手 | ジャンル外を含む**広く浅く** | 購買意図のある**狭く深く** |
| Views | 10万〜 | 2,000〜20,000 |
| CTR | **0.05%以下** | 1.0〜1.5% |
| 中身 | 共感・驚き・笑い | 悩みの言語化＋解決 |
| 報酬 | ほぼゼロ | 出る |

**恒等式で見ると理由が分かる**：バズはViewsを100倍にする代わりにCTRを1/100以下にする。掛け算なので**結果は同じかマイナス**。

さらに悪いのは副作用のほう：

> **バズはアカウントのジャンル認識を壊す。**
> ジャンル外の人が大量にフォローすると、アルゴリズムが「このアカウントは何の専門家か」を判定できなくなり、**以後の投稿がジャンル内の人に届かなくなる**。

**方針：バズを狙わない。「ジャンル内で中規模に伸びる」を再現性込みで狙う。** バズが起きたら喜ばずに、フォロワーの質が落ちていないか（次の投稿のエンゲージ率）を確認する。

## 5. 導線設計：投稿 → プロフィール → リンク → 購入

Threadsは本文に外部リンクを置くとリーチが落ちる。だから導線は**3本に分かれる**。

### 導線A：投稿 → セルフリプライのリンク → 商品（最短）
- 動画が教えている唯一の導線
- CTRは最も高いが、**1投稿につき1商品**しか売れない
- ⚠️ リンクを貼れるのは**自分の投稿への自己コメントのみ**。他人の投稿のコメント欄は規約違反

### 導線B：投稿 → プロフィール → プロフィールのリンク → 複数商品
- 投稿に興味を持った人が**発信者を確認しにくる**動線
- プロフィールに楽天ROOMやリンク集を置くと、**1人が複数商品を見る**
- CTRは低いが、**1クリックあたりの価値が高い**（回遊＋ついで買い）
- **プロフィールクリック率**をKPIに入れる（Threadsのインサイトで取れる）

### 導線C：投稿 → プロフィール → フォロー → 後日購入（LTV型）
- 即売れないが、**同じ人に何度も送れる**
- ここが唯一「1回140円」の天井を超える道 → `10-出口設計とLTV.md`

### プロフィールの役割
プロフィールは**1秒で「この人は何の人か」を伝える関門**。ここが弱いと導線BとCが両方死ぬ。

```
必須要素：
  ・ジャンル語（アルゴリズムにも人にも効く）
  ・立場の証明（「猫と暮らして8年」＝レビューの信用）
  ・PR表記
  ・リンク（楽天ROOM等・1本だけ）
```

## 6. KPIツリー（何を毎日見るか）

```
報酬（結果・見ても動かせない）
 ├─ Views                    ← 毎日見る。最優先
 │   ├─ エンゲージ率（初速30分）  ← 型の良し悪しがここに出る
 │   └─ フォロワー数            ← 週次
 ├─ CTR                      ← 毎日見る
 │   ├─ 投稿内リンクのCTR
 │   └─ プロフィールクリック率
 ├─ CVR                      ← 週次（サンプルが溜まらないと意味がない）
 └─ 1件あたり報酬             ← ジャンル選定で確定済み。月次で確認
```

**報酬額を毎日見ない。** 日次の報酬はノイズしかない。日次で見るのはViewsとCTRだけ。

## 7. インプレッション単価（自社にとっての本当のKPI）

アフィリ報酬より、こちらの数字のほうが当社には価値がある。

```
インプレッション単価（CPM換算） = 作業時間 × 時間単価 ÷ 総Views × 1,000
```

例：月12時間 × ¥4,000/h = 48,000円 ÷ 75,000 Views × 1,000 = **CPM 640円**

これを広告出稿のCPM（Meta広告で数百〜千数百円）と比べる。**自社運用のほうが安ければ、SNS運用は当社の集客チャネルとして成立する**という判断材料になる。

→ この数字を取ることが30日実験の本当の目的（`04-収支シミュレーションと判定.md` §6）。
