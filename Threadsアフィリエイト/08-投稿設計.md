# 08 投稿設計 — なぜその投稿が伸びるのか

`06` の恒等式のうち **Views（37倍のレンジ）** を作る工程。ここが全体の律速。

---

## 1. Threadsのアルゴリズムが見ているもの

Threadsのメインフィードは**おすすめ表示が中心**で、フォロー外にも配布される。だからフォロワーゼロでも伸びる。ただし配布量は下の5つで決まる。

| # | 判断材料 | 効き | 実装 |
|---|---|---|---|
| 1 | **アカウントのジャンル一貫性** | ★★★ | 投稿ジャンルを混ぜない。「このアカウントは何の専門家か」をAIに認識させることが、おすすめに乗る**絶対条件** |
| 2 | **投稿初速のエンゲージ率**（最初の30分〜1時間） | ★★★ | ここで反応が取れないと以降配布されない |
| 3 | 滞在時間 | ★★ | 画像を複数枚／文章を読ませる |
| 4 | 返信数 | ★★ | **返信はいいねより重い**。質問で終える |
| 5 | **外部リンクの有無** | ★★★（マイナス） | リンク付き投稿はアプリ外へ逃がすため評価が下がる |

### ここから導かれる設計

```
・ジャンルは1つに固定する           （#1）
・本文に外部リンクを置かない         （#5）
   → リンクは自分の投稿へのセルフリプライに
・1行目で止める                     （#2）
・質問で終える                       （#4）
・リンクなし投稿を7割入れる           （#5の打ち消し）
```

**動画が「毎日3投稿すべてリンク付き」と教えているのは、この#5を知らないから。** 量は正しいが配分が間違っている。

---

## 2. 初速の設計

投稿から最初の30分〜1時間のエンゲージ率で、その後の配布量が決まる。

| やること | 理由 |
|---|---|
| **1行目に全力**（後述） | フィードで止まるかどうかは1行目だけで決まる |
| 投稿直後に自分でセルフリプライ | 投稿の下に返信が1件付いた状態を作る（＝リンクを貼る作業と兼ねる） |
| ジャンル内の他投稿に返信しておく | 自分のアカウントの活動をアルゴリズムに認識させる |
| 時間帯を固定して検証 | 朝7-9時／昼12-13時／夜20-23時。**同時に複数変えない**（`09`） |

---

## 3. 1行目の設計

Threadsのフィードでは**最初の1行しか見えない**。ここで止まらなければViewsはゼロ。

### 原則：最初の7〜15文字で「自分ごと」にさせる

| ✗ 弱い1行目 | ○ 強い1行目 | 何が違うか |
|---|---|---|
| このブランケットおすすめです | こんな適当に置いておしゃれなのやばくない? | **状況が浮かぶ**。商品名がない |
| 猫用ベッドを買いました | これ置いてから、猫がここでしか寝なくなった | **結果だけ**。因果が気になる |
| 便利な収納グッズ紹介 | 3年間ずっと失敗してた収納、やっと正解が出た | **失敗の物語**＝レビューの信用 |
| 毛が付きにくい素材です | 毛が付く時間が1/5になった | **数字**。検証した感 |

### やらないこと
- 商品名・型番から書き出す（広告に見えて読まれない）
- スペックの羅列
- 「おすすめです！」「神アイテム」（誰でも書ける＝信用ゼロ）
- ハッシュタグを冒頭に置く

## 4. 「80%悩み・情報 / 20%商品」の本当の意味

動画は「商品の話をするな、買った先の未来を話せ」としか説明していない。**なぜ効くのかは3層ある。**

### 層1：アルゴリズム対策
商品紹介だけの投稿は**返信も保存も付かない**。エンゲージ率が上がらないので配布が止まる。悩みの話には「わかる」「うちもそう」が付く。**80%は#2と#4を稼ぐための燃料。**

### 層2：購買心理（問題認識）
**問題を認識していない人に商品を出すと、価格比較しかされない。**

```
問題認識なし → 商品提示 → 「へー」or「高い」で終わり
問題認識あり → 商品提示 → 「それだ」→ クリック
```

80%は商品を売る準備ではなく、**「これは自分の問題だ」と気づかせる工程**。

### 層3：信用の代替（これが本質）
フォロワーゼロの人間の「おすすめ」に価値はない。しかし——

> **悩みを正確に言語化できる人間には、信用が生まれる。**

「毛が付くのが嫌」ではなく「**黒い服を着る日だけソファに座れない**」と書けると、読み手は「この人は本当に同じ状況にいる」と判断する。**80%は信用を作る工程であって、前置きではない。**

### 実装

```
［80%］ ターゲットの痛み3つのどれかを、具体的な状況として描写する
          ↓
［20%］ 「で、これ使ってる」程度に商品を出す
          ↓
［セルフリプライ］ フック一言 ＋ PR ＋ リンク
```

## 5. 投稿フォーマットのカタログ

検証で回す**型は6つ**。`09` で1つずつ潰していく。

| # | 型 | 構造 | 例 | 向き |
|---|---|---|---|---|
| 1 | **情景型** | 状況＋感情 | 「こんな適当に置いておしゃれなのやばくない?」 | インテリア・雑貨 |
| 2 | **失敗談型** | 失敗の履歴＋解決 | 「3年間◯◯で失敗し続けて、やっと」 | 全ジャンル。信用が最も出る |
| 3 | **比較型** | A→B→Cの遍歴 | 「A買ってB買って、結局Cに落ち着いた」 | 検討中の人に刺さる |
| 4 | **数字型** | Before/Afterを数値化 | 「毛が付く時間が1/5になった」 | 効果が測れる商材 |
| 5 | **反論型** | 前提の否定 | 「◯◯は要らないと思ってたけど」 | 認知はあるが未購入の層 |
| 6 | **質問型** | 問いで終える | 「みんな◯◯どうしてる?」 | **リンクなし投稿専用**。返信を稼ぐ |

**型6はリンクなし投稿の主力。** 返信が付くとアカウント評価が上がり、リンク付き投稿のリーチが伸びる。

## 6. 画像設計

Threadsは画像が主戦場。**文章より画像で決まる。**

| 構図 | 使いどころ |
|---|---|
| **俯瞰（部屋全体）** | 情景型。生活の中に置かれた状態 |
| 寄り（質感） | 素材・肌触りを訴求するとき |
| **使用中（人・ペットが写る）** | 最も強い。使っている状態が想像できる |
| Before / After | 数字型とセット |

### ⚠️ 使ってよい画像の制約（`03` 参照）
- ✅ **アフィリエイトリンク作成ページに表示される画像**をダウンロードしたもの
- ✅ **自分で撮影した写真**（制約なし・信用も上がる）
- ❌ 楽天の商品ページからスクショ・長押し保存したもの（**規約違反**）
- ❌ 文字入れ・トリミング等の加工（**規約違反**）

**加工が禁止されているので、Before/After比較画像は自作するしかない。** 実物を買って撮るほうが早く、かつ強い。

## 7. リンクなし投稿の設計（全体の7割）

「アカウントを育てるための投稿」であって、無駄打ちではない。

| 種類 | 目的 | 例 |
|---|---|---|
| 質問型 | 返信を稼ぐ（#4） | 「みんな猫の抜け毛どうしてる?」 |
| 失敗談 | 信用を作る | 「これ買って失敗した話」 |
| 比較・まとめ | 保存を稼ぐ（滞在時間） | 「3年で買った猫グッズ、良かった順」 |
| 日常 | 人格を出す | 実際の生活風景 |

**リンクなし投稿でも、ターゲットの痛み3つのどれかに必ず言及する。** ジャンル認識（#1）を強化するため。

---

## 8. やってはいけない投稿

| ✗ | 理由 |
|---|---|
| 同一文面の連投 | スパム判定 |
| ジャンル外の投稿を混ぜる | **ジャンル認識が壊れる**（#1）。最も致命的 |
| 本文に外部リンク | 配布量が落ちる（#5） |
| 短縮URL | スパム判定＋ASP規約違反 |
| PR表記なし | 景表法・楽天ガイドライン違反 |
| バズ狙いのネタ投稿 | フォロワーの質が落ち、以後のCTRが下がる（`06` §4） |

---

## 9. 投稿テンプレート（そのまま使う）

### リンク付き投稿
```
［1行目：状況または結果。商品名を出さない］

［2〜3行目：痛み3つのどれかを具体的な状況として描写］

［最後の1行：「で、これ使ってる」程度に商品］

#PR
［画像：リンク作成ページ取得 or 自撮り］
```

### セルフリプライ（リンク側）
```
［フック一言：色展開／サイズ／レビュー評価のいずれか］
PR
［アフィリエイトリンク］
```

### リンクなし投稿
```
［1行目：問い または 失敗の告白］

［2〜4行目：具体的な状況］

［最後：質問で終える］
```
