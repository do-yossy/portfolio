# 10 出口設計とLTV — 楽天アフィリエイトは出口ではなく計測器

同じトラフィックでも、**どこへ送るかで1人あたりの価値が2桁変わる**。ここを設計せずに始めると、100%の努力で1%の回収しかできない。

---

## 1. 楽天アフィリエイトの天井

| 制約 | 内容 |
|---|---|
| 料率 | **2〜5%**（ジャンル固定・交渉不可） |
| 1件あたり上限 | **1,000円**（料率5%なら単価2万円で頭打ち） |
| 支払形態 | 原則**楽天キャッシュ** |
| 現金化 | 条件・手数料あり。**約2.5ヶ月のラグ** |
| 関係 | **1回売って終わり**（LTV = 140円） |

**天井は構造的で、努力では超えられない。** 超える方法は「もっと頑張る」ではなく「**出口を変える**」だけ。

---

## 2. 出口の階段

同じ1クリックの価値。

| 出口 | 1成果あたり | 難易度 | 前提 |
|---|---:|---|---|
| **楽天アフィリエイト** | **140〜520円** | 低 | 審査なし・即日 |
| Amazonアソシエイト | 数% | 低 | 審査あり。SNS登録が必要 |
| ASP（A8.net／もしも／afb 等）の物販 | 500〜3,000円 | 中 | 審査あり。**案件ごとにSNS掲載の可否が違う** |
| ASPの高単価案件（美容・健康・金融・転職） | 3,000〜30,000円 | 高 | 実績・媒体審査。**薬機法/金商法の表現規制が重い** |
| **自社サービスへの送客** | **数千〜数万円** | — | **すでに持っている** |
| 自社商品（教材・テンプレ） | 粗利90%超 | 中 | 制作コスト |

### ASPを使うときの注意
- **「SNS可」の案件だけ使う**。多くのASP案件はブログ前提で、SNS掲載NGのものがある
- Threadsが掲載媒体として登録できるかはASPごとに違う。登録時に確認する
- 高単価案件ほど**否認率が高い**（楽天とは逆）。承認率も確認する
- 短縮URLはASP規約違反になることが多い（`03` §2）

## 3. 本命：自社サービスへの送客

当社はすでに**送客先を持っている**。ここがアフィリエイトとの決定的な差。

| 送客先 | 何を送るか | 参照 |
|---|---|---|
| **求人（求職者集客）** | Threadsで集めた層 → 自社求人へ応募 | `../recruitment-platform/` `../kyujinbox-platform/` |
| **Web制作のリード** | 制作実績・ビフォーアフター → 問い合わせ | `../営業システム/07-集客設計.md` |
| Life Tailor | 別テナントの求人 | `../life-tailor-platform/` |

**1応募の価値は、成果1件195円のアフィリとは桁が違う。**

> ⚠️ **試算に使う単価は、当社の実数値に差し替えること。** 応募1件あたりの価値・成約率は `../営業システム/設定.md` と各プラットフォームの実績から取る。以下の数値は構造を示すための仮値。

## 4. 決定的な設計判断：ジャンルは「出口から逆算」して選ぶ

ここが最も間違えやすい。

```
✗ 悪い順序： 稼ぎやすいジャンルを選ぶ → フォロワーが集まる → 出口がない
○ 良い順序： 出口を決める → その出口に合う層が集まるジャンルを選ぶ
```

| ジャンル | 楽天アフィリ効率 | 自社への出口 | 評価 |
|---|---|---|---|
| ペット用品（5%） | ◎ | **なし（行き止まり）** | 検証用としては最良 |
| 美容・コスメ（5%） | ◎ | なし | 同上 |
| インテリア（3%） | ○ | なし | 同上 |
| **転職・働き方** | **✗ 楽天に商材がない** | **◎ 求人に直結** | 収益化は別ASP or 自社 |
| 副業・お金 | △ | ○ | 規制が重い |

**ペット用品で1万人集めても、求人には1人も送れない。** ジャンルは「集まる人の属性」を決める最上流の意思決定。

### 結論：二段構え

```
【第1段：検証】 物販ジャンル（ペット等）で30日
     目的：Threadsでリーチが取れるか／型が作れるか を実費ゼロで測る
     成果物：勝ちパターンと運用スキル（報酬ではない）
                    ↓ 運用ノウハウだけを移す
【第2段：本番】 転職・働き方ジャンルで新規アカウント
     目的：求職者を自社求人へ送客
     成果物：応募（1件の価値が2桁大きい）
```

**第1段でアフィリ報酬を追いかけないこと。** 追いかけると第2段に移れなくなる（ペットのフォロワーは求人に転換しない）。

## 5. LTV設計

### アフィリエイトのLTV

```
LTV = 1回の成果報酬 = 約195円
```

送客した相手が誰かは**分からない**。二度目はない。**リストが残らない。**

### リストを持つ場合のLTV

```
LTV = 客単価 × 購入回数 × 継続期間
```

動画のルパン氏がやっているのはこれ。**フォロワーではなくLINEリストを取る**（`02-カラクリ.md` §B-4）。リストは何度でも送れるので、1人あたりの価値がアフィリの数十〜数百倍になる。

### リストの価値の計算式

```
リスト1件の価値 = 送客できる案件の粗利 × 反応率 × 配信回数
```

### 構造比較（仮値・実数値に差し替えること）

フォロワー1,000人を得たとして：

| 出口 | 計算 | 年間価値 |
|---|---|---:|
| **楽天アフィリのみ** | 月2,900円 × 12 | **約35,000円** |
| **LINE/自社リスト化** | 1,000人 × 登録率5% = 50人<br>50人 × 応募転換5% = 2.5件<br>2.5件 × 応募1件の価値 | **応募単価次第で1桁上** |

**同じ1,000フォロワーでも、出口の設計だけで結果が変わる。** フォロワーを増やす努力より、出口を1段上げる努力のほうが効率が良い。

## 6. Threadsからリストへ送る導線の制約

**⚠️ 外部リンクはリーチを落とす**（`08` #5）。LINE誘導も外部リンクなので同じ制約を受ける。

| 導線 | 可否 | 備考 |
|---|---|---|
| 投稿本文にLINEリンク | ✗ | リーチが落ちる。かつ楽天アフィリリンクとの混在は避ける |
| **プロフィールにリンクを1本** | ○ | **基本形**。投稿→プロフィール→リンク |
| セルフリプライにLINEリンク | △ | アフィリリンクと使い分ける（同じ投稿に両方置かない） |
| ⚠️ LINE等のDMでアフィリリンクを送る | **✗ 楽天規約違反** | 「特定の者にしか閲覧できないメッセージツールでの共有」は禁止（`03` §1-1） |

> **重要**：楽天アフィリエイトリンクを**LINEで配信することは規約違反**。リスト化した後の収益化は、**自社サービスか、DM配信を許可しているASP/自社商品**で行う。ここを取り違えるとアカウントが飛ぶ。

## 8. まとめ：この仕組みの正体

```
需要発見 → コンテンツ → 販売 → 計測 → 再現
   (07)     (08)      (01)   (06/09)  (09)
                        ↑
                   ここだけが差し替え可能
```

**楽天アフィリエイトは「販売」の枠に刺さっている一つの部品でしかない。** 部品を自社求人に差し替えれば、同じループが1桁上の単価で回る。

**「Threadsでアフィリエイトする」を目的にしない**というのは、この図で言えば——**販売の部品に全体を合わせるな**、ということ。
