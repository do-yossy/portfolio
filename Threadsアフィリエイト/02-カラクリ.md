# 02 カラクリ — なぜこの動画は手順を全部無料で見せるのか

手法のカラクリ（なぜ稼げる構造なのか）と、**動画自体のカラクリ**（なぜ29分も無料で全部教えるのか）を分けて分解する。後者のほうが金額が大きい。

---

## Ａ. 手法のカラクリ（これは本物）

### A-1. 信用を「商品」から借りている
フォロワーゼロのアカウントが「これおすすめです」と言っても誰も買わない。この手法の核心は、**発信者の信用を使わず、既にレビューが積み上がった商品の信用を借りる**点にある。

だから手順の第一歩が「自分が売りたい物を選ぶ」ではなく「**既に売れている物を探す**」になっている。動画の博多ラーメンの喩え（博多で塩ラーメンを出しても売れない）はこの説明として正しい。

### A-2. 「PR付き＋いいね100以上」という判定基準がよくできている
Threadsの人気投稿から `いいね100以上` × `青リンクあり` × `PR表記あり` の3条件で絞ると、**「反応が取れる訴求」と「収益化されている商品」の交差点**だけが残る。市場調査ツールを一切使わず、無料で需要検証済みのリストが作れる。ここは素直に優秀。

### A-3. ついで買いが乗る
楽天アフィリエイトは、**クリック後24時間以内にカートに入った商品なら、紹介した物でなくても成果対象**（購入完了は89日以内でよい）。楽天は日用品のまとめ買いが多いため、300円のブランケットを紹介したつもりが、同じ買い物カゴの洗剤やペットフードの分も報酬になる。

これが「楽天は承認率が高い」という体感の正体。**承認が甘いのではなく、成果の裾野が広い**。

### A-4. だから初報酬までは早い
在庫ゼロ・初期費用ゼロ・審査なしで即日開始でき、成果の裾野が広い。**「0→1」だけは他のアフィリエイトより明らかに早い**。ここは動画の主張どおり。

## Ｂ. 動画のカラクリ（金額の出どころ）

### B-1. 数字を検算する

標準ケースの1件あたり報酬を出す。インテリア（料率3%）・平均単価3,500円なら **105円**、ついで買いを1.3倍見込んで **約140円**。

**月560万円を楽天アフィリエイト報酬で作るには：**

| 逆算 | 必要量 |
|---|---:|
| 必要な成果件数 | 5,600,000 ÷ 140 = **40,000件／月** |
| 購入率2%として必要クリック数 | **2,000,000クリック／月** |
| リンククリック率1%として必要インプレッション | **200,000,000／月（2億）** |

Threads全体の月間アクティブユーザーが**5億**（2026年7月時点）。**1アカウントで月2億インプレッションは構造的に不可能**。1件あたりの上限報酬1,000円をすべての成果に適用する極端な仮定を置いても、5,600件／月の成果が要る。

### B-2. 「13日で307万」の正体

同じ計算を受講生実績に当てると：

| 主張 | 報酬として計算 | 売上金額として計算 |
|---|---|---|
| 13日で307万円 | 約21,900件 = **1日1,687件** → 非現実的 | 売上307万 → 報酬 **約9万〜15万円** → 十分ありうる |
| 4日で103万円 | 約7,300件 = **1日1,840件** → 非現実的 | 売上103万 → 報酬 **約3万〜5万円** → ありうる |
| 4ヶ月目で132万円 | 約9,400件 | 売上132万 → 報酬 **約4万〜6万円** → ありうる |

**楽天アフィリエイトのレポート画面は「売上金額」と「成果報酬」が並んで表示される。** 売上金額のほうを提示すれば、実際の30〜50倍の数字を「嘘をつかずに」見せられる。3件とも売上金額として読むと一貫して現実的な範囲に収まる。**これが最も整合する説明。**

### B-3. 本人の「月560万」も報酬とは言っていない

冒頭の表現を正確に読む：

> 「毎月ね、1000万以上**売上**をね、得てる状態」

**売上であって報酬とは一度も言っていない。** そしてこの売上の中身は、動画の最後で明かされている。

### B-4. 本当のビジネスモデル

```
  YouTube動画（無料・29分・手順を9割開示）
        │
        │ 「豪華30大特典」＝ジャンル一覧表／投稿文生成GPT／月別案件100
        ▼
  公式LINE（リスト獲得）      ← 動画の唯一のゴール
        │
        │ ステップ配信・成果対談・限定セミナー
        ▼
  高額講座（受講生100名以上）  ← 月1,000万売上の正体
```

**教えている手法で稼いでいるのではなく、その手法を教える講座で稼いでいる。** だから手順を全部見せられる。**見せれば見せるほど「この人は本物だ」となり、講座が売れる。** 手順の開示は原価ゼロのマーケティング費用でしかない。

### B-5. 開示の粒度が計算されている

全部見せているようで、**自力でやると必ず詰まる場所に導線が置いてある**。

| 詰まる場所 | 動画での扱い | 誘導先 |
|---|---|---|
| ジャンルが決められない | 「今回は決まっている前提で」 | **別動画** |
| 楽天アフィリの登録方法 | 「省略させていただきます」 | **別動画** |
| 投稿文が書けない | 「売れる投稿文を一瞬で生成するGPT」 | **公式LINE特典** |
| どの商品が売れるか | 「月別に売りやすい案件100」 | **公式LINE特典** |
| 継続できない | 「質問は24時間以内に全部返します」 | **コメント欄→関係構築** |

**手順は完全に開示し、実行に必要な材料だけを外に置く。** これが「全部見せているのに囲い込める」設計。

## Ｃ. 話法の設計図（29分の構成）

| 時間 | パート | 使っている原理 |
|---|---|---|
| 0:00–0:15 | 「月560万」＋「特別なことしてると思ってません?」 | 数字の先出し＋**否定形フック**（読み手の予想を先に言語化して否定） |
| 0:15–1:00 | 受講生の報酬画面を提示 | **権威の借用**。自分の実績ではなく「未経験の他人」の実績のほうが刺さる |
| 1:00–2:15 | 「新興SNSだから先行者利益」「13日で307万」 | **希少性＋緊急性**。事実としては誤り（Threadsは2023年7月開始） |
| 2:25–3:15 | 借金200万・バイト生活からの逆転 | **自己開示による同一化**。「特別な才能はなかった」で距離を詰める |
| 3:15–3:55 | 「真似するだけでいい」→ LINE告知（1回目） | **早期CTA**。離脱者からもリストを取る |
| 3:57–19:23 | 手順の実演（画面共有） | **返報性**。無料でここまで貰ったという負債感 |
| 19:23–23:10 | Threads×楽天を選ぶ3つの理由 | **理由づけ**。納得すると自分の判断として定着する |
| 23:10–26:50 | 3つのアクションステップ（紙に書き出させる） | **一貫性・コミットメント**。手を動かした人は続きを求める |
| 26:50–28:10 | 「何もしないまま1年後を迎えるより」 | **損失回避**。利得より損失のほうが2倍以上効く |
| 28:10–29:10 | 「30大特典」（実際は35大とも言っている）→ LINE | **本命CTA** |
| 29:10– | 次回予告・チャンネル登録・「24時間以内に全部返信」 | リテンション＋**コメント数でアルゴリズム加点** |

### 注目すべき2つの逆張り
1. **「絶対成功するとは言い切れません」と明言している**（27:50頃）。断定を避けることで、かえって信用が上がる。誇大広告のリスク回避も兼ねている。
2. **手順の中で「初心者がやりがちなミス」を1つだけ具体的に教える**（リンクタイプを「画像とテキスト」にする）。細部の実務を1点見せると、全体の専門性が保証されたように感じる。

## Ｄ. 動画の指示のうち、そのままやると危ないもの

| 動画の指示 | 実際 | 影響 |
|---|---|---|
| 「楽天の商品ページの画像を長押し保存。**規約でOK**」 | **✗ 明確な規約違反**。楽天サイト内画像の無断DL・スクショは禁止 | **アカウント停止・報酬没収** |
| 画像を5枚添付 | リンク作成ページから取れる画像の範囲のみ | 同上 |
| 毎日3投稿すべてリンク付き | Threadsは外部リンク投稿の評価を下げる | **リーチが伸びない** |
| 「承認率ほぼ100%」 | キャンセル・返品で否認あり。**1商品1個1,000円上限** | 想定より報酬が伸びない |
| 「始まって数ヶ月の新興SNS」 | 2023年7月開始・**MAU 5億** | 先行者利益の前提が崩れている |
| 報酬の受け取りに触れない | 原則**楽天キャッシュ**。現金化に条件・手数料・**約2.5ヶ月**のラグ | 資金繰りの誤算 |

## Ｅ. この型のうち、自社に転用できる部品

手法そのものより、**この動画の設計のほうが自社にとって価値が高い**。当社の受託・採用事業にそのまま移植できる部品：

| 部品 | 中身 | 自社での使い方 |
|---|---|---|
| **手順の完全開示** | 原価ゼロ。開示するほど専門性の証明になる | 採用サイト構築・求人運用の手順を全公開する記事／動画 |
| **詰まる場所に材料を置く** | 手順は見せ、実行に要る材料（テンプレ・データ・ツール）だけ囲う | 見積ロジックは公開、テンプレ一式はリスト登録で配布 |
| **他人の実績を使う** | 自分の実績より「未経験の他人」の変化のほうが刺さる | `../営業システム/成果物サンプル/` を導入事例の形に組み替える |
| **具体的な実務を1点だけ深く** | 細部の正確さが全体の信用を保証する | 「ここで9割がミスする」形式の実務Tips |
| **断定しない** | 「絶対成功するとは言えない」が信用を上げる | 提案書でも同じ（`../営業システム/02-提案文テンプレート.md`） |

**逆に真似しないもの**：金額の単位を曖昧にする（売上を報酬に見せる）、事実でない希少性を煽る。短期の成約率は上がるが、当社は継続取引で回収する事業なので割に合わない。
