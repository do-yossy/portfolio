# Threads × 楽天アフィリエイト — 需要発見から再現までの実行プレイブック

> 作成：2026-09-03 ／ 出典：YouTube「ルパン」氏の解説動画（約29分）の文字起こしを教材として分解
> 目的：**「あれ始めるで」の一言で、カラクリを分解済みの状態から着手できること。**

---

## 0. 前提（ここを外さない）

**「Threadsでアフィリエイトする」ことを目的にしない。**

本質はこれ：

> **需要が確認されているテーマを発見 → その需要に刺さる投稿を作る → 興味を持った人を適切な商品へ送る → 数字を計測 → 売れるパターンだけ残す → 量産する**

```
需要発見 → コンテンツ → 販売 → 計測 → 再現
  (07)      (08)      (01)   (06/09)  (09)
                       ↑
              ここだけが差し替え可能な部品
```

**楽天アフィリエイトは「販売」の枠に刺さっている一つの部品**であって、この仕組みの本体ではない。部品を自社求人や自社商品に差し替えれば、同じループが1桁上の単価で回る（→ `10-出口設計とLTV.md`）。

だから着手時に**いきなり投稿文を100個作らない**。下の10ステップを順に進める。

## 2. 結論（先に読む4行）

1. **手法自体は本物。ただし動画の指示どおりにやると規約違反になる。** 「楽天の商品ページの画像を長押し保存して使う。規約でOK」は**明確に楽天ガイドライン違反**。正しくは「リンク作成ページの画像のみ・加工禁止」（→ `03`）。
2. **「月560万」は楽天アフィリエイトの報酬ではない。** 1件140円前後で560万を作るには**月4万件・月2億インプレッション**が必要。Threads全体のMAUが5億の世界で1アカウントでは成立しない。本人も「**売上**を得てる」としか言っていない（→ `02`）。
3. **現実的な収益は月0〜26,000円、実効時給 約200〜2,200円。** 営業システムの足切り **¥4,000/h** に6ヶ月続けても届かない。**収益事業としては見送り**（→ `04`）。
4. **やる価値は報酬ではなく「Threadsでリーチが取れるか」の実測。** 初期費用ゼロ・在庫ゼロ・撤退コストゼロ。取れたら**同じ運用を求職者集客に転用する**（→ `10`）。**アフィリエイトは計測器であって事業ではない。**

## 3. カラクリ（30秒で）

```
表の話：Threadsに投稿 → 楽天アフィリで報酬 → 月560万
裏の構造：
   無料動画（正しい手順を9割開示・でも自力では詰まる粒度）
        ↓ 「30大特典」
   公式LINE（リスト獲得）
        ↓ ステップ配信
   高額講座（← ここが月1,000万売上の正体）
```

**教えている手法で稼いでいるのではなく、その手法を教える講座で稼いでいる。** だから手順は全部見せられる。開示の粒度も計算されていて、**詰まる場所ごと（ジャンル選定・楽天登録・投稿文作成・商品選び）に別動画とLINE特典が置いてある**（→ `02` §B-5）。

### セールストークと再現可能性の切り分け

| 動画の主張 | 再現可能性 |
|---|---|
| 手順（リサーチ→投稿→リンク） | **◎ 再現できる**。ただし画像取得は規約準拠に直す必要あり |
| 「いいね100+／PR付き」で売れ筋を探す判定基準 | **◎ 優秀**。無料で需要検証済みリストが作れる |
| 「80%悩み／20%商品」 | **◎ 正しい**。理由の説明が浅いだけ（→ `08` §4） |
| 「毎日3投稿×30日」 | **○ 量は正しい／配分が誤り**。全部リンク付きはリーチが死ぬ |
| 「月560万」「13日で307万」 | **✗ 報酬としては成立しない**。売上金額の可能性 |
| 「新興SNSで先行者利益」 | **✗ 事実誤認**。Threadsは2023年7月開始・MAU 5億 |
| 「誰でもできる」 | **△ 着手は誰でもできる／継続とデータ設計ができる人は少ない** |

## 4. 数字の裏取り（すべて一次情報で確認済み）

| 項目 | 実際 | 動画の説明 |
|---|---|---|
| 料率 | ジャンル別 **2〜5%**（美容・健康・ペット5%／ファッション・食品4%／インテリア・日用品3%／家電・PC2%） | 言及なし |
| 1件あたり上限 | **1商品1個につき1,000円**（楽天キャッシュ） | 「承認率ほぼ100%」とのみ |
| 成果条件 | クリック後**24時間以内にカートへ**、**89日以内に購入完了**。紹介商品以外のついで買いも対象 | 「ほぼ100%承認」 |
| 支払 | 発生月 → **翌月末確定** → **翌々月10日**。原則**楽天キャッシュ** | 言及なし |
| 現金化 | 3ヶ月連続で確定3,001円以上 → 銀行振込プラン申請可。ほかは楽天銀行必須＋手数料 | 言及なし |
| **買い回りイベント** | **お買い物マラソン 毎月2〜3回／スーパーSALE 年4回（3・6・9・12月）**。転換率とついで買いが跳ねる | **完全に無視** ← 最大のレバー |
| Threads | 2023年7月開始、**2026年7月時点でMAU 5億** | 「始まって数ヶ月の新興SNS」 |
| 外部リンク | リンク付き投稿の連投は**アルゴリズム評価が下がる** | 「新しいから拡散される」 |
| リンク掲載 | Threadsは**楽天の認定SNS**。ただし**他人の投稿のコメント欄は禁止** | セルフリプライのみ紹介 |
