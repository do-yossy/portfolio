# Threads × 楽天アフィリエイト — 手法の完全分解と実行プレイブック

> 作成：2026-09-03 ／ 出典：YouTube「ルパン」氏の解説動画（約29分）の文字起こし
> 目的：**「あれ始めるで」の一言で、その日のうちに規約準拠で着手できる状態**を作る。あわせて、この手法と動画そのもののカラクリを数値で分解し、自社が取るべき関わり方を確定させる。

## 結論（先に読む4行）

1. **手法自体は本物。ただし動画の指示どおりにやると規約違反になる。** 「楽天の商品ページの画像を長押し保存して使う。規約でOK」は**明確に楽天アフィリエイトのガイドライン違反**。正しくは「リンク作成ページに表示される画像のみDL可・加工禁止」。ここを直せばそのまま使える（→ `03-規約・法令チェックリスト.md`）。
2. **「月560万」は楽天アフィリエイトの報酬ではない。** 標準ケースの単価（1件140円前後）で560万を作るには**月4万件・月2億インプレッション**が要る。Threads全体のMAUが5億の世界で1アカウントでは成立しない。動画本人も冒頭で「毎月1000万以上**売上**を得てる」と言っており、報酬とは言っていない（→ `02-カラクリ.md`）。
3. **現実的な収益は月0円〜1万円、実効時給は約370円。** 営業システムの足切りライン **¥4,000/h**（`../営業システム/01-案件スコアリング基準.md`）を大きく下回る。**収益事業としては見送り**（→ `04-収支シミュレーションと判定.md`）。
4. **それでもやる価値があるのは「収益」ではなく「Threads運用の実測データ」。** 初期費用ゼロ・在庫ゼロ・撤退コストゼロで、リーチ／CTR／CVRの生の数字が手に入る。この数字は採用媒体・自社サービスの集客にそのまま転用できる。**位置づけは実験、KPIは報酬額ではなくインプレッション単価。**

## カラクリ（30秒で）

```
表の話：Threadsに投稿 → 楽天アフィリで報酬 → 月560万
裏の構造：
   無料動画（正しい手順を9割開示・でも自力では詰まる粒度）
        ↓ 「30大特典」
   公式LINE（リスト獲得）
        ↓ ステップ配信
   高額講座（← ここが月1,000万の売上の正体）
```

動画で教えている手法で稼いでいるのではなく、**その手法を教える講座**で稼いでいる。だから手順は本当に全部見せられる（見せるほど講座が売れる）。開示の粒度が絶妙で、**ジャンル選定は別動画・楽天登録は別動画・投稿文生成GPTはLINE特典**と、詰まる場所ごとに導線が置いてある。

|---|---|---|
