# 02 1ヶ月収支シミュレーション（売上・経費・時間）

対象期間：**2026-08-25 〜 2026-09-24**（30周年弾 9/16 発売を含む1ヶ月）
販売チャネル：メルカリ主体（手数料10%）＋買取店（手数料0%・買値は相場の70〜85%）

## 5. 時間の内訳（シナリオB＝月55時間の例）

| 作業 | 時間 | 中身 |
|---|---:|---|
| 相場リサーチ・仕入れ判断 | 20h | 買取表と販売相場の突き合わせ、値動きの追跡 |
| 店舗巡回・受取・発売日対応 | 12h | 新弾発売日・再販・店頭ワゴン |
| 検品・撮影・出品 | 14h | 59件 × 約14分 |
| 梱包・発送 | 8h | 59件 × 約8分 |
| 問い合わせ・値下げ交渉・トラブル対応 | 6h | 値下げ依頼、未着・すり替え申告対応 |
| 記帳・在庫管理・経理 | 3h | 確定申告用の記録 |
| **合計** | **63h**（実働ベース。並行作業で圧縮して約55h） | |

**時間の性質に注意**：この55時間の大半は「細切れ・即応性が要る時間」（発売日の朝、値下げ交渉、発送期限）で、まとまった集中時間としては使えない。Web制作の制作時間と**同じ時間帯を奪い合う**。

## 6. 前提と感度（どこが崩れると赤字か）

| 前提 | 設定値 | 崩れたときの影響 |
|---|---|---|
| 仕入れ掛率 | 売価の62〜65% | 70%になると営業利益はほぼゼロ |
| 月内消化率 | 85% | 70%に落ちると資金が回らず翌月の仕入れが縮む |
| 30周年BOXの相場 | 定価の約1.9倍（¥14,000） | 1.3倍（¥9,400）なら粗利は半減 |
| 定価取得枚数 | A:3／B:6／C:12 | 抽選外れ・入荷無しで直撃。**最大の変動要因** |
| 相場下落 | 月-5%まで想定 | 高額シングル在庫を抱えていると評価損 |

**損切りルール**：仕入れから30日で売れない在庫は、買取店に流して現金化する（案件I）。相場下落局面で在庫を抱え続けるのが、この事業で最も多い失敗パターン。
