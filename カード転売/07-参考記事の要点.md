### 仕入れ先の追加（記事A・B）

`06` の仕入れ先表に、記事から次を反映する。

| 追加した仕入れ先 | 掛率の目安 | 備考 |
|---|---|---|
| コンビニのゲリラ入荷 | 定価 | 巡回コストが高い。ついで買いの範囲に留める |
| リサイクルショップ（ブックオフ等） | 相場の40〜70% | 稀に相場以下の出物。空振り前提 |
| **業者オークション・古物市場（エコオク等）** | 市場価格未満 | **古物商許可が前提**。まとまった数を一度に仕入れられる＝`06` の「まとめ買い選別」の上位互換 |

古物商許可（`04`）を取る理由がもう1つ増えた。業者オークションは許可がないと参加できない。

### リスクの追加：偽物・再シュリンク品

記事Aの指摘で `04` に追加すべき最重要リスク。

- 精巧な**偽造カード**と、**レアカードを抜いて再シュリンクしたBOX**が流通している
- 特に**フリマアプリ経由の仕入れが危険**
- 安全側は正規ルート（ポケモンセンター、家電量販店、信頼できるカードショップ）

→ `06` の「フリマのまとめ売りを相場の50〜60%で買う」は**再シュリンク品を掴むリスクとセット**。BOXは正規ルート、シングルはフリマ・店舗、と分けるのが実務的な落としどころ。

### 失敗パターン（そのまま自戒として採用）

1. 高騰中のパックに焦って高値で仕入れる
2. フリマから偽物・サーチ済みパックを買う
3. 開封ギャンブルに依存する
4. 国内販路だけに絞る（利益に天井）

## 2. 記事C・Dから採用したもの＝「やらない線引き」

記事Cが描く転売業者の手口は、**当社が絶対に採らない**もの。`04` の除外リストに追記する。

| 記事Cが描く手口 | 判定 |
|---|---|
| 小売店に「定価の120%で買い取る」と持ちかけて余剰在庫を吸い上げる | **やらない**。供給を歪める行為で、ブランド毀損が自社サイトの信用に跳ね返る |
| 二次流通業者を装って問屋の正規流通に入り込む | **やらない**。取引先を欺く行為 |
| 行列バイトを動員して買い占める | **やらない**。購入制限の潜脱 |
| 量販店従業員の弱みを握って在庫を出させる | **論外**（強要・脅迫にあたりうる） |
| 断ると「プレ値転売している」と噂を流して圧力をかける | **論外**。記事Cはこの報復こそが最大の危険だと警告している |

記事Dは、狙われやすい商材として「高額カード収録パック」「マリィ・ルチア・リーリエ等の女性キャラSR」「旧Bマーク以前の高レアリティ」を挙げつつ、**転売問題の解決はプレイヤー・ショップ・公式の3方向の対策**だと結論づけている。

**当社の姿勢**：`01` で除外した H（オリパ・開封代行）と同じ扱いで、**供給網に介入する手法は点数にかかわらず全て除外**。カード転売をやるとしても、`06` の「中古シングルを安く仕入れて高い買取店に売る」＝**すでに市場に出回っているものを右から左に流す**範囲に限定する。これは古物商の本来の商売であり、新品の供給を絞る行為ではない。
