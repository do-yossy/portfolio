# 05 どんな人が向いているか

`02` の数字（実効時給 375〜1,124円／利益率12〜17%／月55時間）から逆算すると、この事業で勝てる人の条件ははっきりしている。**「カードが好きかどうか」はほぼ関係ない。**

## 構造から導かれる適性

この事業の利益は次の3つでしか作れない。適性はこの3つに対応する。

| 利益の源泉 | 求められる資質 |
|---|---|
| ① 定価・相場割れで仕入れられる | 発売日の朝に動ける**時間の自由**、店舗との関係、地域に店舗が複数ある |
| ② 相場より高く／早く売れる | 相場の定点観測を**毎日続けられる几帳面さ**、値付けの判断 |
| ③ 経費と時間を削れる | 1件12分の作業を淡々と繰り返せる**単純作業耐性**、記帳の習慣 |

## 向いている人（5条件）

| # | 条件 | なぜ効くか |
|---|---|---|
| 1 | **他にやることの時給が1,000円未満** | 実効時給375〜1,124円。時給2,000円の仕事がある人は、その時間を売ったほうが儲かる |
| 2 | **平日日中に動ける**（学生・主婦/主夫・シフト制・在宅） | 発売日の朝と再販は平日日中に集中する。ここが取れないと粗利の高い枠（案件A・B）が丸ごと消える |
| 3 | **50万円以上の余剰資金がある**（生活費と分離） | 利益は資金にほぼ比例。10万円だと初月は古物商代で赤字。かつ在庫で資金が寝る期間に耐えられる必要がある |
| 4 | **数字を毎日つけられる** | 仕入れ台帳＝古物台帳＝確定申告資料。ここが崩れると「儲かった気がするだけ」になる。実際に赤字に気づけない人が最も多い |
| 5 | **カードショップに通える立地**（都市部・複数店舗が圏内） | 仕入れ経路の数がそのまま売上上限。地方単店舗圏だとオンライン仕入れ頼みになり掛率が悪化する |

**5つ中4つ以上 → 向いている。3つ以下 → 月数千円の小遣い稼ぎで終わる可能性が高い。**

## 向いていない人

| タイプ | 理由 |
|---|---|
| 本業の時給が高い人（エンジニア・制作者・士業） | **機会損失が利益を上回る**。週10時間を制作に回せば数万〜十数万円になる |
| まとまった集中時間しか取れない人 | この仕事の55時間は細切れ・即応性の時間。集中作業とは相性が悪い |
| 在庫の含み損に耐えられない人 | 相場下落局面で「戻るまで待つ」をやると資金が死ぬ。損切りが実行できないと構造的に負ける |
| 記帳・確定申告を避けたい人 | 年20万円超の利益で申告義務。無許可仕入れは古物営業法違反（3年以下の懲役 or 100万円以下の罰金） |
| 「一発当てたい」人 | 1件の粗利は510〜4,834円。積み上げの商売であって、当てものではない |
| カードが好きすぎる人 | 売るべき在庫を手元に残してしまう。趣味と在庫は分離できないと回らない |

## あなた（当社）の場合の判定

| 条件 | 判定 | 補足 |
|---|---|---|
| 1 他の時給 | **✕** | 営業システムの足切りが¥4,000/h。カード転売は最大でも1,124円/h |
| 2 平日日中 | △ | 制作・営業と発売日が競合する |
| 3 余剰資金 | ○ | 資金を置いておくだけなら回す価値はある |
| 4 数字をつける | **◎** | 台帳・KPI管理・自動化はむしろ本業の強み。ここは他の参入者に対する明確な優位 |
| 5 立地 | △ | 店舗数次第 |

**結論：主力事業としては向いていない（条件1が決定的）。ただし条件4が飛び抜けて強いので、次の形なら合う。**

- **年数回のイベント（周年弾・大型新弾）だけ集中して取る単発運用**。9/16の30周年はまさにこれ。月55時間ではなく、発売週に15時間だけ投下する形。
- **作業を人に渡す**：仕入れ判断・値付け・台帳（＝仕組み側）を自分が持ち、店舗巡回・出品・梱包（＝作業側）を条件1〜2に当てはまる人に任せる。この分業ができるなら実効時給の問題は消える。
- **在庫の一部を長期ホールドに回す**（25th：¥4,752→約¥66,000）。時間をほぼ使わないので実効時給の議論の外に置ける。

**逆に、いま採用や外注で関わっている人の中に「平日日中に動けて、余剰資金より時間がある人」がいるなら、その人に向いている事業。** 自分でやるより、設計と資金を出して回してもらうほうが数字は合う。
