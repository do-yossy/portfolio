# 06 買取店ルート実践ガイド（安く買って、高く買い取る店に売る）

`02` はメルカリ販売を前提にした試算だった。ここでは **出口を買取店に固定する**運用を扱う。結論から言うと、**この事業で実効時給を上げる唯一の現実的な手** がこれ。

## 1. なぜ買取店のほうが有利になりうるか

メルカリは「高く売れる」が、手数料10%＋送料＋梱包＋1件ごとの作業が乗る。買取店は「買値は安い」が、**手数料0%・送料無料・振込手数料無料・50枚まとめて1回の発送**。

### 手取りの比較（相場3,000円のカード1枚）

| 出口 | 計算 | 手取り | 相場比 |
|---|---|---:|---:|
| メルカリ | 3,000 −手数料300 −送料210 −梱包30 | **2,460** | 82.0% |
| 買取店（通常水準） | 相場の75% | 2,250 | 75.0% |
| 買取店（高値店） | 相場の85% | **2,550** | 85.0% |
| 買取店（+10%増額） | 75% ×1.10 | 2,475 | 82.5% |
| **買取店（+20%キャンペーン）** | 75% ×1.20 | **2,700** | **90.0%** |

相場12,000円のBOXでも比率は同じで、メルカリ手取りは85.4%（10,250円）。**増額キャンペーン中の買取店は、メルカリの手取りを上回る**。

### 決定的な差は「時間」

| | メルカリ | 買取店（宅配買取） |
|---|---|---|
| 1件あたり作業 | 撮影・出品・値下げ交渉・梱包・発送で12〜20分 | 仕分けとリスト化のみ、**50枚で1回の発送** |
| 50枚さばく時間 | 約10〜15時間 | **約2時間** |
| 入金 | 売れるまで不定（数日〜数週間） | 到着後**最長3日**で振込 |
| トラブル | 未着・すり替え申告あり | ほぼ無い |

→ 粗利率は数%下がるが、**時間が1/5になるので実効時給は2〜3倍**になる。`02` のシナリオB（メルカリ主体・時給794円）に対し、買取店ルートは**時給1,600〜3,500円**のレンジに入る（下の感度表）。

## 2. 買取店の比較（2026年8月時点の増額条件）

| 店 | 増額・条件 | 特徴 |
|---|---|---|
| **遊々亭** | 会員登録で査定**+5%**、ポイント受取に変更でさらに**+10%** | ポケカ専門。12万種以上・買取価格表を公開 |
| **カードラッシュ** | 買取価格リストを公開・宅配/店頭対応 | 大手。BOX買取に強い（例：シャイニートレジャーex BOX ¥20,000／2026-08-02時点） |
| **駿河屋** | 大量買取・幅広い品目 | 旧裏・希少品も拾う。査定は遅め |
| **晴れる屋2** | 買取価格表を公開 | ポケカ専門店。価格更新が速い |
| **カーナベル** | 査定額に応じ最大**600円**ボーナス、ポイント受取**+10%**、1万円以上で送料無料 | |
| **ウリウリトレカ** | 自分の箱で送ると**+10%**。送料・査定料・振込手数料すべて無料、最長3日で振込 | 現金化が速い |
| **トイズキング** | 全買取方法で**+20%**キャンペーン（11月末まで） | 期間限定の最大増額 |
| **CBトレコロ（カードボックス）** | 査定金額アップキャンペーンを随時開催。**キズ判断基準を公開** | 減額基準が読めるので事故が少ない |

> 買取価格は店ごとに数千円の差が出る。**同じカードでも「今どの店が強化買取しているか」で手取りが変わる**ので、送る前に必ず3店以上の買取表を突き合わせる。

## 3. 差益の作り方（4パターン）

### ① キャンペーンに合わせて売る（最優先）
+20%は粗利率をそのまま20%押し上げる。**仕入れは常時、売却はキャンペーン時にまとめて**。これだけで年間の利益が2〜3割変わる。

### ② ポイント受取を仕入れに回す
ポイント受取で+10%になる店（遊々亭・カーナベル）は、**その店で仕入れるなら実質10%引きの仕入れ資金**になる。現金化率は落ちるので、「ポイントは仕入れ、現金は生活費」と用途を分ける。ポイントを貯め込むのは在庫を持つのと同じリスク。

### ③ 店舗間の買取価格差を取る
A店の**販売価格** < B店の**買取価格** が成立することが実際にある（在庫状況・強化買取・キャンペーンのタイミングで発生）。買取表は各店が公開しているので、**販売ページと他店の買取表を突き合わせる**のが作業の本体。

### ④ まとめ買いを選別する
フリマの「引退品まとめ売り」「大量ロット」を相場の5〜6割で買い、**高いものだけ買取店へ、残りはまとめて処分**。仕入れ掛率を下げる最も再現性のある方法だが、選別の目と時間が要る。

## 4. 安く買う側（仕入れ）の現実解

| 仕入れ先 | 掛率の目安 | 備考 |
|---|---:|---|
| フリマのまとめ売り・引退品 | 相場の50〜60% | 選別作業が必要。ハズレが混じる前提 |
| 店頭ワゴン・在庫処分 | 55〜70% | 足で稼ぐ。地域の店舗数が上限を決める |
| フリマの相場割れ単品 | 60〜75% | 通知を仕込んで即決。競合が多い |
| 新弾の定価購入 | 定価（相場の30〜60%） | 最強だが枠が限られる（`01` の案件A・B） |
| 買取店のポイント払い | 実質10%引き | ②と組み合わせる |

**損益分岐**：買取率 − 仕入れ率 が **3%（経費率）** を超えないと赤字。仕入れ65%・買取75%では10%しか残らないので、**仕入れ60%以下を死守する**。

## 5. 収支モデル（買取店ルート）

前提：月の取扱カードの**相場合計 50万円分**／固定費14,000円（交通費8,000・サプライ4,000・雑費2,000。宅配買取は送料無料のため送料0）／作業38時間。

| 仕入れ掛率 ＼ 買取率 | 75% | 80% | 85% |
|---|---:|---:|---:|
| **55%** | 86,000円（時給2,263） | 111,000円（時給2,921） | 136,000円（時給3,579） |
| **60%** | 61,000円（時給1,605） | 86,000円（時給2,263） | 111,000円（時給2,921） |
| **65%** | 36,000円（時給947） | 61,000円（時給1,605） | 86,000円（時給2,263） |

**標準ケース（仕入れ60%・買取78%＝キャンペーン込みの平均）**
売上 390,000円／仕入原価 300,000円／固定費 14,000円 → **営業利益 76,000円（時給 2,000円）**

`02` のメルカリ主体シナリオB（利益43,650円・時給794円）と比べ、**利益1.7倍・時給2.5倍**。出口を買取店に寄せる価値はここにある。

### 時間の内訳（38時間）
| 作業 | 時間 |
|---|---:|
| 買取表と販売価格の突き合わせ・仕入れ判断 | 25h |
| 検品・仕分け・状態チェック | 8h |
| 買取申込・梱包・発送（月3〜4回にまとめる） | 3h |
| 記帳・在庫管理 | 2h |

## 6. 減額を食らわないための実務

査定額を削られると、上の試算はそのまま崩れる。減額基準は公開されている店が多いので、事前に潰す。

| 事象 | 減額幅 | 対策 |
|---|---|---|
| 目視で気づかないレベルの白かけ | 満額の**1〜2割減** | 仕入れ時にライトを当てて四隅を確認。怪しいものは仕入れない |
| ひと目で分かる白かけ・キズ | **5割減** | 買わない。買ってしまったらフリマで状態明記して売る |
| 査定10,000円以上の高額カードが基準未達 | **買取額の1割**、または**買取不可** | 高額品は状態に自信があるものだけ。不安ならPSA鑑定か現状フリマ販売へ |
| 同一カードを大量に持ち込む | **多量減額** | 同じカードは複数店に分散、または時期をずらす |
| 相場下落局面 | 買取表が日単位で下がる | 買取表を見た日に送る。往復で1週間かかると価格が変わる |

**運用ルール**
1. 仕入れ直後に**スリーブ＋ローダー**（状態はここから悪化させない）
2. 送る前に**3店の買取表を比較**し、その日の最高値の店に送る
3. 買取表には**有効期限がある**ので、申込から発送まで24時間以内
4. **減額連絡が来たら返送**を選べる店を優先（返送無料かを事前確認）
5. 買取実績は毎回記録し、「店ごとの実際の掛率」を蓄積する（表示価格と実査定は違う）

## 7. メルカリと買取店の使い分け

| ケース | 出口 |
|---|---|
| 増額キャンペーン中 | **買取店**（メルカリ手取りを上回る） |
| 状態が完璧でない | **メルカリ**（状態を明記して売れば減額されない） |
| 相場が上昇中の話題カード | メルカリ（買取表の反映が遅れるため） |
| 相場が下落中 | **買取店**（即現金化。待つほど損） |
| 大量・低単価（1枚1,000円以下） | **買取店**（メルカリだと作業時間で赤字） |
| 高額単品（3万円以上） | メルカリ or 専門店の店頭査定（複数見積もり） |

**原則：単価が低いほど買取店、単価が高いほどフリマ。分岐点はおおむね3,000〜5,000円。**
