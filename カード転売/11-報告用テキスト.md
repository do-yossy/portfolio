# 11 報告用テキスト（コピペ用）

検討結果を報告するためのプレーンテキスト。**表組みを使わず、LINE・メール・チャットにそのまま貼れる形**。
運用者に渡す募集・説明文は `09-案内文（コピペ用）.md` のほう。用途が違うので使い分ける。

数字の根拠：`02`（収支）`03`（発売日と購入制限）`06`（買取店ルート）`08`（AI分担）`10`（資金別）

---

```
【ポケモンカード転売の検討結果】

■ 結論
・仕入れ資金30万円で、月の利益は約5.2万円（年63万円／税引後47万円）。
・利益は仕入れ資金の月10〜17%が目安。資金を増やせば比例して増える。
・作業時間は月30時間ほど。時給に直すと約1,700円。
・本業（Web制作）の時給4,000円には届かないため、自分の時間を使う事業としては非推奨。
　資金と設計だけ出して、時間のある人に運用してもらう形が最も数字が合う。

■ 毎月いくら資金が必要か
・初回に一括で必要。2ヶ月目以降の追加投入は不要。
　仕入れ資金は「仕入れ→売却→入金→再び仕入れ」で1ヶ月かけて1周する。
・初月にかかるのは、仕入れ資金＋初期費用25,000円
　（古物商許可19,000円／備品5,000円／書類の実費1,000円）
・注意点は2つ。
　1) 毎月、仕入れの15%ほどが売れ残って在庫になる（30万円規模で約3.2万円）
　　→ 30日で売れないものは買取店に流す。これを守れば資金は詰まらない。
　2) 仕入れから入金まで平均20日かかる（買取店なら7〜10日）
　　→ 資金は使い切らず7割で回す。30万円なら仕入れは21万円まで。

■ 資金ごとの売上・利益（1ヶ月・通常月）
・資金10万円　→ 売上10.3万円／利益1.5万円／19時間／時給813円
・資金20万円　→ 売上20.0万円／利益3.4万円／24時間／時給1,405円
・資金30万円　→ 売上30.0万円／利益5.2万円／30時間／時給1,743円
・資金50万円　→ 売上48.3万円／利益8.3万円／42時間／時給1,969円
・資金80万円　→ 売上75.4万円／利益12.5万円／60時間／時給2,089円
・資金100万円 → 売上93.3万円／利益15.3万円／72時間／時給2,127円

※資金を増やすほど月利は下がる（17%→15%）。
　いちばん儲かる未開封BOXが購入制限（1人1点）で月9個までしか買えず、
　増やした資金は粗利の薄いカード（1枚390円）に回るため。
※逆に時給は上がる（813円→2,127円）。巡回や記帳などの固定時間が薄まるため。
※資金10万円は初月の古物商代すら回収できないので、検証目的以外は非推奨。
※個人で回せる上限は資金80万円まで。100万円だと月72時間かかり1人では厳しい。

■ 収支の内訳（資金30万円の場合）
【売上】300,400円
・未開封BOX　　8個 × 11,000円 ＝ 88,000円（メルカリ）
・高額カード　　6枚 × 12,000円 ＝ 72,000円（メルカリ）
・中位カード　60枚 ×  2,340円 ＝140,400円（買取店にまとめ売り）
【仕入代金】213,000円
【経費】35,100円
・メルカリ手数料10% 16,000円（買取店に売る分は手数料0円）
・送料6,300円／梱包材1,400円／交通費2,400円／備品・通信・雑費9,000円
【利益】52,300円

※これは平常運転の期待値。
　仕入れがうまくハマった月は7.3万円、薄い月・相場が下がった月は2.8万円。

■ 作業時間の内訳（月30時間）
・新弾発売日の店舗巡回　　　　3日で10.5時間
・仕入れの判断　　　　　　　　1時間（毎朝5分、リストを見て決めるだけ）
・検品・仕分け　　　　　　　　7時間
・出品　3.5時間／梱包・発送　5時間
・問い合わせ対応　2時間／帳簿の確認　30分

■ 分担（市場調査はAIが担当）
【AIがやること】毎朝の相場チェック、値上がり／値下がりの抽出、
　　「どこで買ってどこに売るといくら儲かるか」のリスト作成、
　　その日いちばん高く買う店の特定、帳簿づけ、月次の収支計算
【人がやること】買う判断とクリック、検品、出品、発送、発売日の店舗巡回

■ 仕入れの上限（ここが売上の天井）
・家電量販店は1人1点、カードショップは1人1〜2BOX、コンビニは1人10パックまで。
・1日に回れるのは4〜5店。整理券に外れることもあり取得率は7割ほど。
　→ 発売週に3日回って、確保できるのは月7〜9BOXが限界。
・家族や知人を動員して買う形は購入制限の潜脱になるので採らない。
　確保数を増やす手段は「回る店を増やす」ことだけ。

■ リスクと注意点
・相場は上下する。投機資金が抜けると数万円のBOXが数千円になることもある。
・偽物と「レアだけ抜いて再包装したBOX」が流通している。
　BOXは正規ルート、高額カードは鑑定済みか信頼できる専門店から仕入れる。
・中古カードを仕入れて売るには古物商許可が必須。
　無許可営業は3年以下の懲役または100万円以下の罰金。申請から約40日かかる。
・年間利益が20万円を超えたら確定申告が必要。
・在庫は資産だが現金ではない。利益5.2万円のうち、実際に手元の現金が増えるのは
　月1万円台。残りは在庫として運転資金に寝る。

■ 直近の予定
・2026年9月16日にポケモンカード30周年の記念パックが発売される。
　定価7,216円のBOXが相場1.4〜4.6倍で推移しており、年に1〜2回の大きな機会。
　この月だけは利益11.2万円（作業49時間）を見込める。
・そこに間に合わせるには、古物商許可の申請を今すぐ出す必要がある（審査に約40日）。

■ 補足：店舗を回らない場合
在宅だけで完結させる形なら、月の利益7.6万円・作業12.5時間・時給6,080円。
利益も時間も店舗巡回ありを上回る。ただし発売日の定価BOXは取れなくなる。
毎月の新弾を確実に押さえたい場合や、店との関係を作りたい場合は巡回ありを選ぶ。
```

## 使い分け

| 用途 | 使うファイル |
|---|---|
| **社内・上長への報告** | 本ファイル |
| **運用してもらう人への説明・募集** | `09-案内文（コピペ用）.md` |
| 発売日の当日オペレーション | `03-30日実行プラン.md` |
| 数字の根拠を追う | `02` `06` `08` `10` |

数字を更新したら `02` `09` `10` と本ファイルを揃えて直す。
