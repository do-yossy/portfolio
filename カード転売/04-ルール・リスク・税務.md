# 04 ルール・リスク・税務

利益より先に、事業を止めうるものを潰す。`../CLAUDE.md` の「規約違反は実装しない」方針をこの事業にも適用する。

## 1. 古物商許可

| 項目 | 内容 |
|---|---|
| 必要な場合 | **中古カードを転売目的で買い取る**とき（フリマ仕入れ、店舗の中古品仕入れ、個人からの買取）。ネット完結でも必要 |
| 不要な場合 | 自分のコレクションを売る／正規販売店で買った**新品未開封パック**を売る |
| 費用 | **申請手数料 19,000円**（不許可でも返還されない） |
| 期間 | 申請から**約40日**で所轄警察署から交付 |
| 罰則 | 無許可営業は **3年以下の懲役または100万円以下の罰金** |

**実務上の結論**：新品BOXだけを扱うなら許可なしでも成立するが、シングル仕入れ（＝この事業の土台）には必須。**W1で申請する**。

## 2. プラットフォーム規約

| 規約 | 内容 | 対応 |
|---|---|---|
| 抽選販売（ポケモンセンターオンライン等） | 転売目的の購入と判断されると**注文キャンセル＋今後の利用制限** | **転売目的で応募しない**。仕入れは店頭先着・一般販売・再販分に限る |
| 購入個数制限 | 1人1点等 | 家族名義の動員や複数アカウントでの回避はしない |
| メルカリ | ポケモン社と連携して転売・偽造品対策を強化。無在庫販売は禁止 | 手元にある物だけを出品する |
| 自動購入ツール | 各社規約違反 | **使わない・作らない**（リポジトリ方針と同じ） |

## 3. 税務

| 項目 | 内容 |
|---|---|
| 所得区分 | 反復継続の営利目的なら**事業所得または雑所得**（趣味のコレクション売却とは扱いが違う） |
| 確定申告 | 副業：年間利益 **20万円超**で必要／専業：基礎控除48万円超で必要 |
| 経費になるもの | 仕入額、販売手数料、送料、梱包資材、交通費、通信費（按分）、PSA鑑定料、古物商許可の申請料 |
| 消費税 | 課税売上1,000万円以下は当面免税 |
| 記帳 | 仕入日・品名・仕入先・金額・売却日・売価・手数料を1行ずつ。**古物台帳の要件も兼ねる** |

シナリオBの年換算利益は約52万円なので、**確定申告は確実に必要**。W1で台帳を作る理由がこれ。

## 4. やらないこと（除外リスト）

| 除外項目 | 理由 |
|---|---|
| オリパ販売・開封代行 | 景品表示法・賭博性の論点、プラットフォーム規約リスク。事業ごと止まる |
| 転売目的での抽選応募 | 規約違反。アカウント停止で仕入れ経路そのものを失う |
| 自動購入・自動巡回ツール | 規約違反 |
| 転売目的の買い占め・行列の割り込み | ブランド毀損。自社サイト（www.social-quality.com）の信用に跳ね返る |
| 無在庫販売 | 規約違反かつ未着トラブルの温床 |
| 小売店に「定価の120%で買う」と持ちかけて余剰在庫を吸い上げる | 供給網への介入。ブランド毀損 |
| 二次流通業者を装って問屋の正規流通に入り込む | 取引先を欺く行為 |
| 行列バイトを動員した買い占め | 購入制限の潜脱 |
| 店舗従業員に圧力をかけて在庫を出させる | 強要・脅迫にあたりうる（論外） |
| 断られた相手の悪評を流して圧力をかける | 論外。関わった側が脅される側にもなる（`07` 参照） |

## 5. 事業リスク

| リスク | 具体 | 対策 |
|---|---|---|
| 相場下落 | 投機マネー流入の反動で急落しうる | 在庫は30日で回す。長期ホールドは余剰資金のみ |
| 仕入れ枠の消失 | 抽選・購入制限の強化 | 仕入れ経路を店頭・フリマ・買取店に分散 |
| 偽造品・再シュリンク品 | 精巧な偽造カードに加え、**レアを抜いて再シュリンクしたBOX**が流通。フリマ経由の仕入れが特に危険 | **BOXは正規ルート**（ポケモンセンター・家電量販店・信頼できるカードショップ）、シングルはフリマ・店舗と分ける。高額品は鑑定済みか店舗仕入れに限定 |
| 取引トラブル | 未着・すり替え申告 | 匿名配送＋追跡＋補償のあるメルカリ便を必須、梱包時の写真を残す |
| 資金拘束 | 売れ残りで翌月の仕入れが縮む | 消化率85%を月次でモニタ、下回ったら買取店で現金化 |
| 本業の機会損失 | 発売日・値下げ交渉が制作時間を侵食 | 週10時間を上限に設定する |
