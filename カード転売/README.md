# カード転売（トレカ物販）事業 — 案件候補と1ヶ月シミュレーション

> 作成：2026-08-24 ／ 対象期間：**2026-08-25 〜 2026-09-24**
> 目的：ポケモンカードを中心としたトレカ物販で、**1ヶ月で立てられる売上・かかる経費・かかる時間**を数値で確定させ、やる／やらないを判断できる状態にする。

## 結論（先に読む3行）

1. **1ヶ月で現実的に立つ売上は 9万〜65万円、営業利益は 1.1万〜11.2万円**（資金10万／30万／80万の3シナリオ）。粗利率は12〜17%に収束する。
2. **実効時給は 375〜1,124円**。営業システムの案件足切りライン **¥4,000/h**（`../営業システム/01-案件スコアリング基準.md`）を大きく下回るため、**Web制作の作業時間を削ってやる事業ではない**。
3. やるなら **①ポケカ30周年（9/16発売）のイベント集中 ②中位シングル（3,000円前後）の高回転 ③買取店を「即現金化の出口」に使う** の3点に絞る。抽選販売への転売目的の応募は各社規約違反なので使わない。
   - **出口を買取店に寄せると実効時給は2〜3倍**（利益76,000円／時給2,000円）。手数料0%・送料無料・50枚を1回で発送できるため（→ `06-買取店ルート実践ガイド.md`）。
4. **向き不向きがはっきり出る事業**。「他にやることの時給が1,000円未満／平日日中に動ける／余剰資金50万円以上／毎日数字をつけられる／カードショップに通える立地」の5条件のうち4つ以上が揃う人向け（→ `05-向いている人・向いていない人.md`）。当社は条件1が×なので、**自分で回すより設計と資金を出して人に回してもらう形**が合う。

## 何が儲けの源泉か（構造）

トレカ物販の利益は「安く売る技術」ではなく **仕入れ枠**で決まる。2026年8月時点の未開封BOX買取相場は、定価5,400〜6,000円の弾が **8,300〜25,067円**（シュリンク付き）で買い取られている。つまり **定価で買えさえすれば粗利は確定している**。ボトルネックは販売ではなく仕入れ側にある。

| 商品（2025-2026年弾） | 定価 | 買取（シュリンク付） | 倍率 |
|---|---:|---:|---:|
| ブラックボルトDX | 5,400 | 25,067 | 4.6倍 |
| ホワイトフレアDX | 5,400 | 21,333 | 3.9倍 |
| インフェルノX | 5,400 | 19,750 | 3.7倍 |
| ストームエメラルダ | 6,000 | 16,125 | 2.7倍 |
| MEGAドリームex | 5,500 | 13,075 | 2.4倍 |
| アビスアイ | 6,000 | 8,300 | 1.4倍 |

（出典：[トレカの地図・未開封BOX買取相場 2026年8月](https://torecamap.co.jp/column/pokeca-box-kaitori/)）

→ **定価仕入れができる枠 ＝ 売上の上限**。1人が正規ルートで確保できる枚数には限りがあるので、そこを補うのが「中古シングルの仕入れ→販売」になる。

## 本業（Web制作）との関係

| 指標 | Web制作（営業システム） | カード転売（本試算） |
|---|---:|---:|
| 実効時給 | ¥4,000 以上（足切り基準） | **¥375〜1,124** |
| 粗利率 | 50%以上が目標 | 12〜17% |
| 現金化 | 納品後、媒体経由（16.5%） | 売れた翌日〜数日（メルカリ10%） |
| スケール | テンプレ流用で工数逓減 | 仕入れ枠と作業時間に線形比例 |

**位置づけの推奨**：主力事業にはしない。**遊休資金の運用先**＋**イベント時（周年弾・新弾発売日）だけ集中して取りにいく単発案件**として扱う。日常運用に週10時間以上を割くと、Web制作の受注機会損失のほうが大きい。
