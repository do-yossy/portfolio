# 09 案内文（コピペ用）

実際に運用してもらう人へ渡すための説明文。**LINE・メールにそのまま貼れるよう、表組みを使わないプレーンテキストで書いてある**。数字の根拠は `02` `06` `08`、適性の根拠は `05`。

前提は「通常月は在宅専業、新弾・周年弾の発売月だけ店頭巡回をフル稼働」のハイブリッド運用（`08` の確定版）。

---

```
【ポケモンカードの転売運用について】

■ どういう仕事か
ポケモンカードを安く仕入れて、高く買い取ってくれる店やメルカリで売ります。
市場調査・相場チェック・仕入れ候補の洗い出しはAIが毎朝やるので、
やってもらうのは「買う・検品する・送る」の3つだけです。

■ 向いている人（5つのうち4つ以上あてはまる方）
1. 今の時給が1,000円未満、または時間に余裕がある
2. 平日の日中に動ける（新弾の発売日は平日の朝が勝負）
3. 生活費とは別に30万円ほどの余剰資金がある
4. 毎日コツコツ数字をつけられる（帳簿が命の商売です）
5. カードショップに通える場所に住んでいる（都市部・複数店が圏内）

■ 向いていない人
・本業の時給が高い人（その時間を本業に使ったほうが儲かります）
・まとまった集中時間しか取れない人（細切れ・即応の作業が多いです）
・含み損に耐えられない人（相場が下がったら損切りが必要です）
・確定申告や帳簿を避けたい人（年20万円超の利益で申告義務があります）
・カードが好きすぎる人（売るべき在庫を手元に残してしまいます）

■ お金の話（1ヶ月）
・通常月　　：売上 約41万円 → 利益 約7.6万円
・発売月　　：売上 約55万円 → 利益 約12.1万円
・年間　　　：利益 約100万円（税引後 約75万円）
※経費は販売手数料10%・送料・梱包材・交通費などで、上記の利益は経費を引いた後の金額です。

■ 時間の話（1ヶ月）
・通常月　　：約12.5時間（ほぼ在宅。買う・検品・まとめて発送するだけ）
・発売月　　：約49時間（店舗を回る日が週3回入ります）
・年間平均　：月18.6時間

■ 分担
【AIがやること】
・毎朝の相場チェック、値上がり／値下がりカードの抽出
・「どこで買って、どこに売ると、いくら儲かるか」のリスト作成
・その日いちばん高く買ってくれる店の特定、増額キャンペーンの確認
・帳簿づけ、月次の収支計算

【やってもらうこと】
・毎朝5分、リストを見て「買う／買わない」を決めてポチる
・届いたカードの検品・仕分け（月8時間くらい）
・月3〜4回、まとめて発送（月3時間くらい）
・新弾の発売日だけ店舗を回る（週3回まで）

■ 始めるのに必要なもの
・古物商許可：19,000円（＋書類の実費1,000円ほど）
　　中古カードを仕入れて売るには法律上必須です。申請から約40日かかります。
・仕入れ資金：30万円（多いほど利益も増えます。10万円だと月1万円程度です）
・備品：スリーブ、ローダー、梱包材で5,000円ほど
　→ 初期費用は合計25,000円ほど＋仕入れ資金

■ 正直に伝えておきたいこと
・相場は上下します。下がった月は利益が出ないこともあります。
・偽物や「レアだけ抜かれて再包装されたBOX」が出回っています。
　仕入れ先は選びます（このルールもこちらで用意します）。
・利益が年20万円を超えたら確定申告が必要です。帳簿はAIが作ります。
・無許可で中古を仕入れて売ると法律違反になります（3年以下の懲役または100万円以下の罰金）。
　なので古物商許可は必ず先に取ります。

■ 直近の予定
2026年9月16日にポケモンカード30周年の記念パックが発売されます。
1年で一番大きい機会なので、それまでに許可の申請と準備を進めたいです。
```

## 使い方メモ

- **相手が身内・知人**なら上記のまま送れる。
- **求人・募集として出す**なら「■ お金の話」を報酬条件（固定給か利益折半か）に書き換える。利益折半の場合、通常月7.6万円の折半で月3.8万円が相手の取り分になる。
- **短縮版が要る場合**は「どういう仕事か」「向いている人」「お金の話」「始めるのに必要なもの」の4ブロックだけ残す。
- 数字を更新したら `02` `08` と本ファイルの両方を直す（`../CLAUDE.md` の二重管理と同じ注意）。
