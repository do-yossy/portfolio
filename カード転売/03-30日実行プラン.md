# 03 30日実行プラン（2026-08-25 〜 2026-09-24）

シナリオB（仕入資金30万円・月55時間）を標準として、日付入りで動かす計画。資金10万ならBOX枠と件数を1/3に、80万なら2倍にして読む。

## 週次プラン

### W1｜8/25(月)〜8/31(日)　基盤づくり ＋ 仕入れ開始
| やること | 時間 | 目安コスト |
|---|---:|---:|
| 古物商許可の申請（警察署・生活安全課／許可まで約40日） | 3h | 19,000円 |
| 販売アカウント整備（メルカリ・ラクマ・magi。本人確認と売上金振込設定まで） | 1h | 0 |
| 仕入れ台帳の作成（日付・品名・仕入先・仕入額・売価・手数料・送料・損益） | 1h | 0 |
| サプライ購入（スリーブ、ローダー、ダンボール、宅急便コンパクト箱、緩衝材） | 1h | 5,000円 |
| 相場の定点観測リストを作る（買取表5店 × 販売相場） | 3h | 0 |
| 中位シングルの試験仕入れ 15枚 | 4h | 約30,000円 |
| 出品（撮影・説明文テンプレ作成込み） | 4h | 0 |

**W1のゴール**：出品15件、初売上、作業導線（撮影→出品→梱包→発送）が体に入っている状態。

### W2｜9/1(月)〜9/7(日)　回転を作る
- 中位シングル 追加20枚仕入れ（約40,000円）、高額シングル 3枚（約24,000円）
- 出品25件／発送15件／値下げ交渉対応
- **30周年商品の販売情報を毎日確認**（先着・再販・店頭入荷）
- 週末：売れ筋と死に筋を仕分け、死に筋は値下げか買取行き
- 時間：13h

### W3｜9/8(月)〜9/15(月)　30周年の準備週
- 販売店リストを確定（近隣の家電量販・カードショップ・書店・玩具店の入荷日と販売方法を電話確認）
- 発売日の巡回ルートと持ち出し現金を決める
- 通常仕入れは絞る（発売日に資金を残す）
- 既存在庫の消化に集中（9/15時点で在庫評価額を確認）
- 時間：12h

### W4｜9/16(水)〜9/24(木)　30周年 本番
| 日 | アクション |
|---|---|
| 9/16(水) | **30th CELEBRATION BOX（¥7,216）／FUTURISTIC BOX（¥27,500）発売**。開店前から巡回ルートを回り、正規購入枠で確保。夕方までに相場の立ち上がりを確認 |
| 9/16〜9/17 | 発売直後は相場が最も荒い。**半分を初動で売却、半分は7〜10日様子見**の二段構え |

| 9/22〜9/24 | 未消化在庫を買取店へ。月次締め（P/L・在庫棚卸し・実効時給の算出） |

- 時間：17h

## 日次ルーティン（平日30〜60分）
1. 朝：新規入荷・再販情報の確認（5分）
2. 昼：前日の売却分を発送、問い合わせ返信（20分）
3. 夜：相場チェック→値下げ判断→新規出品（20〜30分）

## 月末チェックリスト
- [ ] 売上・仕入・経費を台帳に記帳し、営業利益と**実効時給**を算出した
- [ ] 実効時給が¥1,000を下回った → 商材構成を見直す（低粗利のBOX中古仕入れをやめる 等）
- [ ] 30日以上動かない在庫を買取店に出した
- [ ] 年間利益が20万円を超える見込みか確認した（確定申告の要否）
- [ ] 来月の新弾スケジュールを確認し、資金を残した
