# マッチングアプリ運用ガイド（ターゲット適合判定・連絡先交換）

> 個人用の運用メモ。**相手の実名・顔写真・住所・勤務先・LINE ID はこのリポジトリに書かない。**
> 相手は「Aさん」などの仮名で扱う。

## 役割分担

| 担当 | やること |
|---|---|
| 本人 | 写真・プロフィールで一次選別する（マッチ前） |
| アドバイザー（Claude） | マッチ後の**文面・返信内容**から、本当にターゲットに合うかを判定し、連絡先交換の時期と文面を提案する |

写真の印象は一次選別までの材料。**会話に入ってからの判定は、文面だけを根拠にする。**

## ターゲット（本人が会いたい相手）

- 未来を一緒に考えられる人
- 夢がある人
- 趣味が多い人
- 関係：真剣な交際を前提に、自然に仲良くなりたい

## 1. 適合判定（会話から見る）

各項目を3段階で見る。**◎＝そう見える材料が複数、△＝どちらとも言えない、×＝そう見えない材料がある。**
「脈あり／脈なし」と断定しない。見えている材料だけを書く。

### A. ターゲットとの合致（相手の価値観）
| 項目 | ◎の例 | ×の例 |
|---|---|---|
| 未来・将来の話 | 先の計画、やりたいこと、大切にしたいことを自分から話す | 将来の話を避ける、話が出ても流す |
| 夢・やりたいこと | 具体的に語る（行きたい場所、挑戦していること） | 「特にない」が続き、広がらない |
| 趣味の幅 | 複数の趣味を、理由や思い出つきで話す | 趣味の話が1語で終わる |

### B. 会話の相性（相手のペース）
| 項目 | ◎ | × |
|---|---|---|
| 質問が返ってくる | 相手から質問や話題が出る | 質問が一度もない |
| 長さ・温度 | 同じくらいで続く | 短く、減っていく |
| 返信の間隔 | 1日以内で安定 | 間があき続ける |
| 外のやり取りへの姿勢 | 嫌がる様子がない | 避ける・流す |

### C. 注意サイン（見つけたら距離を置く）
- 投資・副業・セミナー・外部サイトやアプリへの誘導、送金・金銭の依頼
- 商品・サービスの紹介、紹介リンク
- 会う約束を、金銭がかかる場・個室・ホテルに寄せる
- 年齢の食い違い、18歳未満かもしれない兆候（**即・終了を推奨**）
- こちらの住所・勤務先・家族・お金を早い段階で聞く
- 不快・拒否を示したのに話題を続ける（こちらは二度と出さない）

### 判定の出し方
| 判定 | 条件 | 動き |
|---|---|---|
| 進める | Aが◎中心、Bが◎中心、Cなし | 連絡先交換を検討（下記） |
| 様子見 | Aが△、またはBに×が混ざる | 会話を続ける。誘わない |
| 引く | Bが×中心、またはCあり | 追わない。間をあける。Cは警告して距離を置く |

## 2. 連絡先交換（LINE）のタイミング

**日数は目安。「1週間以内」を目標にしない。相手のペースが優先。**

次の4つがそろったときだけ「LINEに移ってもよさそう」と判断する。
1. やり取りが、ある程度続いている
2. 相手から質問が返ってくる／相手から話題を出してくれる
3. 返信の長さや温度が、同じくらいで続いている
4. 相手が、アプリの外のやり取りを嫌がる様子がない

そろっていないときは「いまは誘わず、あと数往復あとに」。

### 誘う文のルール
- 理由を1つ添える（**本人の実際の理由。当てはまらなければ使わない**）
- 断りやすくする（「気が向いたら、でも大丈夫です」）
- 押さない。返事がなければ、そのままアプリで続ける
- 相手に、本名・電話番号・写真を求めない
- 電話・通話には誘わない

```
〇〇さんとのお話が楽しくて、もっと気軽にやり取りできたら嬉しいなと思いました😊 もしよければLINEでも話しませんか？アプリのままがよければ、それでも全然大丈夫です。
```

断られたとき：
```
全然大丈夫です😊 またアプリでお話しさせてください。
```

### 移る前の確認（本人のLINE）
表示名・アイコン・ID検索・電話番号での友だち追加の公開設定を確認する。

## 3. 返信内容の方針

- 相手の言葉を**具体的に**拾う（お店・作品・場所の名前など）
- 本人の**事実**を一言添える（盛らない）
- 理由や思い出を聞く質問を**1通につき1つ**まで
- 住所・勤務先・路線・駅名・お金の話は、聞かない・出さない
- 会う話が出たら：**昼間・人目のある場所・事前に友人へ日時と場所を共有**
- 電話を求められたら、事実だけ短く：「通話は控えているので、メッセージでお願いします」
- 返信が遅い・短い・減ってきたら、追わずに間をあける

## 4. やらないこと

- 嘘・経歴や趣味の盛り
- 駆け引き（わざと遅らせる、不安をあおる、罪悪感を使う）
- 勧誘（商品・サービス・セミナー・サロン・投資・副業・紹介リンク）、仕事や事業のための利用
- 相手の気持ちの断定（「脈あり」「脈なし」と言い切る）
- 相手の個人情報の貼り付け・保存
